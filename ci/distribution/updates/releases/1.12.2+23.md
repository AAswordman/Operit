# 1.12.2+23

本版整合联合测试确认的功能与稳定性修复。版本号为 79，沿用 Kong 包名和固定签名，提供完整 APK 及从 +22 升级的增量包。

## 手机自动化

- 改进节点识别、本机执行、滑动时序和手势反馈，恢复已有应用任务时保留原操作页面。
- 精简执行过程中的技术信息，显示扫描、规划、点击等自然阶段文案，保留触点、滑动轨迹和暂停、继续、停止操作。

## 扩展与资源管理

- 增加完整扩展详情、脚本分类、版本和来源信息，支持内置扩展检查更新。
- 改进已安装资源的重复导入保护、更新期间的使用协调，以及删除扩展后的页面返回。
- 主题资源支持图片和字体多选导入，补齐自定义主题字段的导入与导出。

## 图片与 GIF

- 修复图片输入能力与模型列表显示，精简相关模型配置。
- OpenAI 绘图增加 GPT Image 2.6 GIF 参数，包括输出格式、帧数、每帧时长和规划复杂度，并补充质量、背景设置。
- 本次正式发行同时发布当前源码对应的内置扩展资源。已有 OpenAI 绘图等内置扩展需要在扩展详情中检查更新并安装新版资源；只更新 APK 不会自动替换已安装脚本。

## 稳定性与工具

- 流式显示改用增量上下文解析、后台处理及保存点状态恢复，减少长消息、工具协议和回滚重建对主线程的压力。
- 世界书加强读取校验、原子替换和跨运行时串行处理，修复共享条目删除与初始化问题；存储管理保护插件数据目录。
- 修复终端光标位置应答、GREP 上下文行号、SSE 断连关闭、BLE 写入和模型服务缓存问题。
- 同步分段消息朗读、A2A 协议及 ToolPkg API 兼容性检查，完善 A2UI 动态表格与结构化事件上下文。

本版不包含尚未纳入的 1.13.0 更新日志草稿。应用与资源分别发布到既有发行仓库，资源校验并公开成功后才公开应用发行。
