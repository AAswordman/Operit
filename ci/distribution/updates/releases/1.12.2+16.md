# Operit Kong 1.12.2+16

## 包管理与市场

- 修复扩展删除后仍保留文件和列表条目的问题：按当前应用的真实安装来源删除，同 ID 多份文件一起处理，核实删除完成后才提示成功；失败时保留可读原因。
- 市场详情页和列表条目显示真实下载量、速度、耗时及预计剩余时间，覆盖脚本、ToolPkg、Skill 和 MCP。未知总量明确显示未知；临时附件按条目隔离，失败后清理。
- 恢复已有插件通过旧注册入口声明的 Compose DSL 配置，在插件详情中打开设置。

## 对话与提示

- 请求错误提示改为较短的基础停留时间，支持点击整张提示区域关闭；长正文仍可滚动，其他错误继续按队列展示。角色卡、群组和标签的操作结果统一使用应用提示。
- Waifu 首句生成时即可预览正文，并在同一气泡定稿；后续分句保留模拟打字，减少历史内容重复解析。
- 修复工具或思考 XML 中的未配对代码标记影响后续流式正文的过滤路径，避免这类正文一直等待整条回复结束才显示。
- 工作流失败报告展示节点名称、实际工具动作和具体原因，支持选择复制，旧运行记录继续读取。
- 优化工作区终端选项菜单的主题样式，保留环境配置与终端设置入口。

## 功能整理

- 按职责整理源码目录。删除已由插件替代的旧 AutoGLM、FFmpeg、Shell、SQL 原生页面及停用的动态虚拟形象模块；相关底层工具执行能力保留。
- Waifu、聊天图片头像、语音通话和普通悬浮窗继续保留。
