# Operit Kong 1.12.2+9

本次更新集中整理主题与显示设置，完善模型配置、工作流报告、图片预览及对话管理，并减少插件运行时的大结果复制和旧回调积累。

## 功能与体验

- 主题设置整合为基础、聊天、输入、界面与布局五个页签，支持区域玻璃效果、统一草稿、预览和保存；全局聊天布局可以在布局页签中直接调节。
- 显示与行为设置整理为三个页签，集中管理 26 项设置，并修正进入页面时的短暂位移。
- 对话多选增加移动操作，可以移入根目录或指定文件夹，保留消息、角色绑定、归档、锁定与排序等现有信息。
- 模型分组切换保留当前选择和组内编辑记忆；密钥主体与箭头分别进入单密钥编辑和密钥池管理，减少切换时编辑对象错位。
- 工作流新增节点执行报告，展示状态、时间、结果摘要及本地化错误提示；历史时间稳定保存，定时入口按进程内队列串行执行。
- 已发送图片按组叠放显示，支持打开预览、左右翻页、缩放与双击，并及时反映原图过期状态。

## 优化与修复

- 插件结构化工具结果直接生成 JSON 树，通过固定 QuickJS 函数传参，减少大正文反复编码、解析及拼接脚本产生的临时分配。
- Compose DSL 按已提交的界面版本回收旧动作回调；工作流日志、总结进度和通用资源读取减少不必要的完整内容复制。
- 回复在请求重试后重新收到正文时恢复接收状态，避免继续停留在重试标签。
- 更新器根据实际安装 APK 的哈希选择可连接到目标版本的最短完整补丁链，逐步校验基础包、补丁和输出。
- 移除应用自带的表情图片、默认分组自动导入和“恢复默认”入口。创建分组、删除分组和图片导入继续保留；新表情库从空状态开始，已有私有表情和分组继续保留并可管理。

## 安装与发行资源

沿用 `com.ai.assistance.operit.kong` 包名与固定签名，内部版本号升至 `65`。本次以 `v1.12.2+8` 为增量基线，发行附件包含完整 `app-kong.apk`、`+8 → +9` 增量 ZIP、配套补丁 JSON 和 `distribution-release.json`。原签名正式包可以覆盖更新；按现有渠道规则，应用内发现 `+n` 补丁版需要开启 Beta 计划。

语音模型、网页应用导出模板与终端离线资源继续使用已发布的[固定离线资源 v1](https://github.com/3316891527/Operit/releases/tag/resources-v1)，资源目录、字节数和 SHA-256 保持一致。
