# 1.12.2+22

本次更新整合联合测试分支中的主题增强与稳定性修复。沿用 Kong 包名和固定签名，内部版本号递增为 78，可覆盖安装。

## 自定义主题

- 新增全局及区域文字描边，用户与 AI 消息可以分别设置；描边数值框显示小数，提供细线预设。
- 输入区与顶栏 12 个动作按钮支持独立外观、前后景图层、交互状态及明暗模式，修复麦克风等图标被背景尺寸撑大的问题。
- 修正主题属性入口、消息文字色与描边控制，补齐主题工作室多语言；移除描边宽度下方的重复说明。

## 聊天、总结与工具

- 修复发送触发上下文总结时的主线程阻塞；总结返回空内容时重新生成一次，阻止无效摘要入库。
- 同步流式重试修订和 Waifu 撤回处理，修复含 NUL 字符的消息读取及文档块编辑器的高度约束。
- 工具权限说明跟随应用语言，权限列表实时反映扩展的安装和启用状态。
- HTTP 服务改由终端管理，支持浏览器自动登录；改进 MCP stdio 的工作目录、启动失败诊断和浏览器点击、导航结果校验。
- Code Runner 隔离脚本目录和环境，明确超时、退出码与输入结束处理，限制准备和清理步骤的等待时间。

## 配套资源
