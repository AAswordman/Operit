## 🌟 Sobre este fork

Esta es una versión modificada de [Operit AI](https://github.com/AAswordman/Operit) con **soporte completo en español** para la comunidad hispanohablante.

### ✅ Cambios principales
- **100% de la interfaz traducida al español** (7,147 strings)
- **STT (voz a texto) con soporte español** en los 4 proveedores
- **Detección automática de idioma** — la app detecta tu idioma automáticamente
- **SpeechService** usa la locale del usuario en vez de `zh-CN` por defecto
- **HTML Export** usa la locale del sistema para el atributo `lang=`

## 🚀 Características principales

### 🖥️ Entorno Ubuntu 24
Sistema Ubuntu 24 completo integrado, con soporte para vim, MCP, Python y más. Ejecuta comandos Linux complejos y tareas de automatización directamente desde tu teléfono.

### 🧠 Sistema de Memoria Inteligente
El AI clasifica y gestiona memorias automáticamente, con búsqueda en historial, importación/exportación y resúmenes automáticos.

### 🗣️ Interacción por Voz
Conversación natural continua, con soporte TTS local/nube + STT local, voces personalizadas, activación por voz y lectura automática.

### 🤖 Modelos Locales
Soporte para MNN / llama.cpp (GGUF), ejecutando AI completamente offline para proteger tu privacidad.

### 🎭 Personalización de Personajes
Personaliza la personalidad y estilo del AI, con soporte para tarjetas de personaje (Tavern/JSON), backup y compartir por código QR.

### 🔌 Herramientas
40+ herramientas integradas + mercado MCP/Skill + paquetes de herramientas y flujos de trabajo, incluyendo agente de clics automáticos, búsqueda de imágenes, tareas programadas y más.

## 📥 Instalación

### Desde APK
1. Descarga el APK desde [Releases](https://github.com/juanismael85/Operit/releases)
2. Instala en tu dispositivo Android 8.0+
3. Abre la app y selecciona español como idioma

### Compilar desde código fuente
```bash
git clone https://github.com/juanismael85/Operit.git
cd Operit
git checkout feat/spanish-support
# Abrir en Android Studio y compilar
```
