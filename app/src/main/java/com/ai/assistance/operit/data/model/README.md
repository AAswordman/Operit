# 持久化与稳定传输模型

本目录保存 Room、ObjectBox 实体，聊天持久化与查询直接使用的数据结构，以及必须保持类身份的现有传输类型。新增独立业务模型放入所属领域，避免重新集中到本目录。

## 保留范围

- 数据库实体、关系、字段使用的 Embedding 和角色工具白名单配置
- 聊天消息、历史、片段、显示模式和数据库查询投影
- 角色与角色组聊天统计投影
- Parcelable 主题色板与字体传输结构
- 已分发脚本 Java 桥接使用的 FunctionType 与 InputProcessingState

模型服务配置、工具协议、工作流、主题协议、记忆搜索与导出等归属和完整映射见仓库内 `docs/TODO/chore/model-domain-layout/`。数据库版本、实体 UID、保存格式与已有脚本接口的兼容要求继续适用。
