# 7. 验证

按仓库约定，编译、构建和测试类检查只在用户明确要求时执行。本次实现没有运行 Gradle 编译、前端 `typecheck` 和前端生产构建。

## 已完成

用本机已安装的无头浏览器，以 390 × 844 的手机视口走完整本报告，逐页模拟按住、拖动、点按、刮开、涂抹、拨动和撕开，截图检查：

- 浅色与深色主题下的全部 19 页
- `fixture=empty`：个人篇只有相识、空白页和海报，海报换成项目篇数字
- `fixture=guest`：没有缘分页，页码连续
- `fixture=error`：过渡页显示错误原因和重试按钮，错误写入控制台
- 海报保存流程：截图前隐藏按钮，结果提示回到页面
- 入口徽章的三帧手绘版本在浅色和深色背景上的效果
