## 真机验收与复验清单

维护者于 2026-11-05 验收通过。下面是当时列出的检查项，「上线开关」一节是验收之后新增的改动，还没有在真机上检查。

数据：

- 在有长期使用记录的设备上，对比报告与 Token 统计页在同一日期范围内的 token、调用次数和模型排行
- 抽查对话数、消息数、活跃天数等数字，与直接查询数据库的结果比对
- 在 1 月初打开报告，确认窗口是完整的上一年
- 登录 GitHub 的账号能查到第几颗星和插件市场作品；未发布过作品的账号显示还没有作品

性能：

- 在消息量大的数据库上测量采集耗时，作为是否给 `messages` 新增时间索引的依据
- 在低端机上测翻页与动画帧率，重点关注日历涂色、线条抖动和纸屑

隐私与离线：

- 飞行模式下完整走一遍报告，只有插件市场卡片显示联网失败
- 抓取 WebView 请求，确认只出现 `appassets.androidplatform.net`

兼容：

- 横竖屏切换、系统字体放大、深浅色切换时报告不重建
- 侧边栏收起后徽章停止动画

上线开关：

- 系统时间早于 2027-01-03 00:00 UTC 时，侧边栏头部没有徽章，版面和没有年度报告时一致
- 把系统时间调到该时刻之后，再次打开侧边栏，徽章出现，点击进入报告
