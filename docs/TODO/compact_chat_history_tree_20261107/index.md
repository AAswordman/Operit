# 收紧对话历史侧栏布局

[返回总计划](../README.md)

## 问题与范围

维护者真机反馈：嵌套对话树的面板偏宽，文件夹卡片、顶部控件和空隙显得过大。

调整 Android 对话侧栏的宽度、文字、图标、间距和缩进；把每个文件夹重复显示的长按提示集中显示一次。保留系统字体缩放、现有拖动区域、完整列表视口及目录操作逻辑。

## 实施

1. 面板宽度由容器的 86%、上限 340dp 改为 80%、上限 304dp。
2. 减小标题、筛选按钮、新建按钮和行内图标，收紧顶部与列表留白。
3. 文件夹与聊天行采用 44dp 最小高度和 13sp 标题，层级缩进由 8dp 改为 6dp。
4. 长按管理提示移至列表上方，仅在需要时显示一次，完成首次长按后继续按原偏好隐藏。

## 验证

已核对 Git 差异、调用点及拖动视口/缩进一致性。对应本地集成源 `70b6ee2ea` 的 Android Release 构建成功，Gradle 用时 14m 12s；APK 下载大小与哈希一致，V2/V3 签名复验通过，并确认紧凑布局代码已入包。

已完成上述布局调整。文件夹和聊天行均为最小 44dp，加上下外间距后为 48dp；控件使用最小高度，文字仍按系统字体比例缩放。32dp 拖动手柄及列表 fillMaxSize 保留，搜索、折叠、移动和数据库实现无改动。
