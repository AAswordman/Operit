# 单独发送的语音条与音频理解

在 Android 主聊天页单独发送语音：空文字、无附件和引用且没有处理中请求时显示麦克风；录音面板显示真实音量波形和计时，连续三秒无人声结束，最长六十秒。录完先试听确认，发送后由聊天请求选择音频处理方式。

当前实际绑定的对话模型开启直接音频处理时先使用原录音；否则或首段内容前直接音频请求失败时使用已配置的音频理解功能模型；该功能不可用、失败、超时或返回空内容时再使用现有 STT。音频理解与 STT 结果回写同一条语音消息，原录音继续保留。旧版转写语音保持可读。

气泡使用紧凑播放器；命令框模式中的语音卡片右对齐。第一版、视觉调整与音频路由的实现分别记录，运行验证结果以完整验收表为准。
