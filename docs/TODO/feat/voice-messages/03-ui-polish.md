# 录音面板与语音气泡收紧

本文记录外观调整。后续确认页改为直接试听、移除发送前转写步骤，Cursor 语音卡片增加右对齐，见 [音频路由](04-audio-routing.md)。


用户确认上一版语音条基本可用，反馈录音面板观感偏默认控件、语音气泡过宽、实时波形过细。提供的截图可见三秒语音消息和模型回复；未核对安装包提交、具体 STT 配置和完整设备验收结果。本轮调整视觉布局及波形显示，新界面效果仍待设备验收。

## 录音面板

`VoiceMessageSheetContent.kt` 独立负责面板内容。顶部使用麦克风标识、主副标题和圆形关闭按钮，录音区域集中展示状态灯、计时和波形，减少零散控件与留白。颜色来自当前主题，明暗模式沿用主题颜色。

录音状态灯持续轻微呼吸，明确表示正在采集；它不代表音量。真实音量波形单独由 `VoiceWaveform.kt` 绘制，录音时使用 32 根较粗的圆头柱、非线性幅度显示和 90 ms 过渡，较轻的人声也有可见起伏，零音量保持静音基线。历史语音显示 16 根柱以适应短条宽度，底层保存的波形仍为原格式。

确认页区分试听和识别文字，重录、转写重试和发送按当前状态显示，准备及转写期间主按钮显示忙碌状态。权限、三秒静音、六十秒上限、STT 请求和发送文件交接沿用当前会话实现。

## 聊天语音条

`VoiceMessagePlayer.kt` 移除根布局的 fillMaxWidth，收起时的正文宽度按时长限制在 168～228 dp，并服从宿主气泡的最大宽度。默认一行显示播放按钮、波形、简短时长和“文字”入口，去掉独占一行的大文字按钮。

点“文字”后正文按 280 dp 的期望宽度显示转写，实际宽度仍受宿主限制；收起后恢复短条，尺寸变化使用内容尺寸动画。文字入口保留完整的无障碍操作描述。

Bubble 的普通、图片、宽布局及非宽布局四条渲染路径使用嵌入模式，播放器内部背景透明，沿用原气泡颜色、图片背景和文字色，语音上下内边距收为 6 dp。关闭宽气泡布局时，语音不能通过内层播放器撑满可用行宽。

Cursor 的语音卡片同样取消强制整行宽度，保留自身标题风格；普通文本卡片维持原有布局。XML 插件同步采用紧凑播放器，并传入宿主文字颜色。
