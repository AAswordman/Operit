# 语音条验证与完整设备验收

当前共 41 个语音 JVM 用例，其中本轮新增 26 个；测试代码交由仓库 Android Tests 执行，本地未运行 Android 编译、构建或测试。设备验收共 78 项，保留原有 57 项并按当前发送流程修订，新增 21 项音频路由检查。结果未填写即未验收。

静态检查：16 个 Kotlin 文件通过；另两份大型既有文件存在基线解析器限制，类型正确性由云端 Kotlin 编译确认。29 个中英文语音资源键的 XML、键集合、占位符和源码引用检查通过，Git 差异检查通过。资源键相对上一轮新增三个、删除两项已移除的发送前转写文案。

云端在本工作分支派发 `assembleDebug` 与 `:app:testDebugUnitTest`。派发受理与最终通过分别记录，新结果待确认。
