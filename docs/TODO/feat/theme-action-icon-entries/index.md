# 动作按钮图标独立编辑

自定义主题的图标按钮新增 11 行独立动作素材入口，按全局配色的明暗两列组织；每个按钮分别进入自己的素材与属性编辑器，便于逐项自定义。

## 实现范围

- ThemeStudioButtonIcons 在自定义主题的图标按钮外观页中，将输入区 8 个动作和顶栏 3 个动作逐行列出，每行分别显示浅色与深色素材，避免只能从共用容器入口寻找单个按钮。
- 每个按钮行按独立图标标识进入已有编辑器，支持分别修改素材、尺寸、透明度、固定着色和跟随内容着色；还原内置图标只影响当前按钮与当前明暗模式。
- 独立图标编辑器提供返回按钮图标列表的入口，支持连续编辑多个动作；行内展示已绑定素材，未绑定时展示对应内置图标，并保留明暗模式的无障碍名称。
- 新增列表标题和操作说明同步中文、英文、西班牙语、印尼语、日语、韩语、马来语、巴西葡萄牙语和罗马尼亚语；原有主题图标标识及分享格式保持兼容。
