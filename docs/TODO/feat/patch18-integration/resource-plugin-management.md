# 插件删除提示与旧版本清理

本轮修正离线资源详情中的内置插件、沙盒包删除入口，并清理插件更新后遗留的旧版本安装目录。改动沿用现有离线资源和安装记录模块，随 PR #87 进入统一验证。

使用中的资源删除入口显示灰色，点击只发出 OKToast.warning 提醒，保持详情页且不进入删除确认。插件提示先到包管理关闭启用开关；其他运行资源沿用其释放或重启提示。忙碌时仍禁用按钮，未占用时恢复正常删除确认。

插件新版本须完整校验并完成安装，才能清理同资源 ID 的已知旧版本目录、对应安装记录和校验缓存。替换时按资源组持有独占租约，防止仍启用的旧插件被新目录绕过使用检查。旧版本仍有运行引用时保留，关闭后进入或刷新离线资源页再清理；已存在的历史残留也由该入口处理。清理不扫描删除未知目录，不影响其他资源、备份及唯一可用的历史安装。

验证保持源码与资源静态核对；有针对性的存储回归源码交给仓库 JVM 工作流，设备操作保留此前 120 项并追加本轮案例，结果单独填写。

新增 8 项 JVM 回归源码，覆盖成功升级回收、内容损坏时保全旧版、占用释放后清理、仅元数据升级、未知及其他目录保留、残留记录删除、插件元数据变化和资源组独占安装。源码未在本地执行，交给仓库 Android Tests 工作流验证。

本轮设备操作为 RP-01 至 RP-12，已追加到[完整回归](regression.md)及[结果表](results.md)，此前 120 项保持，合计 132 项。

本轮 7 个 Kotlin 文件语法解析、2 个 XML、字符串引用、文档链接和 git diff --check 静态核对通过。没有在本地运行编译、构建或测试，新增 JVM 用例与设备表现均等待实际验证。

## 删除入口复测修正

删除按钮在使用中真正禁用，外层无涟漪点击只显示 OKToast.warning(...).show()；忙碌时外层也禁用。资源详情按生命周期注册当前面板窗口，兼顾手机底部面板与宽屏对话框。旧版本清理范围不变。见 [反馈修正](feedback-fixes.md)。

第二轮将说明点击改为禁用按钮上方的独立覆盖层，并绑定面板根窗口，避免禁用按钮消费父级点击。原按钮仍不可执行删除，忙碌时说明入口也不可操作。见 [第二轮反馈](detail-feedback.md)。
