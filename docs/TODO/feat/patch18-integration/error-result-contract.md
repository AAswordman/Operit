# 编译导入与失败结果归并

StandardFileSystemTools 增加应用 R 导入，解决图片读取失败分支新增资源引用未解析的问题。对本轮及上一轮修改涉及的 Kotlin 文件同时核对未限定 R 引用与应用 R 导入。

## 公共生成入口

工具失败返回结构化结果时，统一聚合器在将结果转为文字前提取错误说明和独立输出。FileOperationData 的 env 与 details 是该操作失败的说明来源；FileApplyResultData 使用其 operation，并分别保留独立差异和有效上下文；PackageActivationErrorData 使用自己的 message。

聚合生成的最终 ToolResult 中，带来源的错误只进入 error，result 只保留独立输出。末尾错误不会再次放入正文；前序失败保留各自来源及实际输出。最终 XML、消息保存和下一轮模型历史仍复用同一份结果。

这条路径不需要每个工具重复实现，不按工具名判断，不解析、剥离来源标签，也不在显示后删除某一行。来源不局限于固定的 android、linux、repo 白名单。原有纯文本字段全文相同不重复拼接的行为保留，不删除不同内容或重复的真实命令输出。
