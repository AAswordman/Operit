# Theme Target Menu Avatars

## Current State

The theme target selector shows the saved AI avatar for its current target. Its expanded role-card and group entries only show generic person or group icons, so users cannot identify targets visually from their configured images.

## Intent

Render every menu target with the same target-scoped AI avatar source used elsewhere in the application.

## Expected Result

- Default and ordinary role cards show their own theme avatar in the target menu
- Character groups show their own group theme avatar in the target menu
