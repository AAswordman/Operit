# 主题布局页签与对话批量移动

将已认可的布局设计稿接入主题，删除单独的内容布局入口及 screen；给对话多选操作增加第五个「移动」按钮和目标文件夹选择窗口。

## 范围与兼容

- 布局页保留「聊天间距」「AI 回复排版」两组卡片，删除装饰性眉题、标题和说明，不影响原主题四个页签。

- 实时预览使用草稿中的数值和正式 Markdown 渲染器，不提前修改全局偏好。
- 批量移动可选择根目录、已有文件夹及嵌套文件夹；按文件夹 ID 分配，不修改角色绑定、归档、锁定或消息内容。
- 多选、移动中禁用、取消、错误保留选择和操作完成反馈一并接入。
- 重试状态仅调查原因，本轮先完成明确要求的两项功能。
