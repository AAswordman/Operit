# 数据与备份

把设置中的数据备份与恢复、聊天记录管理、Token 统计入口和日志查看器收进同一个「数据与备份」入口。主页面采用数据概览与三个页签，详情操作使用底部抽屉。

## 范围

- 备份恢复：文件快照、数据库备份、单项导入导出、备份统计与说明
- 聊天管理：折叠的角色卡与群聊统计、搜索选择、批量关联、构建记忆、删除与无绑定工作区
- 诊断日志：日志写入、导出、五项过滤和清空确认
- Token 统计：只接现有页面路由，保留其界面、统计逻辑和定价设置

已发布的旧备份、聊天管理和日志路由标识继续可用，并打开合并页面的对应页签。备份格式、数据存储、导入策略和锁定聊天保护沿用原实现。

## 实施步骤

1. 建立统一页面、概览、页签与底部抽屉组件
2. 重组备份和聊天管理，接入日志页签及设置入口
3. 核对资源和最终差异，在工作分支派发仓库工作流
