# 禁止覆盖、只读预览与静默输出

## 意图与范围

为现有独立终端命令增加 `--no-overwrite`、`--diff/-D` 与 `--quiet/-q`。前者避免新增和移动目标覆盖同名路径；预览让使用者在写入前查看代码变化；静默选项减少脚本里的成功摘要。参数说明、组合规则与示例直接包含在 `--help` 中，命名使用 `--no-overwrite`。

默认调用、Codex 补丁语法、上下文匹配、换行处理、退出码与既有覆盖行为保留。没有增加配置文件、自动备份或跳过上下文强改选项。

## 禁止覆盖

- `Add File` 和 `Move to` 的目标只允许不存在的路径；已有普通文件、目录、符号链接和断开的符号链接都拒绝
- 普通 `Update File` 仍可按上下文修改已有文件；明确 `Delete File` 后再 `Add File` 可以创建新文件
- 同一补丁按操作顺序判断：先新增的路径会阻止后续同名新增，先删除的名称则允许重建
- 默认仍可跟随父目录链接；实际写入使用独占创建，叶子名称被其他进程抢先创建时立即拒绝，避免检查与写入之间的覆盖竞态
- 检查和预览使用相同规则。实际应用仍是逐项执行，后项失败不撤销前项写入

引擎的可选 `no_overwrite` 标志只控制新增/移动目标的写入方式，默认关闭。本地文件系统通过 `create_new` 独占创建；禁止跟随链接的内部写入路径增加 `O_EXCL`，保留既有目录文件描述符遍历和链接限制。

## 只读预览

`--diff/-D` 隐含检查，可与 `--check` 和 `--no-overwrite` 组合。预览在内存覆盖层执行同一引擎，记录每次成功模拟写入和删除之前、之后的内容，按实际操作顺序展示 unified diff。移动显示目标写入和源路径删除，同一路径多次修改分别显示各步变化。

预览不写入目标、目录、临时补丁副本或 Git 索引，不调用 `git diff`。补丁失败时只报告错误，不把前缀预览当成成功结果。成功退出码为 `0`，即使存在差异也不改成 `1`。

二进制内容只显示差异标记；空文件新增或删除保留路径头；删除符号链接显示链接本身及其目标，写入链接指向的文件则展示实际目标内容的变化。文件名含空格、控制字符或非 UTF-8 字节时使用引号/转义，避免破坏头部。本地原生路径拼接会先按字节编码制表符、换行和回车，保留文件名原字节，避免 URL 解析将它们忽略后指向另一份文件。无法读取原始快照等 I/O 错误会使预览失败，不生成猜测的差异。

交互终端自动显示颜色；重定向、`NO_COLOR` 或 `TERM=dumb` 关闭颜色。`--diff --json` 仍只输出一个 JSON 对象，`mode` 为 `diff`，`diff` 字段为无颜色的预览字符串，失败时为 `null`。`message` 保留只读预览摘要，不重复放入整段差异。原有 JSON 模式不增加该字段。

## 静默组合

`--quiet/-q` 只隐藏普通应用和检查的成功摘要。错误仍通过原有错误通道报告，明确请求的差异、JSON、帮助与版本信息继续输出。

```bash
apply_patch --no-overwrite --file change.patch
apply_patch --diff --no-overwrite --file change.patch
apply_patch --diff --file change.patch --json
apply_patch --check --no-overwrite --quiet < change.patch
apply_patch --quiet --file change.patch
```
