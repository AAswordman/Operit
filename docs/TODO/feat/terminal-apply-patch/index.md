# 终端内置 apply_patch 命令

维护者希望终端能够直接执行 Codex 格式的 `apply_patch`，普通会话和工具命令使用同一入口。升级只增加命令组件，不替换 Ubuntu 安装归档，不要求删除已有环境。

## 实现范围

- 在 `tools/native_apply_patch/` 中派生独立 Rust CLI，保留上游补丁解析、文本匹配、换行、输出及退出码语义，提供本地文件系统适配
- 将 ARM64 Linux 命令及校验信息打入应用资源，在现有终端登录流程安装到应用管理的命令目录；安装使用锁、校验与原子替换，覆盖已有环境升级和新环境
- 接入普通及隐藏终端会话，命令安装成功后再执行会话任务；命令沿用既有终端权限流程
- 增加原版场景、CLI 和安装升级回归，接入仓库工作流，记录实际执行结果

## 交付边界

本功能只提供终端命令。应用内已有 `apply_file` 等文件工具继续使用原有接口。Codex 的模型、账号、执行服务和网络组件不加入应用。

## 实现与检查

实现已接入 APK 资源、Android 缓存、Ubuntu 安装、普通/隐藏会话及真实 chroot 登录。Rust 补丁核心与路径工具保留来源代码，独立文件系统适配移除执行服务依赖；初次移植的 26 个 Rust 来源文件已完成静态代码/字面量对照，83 个 fixture 文件已核对字节一致。

终端核心改动单独保存在维护者的 `OperitTerminalCore` 仓库工作分支，主仓库固定引用对应提交。初始化钩子在登录就绪标记之前运行，安装失败时不执行后续会话任务。`apply_patch` 位于 `/usr/local/bin`，无需重打 Ubuntu 归档。

交叉构建显式安装 `gcc-aarch64-linux-gnu` 与 `libc6-dev-arm64-cross`，完整提供 ARM64 glibc 启动对象和开发文件，不依赖推荐包的隐式安装。此依赖声明由所有构建/测试入口共用。

## 命令行扩展

维护者已在 Android 实机确认基础 `Add File` 可用；本轮为现有命令增加 `--version/-v`、`--help/-h`、`--check/-c`、`--file/-f` 和 `--json`，并提供 `--dry-run`、`-f -` 与 `--` 常见写法。版本使用移植包已有的 `0.1.0`，来源独立命令没有版本参数。

扩展代码放在 `src/cli/`，默认补丁语义保留；可选禁止覆盖规则接入新增/移动目标的写入。检查模式使用内存文件系统覆盖层按同一补丁引擎顺序模拟，所有变更只保存在内存，包含新增后更新、移动、删除、符号链接和多操作依赖。JSON 成功与失败均只输出一个完整对象，并明确区分实际应用与检查计划。

[命令行契约与示例](03-cli-options.md) 记录参数组合及 JSON 协议。库选项、独立入口、Unix 独占创建及两处原生路径拼接共五个来源文件记录适配，其余 21 个来源文件保持原哈希。新选项已接入 Rust 工作区和 ARM64 QEMU 回归，本地不构建或运行测试，实际结果待仓库工作流。

## 禁止覆盖与预览

新增 `--no-overwrite`、`--diff/-D` 与 `--quiet/-q`，帮助中直接列出规则和组合示例。覆盖保护仅作用于新增/移动目标，使用独占创建；预览复用内存检查，成功与失败均不写盘；静默只隐藏普通成功摘要。默认调用行为保留。详见[自定义规则与验证](04-safe-preview.md)。
