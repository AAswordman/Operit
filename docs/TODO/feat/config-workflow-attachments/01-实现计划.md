# 实现计划

## 模型配置

排查初始选择和列表恢复的时序，按实际使用配置和每组编辑记忆恢复。持久化折叠状态。卡片主体编辑单密钥，最右侧按钮进入密钥池，移除管理按钮。

## 更新

检查已安装 APK 的哈希与补丁元数据、跨版本补丁图、资产定位和安装行为，保留现有完整包更新入口。

## 工作流

拆分标题与操作区避免挤压。保存新增执行的节点状态及可本地化错误信息，成功或失败状态均可打开详情，旧记录不伪造数据。同一时间触发的任务串行调度而非抢占并标记失败。

## 图片附件

区分图片的可用状态与过期标签，将已发送多图改为叠放缩略图组和数量角标。复用发送前图片预览器的缩放、翻页能力。

## 验证

补充数据与调度关键路径的单元用例及完整人工清单。仅进行差异、调用与资源静态核对，真实执行结果待后续授权的仓库工作流。
