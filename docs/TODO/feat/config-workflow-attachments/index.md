# 配置、工作流和附件体验

基于已发布 1.12.2+8 进行兼容改进，所有变更集中在同一分支。

- 配置页定位使用中的配置并记住折叠状态；单密钥编辑与密钥池分开入口。
- 核对跨版本增量路径和 Base SHA-256 校验并修复实际问题。
- 工作流标题自适应，新增本地化执行详情及持久化记录，定时任务冲突排队执行。
- 已发送图片隐藏未过期标签，按图片组显示数量并复用手势翻页预览。

原工作区四份对话滑动多选草稿不纳入改动。本轮不派发工作流，不运行本地构建、测试。可选的定时冲突预估提示暂不纳入。

实施状态与验证边界见 [实现说明](03-实现说明.md)，完整 490 项场景见 [完整验收清单](02-完整验收清单.md)。
