## 更新问题证据

`v1.12.2+6` 的客户端在 `PatchUpdateInstaller.resolvePatchChain` 中只从 Release 正文解析中间补丁；当前 `+7`、`+8` 正文是可读 Markdown，完整补丁元数据保留在 `patch_*.json` 附件。

发布资产名称中的哈希前缀分别为 `+6→+7: e701acaa75ec→5d25993d096c`、`+7→+8: 5d25993d096c→55e8442ab0b8`，能够连通。旧客户端漏读中间索引后选择唯一目标补丁，导致基础包 SHA-256 校验失败。本分支修正附件寻址与哈希路径搜索；已安装旧更新器的用户应先通过正式完整 APK 覆盖更新。

以上证据为源码及已发布资产核对，不代表已执行本地 APK 增量还原。
