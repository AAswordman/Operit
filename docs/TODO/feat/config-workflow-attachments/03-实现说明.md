# 实现说明

## 模型配置

配置页从同一份 `ModelConfigSelection` 快照读取分组、候选和组内编辑记忆，避免空列表过渡重置选择。进入分组优先定位当前聊天有效绑定，包括角色卡固定配置；当前分组没有该绑定时恢复该组上次查看配置。用户显式切换编辑项后，普通配置刷新不覆盖当前选择。分组确定按钮不再强制选择首项。配置组折叠状态按稳定 ID 存入现有 DataStore，包括未分组节点。

密钥卡片移除管理文字按钮。主体仅打开单密钥输入，最右侧箭头打开密钥池二级窗口。两种窗口都沿用原保存协调；密钥池及单密钥内容独立持久化，不改变认证协议。

## 跨版本增量

核对 `v1.12.2+6` 客户端源码发现，它从 Release 正文读取中间补丁，无法读取后来采用可读正文的发行记录；缺少匹配起点时又误选唯一目标补丁，最终报 Base sha256 mismatch。现有正式资源的 +6→+7 与 +7→+8 哈希首尾能够连接，不能据此认为版本号本身不支持跨补丁升级。

本分支改为读取 patch JSON 附件，并按已安装 APK 的真实 SHA-256 搜索可到达目标的最短补丁链。删除不匹配时仍套用目标补丁的逻辑，保留每一步基础包、补丁和还原结果校验。无完整路径时使用本地化错误；更新窗口和失败窗口都提供用户主动选择的完整 APK 更新入口。

已经安装 +6 的客户端不能获得尚未安装的新更新器代码，需要先通过正式 Release 的完整 APK 覆盖更新一次。跨基础版本仍使用完整 APK，不改变既有安装包签名或版本号。

## 工作流

列表标题和说明独立占一行，操作区使用 FlowRow 自适应换行，避免按钮挤压标题为逐字换行。

新增执行报告记录节点名称、结果状态、开始结束时间、错误语义类别和成功结果摘要。成功、失败状态条均可点击，节点菜单共用同一详情面板。用户看到失败节点及本地化原因和处理提示，界面不输出原始异常堆栈。历史沿用每个工作流最近 30 条原子保存记录，新增字段均有默认值；旧记录不推测或补造节点结果。

运行标识、执行开始与结束时间、日志时间戳始终写入 JSON，即使编码器省略默认值，也保留记录创建时的值，保证重新读取后的历史时间稳定。字段名称及旧记录读取规则兼容原格式；回归用例同时检查关键字段存在和完整记录往返一致性。

定时 Worker 共用进程内串行队列，等前一次任务完成后再开始下一次，排队不创建失败记录或增加失败计数。等待中的取消会移除排队标记。运行中防重改为原子登记，手动执行占用同一工作流时定时 Worker 可重试，不记作一次执行失败。已执行中的主动取消保留已有节点信息。

跨工作流运行时长预测与节点编辑中的撞时提醒是可选项，本轮未实现。队列不替代 Android WorkManager 的系统调度约束。

## 已发送图片

两种消息样式共用 `attachments/images` 中的图片组组件。关联图片池链接后紧邻的附件描述，将同一次上传合为一项；普通图片文件附件也进入图片组，普通文件附件维持原功能。

图片组最多叠放三张横向错位缩略图，右上角显示消息原有图片总数；点击从第一张可用图片进入与发送前相同的 `AttachmentImagePreviewDialog`，支持左右手势翻页、缩放与双击。有效图片不再重复显示文件名或“图片”标签。图片池变更通过 Flow 通知显示层，原图实际失效后显示过期数量；预览缓存随池中原图删除，不额外延长图片有效期。
