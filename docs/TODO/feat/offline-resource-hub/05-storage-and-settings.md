# 本地模型清单与设置入口

数据管理的本地模型清单此前把全部新语音模型显示为语音识别，也没有列出 OCR 和共用语音引擎。本轮在原数据管理包内补齐类型、文件占用和删除入口：MNN、llama.cpp、语音识别、语音合成、文字识别与运行引擎分别筛选。已安装 OCR 和引擎按真实资源目录展示，包内资产不作为可删除下载资源；删除通过原资源互斥与运行引用保护，并保留逐字节进度。返回页面时重新扫描。

数据管理总览和详情共用实际模型清单计数，避免把用途、框架及版本目录当成模型个数。存储明细也按识别、合成、OCR 与引擎目录分别归类。

离线资源的识别分类改为“语音识别”，合成继续独立分类。设置页把离线资源和外部 HTTP 调用归入“数据和权限”；删除独立的隐私清理和外部调用分组，并从全部九个语言目录移除两个不再使用的分组标题。补齐九种语言中的模型类别、资源数量及离线资源入口说明。

源码静态检查后提交原功能分支；依赖 PR 和功能 PR 按用户授权合入 dev，再通过发布同步 PR 将 dev 合入 main，最后派发仓库工作流。验证状态以实际回执为准。

发布目标为递增补丁 `1.12.2+14`，`versionCode=70`，以已发布的 `v1.12.2+13` 作为增量基础；签名 APK 与补丁由仓库发行流程生成。
