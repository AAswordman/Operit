# 验证与完整回归

本轮完成源码静态检查和真实资源归档核对；未在本地运行 Android 编译、构建或测试。当前目录为 51 个资源包，248 个外层包内文件的大小、SHA-256 与安装元数据逐项匹配；10 个 ToolPkg 的插件 ID、子包及逆向四个运行资源声明已核对。下载归档总量为 48,935,661 字节。

原有 23 项模型 JVM 回归、1 项 OCR 仪器回归继续保留。本轮补充 4 项大小/速率 JVM 回归，并将资产准备回归更新为 13 项 Python 用例；它们交由统一测试分支仓库工作流执行。语法解析不等同于编译或测试通过，模型推理、OCR 真实识别和完整扩展运行尚无新设备结果。

| 检查或命令 | 环境与变体 | 结果 |
| --- | --- | --- |
| Kotlin/Gradle、Python、XML、工作流语法与 diff | Ubuntu 静态解析 | 通过，未执行编译 |
| 51 个 ZIP 的归档及逐文件校验 | 实际发行文件 | 248 个文件匹配，10 个插件与 4 个逆向资源接线一致 |
| verify_hub_catalog.py | 当前功能工作区 | 51 组，193 个模板源码文件与 40 个扩展源码指纹匹配 |
| Debug 构建与完整 JVM | 统一测试分支 | 本轮提交后各派发一次，结果以仓库运行为准 |
| Android UI、下载、扩展、推理和 OCR | Android 设备 | 尚未运行 |

原 [31 项语音配置设备清单](../speech-services-workbench/02-verification.md) 继续保留。本轮下面同时覆盖已有资源、新模型、模板、OCR 与取消恢复。
