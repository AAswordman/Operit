# 02 Persistence And Lifecycle

## 旧实现

本地运行时从 `mcpServers` 读取命令，远程运行时从 `pluginMetadata` 读取 endpoint、连接类型和认证信息。导入没有维护两张表之间的互斥关系，缓存也可能跨传输类型保留。

## 修正

- 导入 stdio 时写入 `mcpServers`，移除同 ID 的远程元数据。
- 导入 HTTP/SSE 时移除同 ID 的本地配置，写入远程元数据。
- 传输配置被替换时移除该 ID 的工具缓存和运行状态，等待下一次启动重新发现工具。
- 仅保留已有远程记录的展示字段，连接字段以导入内容为准；新远程记录使用标准默认元数据。
- 本地和远程的手动写入路径遵守同一互斥规则。
- 远程详情不进入本地 JSON 配置编辑路径。
