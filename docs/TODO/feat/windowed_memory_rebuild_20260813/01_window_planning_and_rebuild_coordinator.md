# 窗口规划与重建协调

旧实现：

- `MemoryAutoSaveScheduler` 只按候选点回看最近消息
- `MemoryLibrary` 已集中完成知识图谱解析、去重、合并和记忆空间资料更新

意图修正：

- 将完整会话拆为固定数量的用户/助手消息窗口
- 摘要消息不参与长期记忆提取，不因摘要数量改变原始消息窗口边界
- 协调器顺序处理窗口，向 UI 报告运行、完成、失败、取消状态

预期结果：

- 单次请求规模稳定，长聊天可完整遍历
- 每个窗口仍能基于已有记忆进行更新与合并
- 密集总结的长会话仍按用户所选窗口大小推进，不会按总结数发起请求
- 记忆图谱输出使用具名对象 JSON，`main` 可为空且不会阻断同窗口的实体、更新、合并与连边
- 分析输入移除助手思考和工具结果正文，候选检索使用有限窗口上下文，避免短尾问题把无关记忆带入更新
