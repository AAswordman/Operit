# 第二轮实机反馈修正

本轮以用户认可的 HTML 排版为参考，调整第一版 Android 主题工作区的留白、分组与入口可发现性。所有修改继续使用现有主题草稿和保存链，不更改已发布的 1.12.2+8 偏好键。

## 计划与范围

- [x] 核对重构前的主题入口、当前源码和 HTML 的布局层次
- [x] 统一分区图标、描边、卡片间隔、控件内边距、行分隔和居中窗口
- [x] 将经典／Agent、气泡／命令式和主题模式统一为卡片内缩的分段选项
- [x] 将消息布局与消息外观分区，用户消息、AI 消息、头像与名称放入外观入口
- [x] 思考粒子颜色恢复为界面页的独立分区，保留颜色选择器和最近颜色
- [x] 输入框质感使用二级窗口，磨砂／水玻璃及独立参数沿用原有能力
- [x] 显示名称恢复为磨砂玻璃，维护九种语言的对应资源
- [x] 实时预览默认收起，展开前不解析预览字体和媒体；完整预览入口保留
- [x] 背景媒体与背景效果分区，提供媒体封面及图片／视频选择入口
- [x] 已发送图片组在命令式消息中右对齐；气泡式保留原有右对齐
- [x] 选图勾选背景改为浅圆形衬底，保留选择、滑动多选和长按预览
- [x] API 密钥直接内联密码输入，右侧箭头打开密钥池；打开前先保存当前编辑
- [x] 完成静态核对和完整差异检查

## 功能对照

| 原有能力 | 当前入口与行为 |
| --- | --- |
| 跟随系统、浅色、深色 | 主题 → 主题模式；仍写入原来的两个模式偏好 |
| 主色、次色、文字颜色模式 | 主题 → 颜色定制；调用原颜色面板和颜色解析器 |
| 系统字体、字体文件、字号 | 主题 → 字体；保留文件选择、清理与草稿资产管理 |
| 应用语言 | 主题 → 语言；仍为应用全局配置 |
| 图片、视频、裁剪、背景透明度与模糊 | 背景 → 背景媒体／背景效果；二级窗口保留媒体详细编辑 |
| 视频静音与循环 | 背景 → 选择背景与构图；仍使用原播放器和保存偏好 |
| 气泡／命令式、头像显示与宽布局 | 消息 → 消息布局；按实际聊天样式显示原支持项 |
| 用户和 AI 背景色、文字色、透明度 | 消息 → 消息外观 → 用户消息／AI 消息 |
| 消息专用字体、圆角、图片气泡、九宫格参数 | 消息 → 消息外观 → 对应消息二级窗口；保持样式适用范围 |
| 角色头像、全局用户头像、用户名、头像形状 | 消息 → 消息外观 → 头像定制；保持原保存范围 |
| 思考过程、供应商、模型、角色名、用户名 | 消息 → 消息信息，展开后编辑 |
| Token、速率、耗时、时间、任务状态 | 消息 → 消息信息，展开后编辑 |
| 输入处理状态与对话浮点动画 | 消息 → 消息信息；二者与思考粒子颜色保持独立 |
| 经典／Agent、悬浮输入、输入透明度 | 界面 → 输入框样式 |
| 思考粒子颜色 | 界面 → 思考粒子颜色独立分区；本轮前入口已存在于输入大卡片底部 |
| 磨砂／水玻璃与区域独立参数 | 各消息、输入、侧栏和卡片入口；跟随全局、独立设置与重置逻辑保留 |
| 侧栏背景与选中态、包管理按钮配色 | 界面 → 侧栏与按钮配色二级窗口；保留逐项恢复默认 |
| 保存、撤销、批量应用、主题重置、目标切换保护 | 固定底栏和主题操作；保持原草稿事务 |

HTML 的演示色板、模拟聊天和示例媒体不作为 Android 的新增功能。水玻璃专属参数不属于本轮范围。
