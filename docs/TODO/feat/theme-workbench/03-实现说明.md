# 实现说明

主题设置采用已确认的 HTML 信息布局，业务与持久化继续使用 Android 现有实现。日常改动保留在 `feat/config-workflow-attachments`，基于已发布 +8 做兼容扩展。

## 工作区与真实业务

- `screens/theme/ThemeSettingsTabs.kt` 使用主题、背景、消息、界面四个页签，输入设置归入界面。保存栏固定在滚动内容外，显示当前角色和草稿状态；撤销、批量应用与重置从主题操作窗口进入，重置和批量应用保留确认。
- `screens/theme/workbench/` 提供紧凑卡片、整行开关、居中且可滚动的窗口、草稿实时预览和两侧消息编辑窗口。背景、字体、头像、颜色与消息编辑继续调用原组件及 ActivityResult 回调，未将 HTML 示例存储或 CSS 渲染带入应用。
- 主题色对应已有颜色定制：保留自定义颜色开关、主色、次色及文字颜色模式，并复用 `ThemeColorSchemeResolver`。没有添加 HTML 中的固定色板、浏览器字体列表或浏览器媒体限制。气泡圆角仍使用现有开关，图片渲染模式仍使用两侧共用的原字段。
- 消息信息默认折叠，显示十二项真实字段的开启数量。头像、用户与 AI 字体、图片气泡、九宫格裁剪和平铺控制在二级窗口编辑；消息气泡仍遵守玻璃与图片互斥的既有规则。命令式 AI 消息仍只提供当前已有的背景透明度。

## 区域玻璃与兼容

`data/preferences/glass/GlassRegion.kt` 定义八个区域：用户消息、AI 消息、输入框、侧栏背景、侧栏按钮、对话列表、设置卡片、包管理卡片。用户区域参数在命令式与气泡式间通用，各样式的启用开关继续独立。

每个区域有一个覆盖开关和模糊、边缘宽度、高光、阴影、染色强度五个参数。`GlassThemePreferences` 将它们接入已有主题字段注册表，默认覆盖关闭；旧主题读取时补入正常默认值，仍使用原全局参数。启用独立设置时以当前全局参数建立区域值，关闭后重新跟随全局。

`GlassAppearance` 按区域解析参数，`liquidGlass` 和 `waterGlass` 接收区域标识。正式用户与 AI 消息、两种输入框、侧栏与侧栏按钮、对话列表、设置与包管理渲染均接入对应区域。侧栏选中按钮的文字对比度也使用按钮区域的染色参数。

独立模式下，区域染色强度与显式背景透明度相乘，正文和附件不参与该透明度合成。跟随全局时保留原有透明度解释，不改变已发布主题的显示。恢复全局参数只重置全局五项；恢复某区域参数只重置该区域五项；重置整个主题才恢复所有区域默认值。

开启输入框玻璃时同步启用透明背景，并清除冲突的不透明显式值，避免开关开启但输入框仍按不透明区域绘制。玻璃系统版本限制和两类效果互斥保持原规则。

## 草稿、全局字段与资源

`ThemeEditorSession`、`ActivePromptManager` 和原主题读写接口继续负责保存、放弃、切换角色保护、复制及重置，新增区域字段与其他外观一起保存。媒体和字体继续使用内部资源暂存与清理，外部选择回调保留发起选择时的草稿实例。

全局用户名继续参与本会话保存和放弃，但不加入角色外观批量复制；全局用户头像沿用原有独立保存行为。语言仍是应用全局设置，先处理未保存草稿，再持久化语言并重启主界面。

## 预览边界

预览使用固定示例消息与演示统计，不连接模型服务。配色、主题字体、消息字体、图片气泡、背景媒体和玻璃调用正式解析及渲染能力；示例不是实际聊天记录或运行性能证据。

内嵌视频始终静音，声音在背景编辑窗口试听；预览折叠、窗口失焦、页面离开和应用后台按对应状态暂停或释放播放器。完整预览打开时不同时保留内嵌预览播放器。窗口播放与实际解码仍待设备验收。
