## HTML 设计稿结构

同一工作区按“连接、参数、上下文总结、功能分配”排列四个页签。上下文总结紧邻功能分配左侧，继续通过顶部卡片选择配置，不引入配置列表首页或额外详情层。

功能分配将分散的大卡片改成连续的紧凑列表，直接展示功能名称、配置名称与具体模型。沿用全部功能、当前配置两种查看范围，并提供按需展开的搜索框；当前配置的绑定使用原配色的浅色背景和侧边标记。十二项功能保持原次序。

功能编辑继续使用原居中窗口。配置选择改为按分组组织的选择框，具体模型仍可选择或填写；保留原有的功能参数覆盖、输入校验、保存与取消行为。

上下文总结包含上下文长度、最大长度、自动总结开关、比例阈值、消息条数触发、自定义规则、上一轮摘要、四个摘要板块、对话回顾和历史媒体保留。策略随顶部当前配置独立保存；总结模型使用全局功能映射，历史媒体回合数保持全局生效。
