# 页面改动与实现范围

## 基础与边界

本稿直接修订 `operit-model-workbench-v2.html`。顶部配置卡片、配置分组、重命名、配置操作、用途入口、连接设置、模型列表、密钥池、参数分区和原有居中窗口继续使用第二版实现。

共享配色与基础组件样式保留。新增样式只针对四页签排版、功能列表、功能绑定预览和上下文总结区域；实际手机观感仍需审阅。

## 四页签

```text
模型与参数配置/
	当前分组与模型配置卡片
	连接
	参数
	上下文总结
	功能分配
```

四个页签继续使用同一滚动容器、选中状态、面板关联和键盘导航。顶部选择变化会更新配置所属内容；全局功能映射不因切换顶部配置自动重绑。

## 功能分配

十二项功能保留第二版的原次序。列表使用一个连续容器，每行突出功能名称，配置名称置于右侧，具体模型单独一行，降低大卡片的重复留白。当前配置绑定保留浅色强调和侧边标记。

全部功能与当前配置沿用原筛选语义。搜索默认收起，展开后可按功能名称、配置名称或模型过滤；收起后清除搜索条件。显示数量随筛选更新。

编辑窗口以当前选择的配置和模型作简短预览，配置选择器按原分组组织，模型输入继续提供候选并支持填写。随机性与最大输出覆盖仍在可选折叠区，保存沿用原输入校验。切换配置保留参数覆盖草稿；取消不修改绑定；保存后同步更新列表、顶部用途数和总结页模型入口。

本稿未新增独立的功能思考编辑器，第二版参数页中原有思考规则编辑保持原样。后续 Android 重构仍应保留现有十二项功能的模型索引、思考偏好、真实测试和保存协调能力，不能依据 HTML 的简化项删除。

## 上下文总结

- 上下文长度、最大长度、自动总结、触发条件、规则、四个摘要板块及回顾随顶部配置保存
- 总结执行模型使用全局 `SUMMARY` 功能映射，可直接打开同一功能编辑窗口
- 历史图片与音视频保留回合数使用全局状态，切换顶部配置时不重置

常用控制项采用原稿的配色、输入框和开关，规则与摘要板块使用折叠编辑。长文本可以在原居中窗口展开，保存才更新文本；取消保留先前内容。

比例阈值以 10% 到 95% 表示，消息条数范围为 1 到 20。关闭自动总结后禁用相关控制，上下文长度与全局媒体保留仍可编辑。日常上下文不得超过最大上下文，非法输入显示错误并保留原先的有效状态。

## 交付与后续

手机上的既有第二版文件直接更新；统一索引主入口指向该文件。仓库保持原有 `design.html` 路径，说明文档同步改为当前四标签方案。

本文记录 HTML 的设计范围。对应 Android 工作区已经按四标签接入，实际保存、导航和能力复用见 [实现说明](02-implementation.md)。资源下载、OCR 与插件外置、工程模板拆包、终端环境预装不在本轮范围。
