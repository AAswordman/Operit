# 实现与兼容说明

模型与参数配置原有连接、参数、功能分配三个标签。本轮在参数与功能分配之间加入上下文总结，设置首页保留一个模型工作区入口，原总结入口路由直接打开总结标签。

## 功能与归属

- `settings/contextsummary/ModelContextSummaryContent.kt` 根据顶部选择的实际 `ModelConfigData` 创建编辑器，完整显示上下文长度、最大长度、自动总结、比例和消息触发、补充规则、上一轮摘要、四个结构板块、对话回顾及媒体保留；每个标签保留独立滚动位置
- `ContextSummaryComponents.kt` 复用原总结页的控件、折叠与长文本编辑，原独立屏幕和分散的自动保存效果移除；长文本确认才写回，关闭或取消保留之前内容
- `ContextSummaryDraft.kt` 为输入提供独立草稿。数据库变化只同步没有本地修改的字段，防止先前保存的结果覆盖继续输入中的文本；切换顶部配置后使用对应配置的草稿
- 总结执行模型继续使用全局 `SUMMARY` 功能映射。总结页显示实际绑定的配置与模型，并与功能列表共用 `ModelFunctionAssignmentDialog`，保持模型索引、分组信息、思考偏好和原有能力测试
- 历史图片与音视频回合数继续保存在 `ApiPreferences`，切换模型配置不重置；恢复默认仅重置媒体保留，不影响总结规则

## 保存与错误

总结草稿接入现有 `ModelConfigSaveCoordinator`。正常输入采用七百毫秒防抖；配置、分组和标签切换前同步完成保存，退出或进入后台继续使用工作区原有保存协调。

`ModelConfigManager.updateContextSummarySettings` 在同一次 DataStore 编辑中写入相关上下文与总结字段，保留服务、密钥、其他参数、最大上下文模式等不属于本次编辑的字段。关闭自动总结或按条数触发后，不采用失效控制项里尚未提交的输入，继续保留对应原值。

输入检查覆盖正数且有限的上下文长度、日常长度不超过最大长度、大于零且小于一百的总结百分比、启用时的正整数消息阈值及非负整数媒体回合数。非法输入显示在对应板块；切换时保存失败保留当前页。

百分比只改变显示单位，存储继续使用原来的零到一比例。Android 沿用已有配置的有效范围，不采用 HTML 示例中 10%—95% 与消息 1—20 的演示限制。原字段、配置文件格式和导入导出结构不变，不需要数据迁移。两项历史媒体偏好继续独立保存，与配置字段不构成跨 DataStore 的原子事务。

功能编辑窗口串行写入绑定和思考偏好，避免连续操作读取旧映射后相互覆盖；关闭前等待所有待写入任务，避免窗口离开组合时取消尚未完成的修改。真实测试继续使用原 `ModelFunctionEditor`，没有把 HTML 的示例结果接入应用。

## 功能列表与导航

功能列表保留全部十二种功能及原次序，改用连续紧凑行，突出功能名称、配置名称和具体模型；保留全部与当前配置筛选，新增可收起搜索与结果数量，保留重置功能分配。

`Screen.ContextSummarySettings` 保留原路由标识，内容改为 `ModelConfigScreen(initialTab = SUMMARY)`。设置首页删除独立入口，模型入口说明更新为四类设置；连接与参数的原编辑器继续复用。

## 验证边界

新增八项 JVM 单元测试，覆盖数据库回写与继续输入、未修改字段同步、结构标题保留、关闭项处理、非有限值及范围、上下文上下限、消息条数和媒体回合数。未在本地运行 Android 编译、构建或测试；云端执行结果尚待确认。

Kotlin 语法解析、中文英文资源 XML、占位符、资源引用、导航调用点和差异检查已完成。静态检查不等于编译或设备验收，完整操作与结果表见 [验收清单](03-regression.md)。

语音服务、离线资源页面及资源外置不属于本轮实现。
