# 验证与完整回归

## 当前证据

已写入 `SpeechProfileDraftTest` 十四项 JVM 回归：档案往返及非 JSON 请求体、跨引擎保留高级参数、空结构值、三类非法 JSON、非法/空白规则、写入中继续输入、独立档案写入、保存回执保留原始文本、旧回流版本、外部更新、待保存输入保护及取消保存。用例未在本地执行。

本地只执行源文件语法解析、字符串/XML/图标引用、差异空白及文档链接的静态检查，不执行 Gradle 编译、构建、JVM 或设备测试。原生构建与 JVM 验证交给工作分支上的 `android-build.yml`（assembleDebug）及 `android-tests.yml`。HTTP 204 仅表示派发受理，运行结论需以仓库工作流实际结果为准。

下列设备回归尚未执行。真实服务、资源包和麦克风相关路径需相应条件；设备冒烟记录不作为本次仓库交付的额外前置审批。HTML 的既有 28 项 DOM 结果只验证设计稿，不替代原生验证。
