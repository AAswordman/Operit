# 语音服务原生工作区

按已选定的 [HTML 设计](../speech-services-design/design.html) 重构 Android 语音服务配置。现有长表单和下拉菜单改为三个固定等宽入口、档案卡片、选择面板、常用字段、折叠高级选项和同页真实测试。

## 实施范围

- 沿用已发布的 TTS/STT 档案与唤醒偏好格式，保留九种 TTS、三种 STT 和全部唤醒能力
- 编辑状态按档案隔离，TTS/STT 分别保存；切换和复制前提交有效修改
- 面板支持搜索、手动填写、系统默认值和真实模型/音色加载
- 同页试听使用独立服务与当前编辑快照，离页、切换及进入后台时释放；识别保留真实权限和共享服务的录音归属
- 唤醒按后台监听、怎样唤醒、唤醒以后和关键词附件组织

3. 补充完整回归步骤与必要自动回归，静态审阅后提交、推送并派发工作分支 Debug/JVM 工作流
