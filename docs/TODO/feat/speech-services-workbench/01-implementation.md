# 原生结构与兼容

## 页面与面板

`SpeechServicesSettingsScreen` 保留原路由参数和初始标签导航，将内容交给 `components/speech/workbench`。顶部朗读、识别、唤醒三项固定等宽；档案卡、引擎连接、声音参数与同页测试依次排列。窄窗口使用底部面板，600dp 及以上窗口使用居中面板。表单支持键盘避让和滚动，选择面板支持搜索、当前项标记、刷新和独立的手动输入。

TTS 保留九个提供方、系统语言与实际设备音色、HTTP 全部请求字段、在线凭据/模型/音色、MiMo 多行音色配置、豆包 App ID 和 VITS 包路径/说话人/选项。OpenAI 兼容模型和音色继续调用现有加载器；内置音色使用各提供方真实常量，不使用 HTML 的演示清单。HTTP 高级项、VITS 选项和清理规则默认收起，五个清理模板与旧页面一致。

## 档案保存

TTS/STT 各自拥有按档案 ID 创建的编辑状态，350ms 防抖后通过原 API 写入。写锁串行化保存与档案操作，写入期间继续输入会在同次提交操作返回前继续保存。切换、复制、重命名、删除和打开独立朗读工具前提交当前有效草稿，离页取消防抖时执行最后一次有效写入。非法 JSON 或正则显示错误并停止保存，不把非法内容写入档案。

已保存模型与原始编辑文本分别记录；自身保存回流不清空新加的空白规则、不改写用户正在编辑的格式。无待保存修改时接收独立工具等入口更新的配置，并按 `updatedAt` 排除旧回流。高级 HTTP 参数和 VITS 选项在切换引擎后仍保留。

档案支持空白新建、从当前复制、新档案命名、重命名和删除。删除当前档案时先选中其他档案，再调用原删除 API，最后一份不能删除；确认窗口绑定原删除对象。已有 DataStore 名称、schema、档案字段、运行时偏好投影、服务类型和唤醒配置键均沿用。

## 真实试听与识别

`VoiceServiceFactory` 增加接收明确 TTS 档案快照的创建入口；原有调用继续读取当前已保存档案。同页试听按需创建独立实例，应用当前清理规则、语速和音调，并显示实际初始化/播放错误。停止操作调用真实服务；修改配置、切换标签/档案、离页或应用进入后台会释放本次试听。初始化或停止操作取消后，旧回执不覆盖后来的操作状态。

识别测试保留原来的权限申请、语言、状态/错误/完整结果流、复制、配置切换和资源释放，只将语言菜单与开始/停止布局换为工作区组件。仍只取消本次测试拥有的录音；本地唤醒共享的服务不被误当作测试录音。

## 唤醒

按后台监听、怎样唤醒、唤醒以后和关键词附件分组。保留系统助手入口、麦克风权限、STT/个人模板方式、三次真实模板采集及清除、唤醒词/正则、问候语、新建对话与分组、超时、四种关键词附件的增删/启停/编辑。模板录制与保存期间阻止关闭面板；采集逻辑和原模板格式保持一致。

在线 STT 档案不用于后台唤醒，页面明确显示现有后台路径使用本地 Sherpa NCNN。无响应超时只写入 1–600 秒的有效输入，不将越界显示值偷偷夹取为另一个保存值。关闭问候或新建对话时禁用对应输入。附件编辑改为相同的自适应面板，其他页面使用的共用附件组件不变。
