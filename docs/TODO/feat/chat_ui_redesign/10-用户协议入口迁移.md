# 第十节：用户协议入口迁移

本次补录：用户确认目前 Bug 均已修复，本页功能验收结果按用户确认记为通过。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

## 改动

- 工具箱不再展示用户协议卡片，保留 `toolbox.agreement` 登记和原生路由，避免切断已有导航。
- 设置中的关于页面增加用户协议入口，沿用原协议正文页面；阅读模式不显示同意按钮，也不启动倒计时。
- 首次启动时 `MainActivity` 调用协议页的同意流程保持原样，仍由首次同意回调写入接受状态。
- 本节不改协议文本、版本号及其他工具箱入口。

## 验证

源码核对两个调用入口、侧边栏与工具箱可见性及返回导航；`git diff --check` 检查差异格式。本地依仓库规范不构建、不运行测试。设备上仍需检查首次启动同意与关于页面阅读体验。
