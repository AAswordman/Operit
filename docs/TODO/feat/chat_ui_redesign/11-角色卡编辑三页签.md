# 角色卡编辑三页签

## 原状

角色卡创建和编辑共用长滚动弹窗。名称、描述、头像固定在顶部，其他内容、标签与模型、记忆、工具权限绑定混排在滚动区和高级折叠区。编辑中的角色卡无法直接进入现有的导出流程。

## 本节变更

- 基础页签放名称、描述、头像、角色设定、开场白和标签。标签管理在弹窗中打开已有标签创建或编辑流程，切换页签或管理标签不保存角色卡草稿。
- 内容页签放聊天和语音补充、自定义提示词及备注；绑定页签放模型配置、记忆空间与工具白名单。保留原有固定/跟随全局语义及工具权限校验。
- 导出与保存使用相同的字段收集和校验。导出先保存当前角色卡，再按实际保存后的 ID 打开原有导出方式选项；取消和关闭不保存文字草稿。已有角色卡的头像即时保存，新建角色卡先显示预览，保存后关联真实 ID。
- 本节只调整角色卡编辑 UI 与调用接线，不修改角色卡数据格式、记忆图谱或其他工具箱入口。

## 后续修正

- 修正基础页条件包住绑定页、内容页字段落在条件外的结构问题；页签切换时同步重建该页布局节点和滚动状态，编辑草稿仍由弹窗外层保存，避免切页时旧节点被错误移动。
- 基础页顶部改为头像在左、名称和描述在右。点头像直接打开图片选择器，已选头像仍可重置；不再显示重复的头像文案或独立的选择按钮。
- 默认记忆空间只有重命名功能，改为点击编辑图标直接打开重命名弹窗；其他空间继续通过菜单执行重命名或删除。

## 核对


- 静态核对：确认创建和编辑入口均使用三页签；所有原有编辑字段和选择器仍可到达；保存与导出拿到一致的字段。
- 设备回归：切换页签后内容不丢失；头像选择和重置、开场白翻译、大屏编辑、标签创建和编辑正常；固定模型、固定记忆空间及工具白名单的切换和保存正常。
- 设备回归：新建和编辑角色卡从弹窗导出时先保存再打开导出方式；关闭或取消不保存文字草稿；键盘弹出时页签和底部操作仍可用。
