| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 01 | 打开内置脚本包详情 | 窗口扩大，标题居中；ID、分类、来源、默认状态与声明一致 |
| 02 | 打开外部脚本包详情 | 作者与来源正确；删除入口仍可用 |
| 03 | 打开带环境变量的包详情 | 独立列出全部变量名称和说明，必填/可选标记正确 |
| 04 | 打开不声明环境变量的包详情 | 不显示空环境变量区块 |
| 05 | 使用很长的变量名、说明及非英文内容 | 内容换行完整显示，不截断为省略号 |
| 06 | 在原环境变量设置中编辑并保存，重新打开详情 | 配置仍由原设置保存；详情只展示声明，不展示配置值 |
| 07 | 查看参数超过三项的工具 | 完整展示全部参数名称、类型与必填星号 |
| 08 | 点击运行 | 标题显示工具名称和说明，无源码编辑框 |

| 10 | 查看长参数说明 | 可完整换行阅读，无需先选中输入框 |
| 11 | 给 prompt 或 *_prompt 粘贴多段文字 | 支持多行；其他参数保持单行输入 |
| 12 | 输入最后一个参数，打开和关闭键盘 | 窗口随可用高度调整；输入框和说明可滚动到可见处，底部按钮可访问 |
| 13 | 切换小屏、横屏、大字号及较大屏幕 | 窗口受可用区域约束，操作可换行；较大屏幕不会无限拉宽 |

| 15 | 正常填写参数后运行 | 执行插件原始脚本；运行中禁用重复运行和参数修改 |
| 16 | 执行返回多个结果或长结果的工具 | 结果持续累积，可滚动阅读和复制 |
| 17 | 执行失败的工具，再次正常运行 | 显示错误并恢复按钮；再次执行清理上次结果 |
| 18 | 用顶部关闭、底部关闭、外部点击或返回键关闭 | 弹窗正常退出；执行中退出不伪报执行错误 |
| 19 | 打开包含状态的沙盒包，切换状态页签 | 原有状态工具继承、排除和覆盖规则保持，工具与说明随页签更新 |
| 20 | 打开工具包容器与子包详情，再运行子包工具 | 子包环境变量正确展示；执行目标是子包而非容器 |
| 21 | 使用子包开关、插件配置、模板、性能监测和删除入口 | 原有入口及操作行为保持可用 |
