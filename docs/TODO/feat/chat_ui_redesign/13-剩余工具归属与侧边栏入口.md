# 第十三节：剩余工具归属与侧边栏入口

## 原状

工具测试中心、应用权限管理、UI 调试、应用日志、幻象进程控制和 HTML 打包器仍依赖工具箱卡片。助手配置同时展示在侧边栏。UI 调试悬浮窗展开后占满屏幕，遮挡底层触摸；批量测试会执行文件、网络与系统写操作。

## 目标与作用域

- 删除应用权限管理和幻象进程控制的页面、包装组件及路由。不动其他应用列表工具仍使用的包可见性权限，也不改终端子模块。
- 设置页增加诊断与日志分组，进入应用日志导出与清理、UI 调试及工具测试中心；这些页面不再发布工具箱卡片。
- 工作区主页增加 HTML 打包入口，沿用现有选择网页目录及 Android/Windows 导出流程；不引入新的 `operit_editor` 原生桥。
- UI 调试悬浮窗收为局部面板，元素改为可滚动列表；读取页面时隐藏自身和聊天浮窗，读取完成后恢复。
- 批量测试只执行明确标记的设备信息与系统设置读取；其他项目保留逐项运行，运行前确认副作用。
- 助手配置仅暂停侧边栏展示，保留页面路由、配置逻辑及其底层实现，待与仓库 owner 沟通后再决定清理。

## 验证

- 静态检查：入口、路由与页面引用及 `git diff --check`。
- 本地编译和测试未运行：仓库默认禁止；推送后触发 Android Tests 与 assembleDebug。
- 设备回归仍需确认：设置三项入口、工作区导出、调试悬浮窗触摸与刷新、测试中心只读批量及逐项确认。
