# 对话列表与嵌套文件夹

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

## 作用域

本节改造现有 `ChatHistorySelector` 对话历史面板，保留它在聊天页的入口。设计稿中把列表放进主侧边栏是后续目标，本节不迁移到主侧边栏，不改主导航布局。整轮 UI 重构完成前不创建 PR。

## 原有行为

文件夹仅由聊天的 `group` 名称表达，创建分组会生成一条空聊天。列表只能显示一层分组，只能拖动聊天，默认使用置顶优先及保存的显示顺序。

## 实现计划

1. 增加独立文件夹记录、稳定 ID、父节点和显示顺序，将已有分组迁移为根文件夹并保留原聊天及绑定
2. 增加可持久化的最近使用时间，主动打开或发送聊天时更新，不用改标题等元数据的更新时间排序
3. 在现有面板中提供文件夹树、统一行高和缩进、轻量拖动柄、文件夹菜单及居中新建弹窗
4. 支持文件夹整棵子树移动、同级插入和移入文件夹；禁止拖进自身或后代，拖动时支持边缘滚动和悬停展开
5. 保留三种显示模式和两个自动切换开关，适配任意层级文件夹；搜索保留匹配项的祖先路径，退出搜索恢复展开状态
6. 增加默认与最近使用排序，保存手动顺序；删除文件夹默认将内容提升到父级，删除聊天保持独立操作
7. 保留现有聊天编辑、置顶、锁定、角色卡/群组绑定、导入导出和工具包聊天菜单入口
8. 增加相称的树结构与迁移回归用例，更新 9 种语言，推送个人分支并触发仓库工作流

本地完成差异和资源结构核对，未执行构建、测试或实机验证。CI 结果以仓库工作流为准。

交互调整：右侧拖动柄直接响应拖拽，无需长按；对话和文件夹行仅响应点击选中或展开。操作菜单仅由三个点打开，拖动柄的点击与按住不会触发行点击或菜单。同步更新九种语言的拖动提示。

回归操作与预期：点击三个点应打开对应操作弹窗；长按对话或文件夹行不弹菜单；从右侧拖动柄直接拖动，应进入原有拖动预览、悬停展开与放置流程；点击或按住拖动柄不选中对话也不弹菜单。上述设备操作未在本地执行，交由后续验证。

## 迁移测试运行依赖

`ChatFolderMigrationTest` 复用 `JvmSupportSQLiteDatabase`，通过 JDBC 在内存 SQLite 数据库中验证 Room 21 → 22 的生产迁移 SQL。`app/build.gradle.kts` 使用 `testRuntimeOnly` 声明 `org.xerial:sqlite-jdbc:3.46.1.3`，使 JVM 测试能建立连接；该驱动不进入应用运行依赖或 APK。

[此前的 Android Tests 报告](https://github.com/3316891527/Operit/actions/runs/38252600463) 中，唯一失败项在数据库连接阶段报 `No suitable driver found for jdbc:sqlite::memory:`。补齐驱动后保留原有迁移与数据保留断言，验证结果以重新触发的 Android Tests 工作流为准。

## 归档往返测试的序列化配置

`ChatFolderArchiveTest` 的往返用例启用 `encodeDefaults = true`，与 `ChatHistoryManager` 的归档导出配置一致，确保动态默认的导出时间被完整保存。默认 `Json` 可能省略与当前时间相同的 `exportedAt`，解码时重新生成时间，导致完整归档相等断言偶发失败。

本次仅调整测试序列化配置；完整归档、聊天历史、目录 ID、最近使用时间断言及旧归档兼容用例保留。本地进行源码与差异核对，远端验证仅触发 Android Tests，结果待确认。
