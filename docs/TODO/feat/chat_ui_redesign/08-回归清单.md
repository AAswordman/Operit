## 操作与预期

1. 打开语音服务配置：显示 TTS、STT、语音唤醒三个页签，切换后从内容顶部开始

3. 新建、切换、重命名和删除 TTS 配置：配置管理和自动保存可用
4. 修改 TTS 并打开试听：继续使用当前 TTS 配置，可播放和停止
5. 新建、切换、重命名和删除 STT 配置：配置管理和自动保存可用，测试区跟随当前配置
6. 未授权麦克风时进入 STT：显示授权按钮；拒绝时不录音；授权后可测试
7. 选择本地 Sherpa 识别：选择语言并开始、说话、停止，显示识别状态和结果
8. 选择 OpenAI STT：测试使用当前端点、密钥和模型，停止后返回结果；错误显示在测试区
9. 选择 Deepgram STT：测试使用当前配置，停止后返回结果；错误显示在测试区
10. 连续运行两次测试并复制结果：第二次清空上一轮文本，复制得到本轮结果
11. 测试时更换配置或修改端点、密钥、模型：旧测试结束，新测试使用新值
12. 测试时切换页签、返回、进入后台：本次测试录音结束，再进入可重新测试
13. 本地识别正被其他功能占用：测试按钮不可发起并行录音，不中断其他功能
14. 切换 STT 唤醒与个人模板模式：显示相应配置，重新进入保留模式
15. 打开持续监听：申请麦克风权限后启用；关闭与重进后状态一致
16. 修改唤醒词、正则和通话超时：保存并重进后生效，超时保持原有 1–600 秒约束
17. 录制三次个人模板并保存、重进、清空：模板保存成功，清空后提示无模板
18. 个人模板录制时离开页面或进入后台：停止采集并释放麦克风，再进入可录制
19. 修改问候开关、问候文本、新建对话与分组：保存后保留，唤醒行为使用原有配置
20. 开启并编辑关键词附加内容：添加、修改和删除可保存，语音附加行为可用
21. 点击唤醒页签的系统助手按钮：直接打开系统助手设置；不能打开时提示错误
22. 进入原生默认助手路由：显示语音服务的唤醒页签，无旧教程界面；返回可用
23. 打开工具箱：获取密钥、SQL 查看器、FFmpeg 工具箱、命令执行器、命令终端、两个 AutoGLM、文本转语音、语音识别、默认助手卡片均不显示
