## 操作与预期

<details><summary>侧栏与聊天页面</summary>

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 01 | 打开主聊天页，查看空对话、长标题和已有消息 | 一行透明控件显示菜单、对话标题和三项操作；长标题省略，滚动消息不遮挡控件 |
| 02 | 在聊天输入框输入文字，点击菜单按钮 | 收起键盘并打开主侧栏；草稿保留 |
| 03 | 在聊天页及设置页右滑打开侧栏 | 打开同一侧栏；当前角色和对话一致 |
| 04 | 分别点收起按钮、右侧空白、空白处左滑、系统返回 | 手机抽屉关闭；返回不同时切页 |
| 05 | 平板布局展开、收起侧栏，切换横竖屏 | 展开显示完整目录，折叠入口可重新展开；当前对话保留 |
| 06 | 滚动长目录，查看角色、导航和底部入口 | 目录独立滚动；角色区紧凑；包管理、设置和主题按钮固定为细长一行 |
| 07 | 使用小屏、大字体、中英文和浅深色主题 | 文案可识别；操作入口可点；布局和颜色跟随主题 |
| 08 | 从底部进入包管理、设置及其子页面 | 显示相应标题；返回入口可用 |
| 09 | 点击权限、工作流及按名称显示的插件侧栏入口 | 均直接进入原有页面；插件不经过总菜单 |
| 10 | 无插件入口及多个插件入口时打开侧栏 | 无入口时没有零数量占位；多个入口可滚动，包管理仍固定可进入 |

</details>

| 12 | 在角色选择弹窗点外部、按返回 | 仅关闭弹窗；角色不变 |
| 13 | 点击角色旁设置或选择面板的编辑入口 | 打开角色管理页；原有基础、内容、绑定编辑可用 |
| 14 | 修改角色名、头像或群组后返回侧栏 | 名称和头像更新，与聊天使用的角色一致 |
| 15 | 在侧栏切换三种历史显示方式并重启应用 | 显示范围正确；文件夹、角色分组及偏好保留 |
| 16 | 切换角色自动切换对话、切换对话自动切换角色两个开关 | 仅按对应开关自动切换；主聊天与侧栏状态一致 |
| 17 | 从聊天、设置、工作区主页新建和选择对话 | 关闭手机抽屉并进入对应消息页；不额外创建对话 |
| 18 | 在角色分组、群组和已有文件夹中创建对话 | 对话绑定和文件夹归属正确；新对话选中 |
| 19 | 点搜索图标，搜索标题和内容，清除、收起搜索，再关闭侧栏 | 仅展开细搜索框；结果及空提示正确；关闭不残留搜索键盘 |
| 20 | 新建顶层及多级文件夹，展开、折叠、重命名 | 目录层级正确，状态及名称保留 |
| 21 | 长按目录项拖动，悬停展开，滚动长目录 | 拖动可用，抽屉不随目录拖动关闭 |
| 22 | 将对话和子文件夹移动到其他目录、根目录 | 层级及归属更新；不会出现循环目录 |
| 23 | 切换时间、名称和手动排序，手动上移下移 | 排序与设置一致；搜索时不允许拖动排序 |
| 24 | 编辑标题和角色/群组绑定，置顶、取消置顶 | 对话条目和分组更新；当前对话内容不丢失 |
| 25 | 锁定对话后删除，解锁后删除，取消删除 | 锁定保护有效；仅确认且允许删除时移除 |
| 26 | 删除含子目录和对话的文件夹 | 删除确认有效；原有保留内容规则不变 |
| 27 | 多个对话同时生成并打开目录 | 对应条目显示生成状态；菜单保留并发数量提示 |
| 28 | 无对话时打开侧栏并新建，关闭后重启 | 空提示正确；新对话可进入；已有数据无需迁移 |

</details>

<details><summary>工作区、悬浮窗与导航</summary>

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 29 | 点击顶部最右侧工作区入口，再点一次 | 打开原有工作区主页，再回消息页；顶部控件不遮挡页签 |
| 30 | 无当前对话时打开、关闭工作区主页 | 显示未绑定提示；不自动创建空对话 |
| 31 | 创建、选择工作区并分别取消 | 打开原有模板或目录选择器；取消后返回主页 |
| 32 | 绑定 Android、Linux、SAF 目录并从主页打开 | 环境与路径正确；原有文件、预览、导出功能可用 |
| 33 | 普通角色和群组的多个对话共享目录 | 主页目录概览、绑定对话和角色统计正确 |
| 34 | 编辑文件后在主页、工作区、终端之间切换 | 已打开文件、未保存状态和终端会话保留 |
| 35 | 从工作区主页打开 HTML 打包器 | 进入原有打包页面，返回入口可用 |
| 36 | 终端新建、关闭会话；工作区命令打开终端 | 会话数更新；离开终端无残影；命令切入统一终端页 |
| 37 | 预览浏览多个网页；工作区、终端和主页逐次返回 | 先处理网页返回，再回主页，最后回消息页 |
| 38 | 工作区准备中，从侧栏选对话、新建对话或切换角色 | 准备任务取消；进入消息页，不异步重开旧工作区 |
| 39 | 有未保存内容的页面中，从侧栏选择另一对话或角色并取消离页 | 留在原页面；当前对话和角色不提前改变 |
| 40 | 同上，确认允许离页 | 完成原有离页处理后，进入选中对话或角色的消息页 |
| 41 | 在工作区解绑、重命名、关闭未保存文件后切页 | 对应弹窗按原有页面可见性规则显示 |
| 42 | 点击顶部工作区左侧的上下文圆环，在生成后再次查看 | 窗口用量、输入、输出、总 Token 显示并更新 |
| 43 | 用上下文左侧按钮打开、关闭悬浮窗，允许及拒绝麦克风权限 | 沿用原有权限处理；启动就绪后应用进入后台 |
| 44 | 从设置回聊天，打开悬浮窗后再返回应用 | 悬浮窗使用共享主对话状态；顶部控件与页面导航可用 |
| 45 | 使用悬浮聊天、嵌入聊天的角色和历史入口 | 保留各自面板；不会要求主抽屉存在 |
| 46 | 生成中在聊天、设置、包管理间切换并回聊天 | 使用同一主 ViewModel；历史、草稿和生成状态一致 |
| 47 | 分别用浅色、深色及自定义侧栏背景，查看未选中、选中和拖动预览标题 | 标题及次级信息与背景有可辨对比，不继承聊天正文的固定文字色 |
| 48 | 点底部主题按钮两次，重启后再切换角色或群组 | 当前目标的深浅模式被保存；切换按钮不改变头像、背景等其他配置 |
| 49 | 打开主题设置的“界面”标签，修改其他页面工具栏设置 | 不再显示旧聊天顶栏透明、覆盖及图标颜色设置；仅影响说明所指页面 |
| 50 | 在聊天、设置、包管理和工作区间反复切换 | 顶部入口只显示一组；记录实机流畅度，不以静态核对判定性能 |

</details>
