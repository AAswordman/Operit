# 角色弹窗、模型标识与记忆设置

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

角色编辑改用较柔和的灰色圆角表面，根据当前页实际内容收紧高度，在可用窗口中居中显示。短页不再固定占用屏幕的 78%，长内容可以滚动，标题、页签和操作区保持可见。Agent 的当前模型和展开列表加入现有供应商品牌标识。记忆设置则集中为自动提取、检索、历史重建三个可点击与滑动的页签。

## 角色弹窗与模型标识

[角色编辑](../../../../app/src/main/java/com/ai/assistance/operit/ui/features/settings/components/CharacterCardDialog.kt)复用新的[分页弹窗](../../../../app/src/main/java/com/ai/assistance/operit/ui/common/dialogs/ContentSizedTabbedDialog.kt)。窗口宽度上限为 640dp，屏幕及键盘共同限制可用高度。当前页通过滚动容器内部的完整内容测量决定页高，保留各页独立滚动位置与表单草稿；窄屏或大字体下，底部操作可换行。表单采用圆角、淡色容器和较柔和的边框。

[Agent 输入栏](../../../../app/src/main/java/com/ai/assistance/operit/ui/features/conversation/chat/modules/input/agent/AgentChatInputSection.kt)的两种输入布局、模型摘要、配置列表以及多模型配置展开后的各个条目，均复用 ProviderLogoLoader 的供应商素材。标识随实际配置的供应商变化；现有加载器没有登记素材时不增加占位标识。名称仍可省略，配置中的长模型名增加宽度约束。

设置首页保留 GitHub 账号管理入口，登录和退出统一在既有账号页面操作。

## 角色用户资料

角色管理列表在每张角色卡上提供独立的用户资料按钮。新的[资料弹窗](../../../app/src/main/java/com/ai/assistance/operit/ui/features/settings/profile/RoleUserProfileDialog.kt)以角色实际使用的记忆空间读取和保存 user.md：固定绑定使用指定空间，跟随全局使用打开时的活动空间，并在弹窗内显示空间名。多个角色绑定同一空间时编辑的是同一份资料。

资料支持编辑、Markdown 预览和现有 12,000 字符限制。关闭、取消及系统返回统一确认未保存修改，保存期间避免重复保存与关闭；读取、保存失败显示错误并保留草稿。锁定只限制模型自动更新，手动编辑继续可用。入口复用现有文档仓库及其迁移初始化，不建立另一份角色资料存储。

## 记忆设置三页签

页面协调层位于[MemorySearchSettingsDialog](../../../../app/src/main/java/com/ai/assistance/operit/ui/features/memory/screens/dialogs/MemorySearchSettingsDialog.kt)，各页与数据读取集中在 ui/features/memory/settings/。首次成功读取后建立一份草稿，切页、刷新状态及关闭模拟搜索均保留草稿；保存成功后关闭并重新执行当前检索。关闭或进入功能模型配置前确认未保存修改，读取失败时保留重试入口，保存失败保留表单。

| 页签 | 已实现选项及行为 |
| --- | --- |
| 自动提取 | 当前空间的待处理候选数、聊天数、处理中数量、失败数量及最近错误；下次检查时间和刷新入口；1–30 分钟检查间隔、自定义提取规则、资料自动更新与锁定 |
| 检索 | 四通道权重、按空间保存的云端向量开关、功能向量模型摘要与配置入口、向量维度统计及重建进度、使用当前草稿权重与阈值的模拟搜索 |
| 历史重建 | 当前空间绑定的聊天选择、全选与取消全选、8–48 条原始消息窗口、全部时间或包含起止日期的范围、确认开始、取消及实际进度 |

自动提取沿用至少积累 5 个候选的调度规则，失败候选参与重试；显示待处理与失败数量时分别统计。修改间隔后，调度器直接读取新的已保存计划，避免旧内存缓存阻止新间隔生效。

云端向量开关默认开启以延续已有绑定行为，关闭后，当前空间的记忆生成、文档分块、合并和检索均不发起向量请求。向量服务地址、密钥及模型继续在普通模型配置和功能绑定中管理。向量重建读取已保存的开关与绑定，未启用或未绑定时按钮不可用；模拟搜索则显式传入当前草稿开关与相关性阈值，不保存这些草稿。

历史重建复用 ChatMemoryRebuildManager 和既有窗口规划器，追加或更新记忆。记忆设置入口固定写入正在浏览的空间，不改变全局活动空间；原聊天历史设置入口仍按原有角色绑定规则分配目标空间。两处共用日期选择组件和单个后台任务。已有任务运行或取消清理期间不启动第二个任务，当前窗口只能取消自己空间的任务；完成及取消后刷新图谱、目录和维度统计。

## 参考与兼容

页面分组和选项含义对照新版角色插件 plugins/packages/buildin/character_cards/resources/character-memory.html 及相关记忆设置代码。当前实现使用 Operit Android 的现有 Compose 页面和后台服务；向量配置使用本轮前已完成的功能模型绑定。

本轮不改变角色、聊天或用户资料的存储格式。新增的云端向量开关保存在对应记忆空间的现有搜索偏好中。新增文案由九种语言的 strings_memory_settings.xml 提供，格式参数一致。

## 用户偏好页面的归属判断

保留独立用户偏好页面。该页还承担记忆空间创建、切换、重命名、删除与旧档案查看；这些管理操作作用于记忆空间，多个角色可能共享同一空间。角色卡提供当前绑定资料的就近编辑和预览，记忆设置提供空间级自动更新与锁定，两者使用相同存储。将整页直接移入单张角色卡，会混淆角色和共享空间的管理范围。
