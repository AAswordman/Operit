# 第十九节：侧边栏插件入口与包管理操作面板

## 原状与目标

聊天历史已使用可滚动的惰性列表，没有创建数量上限。注册的插件入口使用 36dp 导航行，区域高度固定限制为 108dp，文字和点击范围过小。本节保留聊天历史独立滚动，将插件区改成可折叠的完整按钮列表，高度随内容变化并受抽屉剩余空间约束。

包管理的排序、筛选和更多操作使用下拉菜单；技能与 MCP 仍使用右下角市场及导入按钮。统一用带标题、图标与选中状态的底部操作面板，四个标签页统一在顶部显示市场及添加或导入入口，技能与 MCP 不增加插件排序规则。

## 实现范围

- 插件导航入口最小高度 48dp，文字和图标增大，使用有边界的完整按钮。插件区可以折叠，多个入口可滚动，聊天列表占剩余高度，不限制聊天创建数量。
- 插件排序、筛选和包管理更多操作使用统一的底部面板，保留全部现有操作及保存规则。
- 删除技能顶部目录卡片，市场和导入移至顶部，刷新和加载错误移到操作面板。
- MCP 市场与导入移至顶部；原播放按钮继续调用 MCP 初始化链路，改成有文字的启动服务按钮，保留服务连接统计与刷新能力。
- 删除设置中的 UI 调试工具、工具测试中心入口。先追踪路由和其他调用，删除独立的测试中心逻辑；UI 调试器仍有共用调用的部分保留。
- 审核工作流 PR #1294 的实际代码与现有分支差异，确认兼容后整合；工作区重构暂不纳入。
- 关闭已整合的上游 PR #1112、#1244、#1191，不删除源分支。

## 实现结果

- 插件入口改为最小 52dp 的完整按钮，支持两行名称。插件区可折叠，展开列表最多使用抽屉内容区高度的 30%，少量入口按内容收缩；聊天历史继续使用剩余空间独立滚动。
- `ActionSheet` 为包管理和工作流提供统一圆角操作面板。排序可以在面板内选择依据与方向，筛选和操作项点击后关闭，全部设置沿用现有持久化。
- Skill 删除顶部目录卡片及市场、导入和错误悬浮按钮。顶部保留市场、导入，更多面板包含刷新和加载错误；原有详情、导入方式、搜索与拖动行为保留。
- MCP 删除顶部状态卡片和三枚悬浮按钮。市场与导入位于顶部，状态行提供启动服务、加载进度和刷新；状态统计随配置更新，只计入已启用且已取得工具的服务。
- 设置移除 UI 调试工具和工具测试中心。工具测试中心独立实现及路由已经删除；UI 调试器保留供原生导航及悬浮窗调用的实现。
- 已整合 [#1294](https://github.com/AAswordman/Operit/pull/1294) 的三次提交，包括列表与详情重构、复制、JSON 导入导出和画布点阵。工作流执行引擎保持原有实现；画布背景及提示补充跟随深浅主题，列表更多操作使用共用面板。
- [#1112](https://github.com/AAswordman/Operit/pull/1112)、[#1244](https://github.com/AAswordman/Operit/pull/1244)、[#1191](https://github.com/AAswordman/Operit/pull/1191) 已关闭，源分支保留。工作区重构本轮未纳入。
