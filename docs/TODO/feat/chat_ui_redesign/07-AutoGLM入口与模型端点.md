# 第七节：AutoGLM 入口与模型端点

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

测试全部通过。完整操作与预期保留，结果如下。

AutoGLM 的旧一键配置直接写入模型名与智谱标准端点，再自动绑定 UI 控制器和切换自动化工具包。它没有通过模型列表获取 AutoGLM。模型配置已提供同一个标准端点，内置自动化脚本也已提供主屏幕、虚拟屏幕和并行执行工具。

## 改动范围

- 将智谱中国标准端点的说明从 `CN standard` 改为 `CN standard / AutoGLM-Phone`，实际 URL 保持 `https://open.bigmodel.cn/api/paas/v4/chat/completions`
- 移除工具箱中的 AutoGLM 一键配置和 AutoGLM 执行卡片，内置卡片从 13 个减到 11 个
- 保留这两个页面的隐藏原生路由，以及既有模型配置、UI 控制器绑定和插件运行能力
- 不增加模型提供商类型、模型列表预置或新的执行工具；其他标准、Coding 端点及其说明保持原样

## 配置与执行

1. 在模型配置中选择智谱提供商与 `CN standard / AutoGLM-Phone` 端点
2. 填入智谱 API 密钥和模型名 `autoglm-phone`，开启模型支持图片解析
3. 在功能配置中将 UI 控制器绑定到该模型配置
4. 在插件管理中启用自动化 AutoGLM 子代理，使用现有主屏幕或虚拟屏幕执行工具

选择端点不会自动替换模型名、创建模型配置、绑定 UI 控制器或切换插件。端点说明也不代表远程模型列表会返回 AutoGLM。

依据：[智谱 AutoGLM-Phone 官方调用指南](https://docs.bigmodel.cn/cn/guide/models/vlm/autoglm-phone)，其示例使用 `https://open.bigmodel.cn/api/paas/v4` 与模型名 `autoglm-phone`。
