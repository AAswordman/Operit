# 上下文统计与累计用量

当前聊天顶栏用圆环和下拉菜单显示窗口占用及累计输入、输出 Token，统计入口夹在悬浮窗与工作区之间。PR #1249 提供了请求窗口的分类估算，但没有累计用量页。

本轮采用已确认的 B2 排版：在输入设置的记忆分组上方增加上下文区块，显示窗口占比、已用与上限、当前对话累计用量。点击整块后关闭设置菜单，打开居中的上下文与用量弹窗。

## 作用域

- 将 #1249 的请求快照、分类估算接入现有消息准备链路，详情读取不发布窗口估算，也不更新累计计数
- 新建 `core/chat/context/` 与 `ui/features/conversation/chat/modules/usage/`，分别承载窗口拆分与统计界面
- 窗口占用页展示消息历史及用户、AI、工具结果子项，系统提示词、常驻工具、MCP/包工具、技能目录、压缩摘要和其他占用
- 显示剩余空间、自动总结缓冲与设置阈值，复用现有手动总结操作
- 累计用量页读取当前对话已有输入、输出计数，展示总计及输入、输出构成；不从当前可见消息重新求和
- Agent 与经典输入设置共享入口和弹窗，移除两个顶栏圆环调用点及旧组件
- 补齐字符串、估算回归用例和本轮实机检查清单

## 实施顺序

1. 接入窗口快照与分类估算，保持既有窗口计算接口行为
2. 实现上下文入口、窗口页、累计页及总结状态
3. 接入两种输入设置并清理顶栏旧入口
4. 核对差异、资源与调用点，推送分支并派发 Android Tests、assembleDebug

## 标题主题配色修正

输入设置中的“上下文”标题显式使用 `MaterialTheme.colorScheme.onSurface`，两种输入样式共用同一入口。默认浅色主题显示深色文字、深色主题显示浅色文字，切换主题时随配色更新，避免继承弹窗的默认黑色。窗口与累计详情由既有主题 Surface 提供文字色。
