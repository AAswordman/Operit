# 工作区与终端统一入口

## 原有状态与目标

聊天页右上角分别提供终端和工作区按钮，两者直接打开各自的浮层。对照参考工程的 `WorkspaceTopBarButton`、`WorkspacePanel` 和 `WorkspaceHomeContent`，改成一个工作区入口，打开独立的主页，再进入工作区或终端。

## 作用域

- 工作区统一导航状态、主页和页面容器位于 `ui/features/conversation/workspace/hub/`。
- 右上角保留一个工作区按钮，继续使用已绑定/未绑定的图标；进入时隐藏输入法。
- 主页显示当前工作区、关联对话和角色卡、绑定目录、实际终端会话数，以及创建、选择、工作区和终端入口。
- 创建和选择入口直接调用现有项目模板弹窗与目录选择器；保留 Android、Linux 和 SAF 工作区的绑定能力。
- 工作区复用现有文件管理、编辑、预览、命令和导出；终端复用现有终端页面及会话。
- 页面间切换保留工作区编辑状态；终端不可见时移出组合，保留已有 SurfaceView 释放规则。
- 返回先从工作区/终端回主页，再从主页回聊天；准备过程可取消，取消后不得异步重新打开页面。
- 本节是入口与页面结构迭代，不更改数据库、归档格式、工具 API 或工作区存储路径。
