# 工作区与终端统一入口回归清单

测试全部通过。完整操作与预期保留，结果如下。

本清单覆盖本节入口和复用功能。覆盖工作区与终端的统一入口及原有功能。

## 操作与预期

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 01 | 在聊天页查看右上角；输入文字后点击入口 | 仅一个工作区入口；隐藏键盘并打开主页 |
| 02 | 无当前对话时打开和关闭主页 | 显示未绑定提示；不自动创建空对话 |
| 03 | 未绑定时点击创建工作区 | 直接显示现有项目模板弹窗；选定后绑定当前对话 |
| 04 | 在创建弹窗点击取消或按返回 | 返回主页，不进入旧设置面板 |
| 05 | 未绑定时点击选择工作区并取消 | 直接显示目录选择器；取消后返回主页 |
| 06 | 分别绑定 Android、Linux、SAF 目录 | 绑定环境和路径保持正确；主页显示对应目录 |
| 07 | 多个对话、普通角色卡和群组共享同一目录 | 概览按路径及环境统计对话，角色卡含群组成员并去重 |
| 08 | 已绑定时点击工作区入口或概览中的目录 | 打开现有工作区文件管理；编辑、预览和导出入口可用 |
| 09 | 修改文件后切主页、终端、聊天，再回工作区 | 已打开文件、内容和未保存标记保留 |
| 10 | 从主页或会话统计点击终端 | 打开现有终端；已有会话保留，数量与管理器一致 |
| 11 | 在终端新增/关闭会话并回主页 | 会话数更新；离开终端时显示层释放，无终端残影 |
| 12 | 工作区或终端按返回，再在主页按返回 | 先回主页，再回聊天 |
| 13 | 工作区预览浏览多个网页后按返回 | 先处理现有网页返回，再返回主页 |
| 14 | 工作区准备中按返回、点入口关闭或切换对话 | 准备任务取消；不异步重开，也不更新旧对话的工作区 |
| 15 | 工作区后台命令打开终端 | 切到统一页面中的终端；主页和工作区入口仍可访问 |
| 16 | 工作区解绑/重命名/关闭未保存文件时切页 | 弹窗仅在工作区可见时显示，不覆盖主页或终端 |
| 17 | 切换浅色、深色、背景主题和不同语言 | 页面跟随主题；新字符串完整，无写死颜色或中文文案 |
| 18 | 在聊天悬浮窗、嵌入聊天和其他主页面查看入口 | 统一入口仅在主聊天页显示；隐藏页面不抢返回或输入 |
