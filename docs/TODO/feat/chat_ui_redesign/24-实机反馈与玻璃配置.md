# 第二十四节：实机反馈与玻璃配置

多人实机测试发现页面切换叠影、侧栏在部分手机上占用过宽、进入设置有等待、悬浮窗沿用默认角色以及自定义色显示不符的问题。外观反馈还包括侧栏玻璃高光过强、包管理两个按钮配色不协调和记忆空间菜单层级不足。本节同步这些反馈对应的修复，并补充按主题保存的玻璃外观配置。

## 运行与交互

- `AppContent` 限制页面绘制边界；隐藏的留存页面不放置，退场页面关闭触摸、焦点和无障碍语义；聊天页离开时不再与透明的新页面交叉绘制，避免聊天气泡、输入框和顶栏透到设置与包管理页面
- 导航动画关闭时采用零时长切换；未进行跨页转场时直接呈现当前页，不沿用复用页面上次的透明度
- `DrawerContent` 同时触发页面导航和抽屉关闭，不再等待关闭结束后才切页；`PhoneLayout` 在图层阶段读取抽屉动画进度，减少逐帧重组
- 手机侧栏按当前窗口宽度的 66% 展开；平板沿用已有布局
- `FloatingChatService` 发送消息时采用 `preferActiveRoleCard = true`，与主聊天界面保持一致；历史消息归属和会话模型保持原有规则

## 玻璃与配色功能

“主题和外观 → 界面”增加玻璃预览、五个参数滑块和参数恢复默认。默认值为模糊半径 12dp、边缘宽度 0.4dp、边缘高光 18%、阴影半径 4dp、表面不透明度 24%。范围分别为 0–40dp、0–2dp、0–80%、0–20dp、0–100%；边缘、高光和阴影归零时关闭对应绘制。

`GlassThemePreferences` 注册独立主题键，`GlassAppearance` 读取当前主题；`LiquidGlass` 与 `WaterGlass` 统一使用这些参数，移除调用方的硬编码外观。已有输入框、聊天气泡和侧栏开关继续生效。去除额外饱和度、对比度调整并减弱折射、高光及阴影，降低薄膜般的观感。

新增对话列表、设置分组与卡片、包管理列表与按钮三个独立磨砂开关，默认关闭。对话列表作用于聊天行；包管理覆盖插件、沙盒包、Skill、MCP 列表及市场与添加/导入按钮。设备需支持现有 Android 13 玻璃实现。

侧栏重新读取旧主题保存的背景色、选中背景色及对应启用标记，并依据表面明暗选择文字。界面页提供这两项选色和独立恢复默认。包管理获取入口统一为 FilledTonalButton，市场与添加/导入按钮分别提供背景选色和恢复默认，文字按合成表面选择对比色。透明底色仍会与背景混合，表面不透明度为 100% 时保留所选底色。

参数、区域开关和按钮颜色接入既有主题读取、保存、复制和重置路径。`ThemeEditorSession` 先编辑草稿，保存和放弃沿用既有机制；最近选色复用已有记录。新增字符串覆盖现有九种语言。

## 设置标题与插件默认图标

后续外观反馈要求颜色定制同时作用于设置主页的分组标题与插件默认图标。此前这两处固定采用黑白正文色，即使开启颜色定制，也不会跟随主色。

`SettingsScreen.SettingsSection` 读取当前主题的 `useCustomColors`：关闭时沿用 `onSurface`，保持浅色黑字、深色白字；开启时为全部九个分组的标题文字及对应图标使用 `MaterialTheme.colorScheme.primary`。组内设置条目的文字与图标继续采用现有正文配色。

`PluginTabContent` 仅为默认九点图标增加相同的开关判断：开启时使用当前主题主色，关闭时沿用原有内容色。插件自带 Logo 与禁用条目的透明度保持原样。插件开关已采用 Material 主题配色，本次沿用其实现；主色的深浅主题适配共用现有颜色解析，不增加配置键或改变主题保存格式。

此项调整在原 194 项完整清单后补充 6 项，全部保留为未测；原有操作和历史结果继续保留。

## 菜单与布局

权限、工作流入口采用图标加双行文字，间距 12dp，至少 56dp 高度并可随字体自然增高。自建记忆空间操作改为主题色圆角按钮和 16dp 圆角菜单，重命名、删除配图标，删除使用危险色；默认空间只可重命名和删除确认流程保持原样。

## 验证
