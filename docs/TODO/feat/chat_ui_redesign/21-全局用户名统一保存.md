# 第二十一节：全局用户名统一保存

## 原状与目标

显示与行为、主题设置都提供全局用户名输入，两处读写同一个 `DisplayPreferencesManager.globalUserName` 字段。主题页用户名单独保存在组件状态中，右侧按钮直接写入；修改名字不会触发主题草稿的变更标记，也不会纳入离开页面时的保存或放弃流程。

## 实现范围

- 删除显示与行为中的用户名输入框及其独立状态。
- 主题页保留唯一入口，删除输入框右侧的单独保存与直接写入逻辑。
- 在主题编辑会话中独立维护全局用户名草稿与基线，名字变动参与底部保存激活、放弃修改和离开提醒。
- 统一保存仍写入原有全局名字字段，不引入角色专用用户名；只改名字时不写入角色主题。
- 恢复原输入后不再标记名字为未保存，清空后统一保存可清除名字。视觉主题重置不改动全局用户名。

## 实现结果

显示与行为不再创建用户名输入状态。主题设置的用户名由 `ThemeEditorSession` 独立维护全局草稿和基线，输入参与变更标记，原有离开与切换角色提醒复用同一标记；放弃时恢复名字，视觉重置保持名字。

统一保存捕获点击时的用户名；修改过名字才写入 `DisplayPreferencesManager` 的原全局字段。只改名字时跳过角色主题写入；保存期间继续输入仍作为新草稿保留。主题页不再提供名字的独立保存按钮或即时写入路径。
