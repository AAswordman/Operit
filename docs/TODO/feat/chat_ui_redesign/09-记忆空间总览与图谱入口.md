# 第九节：记忆空间总览与图谱入口

## 原状与目标

侧边栏的记忆库直接进入图谱，切换文件夹面板中的空间或从用户资料打开关联空间都会修改聊天使用的全局活动空间。记忆空间的创建、重命名与删除分散在用户资料设置里，角色卡的记忆绑定也不易一眼看清。

设置的提示词配置区在角色卡编辑下增加记忆管理入口。总览列出当前全局空间、全部记忆空间和每张角色卡的绑定状态；点空间进入已有图谱，浏览不改变全局，只有显式更换全局空间才影响聊天。图谱节点绘制、布局、搜索与记忆数据结构保持不变。

## 改动范围

- 记忆库从侧边栏移到设置，保留旧原生路由和聊天中的记忆入口，统一指向总览。
- 总览支持新建、重命名、删除空间及调整角色记忆绑定；删除前提示角色绑定和记忆数据会受影响，沿用既有数据管理接口。
- 用户资料页面维持独立；其“打开关联记忆库”直接传空间 ID，不设为全局。用户偏好编辑、自动更新与锁定仍在原页面，云端 Embedding 仍在现有记忆搜索设置里。
- 空间详情直接按 ID 加载既有记忆 ViewModel；文件夹面板只导航该空间的文件夹，不再切换空间。
- 图谱外围将多枚悬浮按钮收拢为搜索栏下方操作区和添加菜单，保留框选、批量删除、连接、新建记忆、导入文档功能；图谱本体不动。

## 验证边界

静态检查覆盖导航、空间 ID、按钮功能映射、资源 XML 与差异格式。本地依仓库规范不运行编译或测试；真实设备上的长名称、紧凑窗口、返回导航与图谱触摸交互需回归验证。提交后触发仓库 Android Tests 和 assembleDebug，执行结果不在本轮轮询。
