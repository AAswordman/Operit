# 透明顶部、侧栏主题动画与记忆向量模型

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

## 背景与目标

设备反馈指出系统状态栏与工具栏仍显示独立色块，深色主题的系统信息与部分标题缺乏对比。侧栏权限和工作流位置也不符合要求。记忆向量模型仍单独在记忆库填写连接参数，角色编辑页只能点击切页。

## 实现范围

1. 系统状态栏始终显示系统信息并采用透明背景，工具栏保留导航但改为紧凑透明区域；删除相关主题开关与独立颜色入口，统一根背景、页面底色和文字对比
2. 权限、工作流置于角色卡上方，插件入口仍直接按名称导航
3. 侧栏深浅切换从按钮位置扩散覆盖整个应用；设置页及系统主题变更直接生效
4. 角色编辑基础、内容、绑定采用可滑动分页，点击标签也有切页动画，保留表单和各页滚动状态
5. 功能模型增加记忆向量绑定，复用模型配置中的端点、Key、模型索引和请求头；功能页连接测试及记忆生成、搜索、重建共用绑定
6. 移除记忆库的独立向量模型编辑入口，保留权重、提取规则、维度统计、重建与模拟搜索；本轮不改记忆库页签布局

## 界面实现

系统状态栏由 `OperitTheme` 保持显示，背景固定透明并关闭系统对比色遮罩，系统图标随深浅模式切换。`AppContent` 对非聊天页面采用 48 dp 的透明顶部，标题与操作使用页面文字色；聊天沿用透明控件行。页面表面色与根背景统一，主题设置移除顶部透明、系统栏隐藏、独立颜色和强制顶栏文字色的编辑入口及对应偏好读取。

侧栏品牌行之后依次显示权限与工作流、角色卡和对话目录。插件入口继续位于目录下方，底部仍是包管理、设置及主题按钮。

`ui/theme/transition/ThemeRevealHost.kt` 捕获侧栏按钮切换前的旧画面，等待新深浅主题进入组合，再从按钮位置揭示新主题，动画持续 480 毫秒。转场期间拦截重复点击，成功、异常或主题变化等待超时都会清理截图。只有侧栏按钮调用动画控制器，设置页及系统模式变化直接更新主题。转场临时持有一张全屏截图，其设备内存占用和视频背景表现仍待实机验证。

角色卡编辑的基础、内容、绑定改为 `HorizontalPager`，点击标签也平滑切页。草稿仍在外层共享，各页独立保留滚动状态；保存、取消、全屏编辑和绑定选择沿用原有入口。

## 记忆向量模型

用户先在模型配置创建云端向量模型，再到功能模型配置的“记忆向量”卡片选择配置和具体模型。该卡片的连接测试发送 OpenAI 兼容的向量请求，成功时显示模型名称和返回的向量维度。记忆库设置展示绑定模型，并提供进入功能模型配置的入口。

`data/embedding/MemoryEmbeddingModelResolver.kt` 统一读取 `MEMORY_EMBEDDING` 的配置 ID 与模型索引。记忆创建、文档分块、内容更新、记忆合并、语义搜索、模拟搜索和向量重建均通过这个解析器读取当前绑定；功能页连接测试使用相同的解析器和 `CloudEmbeddingService`。所有记忆空间共用功能绑定，各空间的搜索权重、提取规则和自动保存间隔仍分别保存。

普通模型配置中的 `/chat/completions` 和 `/responses` 地址会转换到同一服务的 `/embeddings`，服务根地址和 `/v1` 基址会补上向量路径；已填写的向量地址保持对应路径。完整自定义地址可用末尾 `#` 固定。端点转换保留原始路径和查询参数编码，并校验 HTTP 地址。请求复用单 Key 或 Key 池及自定义请求头，向量响应必须包含非空的有限数值数组。

记忆向量初始为未绑定。解绑、重置功能配置或删除已绑定模型均清空向量绑定；未绑定时不启用云端向量调用，重建入口报告需要配置。不存在的模型配置和越界模型索引会明确报错。切换向量模型后，应使用记忆库现有重建入口统一已保存的向量。

旧的 `CloudEmbeddingConfig`、记忆库独立连接参数读写和编辑控件已移除。此前此开发分支中的独立连接参数不再作为请求来源，需在模型配置中创建并绑定模型。已有记忆、文档分块及向量索引的数据格式保持不变。
