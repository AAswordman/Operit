# 第十四节：对话与角色进入主侧边栏

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

## 原状与目标

主侧边栏仅负责应用导航，聊天页另外提供角色与历史面板，两层顶部区域挤占消息空间。本节将角色和嵌套对话目录放进主侧栏，并以紧凑透明控件行保留当前对话标题和常用操作。

设备反馈表明，第一版侧栏的大号卡片、常驻搜索框和底部竖排按钮占用过多空间；目录标题继承了聊天主题的文字样式，深色背景下可能无法辨认。本节在既有迁移基础上缩小控件，明确目录文字与背景的对应关系，并移除重复入口和失效设置。

## 实现范围

- `ui/features/conversation/chat/modules/sidebar/` 提供侧栏组件、共享状态和 `MainChatControls`。`OperitApp` 创建 Activity 级 ChatViewModel，侧栏和主聊天路由共用当前对话、生成状态、历史筛选及角色切换设置。
- 侧栏品牌与收起按钮使用一行，角色头像、名称及切换箭头使用下一行，旁边用小图标打开角色管理。角色卡和群组选择继续复用现有选择面板，头像规则不变。
- 目录工具行包含 36dp 高的新建对话按钮，以及文件夹、搜索和历史设置图标。搜索由图标按需展开为 36dp 高的输入框，主动展开时请求焦点；关闭抽屉或跳转前清除焦点并收起输入法。
- 嵌套目录占剩余高度。原有三种显示方式、搜索、排序、拖动、置顶、锁定、绑定编辑、删除和目录数据继续复用。目录主标题、次级信息、选中行和拖动预览明确设置对应文字色，侧栏自定义背景也传递给目录。
- 权限和工作流在目录下方并排为细长导航行。插件注册的侧栏入口直接按名称显示为 36dp 高的行，点击即进入对应页面；没有注册入口时不显示插件总按钮或零数量占位。入口较多时独立滚动，底部操作保持固定。
- 底部包管理与设置采用等宽 36dp 高的横排按钮，右侧增加 36dp 的深浅主题切换图标。切换通过现有主题存储写入当前角色卡或群组，关闭跟随系统并保存所选模式；重新打开应用后保留。
- 主聊天路由隐藏应用工具栏及原聊天内部顶栏，改为 44dp 高、上下各 4dp 的透明控件行。左侧为菜单和当前对话标题，右侧从左到右为悬浮窗、上下文用量、工作区/终端统一入口。长标题单行省略，菜单保留多对话生成数量提示。
- 消息区域与工作区/终端页为透明控件行预留 52dp，滚动消息和工作区页签不会覆盖顶部操作。工作区入口继续使用原有切换及取消准备任务逻辑，主页和终端功能不变。
- 主题设置移除旧聊天顶栏的透明、覆盖模式和历史/悬浮窗图标颜色入口，同时清理对应 Android 展示分支与图标颜色配置。设置、包管理等页面继续保留工具栏与返回操作，设置名称改为“其他页面工具栏”并说明作用域；九种语言同步更新。
- 手机和较宽布局共用展开侧栏。手机保留按钮、右侧遮罩、遮罩左滑和系统返回关闭，目录拖动不与全屏抽屉手势争用。平板折叠栏可重新展开。
- 从侧栏新建、选择对话或切换角色时，先关闭手机抽屉，通过路由离页检查后再修改状态并返回消息页；被阻止时不会提前切换。悬浮和嵌入聊天保留自身历史、角色入口。

## 数据与兼容性

本节不迁移对话、目录、角色绑定或主题数据，保留历史显示方式及自动切换的原有偏好键。HTTP 主题响应仍使用其原有字段，旧聊天顶栏透明与覆盖配置仅由该既有响应读取，Android 主题页不再提供相应设置入口。

包管理的插件、沙盒包、Skill 和 MCP 分类保持现状。插件侧栏导航仍使用原有注册条目和路由，变化仅为展示方式。
