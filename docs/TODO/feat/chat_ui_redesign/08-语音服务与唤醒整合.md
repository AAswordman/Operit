# 第八节：语音服务与唤醒整合

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

语音配置原本分布在工具箱、助手配置与语音服务配置。用户需要跳转到工具箱测试识别，旧测试页默认使用本地引擎，不能直接验证当前选中的 STT 配置；唤醒行为和系统默认助手引导又位于另外两处。本节把它们归入语音服务配置。

## 改动范围

- 语音服务配置增加语音唤醒页签，与原有 TTS、STT 页签并列；切换页签回到内容顶部，唤醒页签不显示 TTS/STT 配置管理和说明
- TTS 保留现有配置与试听入口，工具箱的文本转语音卡片移除
- STT 配置下方直接展示识别测试区，使用当前配置 ID、引擎及正在编辑的端点、密钥、模型名，提供语言选择、开始、停止、识别状态、可选中结果和复制
- 识别测试先检查麦克风权限；配置变化、切换页签、离开页面和进入后台时结束由测试区发起的录音，并释放测试服务；共享本地服务正在识别时不会发起另一次测试
- 原助手配置中的完整唤醒设置迁入独立的 `settings/components/speech` 组件，包括识别模式、个人模板、持续监听、唤醒词与正则、通话超时、问候、新建对话分组和关键词附加内容
- 个人模板仍录制三次并沿用原有存储格式；录制前申请麦克风权限，保存完成后关闭弹窗，离开页面或进入后台时取消采集并释放录音资源
- 语音唤醒页签顶部提供一个打开 Android 系统助手设置的按钮，直接使用 `ACTION_VOICE_INPUT_SETTINGS`；无法打开时提示并记录错误
- 工具箱移除文本转语音、语音识别和默认助手设置三个卡片，内置卡片从 11 个减到 8 个；其他卡片及 ToolPkg/ComposeDSL 注册方式保持原样
- 原生路由 ID 保留：文本转语音仍打开既有试听页面，语音识别复用新测试组件，默认助手路由转入语音服务的唤醒页签；原有默认助手教程页面及包装器删除
- 助手配置页移除唤醒页签及相关状态，仅保留现有虚拟形象预览、导入和配置
- 九种语言补齐三个识别测试字符串；已有语音配置键、服务选项及唤醒偏好不迁移或清空
