# 插件详情与工具运行弹窗

## 原有行为

沙盒包详情没有显示脚本声明的环境变量，工具列表的参数信息只列前三项。运行弹窗提供一个高度 160dp 的源码编辑框，编辑仅用于当前执行、不保存到插件，参数说明放在输入框的占位文字里，未聚焦或已有内容时不易查看。详情与运行弹窗都受默认平台窗口宽度和 600dp 高度上限约束。

## 本节目标

对照参考工程 `PackageDetailsDialog.dart` 与 `PackageToolRunDialog.dart` 调整已有 Android 弹窗。

- 从工具运行入口移除源码编辑框及临时源码状态，继续执行工具原本的脚本
- 详情完整显示声明的环境变量名称、说明及必填/可选标记；运行时简要提示使用包环境变量，与工具参数分开
- 标题、信息、环境变量和工具列表按参考图重新排版，保留现有工具包子包、状态切换、插件配置、性能监测与删除功能
- 参数输入框使用圆角，参数说明常驻在框下方并完整换行，必填星号保留；提示词输入保留多行能力
- 弹窗扩大到屏幕可用宽度，较大屏幕限制最大阅读宽度；根据可用高度和键盘收缩，中间内容滚动，底部操作持续可见
- 颜色跟随现有主题，沿用既有环境变量配置与执行接口，不增加源码保存、超时参数或配置存储
