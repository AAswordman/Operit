# 第二十节：侧边栏玻璃与默认配色

## 原状与原因

新侧边栏的导航行、插件按钮和底部快捷入口没有调用 `liquidGlass`，虽然偏好仍保留磨砂开关，展开侧栏的按钮实际不响应。水玻璃只采集应用背景，纯色背景没有纹理；底色在采样修饰符外绘制，也没有完整进入采样层。侧栏水玻璃的低底色覆盖和 6–8dp 模糊使它更接近透明面板。

## 目标与作用域

- 为新侧栏的导航、插件及底部按钮统一恢复磨砂背景；保持文字、图标和选中状态清晰。
- 背景底色、图片和视频先合成再统一采样，避开侧栏自身和前景内容，避免循环采样。
- 单独提高侧边栏水玻璃的模糊强度和主题底色覆盖；输入栏及消息气泡沿用原有参数。
- 删除侧栏专用背景色与强调色控件，以及色板选择器中对应的入口和回调。侧栏渲染只使用当前主题的默认配色。
- 保留旧主题数据字段的读取与导入兼容性，但侧栏不再应用旧颜色覆盖。两个玻璃开关继续保存与恢复；不支持的 Android 版本禁用对应开关并说明条件。
- 工作流 UI PR #1294 已关闭，源分支保留。

## 实现结果

`SidebarButtonSurface` 统一使用玻璃修饰符，启用时移除实色覆盖，保留普通模式、点击和选中状态。权限、工作流、已注册插件和底部三项入口都复用该组件；按钮模糊为 18dp，关闭折射，贴合磨砂选项含义。

应用背景在完整合成层统一提供水玻璃采样，包含底色与图片或视频，不采集前景文字与玻璃自身。侧栏的水玻璃模糊提高到浅色 18dp、深色 24dp，底色覆盖提高到 29% 和 36%；其余水玻璃调用沿用原有参数。

侧栏渲染只读取当前主题配色，设置页独立展示两种玻璃效果。专用颜色控件、色板分支和回调已删除；旧主题字段留在数据格式中以兼容预设导入。Android 13 以下禁用玻璃选项，并显示支持条件。

工作流 UI [#1294](https://github.com/AAswordman/Operit/pull/1294) 已关闭，源分支保留。[完整回归清单](20-回归清单.md)共 95 项，包含此前全部检查。

实际玻璃观感和视频采样需由设备回归确认。本地仅核对源码与资源；Android Tests 和 assembleDebug 在最终提交推送后派发。
