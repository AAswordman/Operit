# 扩展统一更新与内置来源

基于扩展详情页分支 070b71a2，原分支保持。此前更新检查分散于单项详情，只有市场安装标记可以查询；内置插件与脚本入口在离线资源，更新缺少跨界面执行隔离。

## 已实施

- 插件与脚本列表上方共用检查更新，左侧显示更新数量。检查结果由列表、详情共享；更新按钮直接调用下载与安装，不跳转市场详情
- 检查并发限制为 4，单项来源失败单独记录，不能误报所有内容均为最新。手动导入且无来源标记的内容不猜测市场身份
- 更新期间插件与子包、脚本的开关、打开及执行入口禁用。同步调用、流式调用收集及等待引擎后的派发均检查真实状态。插件返回 package is unavailable/disabled，脚本返回 script is unavailable/disabled，后接对应 ID
- 更新拥有独立状态，不改用户启用偏好。安装前停止相关插件运行时、释放内置资源引用并暂时撤出可用运行时集合；完成、失败、取消均清除状态并重新加载。更新结束前重新绑定已激活工具，移除新版已删除的工具，并关闭持有旧脚本的执行对话框。相同插件的新旧子包不允许同时被另一次更新覆盖
- 市场的精选左侧增加内置来源，插件和脚本可搜索、下载与更新。内置目录由 APK 固定包身份，显式检查更新时读取维护者资源仓库的最新正式资源发行，按 v2 合并目录和 v3 独立目录识别内置内容。下载仍按固定 URL、大小与 SHA-256 校验
- 40 项内置内容从 offline-packs.json 移到独立的 builtin-extensions.json；离线资源只剩 11 项模板、引擎与模型组，移除对应分类和安装入口。已有安装目录、校验记录和启用设置保留；查询目录新版本不会隐藏已验证的旧安装
- 后续资源准备生成 resources-v3 发行，避免改写已公开的 resources-v2 附件。目录、APK 打包输入、资源产物及发布复用检查均同步验证两份清单
- 市场列表、详情和更新进度改为紧凑的阶段文字与横向进度条，保留传输量、速度、耗时与剩余时间
- 消息信息在生成回复时保存带思考强度的模型显示名，例如 codex/gpt-6.1-sol(max)。该显示元数据沿用既有消息持久化，不改变请求模型名，不以当前设置补写历史消息；未启用或不支持强度档位时不添加强度

## 验证与边界

已完成静态差异格式、Python 语法、JSON/XML 解析和新资源 key 重复检查。固定目录检查核对了 51 项归档与 193 个源码文件。本轮复核了 12 个 Python 文件、2 份 JSON 和 9 种语言的 XML；两份目录重组后与原 51 项归档目录完全一致，文件 URL 和摘要未被重写。

回归源码覆盖停用/更新中的同步与流式调用、子包互斥，以及目录升级后的历史安装识别；资源构建/发布及 APK 检查用例已适配双目录。默认未执行本地构建测试。

待远程编译、回归和真机验收。内置更新发现兼容已发布的 v2 合并目录及后续 v3 独立目录；本次不公开发布资源或应用 Release。新版本清单与实际下载结果需要新包验证，不能把静态检查当作运行通过。
