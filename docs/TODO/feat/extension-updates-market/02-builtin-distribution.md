# 内置来源与资源分发

市场的精选左侧增加内置来源，沿用插件、脚本筛选与搜索。内置内容来自维护者资源目录，共 10 个插件和 30 个脚本。该入口不向外部市场服务器创建条目。离线资源的插件、沙盒分类和对应安装入口移除。

原 51 项固定资源元数据拆为 `app/config/offline-packs.json` 的 11 项普通资源及 `app/config/builtin-extensions.json` 的 40 项扩展。归档身份、安装目录、URL、版本和摘要保持；两份目录按原顺序重组与原目录完全一致。查询新版目录后，已有安装按实际安装版本的包名识别，新增子包不会让旧版安装消失。

显式检查更新时，通过维护者资源仓库的 Releases API 查找最近正式发行中的内置目录。APK 固定资源组身份、类型、路径与根包名，在线目录可以更新内容及子包。目录与归档均受路径和摘要校验约束。新目录尚未公开时报告来源检查失败。在线目录缓存随 APK 固定资源标签隔离，旧目录记入安装历史。

资源准备、APK 打包输入、资源报告、产物检查、发布附件和复用校验均纳入双目录。新准备产物使用 `resources-v3` 标签，开发固定目录继续引用现有 `resources-v2-d16730007f8d94095264` 的不可变归档。当前没有生成或公开新资源发行。

市场与内置下载共用阶段文字加横向进度条，保留字节量、速度、耗时和剩余时间。内置入口复用现有单调时钟速度采样，安装阶段不会被完成字节回调改回下载阶段。

源码实施 [DONE]，发布与运行验收状态见 [03](03-message-info-and-verification.md)。
