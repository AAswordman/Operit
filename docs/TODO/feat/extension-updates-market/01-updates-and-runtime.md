# 统一更新与执行隔离

此前扩展详情各自请求市场，并引导打开市场详情。现在列表上方的公共入口统一检查已安装插件、脚本的市场标记和内置来源，列表与详情共享结果。请求并发为 4；单个来源失败保留失败状态，不按成功检查处理。没有市场标记的手工导入项不猜测来源。

发现更新后，列表和详情中的开关位置显示更新按钮，直接下载并安装。检查目录与安装互斥，避免下载时清单切换。更新状态与启用设置独立，插件根包、旧子包及新版子包在替换期间共同锁定。更新时禁止开关、打开界面、执行和删除；工具卡片使用禁用颜色。

同步脚本入口与流式收集入口在进入及等待引擎后检查可用性；ToolPkg Hook 和 Compose DSL 的派发也检查更新状态。插件返回 `package is unavailable: <id>`，脚本返回 `script is unavailable: <id>`。对象类型保存在独立更新状态中，文件替换导致旧映射消失时仍能返回正确类型。

替换期间依赖图会短暂不完整，清理逻辑只更新有效运行集合，不把缺失节点当作用户撤销启用。完成后重新加载包元数据并绑定已激活工具，清掉新版删除的工具，再解除更新状态。完成、失败及取消后的清理使用不可取消上下文。保留的脚本执行对话框在版本修订时关闭，避免再次提交旧脚本。

相关回归源码覆盖同步与流式入口在停用、更新时的拦截，子包重叠更新与目录检查互斥；尚未执行。
