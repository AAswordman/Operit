# 内置资源管理与检查反馈

设备反馈指出，内置资源迁到市场后缺少原有的 ZIP 导入、导出和删除，启用胶囊的触摸尺寸也扩大了可见边框。更新检查还需要直接提示空来源与完整失败原因。

本轮范围：

- 可见启用胶囊收紧到开关轨道加少量内边距，48dp 触摸区域留在边框外
- 内置市场外层明确展示资源目录的真实版本；该值是内容版本，不能伪称工具声明的语义版本
- 添加插件和脚本面板增加独立的内置资源 ZIP 导入入口，选择目标资源后使用原归档校验，不交给普通 JS/ToolPkg 导入器
- 已安装内置扩展详情底部按性能监测、导出、删除排列，导出完整 ZIP，删除仍需确认
- 导入和删除沿用更新执行隔离，停止旧运行时并释放引用，结束前刷新并重绑定工具
- 检查结束统一使用 OKToast，覆盖没有可检查来源、已是最新、有更新和完整来源错误，删除红字与二次弹窗

保留详情页子包数量、子包列表和完整简介，外层不恢复子包数量。资源 ID、版本、文件路径、摘要和历史安装兼容仍使用原协议。


内置市场使用当前目录的资源版本；已安装列表中，工具声明的语义版本照常展示。没有声明版本的内置脚本显示实际已安装资源的版本，并明确标为资源版本，避免把内容摘要写成 v1.0 一类工具版本。

ZIP 导入先选择当前类型对应的资源，再校验 operit-resource.json、资源身份、受支持版本、完整文件清单和 SHA-256。导出只包含实际安装的资源目录，不包含组目录中的安装记录；失败或取消会删除不完整的导出文档。

## 导入说明与删除返回收尾

导入说明统一为“选择对应的插件或脚本，再导入对应的 ZIP 资源包。”，九种语言同步移除离线资源来源描述。归档校验和导入流程沿用原实现。

删除内置资源会刷新可用扩展，外层路由可能先移除详情子页面，连带取消子页面中的删除协程，使成功返回回调丢失。删除协程改由外层详情路由的作用域持有；子页面因资源刷新消失后，删除成功仍调用既有返回回调退出详情。失败继续显示原有错误，不把失败当作删除成功；真正离开路由时仍随路由取消。

源码实施 [DONE]。本轮仅修正文案与删除操作的协程归属，未执行本地编译、构建或测试。静态检查及远程验证以本次提交记录为准，删除后返回仍待新包设备确认。
