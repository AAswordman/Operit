# 工具权限界面

按已确认的白色设计重组 Android 工具权限页：默认三段选择与统一单项规则列表取代允许、禁止两个分组，大段说明移至标题旁的帮助入口。原型右上角的三个预览控制不进入应用。

原页面文案将全局默认描述成可以覆盖单项设置，与真实执行器不一致。本轮保留原 DataStore 键、允许/询问/禁止三种值和单项优先语义，明确修改默认不覆盖单项规则。独立组件位于 `ui/features/settings/toolpermissions/`，原路由入口继续调用新页面。

交互与存储说明见 [规则管理](01-rules.md)。设备检查统一加入 [完整验收清单](../data-and-backup/verification.md)，本地不运行 Android 编译或测试。
