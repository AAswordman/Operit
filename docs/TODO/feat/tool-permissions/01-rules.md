# 规则管理

默认方式使用等宽三段选择，展示允许自动运行、每次询问与禁止执行。单项列表显示完整工具名、真实工具说明与当前规则，可按名称和说明搜索，并按全部、允许、询问、禁止筛选。状态数量始终表示各类规则总数，结果数量跟随搜索。

单项编辑提供跟随默认和三种显式规则。即使单项与默认相同也保留，只有跟随默认才删除对应键。未修改时保存按钮不可用。默认方式、单项修改和批量应用直接写入现有 DataStore。

添加工具使用底部面板，目标规则、搜索、已选数量与提交区保持可见，长列表独立滚动。选择跨搜索保留，可查看已选、全选当前结果，并提示已经使用目标规则的工具。关闭、返回或取消不保存。

批量管理只对已选单项规则生效，选择跨搜索与状态筛选保留，全选仅作用于当前结果；支持统一修改以及统一跟随默认。返回先退出批量状态。添加和批量变更均在一次 DataStore 写入中处理，避免中间状态。

默认与单项规则来自同一份持久快照，包含当前未注册工具的已有规则。保存和撤销成功使用 OKToast 成功轻提示，失败使用 OKToast 错误提示。规则区单独提供“撤销上次修改”，只恢复本页面上一次实际变更的字段，不重写其他工具；成功撤销后隐藏入口，无变化操作与保存失败保留已有撤销记录。页面不再显示底部 Snackbar。

标题“工具权限”旁提供可点击的说明图标；说明内解释规则优先级、添加、批量、取消和撤销，以及它与 Android 系统权限的区别。主页面保留简短说明，跟随应用浅深色。
