# 市场安装的传输进度

市场原先只在安装按钮上显示旋转图标或百分比，下载较大插件时无法判断速度、已下载量和剩余时间。

从真实网络读取字节采样，向市场列表和详情页传递已下载量、服务器总量、速度、耗时和预计剩余时间。详情页在顶部标题下展示环形进度与信息面板，列表在对应条目中展示紧凑信息，不增加底部进度条。

## 作用域

- 在独立 `data/transfer` 包内实现字节统计、单调时钟采样和传输流上报
- 接入脚本、ToolPkg、Skill 仓库和 MCP 仓库的实际下载流
- 列表和详情共享同一安装状态，在非下载阶段展示实际安装动作
- 使用独立 `market/transfer` 界面组件，维护九种语言文案和十四项 JVM 回归
- 并行传输使用独立临时目录并保留附件文件名，结束或失败后清理，状态在刷新异常时也会解除

市场详情的版本历史操作使用明确的 `trailingAction` 参数，避免扩展界面参数后产生位置参数歧义。根 Gradle 配置统一固定应用与 Android 库的 NDK，与 CI 安装和原生工具使用的 25.1.8937393 对齐。

## 回归检查

| 编号 | 做什么 | 预期行为 |
| --- | --- | --- |
| M01 | 下载已知大小的脚本或 ToolPkg | 环形进度、已下载量、总量、速度及剩余时间随实际传输更新 |
| M02 | 下载没有 Content-Length 的仓库归档 | 展示已下载量、速度和耗时，明确总量未知，不伪造百分比与预计时间 |
| M03 | 下载 Skill 仓库或命中 Skill ZIP 缓存 | 实际下载时展示统计，命中缓存直接显示导入阶段 |
| M04 | 下载 MCP 仓库并开始解压 | 传输统计正常，解压时切换为安装阶段，配置型 MCP 直接显示配置导入 |
| M05 | 下载中在列表、分类和详情间切换 | 同一条目共享状态，重复安装被阻止 |
| M06 | 并行下载多个不同条目 | 每项统计独立，互不串用字节数、速度和阶段 |
| M07 | 下载失败、校验失败或响应长度不符 | 不提示安装成功，清理失败的下载文件，状态解除后允许重试 |
| M08 | 很快完成的小文件和未知大小归档 | 首末采样都上报，最终字节正确，不出现除零、负值或无效预计时间 |
| M09 | 切换深浅主题、语言、窄屏和大字体 | 文案可读、信息自动换行，详情顶部展示面板且没有底部进度条 |
| M10 | 下载后继续校验、安装、记录 | 展示当前真实阶段，结束后恢复已安装状态 |
| M11 | 编译含版本历史操作的市场详情页 | 使用明确的 `trailingAction` 参数，不因新增进度参数破坏实参顺序 |
| M12 | 在 CI 预装 r25 的环境构建所有 Android 原生模块 | Gradle 使用固定的 25.1.8937393，与原生 ripgrep 一致，不请求默认的 r27 |
