# 包管理列表与入口迭代

当前插件页逐项使用圆角卡片，市场、导入和环境变量占据右下角。插件支持手动拖动，沙盒包、技能和 MCP 各自已有布局。本次采用 B 方案改造插件列表，在保留现有详情展示的基础上整理操作入口。

## 实现范围

- 插件列表改为连续平铺行，只有拖动中的条目使用不透明表面和阴影。
- 市场与导入移到列表上方，右上角菜单提供刷新、环境变量和导入格式说明；加载错误存在时提供查看入口。
- 仅插件页提供名称、包内文件大小、安装时间、最近使用和启用状态排序，支持反向排列及状态筛选。
- 手动拖动切换到自定义顺序。再次选择自动排序必须完全按真实排序依据计算，不得保留手动置顶权重。筛选状态下拖动保留不可见插件的顺序。
- 成功安装与更新都写入新的安装时间；AI 调用、手动执行以及所属子包执行都记录到父插件。没有历史时间记录的插件排在对应时间排序的末尾。
- 保留父插件关闭时子包开关置灰的本地修正。
- 完成后依次整合上游 PR #1112、#1244、#1191 的功能提交，保留更新检查、模板创建、分享导入和环境变量管理。

## 验证与提交

维护排序回归用例和完整手动检查清单。本地仅检查差异、Kotlin 语法与资源引用，按协作约定在个人分支派发 Android Tests 和 Android Build，不轮询结果。现有详情布局、沙盒包排版、技能和 MCP 排序保持原有行为。

## 中文排序的 JVM 验证

Android 的 `java.text.Collator` 使用 ICU 中文拼音规则。JVM 名称排序用例通过作用域内的排序器工厂替换，将比较和强度设置委托给真实 ICU4J，保持应用排序代码和拼音预期不变；工厂在用例结束时自动恢复。

覆盖中文正序、倒序、同首字的完整名称比较，以及标识和手动顺序不干扰名称排序。ICU4J 仅通过 `testImplementation` 引入，不进入 APK。此次修正只重发 Android Tests，无需重新派发 Android Build。远端结果待反馈。
