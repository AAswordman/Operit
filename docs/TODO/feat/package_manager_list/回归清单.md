## 操作与预期

1. 深色打开插件页：连续深灰背景、平铺条目和细分隔线，普通条目没有独立卡片底。
2. 浅色打开插件页：同样的平铺结构，文字和功能图标随主题切换。
3. 点击插件：打开已有详情展示；说明、工具运行、UI 与模板入口可用。
4. 插件启用和关闭：开关、条目明暗和实际启用列表一致。
5. 父插件关闭后查看子包：子包开关关闭并置灰，点击不会写入启用状态。
6. 重新启用父插件：子包按现有保存的偏好恢复，有效状态正确。
7. 插件名称正序与倒序：中文按拼音、英文按字母排列。
8. 文件大小正序与倒序：按包内文件总大小排列，不按下载压缩包体积。
9. 安装时间两个方向：有安装记录的插件按时间排列，无记录项在末尾。
10. 更新一个已安装插件：安装时间变为本次更新成功时间。
11. AI 调用插件工具：最近使用记录更新到所属父插件。
12. 详情中手动运行工具：最近使用记录更新到所属父插件。
13. 使用子包工具：更新父插件最近使用，不生成单独的列表条目。
14. 最近使用两个方向：使用过的按时间排列，从未使用的在末尾。
15. 启用状态正序：已启用在上、未启用在下，没有状态分组标题。
16. 启用状态倒序：未启用在上、已启用在下。
17. 把未使用插件拖到最上方：显示顺序进入自定义模式。
18. 再选最近使用排序：未使用插件回到末尾，拖动没有置顶权重。
19. 搜索后拖动：可见项按拖动排列，清空搜索后隐藏项仍保留。
20. 筛选后拖动：不可见项的相对位置仍保留，切回全部后没有丢失。
21. 关闭并重新打开页面：排序依据、方向、筛选和手动顺序按各自设置恢复。
22. 切换沙盒包、技能和 MCP：不出现插件排序、筛选规则，原有列表行为正常。
23. 顶部市场按钮：进入现有包市场；返回后插件页可刷新。
24. 顶部添加或导入按钮：插件和沙盒包提供对应导入与模板创建操作。
25. 右上角菜单：刷新、环境变量、导入格式说明可用，刷新期间禁用重复刷新。
26. 包加载失败：列表显示简短错误入口，右上角菜单可打开完整错误详情。
27. 市场安装旧版本后检查更新：可提示更新并跳转到对应市场详情。
28. 本地导入后检查更新：明确提示缺少市场来源，不发起错误更新。
29. 技能与 MCP 详情检查更新：沿用 PR #1112 的来源识别和更新结果。
30. 创建 JS、TS 插件及 JS 沙盒模板：标识校验有效，同名拒绝覆盖，新模板不自动启用。
31. 从其他 App 分享 .js 或 .toolpkg：可以选择导入或作为聊天附件；混选其他文件沿用聊天附件流程。
32. 环境变量管理：按包展示声明、配置进度、必填状态和敏感值显示控制，保存后工具读取新值。
33. 更新后检查最近使用：安装时间更新，既有使用记录保留。
34. 删除再重新安装：清除旧使用记录，重新安装得到新的安装时间。
35. 实际执行插件功能并触发内部调用：最近使用记录更新，浏览详情保持原有记录。
