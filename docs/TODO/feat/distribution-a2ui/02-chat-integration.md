# 消息、交互与状态接入

参考发行版的聊天渲染与本分支不同。这里沿用本分支的 MessageSection、ChatTimelineEntries、LocalChatMessageSlice 和 MarkdownRenderFragment，在原有消息节点路径解释明确的 `a2ui` 围栏，不拼接全部片段另做一套渲染。

`ToolExecutionManager.ToolRuntimeContext` 提供真实聊天 ID 和请求运行 ID；原生 `A2uiTools` 执行器从该可信上下文完成编译、修订和 live 更新，不从模型参数读取聊天身份，也不依赖 JsEngine 或引导包。卡片引用以每轮 `card-1` 等短名称返回，不能跨请求复用；请求取消或结束时撤销临时生成能力。

EnhancedAIService 的首次模型流和工具后续流均在写入缓冲、轮次和 UI 前展开引用。CardReferenceExpander 随 SAVEPOINT/ROLLBACK 一起保存及恢复解析状态，解码、文本快照和事件使用同一互斥区。完整卡片保存为自包含的 A2UI 文本；普通代码、思考和工具输出里的短引用不展开。

AI 正文围栏交给 A2uiCard，身份由聊天、消息时间戳、候选索引、源码指纹和整条消息的节点索引组成。长消息分块仍使用原有节点索引。XML 子节点不继承卡片身份，避免把思考或工具结果再次当作正文卡片。普通 Markdown 与用户消息保留原路径。未解析的引用显示简短提示。

旧 XML 工具标准化、截断修复和执行提取不会读取 A2UI 围栏内部内容，避免展示文本被解释为工具调用。卡片中的工具请求先经用户确认，再作为普通用户请求进入现有模型、角色卡和权限管线，不在渲染器中执行工具。

`trySendA2ui` 校验当前聊天、完整消息、候选版本、预览状态及聊天忙碌状态，并在配置异步读取后再次检查。提交不消耗输入框草稿、附件和回复目标；同聊天的待提交请求去重。宿主确认面板保留真实发送失败提示。

卡片填写数据和本地保存结果写入应用私有原子文件。文件名带消息及候选前缀，滚动离屏后仍能恢复。删除消息、截断、清空、删除聊天和导入覆盖会清理对应状态；候选删除会重排索引，因此清理该消息的卡片状态，避免沿用其他候选的数据。复制聊天分支时同步复制已有和排队中的状态，并按消息截止时间过滤表单文件。live 最终快照在聊天目录内保存。

给模型回传的历史只在 MessageSection.Text 中将卡片压缩为可见内容摘要，保留思考、工具和协议片段，外层代码示例和未完成卡片不压缩。数据库仍保存完整卡片，原有消息存储格式不变。

[DONE] 接入与回归用例已写入；运行行为待云端及调试包确认。


本轮正常结束且不存在待执行或截断工具调用时，EnhancedAIService 将本轮尚未定位的已编译卡片追加到原消息管线，再记录送模历史。模型返回空正文也执行同一步。已通过引用定位的卡片不重复追加，未展示的旧修订只自动追加最新版；流式回滚后按实际正文重新判断。既有完整 A2UI 消息继续渲染，不迁移存储协议。
