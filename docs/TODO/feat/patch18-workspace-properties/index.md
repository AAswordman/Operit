# 工作区文件属性

## 目标与范围

在文件和文件夹的长按菜单中，于粘贴下方增加属性操作。面板采用紧凑的信息行，展示名称、所在目录、类型、大小和修改时间；文件夹额外递归统计文件与子文件夹数量。名称单击复制原始文件名，目录单击复制所在目录的完整路径并保留结尾斜杠。普通文本行包在 DisableSelection 中，不使用 SelectionContainer、TextField 或长按选择动作；只有显式进入时间编辑器才出现输入框。

大小同时展示二进制单位和精确字节数，如 `1.50 KiB (1,536 byte)`。统计包括隐藏文件，不受文件列表搜索和隐藏开关影响；数量不包括被查看的文件夹本身。链接不追随目录目标，避免环形链接或越过当前目录树，链接在文件数中计一项并只统计链接本身大小。无法读取的目录和大小未知的项目明确提示统计未完整，不将未知大小当作已知零字节。

## 实现边界

专用代码位于 workspace/browser/properties，浏览器主文件只接入菜单与固定路径的面板状态。属性读取、遍历及修改时间在 IO 线程运行；关闭面板取消读取，加载错误提供重试，列表不会受统计阻塞。

Android 本机文件使用 NIO 不追随链接的属性读取；应用内 Linux 目录沿用终端的 PRoot 路径映射；已连接的远端目录沿用现有文件提供方；外接授权目录直接读取 DocumentsContract 元数据。各来源独立处理，不在某来源失败后悄悄改用另一来源。链接不支持修改时间，文档和远端提供方目前没有公开的时间写入接口，因此面板显示说明并禁用更多按钮，不伪装支持。

更多菜单提供修改时间，使用本地时区和秒级格式，支持当前时间快捷填入。文件夹可选择应用到所有内部项目；只改修改时间，不改访问时间、权限或内容。递归更新先处理子项后处理目录，不跟随链接；部分失败保留实际成功与失败数，成功后刷新列表和属性，未提供回滚。

所有者和用户组本次不加入。普通工作区的常用属性不依赖它们；文档提供方也不保证能给出真实的所属用户或组，不能用应用用户名代替真实文件所有者。

## 静态检查与后续回归

本轮只检查 Kotlin 静态语法、资源引用、XML 和 git diff --check，未执行本地构建、测试或设备验证。待后续统一提交时再做构建与完整验收。

1. 文件与文件夹长按：属性应位于粘贴下方；原复制、剪切、粘贴、重命名、打开、分享、删除仍可用
2. 打开普通文件属性：核对名称、父目录、扩展名类型、精确字节与修改时间
3. 单击名称或目录：一次点击直接复制对应原始值；长按不出现选择手柄、系统复制菜单或输入法
4. 空文件与空目录：大小与计数为真实零值；长名称、中文、空格及换行文件名正确显示和复制
5. 多层目录与隐藏文件：递归大小、文件和子文件夹数一致，不统计当前目录本身
6. 符号链接及循环链接：不展开目标，统计可结束；链接属性可识别且不提供时间写入
7. 大目录统计中关闭或切换：界面可操作，旧请求取消，失败显示错误且可重试
8. 无权限目录、删除中的文件、大小未知的文档：不把失败伪装为空目录或已知零值
9. 修改文件时间：有效日期可保存，非法日期不能确认，当前时间快捷操作有效
10. 修改文件夹时间：不勾选只改当前目录，勾选则修改内部文件和子文件夹，显示部分失败数量
11. 外接授权目录和已连接远端目录：可读属性与递归统计，未提供时间写入能力时明确禁用
12. 主题和窄屏：属性内容可滚动，长路径换行，按钮与信息不重叠
