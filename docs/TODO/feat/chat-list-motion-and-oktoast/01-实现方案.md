# 实现方案

## 对话列表

菜单仅保留编辑、总结标题、置顶、锁定、删除等操作。移动继续使用已有拖动柄、目录悬停展开与根目录投放，删除无引用的移动选择弹窗。

侧栏顶部胶囊维持原先新建对话按钮的布局权重，内部右侧加入有独立触摸语义的文件夹按钮与细分隔线；胶囊外保留原文件夹按钮等宽的空位，搜索与显示设置位置保持。独立历史面板复用胶囊组件。

删除确认后，将目标 ID 标记为正在消散，标题使用真实文字渲染层分块消散，约 0.5 秒后触发原有删除入口。删除结果回调决定结束或恢复显示；不提前从数据列表中隐藏目标。列表项使用稳定 key 与位置动画补位，动画期间拒绝重复操作目标。

## 新建动画

参考来源：[Operit2 NewChatIntro.dart](https://github.com/AAswordman/Operit2/blob/main/apps/flutter/app/lib/ui/features/chat/components/NewChatIntro.dart)。参考的是像素聚合字形的视觉思路，使用 Android Compose 独立实现，不引入其前端运行时。

使用新建成功回调携带准确的对话 ID 驱动一次性动画。主聊天页仅在该 ID 当前可见、消息为空且加载完成时播放。总时长固定 1.8 秒，粒子从侧栏方向汇聚成 Operit 后淡出；保留原输入框、页面内容和触摸事件，不增加问候打字演出。切换、发送、离开页面或系统关闭动画时立即结束，旧空对话不播放。

## OKToast

独立目录维护提示状态、队列与 Android 展示宿主。提供 info、success、warning、error 显式入口，统一图标、语义颜色与短进出动画；普通提示中心位于可见窗口高度 90%，卡片按文字宽度收缩且文字居中；配置错误、HTTP 重试与最终请求失败使用同一上方较宽卡片，正文起始侧对齐，两类提示都没有关闭按钮；根据无障碍建议增加阅读时间。使用应用窗口，不申请新的悬浮权限。

应用轻量启动阶段注册 Activity 生命周期，覆盖主页面、崩溃报告和恢复页面；切换 Activity 时清理旧窗口和延迟回调；应用后台不堆积过期提示。调用允许来自工作线程。相同短时间非错误提示合并，错误提示保留调用边界的去重策略，队列有容量和阅读时长上限。

逐处阅读现有调用：操作完成使用 success、运行失败使用 error、缺失前置条件或受限制使用 warning、开始执行和中性状态使用 info。动态结果按成功与失败分支明确选型，聊天请求错误保留原来的每回合去重语义。
