# 对话列表精简、短动画与 OKToast

本轮从已发行的 1.12.2+6 对应 dev 开始，所有改动集中在同一条分支和一个 PR。保留既有数据与外部接口，只调整应用内交互和提示展示。

## 目标与范围

- 删除对话操作菜单中的上移、下移、移动到，以及文件夹菜单中的移动到。保留长按拖拽、排序和其他菜单功能，清理无入口的移动弹窗代码。
- 新建对话胶囊内包含独立的新建文件夹按钮，保持胶囊原宽度；右侧搜索、显示设置不挪占预留空位。
- 左滑删除与菜单删除共用确认流程，确认后标题短暂像素消散，再调用真实删除；其余列表项平滑补位。锁定、取消与删除失败必须保持正确。
- 参考 Operit2 的新建动画思路，独立实现适合 Android Compose 的短过渡。侧栏收起时像素进入空白主界面并组成 Operit，不阻塞输入、发送和导航，减少动画设置生效时跳过粒子效果。
- 新增独立 OKToast 组件目录，支持 info、success、warning、error。逐处阅读提示含义并显式选择状态，迁移应用内系统 Toast 与聊天临时提示。
