# 本轮验收反馈修正

## 本轮范围

在原功能分支继续修改 OKToast 布局，以及缺失模型配置和请求失败的处理。对话列表和固定 1.8 秒的新建动画沿用已实现行为。插件创建文件的统计与快照覆盖仅做代码调查，单独记录评估，不纳入本轮实现。

## OKToast

原实现固定在顶部并撑满可用宽度，含独立关闭按钮。普通提示改为以可见窗口高度 90% 处为提示中心，宽度随内容收缩，最长不超过可见窗口宽度 90%；长文换行并限制高度后滚动。图标贴近文字，文字居中，删除关闭按钮，仍按内容与无障碍建议时间自动消失。

## 缺失配置与失败请求

发送前读取实际角色卡或功能绑定的模型配置，缺失可用密钥或模型 ID 为空时给出明确错误，保留草稿与附件。不为自定义模型维护有效 ID 白名单；服务端返回的鉴权、模型不存在等错误正常显示。

设备崩溃缓冲区记录到 401 后的原生 SIGABRT，终止点位于 MessageProcessingDelegate 的发送协程。已有共享流会保存终止原因，但主发送协程再次抛出终止异常，收集协程也会重复抛出。将普通请求失败作为终态直接收尾和展示，取消仍保留取消语义，严重运行时错误仍传播。此次代码修正不能等同于设备运行时问题已通过真机验证。

## 验证

仅做差异、Kotlin 语法及 XML 静态检查，派发远端 Android Build 与 Android Tests；不运行本地编译或测试。完成后扩充原完整验收清单，所有新增结果待填写。
