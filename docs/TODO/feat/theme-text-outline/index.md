# 自定义主题文字描边

自定义主题新增独立的文字描边能力，覆盖全局字体以及用户消息、AI 消息等所有已支持区域字体；文字填充、气泡边框与文字轮廓分别控制，普通主题设置保持原有入口。

## 实现范围

- ThemeAppearanceText 新增可选 stroke 声明，ThemeScriptContract 校验独立颜色与 0..8dp 宽度；宽度为 0 时单独关闭，未声明时继承上级，旧主题未配置时保持原有外观与默认导出字段。
- ThemeStudioTextStroke 在自定义主题的全局字体与 13 个已支持区域字体入口增加文字描边板块，提供继承、关闭、自定义、颜色和宽度；用户消息与 AI 消息可分别设置，普通主题设置不增加控件。
- ui/theme/script/text 提供统一文字轮廓作用域和绘制组件，Compose 文字复用同一布局先画轮廓再画原文，保留文字填充色、链接、选择与无障碍节点；现有 UI 文字调用通过导入适配接入全局能力。
- 消息段落、引用、表格、代码高亮和工具 Canvas 摘要接入独立描边绘制；原生布局、流式裁剪和链接命中仍使用原有坐标，描边这一遍跳过行内图片并保留原始文字颜色与素材绘制。
- 经典与 Agent 输入框接入文字描边，输入区和输入框按原有字体层次分别覆盖；String、TextFieldValue 与 TextFieldState 输入入口继续使用原生编辑器的滚动、选择、输入法和转换回调。
- 工作室控件清除外部描边作用域以保持编辑可读，嵌入预览和全屏预览继续通过正式脚本宿主呈现实际主题；字体预览和组件状态作用域同步接入对应区域描边。
- 新增 5 条文字描边文案同步九种语言，更新主题 JS 类型声明、协议与创作指南，并新增 7 项纯 JVM 声明回归源码及完整操作清单。

## 颜色入口对齐

本分支已承接 PR #138 的主题属性修复。消息区域只有一个消息文字色入口；区域字体只保留字体、排版和文字描边，全局字体保留全局文字色。读取顺序固定为区域内容色、旧区域排版色、全局文字色和业务默认色，不按操作顺序覆盖。主动修改或清空统一入口时清理重复的旧区域排版色，保留新增文字描边与其他字体参数。

## 声明与生效规则

`typography.stroke` 配置全局文字轮廓，区域通过 `textStyle.stroke` 覆盖。`color` 默认黑色，`width` 默认 1dp、允许 0..8dp；宽度为 0 明确关闭，省略或设为 null 继承上级。输入框沿用全局、输入区、文本输入框的字体层次。气泡的 `strokeColor/strokeWidth` 继续控制容器边框。

制作工作室的操作控件关闭外部文字轮廓作用域，预览由独立脚本宿主提供真实声明。普通主题设置不增加描边控件。

## 静态核对范围

核对所有接入组件的命名参数、重复导入、资源引用与 XML；使用项目 BOM 对应的 Material3 1.4.0 源码核对公开接口。现有原生 UI 的大量文件仅替换文字或输入组件导入，实际绘制集中在 ui/theme/script/text 包。编译与运行结论以仓库工作流为准。

## 百分号说明资源

背景透明度说明中的 0% 和 100% 是展示文本。五种语言补齐 formatted=false 后，九种受支持语言统一按字面值处理；文案正文保持不变。

## Compose UI 目标声明
文字、输入框、描边容器与区域字体作用域显式标注 UiComposable，并在可组合插槽类型上声明同一 UI 目标。输入框装饰器用明确的 UI lambda 调用内部编辑器，消除高阶插槽的递归目标推断。已有文字描边、布局与编辑回调继续由原有组件承担，编译结果交由仓库工作流确认。
