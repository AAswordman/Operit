# 语音结果分离与累计用量分类

基于包含 +13 紧急修复的 dev 分支开展，两项改动共用本分支。正式发布仍等待维护者完成 Debug 实测。

1. 语音原话与音频辅助观察分别保存。界面只展示原话，间接音频请求额外携带独立观察；直接音频仍发送原录音。
2. 仅累计用量页平铺九类累计消耗。窗口占用页保留消息历史及其三项子列表，其他层级不变。
