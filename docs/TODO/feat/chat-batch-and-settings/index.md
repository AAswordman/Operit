# 对话批量管理与设置入口整理

当前列表在新建胶囊右侧保留空槽，搜索和列表设置靠右；只能逐条总结标题、归档、锁定和删除。语言独占设置页面，普通设置页的顶部栏也沿用聊天背景的透明效果。

第一批在同一分支实现以下三项，后续修正继续累积在同一 PR：

- 搜索和列表设置各左移一个槽位，最右侧加入批量操作。选择模式展示复选框、数量、全选、退出和四类操作；关闭拖拽、侧滑和单条操作菜单，保留目录展开与滚动。
- 语言以应用全局设置放进主题基础页的下拉菜单，继续支持跟随系统与手动指定语言。沿用已保存的语言配置和切换后的重启行为，切换前复用主题草稿的保存、放弃、取消流程。
- 普通设置页的顶部栏与状态栏下方使用主题底色，文字和操作按钮按主题配色。主题与外观、离线资源保持原有展示方式。

插件文件统计与快照收集继续搁置。本轮不修改版本号或执行正式发布。

## 实现约束

- 批量任务在主聊天 ViewModel 生命周期内逐条执行；记录成功、跳过、失败数量，单条失败不阻断后续条目，不并发发起总结请求。
- 全选仅覆盖当前列表中可见的对话行，包括屏幕外可滚动的行，不跨归档视图、角色范围、搜索结果或折叠目录；范围缩小时移除不可见选择，避免误操作。
- 批量删除二次确认，保留锁定对话；实际删除继续经过当前会话切换、回复停止与数据库锁定检查的既有流程。
- 保留已发布语言路由入口，统一显示主题页，移除独立语言页面的重复实现。
- 按仓库要求不运行本地构建或测试。完成后派发 Android Build 与 Android Tests，再创建目标为 dev 的 PR；不轮询 CI。
