1.12.2+8（versionCode 64）：加入对话批量管理，调整模型与参数配置页面，并完善图片交互、请求错误提示和稳定性。

## 更新

- 对话列表支持批量总结标题、归档、锁定和删除。保留当前筛选范围、锁定保护与删除确认，并显示执行进度和结果。
- “模型与参数配置”整合连接、参数和功能分配三个页签。请求能力改为纵向整行开关，工具调用位于流式输出上方，保留开启数量；十二类功能分配改为一行一项，沿用原绑定与测试菜单。
- 每份模型配置可独立选择流式或非流式输出。新配置的工具调用、流式输出默认开启；升级时已有配置继承原来的全局流式选择，之后可以分别修改。
- 模型设置中的详情与编辑窗口居中显示。“查看配置预览”收进顶部“更多”，保存后展示配置结构，密钥及请求头内容遮罩。
- 语言选择整合到主题基础设置；普通设置页顶部栏使用主题底色。模型服务选择显示 Logo 和“服务方式：名称”，减少重复提示。
- 慢速模型的首字等待上限延长到 300 秒。用量统计图按柱标注时间，自定义相册支持连续划选，已选图片支持左右翻页。

## 优化与修复

- 请求重试和密钥池换钥时保留具体原因，通过上方提示展示。明确的非法参数直接结束；无效密钥根据是否还有候选密钥决定结束或换钥；余额不足、限流和临时故障继续使用原重试预算。
- 图片气泡平铺改用纹理填充，减少窄切片带来的重复绘制；常用调节收拢为装饰大小、文字留白和边框预设，高级参数继续保留。
- 内置浏览器限制重复开窗与重复外部应用确认，保留用户主动登录和重试操作。
- Root 与 Shell 的 UIAutomator 页面读取保存并恢复旋转设置，减少读取过程中对设备方向的影响。

## 更新安装

沿用 Kong 包名与固定签名，以 `v1.12.2+7` 为增量基线，提供完整 APK、`+7 → +8` 增量 ZIP、补丁元数据和发行摘要。已安装原签名正式包的用户可以覆盖更新；按既有更新渠道规则，`+n` 补丁版需要开启 Beta 计划。

## English

- Added batch conversation title generation, archiving, locking and deletion, with progress, result summaries and existing lock protection.
- Reorganized model settings into Connection, Parameters and Function assignments. Capabilities and assignments use single-column rows, while the existing function editor is retained.
- Streaming is now saved independently for each model configuration. New configurations enable tool calls and streaming by default; existing configurations inherit the previous global streaming choice once during upgrade.
- Centered model settings dialogs and placed the masked configuration preview under More. Language selection is available in theme settings, and ordinary settings headers follow the theme background.
- Extended the first-token timeout to 300 seconds, clarified activity chart labels, added continuous gallery selection and enabled paging through selected images.
- Preserved useful retry and key-rotation errors, reduced repeated image-bubble drawing, limited duplicate browser popups and external-app confirmations, and preserved rotation settings around UIAutomator reads.

The incremental baseline is `v1.12.2+7`. Assets include the full APK, the `+7 → +8` incremental ZIP, patch metadata and the distribution manifest, using the existing Kong package and signing certificate.
