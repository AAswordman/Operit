# 首字超时、统计刻度与图片交互

继续使用 `feat/chat-batch-and-settings` 和 PR #18，保留前面已实现的批量管理、语言入口和设置顶部栏，统一构建验收。

## 本轮范围

- 将自定义 5004 首字等待期限从 45 秒改为 300 秒，保持限流冷却和网络连接超时的原有语义。
- 每日生成完整 24 个小时桶，包括没有用量的日期；每根柱显示小时，柱宽按文字和年度图的可读间距扩展，支持横向滚动。
- 每周的七根柱按月份、日期分两行标注；每月的周柱显示实际起止日期，完整明细仍显示在下方。周、月底线与首末柱边缘对齐。年度与累计图保持原有刻度和布局。
- 自定义相册支持从图片横向拖动连续划选；上下拖动继续滚动，长按继续预览，边缘停留可滚动跨行选择。
- 输入栏已选图片预览支持左右翻页，顺序与附件一致，跳过非图片。保持双击、双指缩放、缩放后的拖动；缩放时先操作图片，恢复适配后再翻页。经典、Agent 与悬浮输入使用同一预览实现。

本轮不执行设置界面重构或生成设计稿，不修改版本或发布 Release。不运行本地编译、构建或测试；完成后更新同一 PR 并派发仓库工作流，不轮询 CI。

## 代码与验证

- `LlmRetryPolicy.FIRST_TOKEN_TIMEOUT_MS` 为 300000 毫秒；`FirstTokenWatchdog` 与 5004 错误元数据沿用该常量。限流冷却仍是独立的 45 秒。
- `TokenActivityAggregator` 对零用量单日也生成 24 个小时桶。`TokenActivityAxisLayout` 为日、周、月视图提供逐柱时间标签；周、月图底线跟随柱范围，年度与累计图保留原月份刻度。
- `GalleryDragSelection` 负责选区与边缘滚动，`ChatImagePickerDialog` 保留单击、复选、长按预览与纵向滚动。
- `AttachmentChip` 从调用处传入的附件列表筛出图片，经典、Agent 及两种悬浮输入共用 `AttachmentImagePreviewDialog` 的多图页。翻页保留已选顺序；双指手势与放大平移不触发翻页，预览标题与页码跟随当前图片。
- 已添加 5004 时间值、空日期小时桶、图表跨月刻度与拖动选择顺序的 JVM 回归用例；**尚未在本地运行**。真机触摸互斥、窄屏文字以及真实慢请求的结果待填写在 [完整验收清单](02-完整验收清单.md)；静态检查不替代这些验收结果。
