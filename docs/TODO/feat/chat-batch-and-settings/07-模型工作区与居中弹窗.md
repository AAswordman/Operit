# 模型工作区与居中弹窗

沿用 PR #18 的 `feat/chat-batch-and-settings` 分支，目标 `dev`。将已确认的第二版模型工作区设计落实到 Android；设置首页保留一个模型入口，旧功能配置导航直接打开功能分配标签。

## 实现范围

- `settings/model/ModelWorkspaceComponents.kt` 提供连接、参数、功能分配标签，共享折叠分区与居中窗口。折叠区保持编辑器组合，收起时不测量和放置正文，避免销毁输入草稿与保存注册；顶部保留原文件夹管理，配置选择改为居中窗口。
- `ModelConfigScreen.kt` 复用原分组、新建、排序、导入导出、重命名、删除和真实连接测试。每个标签有独立滚动状态；切换标签、配置和分组前先通过保存协调完成待写入内容，保存失败时保留当前页。
- `ModelApiSettingsSection.kt` 继续提供完整服务选择、OAuth、本地模型、可编辑地址与真实模型列表的搜索、多选、排序和刷新。当前服务显示 Logo；单密钥与新版密钥池放进同一个居中管理窗口，打开、关闭前都完成保存。
- `ModelRequestCapabilities.kt` 展示流式、工具、图片、音频、视频五项能力。流式现已改为每份模型配置独立保存；经典和 Agent 输入菜单移除重复开关，其他菜单操作保留。Codex 和 Antigravity 沿用原图片/PDF 直传限制，其独立音视频直传显示为不可用；Codex/Gemini 搜索、Claude 缓存和 DeepSeek 提示继续保留。
- 参数页默认折叠生成、思考、采样与重复、自定义、请求队列五区。`ModelParametersSection.kt` 保留标准参数与自定义参数的类型、值、启停和重置；参数写入串行化并注册到保存协调。请求队列继续使用原两个字段，零或空表示不限制，加入切换与后台保存协调。
- 思考配置继续复用完整规则与档位编辑器，保留九种匹配方式、提供商范围、默认请求路径、开关及档位控件、启用/关闭写入动作、规则和档位排序，以及第一条命中语义。
- 原功能页的绑定、模型索引、思考覆盖和十二类真实功能测试移动到 `settings/model/ModelFunctionEditor.kt`。`ModelFunctionAssignments.kt` 提供单列功能行、当前配置筛选与居中编辑，保留跨分组绑定显示和记忆向量未配置特例；功能保存中的任务参与页面切换协调。
- 密钥池仍使用原真实存储与检测逻辑，保留紧凑列表、拖动、状态、暂停继续、清空标记、导入导出和超过二十把的大池呈现。详情及批量选择由底部面板改为居中窗口，列表分配剩余高度，确认与取消留在窗口内。工作区的思考、请求头、密钥行操作等选择菜单统一居中。

## 兼容性

功能映射、参数和密钥保持原存储格式。模型配置新增 `enableStreamOutput`，偏好版本由 5 升至 6，将旧全局流式选择一次性写入已有配置；已有独立字段不被覆盖，新配置默认开启。旧功能导航仍可进入统一工作区；新增文案提供中文与英文资源。布局和窗口触摸效果需要随 Android 构建产物验收。

## 核对与验收

功能列表的标题生成项使用 `Title` 静态图标；图标子集与清单通过 `tools/icons/sync_material_icons.py` 按固定 AndroidX 1.7.8 来源及锁定的终端源码重新生成，同时移除不再引用的 `Lightbulb`、`Repeat` 子集文件。`--check` 已确认应用和终端的静态图标引用全部覆盖。`ModelApiSettingsSection.kt` 显式导入 `Tune`，供请求能力标题解析对应的图标扩展属性。

完成静态差异检查、Kotlin 语法解析、中文英文 XML、资源引用、调用点及居中窗口入口核对。没有在本地执行 Android 编译、构建、单元测试或真机测试，静态解析不等同于编译或运行通过。远端 Android Build 使用 `assembleDebug`、`publish_release=false`，Android Tests 使用仓库原工作流；派发状态和结果以 PR 的实际记录为准。
