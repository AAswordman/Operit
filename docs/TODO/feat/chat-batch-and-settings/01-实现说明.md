# 实现说明

## 对话批量操作

`ui/features/conversation/chat/modules/history/batch/` 维护操作控件，执行器位于 `chat/viewmodel/history/`，动作和进度声明位于 `chat/foundation/model/`。侧栏和独立历史面板都通过现有聊天 ViewModel 接入，搜索与列表设置各左移一格，新建胶囊宽度不变，最右侧显示批量操作图标。

选择模式用整行复选框语义切换对话，不会打开聊天。可全选当前展开列表、取消选择和退出；全选包含可滚动到但尚未上屏的行，不包含折叠文件夹、另一归档视图或其他筛选范围。当前列表范围缩小时清理隐藏选择。列表仍可滚动、展开目录和快速定位。

进入选择模式后移除拖动柄、单条菜单及侧滑识别器，并取消尚未结束的拖动。操作栏使用展开与淡入淡出过渡。退出后恢复单条操作和原拖拽行为。

总结标题、归档、取消归档、锁定、解锁、删除均逐条等待处理。混合锁定状态点击锁定会统一锁定；全部选中项已锁定时提供解锁。任务在 ViewModel 中执行，不因收起抽屉或行离屏而重新启动。进行中在两个面板共享进度并禁用重复提交；最终仅汇总一次成功、跳过、失败数量。

标题总结与单条操作共用同一实现和占用标记，保留无用户正文时跳过、生成期间用户改名或删除时不覆盖的行为。批量删除二次确认后复用单条删除的底层流程，包括停止回复、切换当前对话、最终锁定检查和待发消息清理。锁定或已不存在的目标记为跳过；其他单条失败记为失败并继续后续条目。批量删除直接处理存储结果，列表使用既有移除与补位过渡，单条删除的消散动画保持原状。

## 语言入口

`ui/features/settings/language/ThemeLanguageSection.kt` 放在主题基础页字体设置之后，使用下拉菜单列出跟随系统与全部现有手动语言。设置首页删除独立语言入口，主题入口副标题说明颜色、背景、字体与语言。

语言继续写入 `UserPreferencesManager.appLanguage`，属于应用全局设置，切换角色、重置角色主题或应用主题到全部角色均不会改写语言。下拉菜单按保存值显示跟随系统，手动语言继续处理已有语言别名。切换后沿用重新打开应用的行为。

主题草稿有更改时，语言切换进入既有保存、放弃、取消流程；只有保存成功或明确放弃后才保存语言并重新打开应用。全局语言先完成持久化，再应用到系统与应用资源。跟随系统读取设备系统资源，Android 13 及以上清除应用显式语言覆盖，避免把当前手动语言当成系统语言。

已发布的 `Screen.LanguageSettings` 路由标识保留并显示完整主题页，移除原独立语言页的重复实现。

## 顶部栏

`ui/features/settings/navigation/SettingsAppBarPolicy.kt` 根据设置导航归属统一决定顶部栏背景。普通设置页的普通和滚动态顶部栏都使用不透明主题背景色，标题、返回和操作按钮使用配对的 `onBackground`；`TopAppBar` 自身处理状态栏插图，因此状态栏下方也有完整底色。

主题页及旧语言路由保留背景预览。离线资源使用独立 Activity，本轮不修改其顶部栏。
