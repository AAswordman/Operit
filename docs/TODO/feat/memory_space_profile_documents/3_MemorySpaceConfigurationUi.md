# Memory-space configuration UI

Status: [SUPERSEDED]

The initial implementation removed the global user-preferences route and settings entry. It put
document editing, automatic-update control, and whole-document locking into the selected
memory-space configuration surface.

The selected memory space keeps the existing stable identifier used by ObjectBox and character-card bindings. The screen edits only that space's `user.md`.

This surface was superseded by [the standalone user-configuration UI](4_StandaloneUserConfigurationUi.md).
The storage ownership and stable identifiers remain unchanged; only the user-facing management
location moved.
