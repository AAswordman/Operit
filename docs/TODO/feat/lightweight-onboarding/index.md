# 单页首次使用流程
原先首次启动依次展示协议、宣传和权限设置，聊天主页还会因为默认 DeepSeek 密钥为空而被配置页替换；首页公告和市场协议另有强制倒计时弹窗。
本次将首次使用改为一张居中的启动页：透明前景图标、应用名、广告词“让想法，走出对话框。”和“开始”按钮。点击后直接进入原聊天主页，不再在欢迎页展示协议确认框、协议链接或额外引导。首次启动只记录流程完成状态；已有旧协议确认记录的覆盖安装用户保留完成状态。
## 范围
- 欢迎页使用透明前景图标居中显示，移除图标外层容器和大面积非功能留白。
- 欢迎页只保留品牌、广告词和开始按钮；用户协议与隐私边界说明从设置入口主动阅读。
- 阅读页显示居中的“Operit Kong 用户协议与隐私政策”标题，正文使用项目已有 Markdown 渲染器处理标题、粗体和链接。
- 协议正文删除草稿元信息和第 22.5 条；第十五条作为本文档内的个人信息、隐私与授权边界说明，不引用不存在的独立隐私政策。
- 首次启动状态使用 `onboarding_completed`；已有 `agreement_accepted` 或 `accepted_agreement_version` 记录只做一次兼容迁移。
- 删除旧权限引导页面、ViewModel、引导专用配置路由、配置拦截及无引用资源。
- 删除首页远程公告弹窗、请求及确认记录；市场不再自动弹协议，保留菜单内主动阅读。
- 新增文案覆盖中文、英语、日语、韩语、西班牙语、巴西葡萄牙语、印尼语、马来语、罗马尼亚语。
- 不改变正常的模型设置、功能权限设置、聊天发送时的配置校验或插件安全黑名单。
## 交付
只提交到个人 fork 的功能分支，不创建上游 PR，不合并 main 或 dev，不发布正式包。按约定不运行本地构建或测试；提交后触发仓库 Debug 构建和 Android Tests，不轮询。
验收见 [01-regression.md](01-regression.md)。
