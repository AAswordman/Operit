| 2 | 新建名称只判空，允许夹带目录段 | WorkspaceBrowserSupport 统一单个名称校验；新建文件、目录与重命名均拒绝点目录、斜杠、反斜杠和 NUL，创建对话框保留输入并显示错误 |

| 4 | 编辑搜索中的正文会重置当前匹配并滚动 | WorkspaceManager 在同一文件与查询中保留有效匹配序号；CanvasCodeEditorView 的高亮更新不滚动，CodeEditor 仅收到上/下一处的显式导航请求时定位 |

| 7 | 书签显示名查询及相关导入无调用 | 删除 querySafBookmarkDisplayName、DocumentsContract、TextLayoutResult 与 Dialog 未使用导入 |
| 8 | 加载期间静默丢弃后续目录请求 | FileManager 用新的读取 Job 替换前一次请求，目录加载与文件操作状态分开；旧任务的 finally 不会清除新请求的加载状态 |
| 9 | 修改时间按照原始字符串比较 | WorkspaceBrowserSupport 将毫秒、ISO 偏移时间、本地完整时间和工具短日期转换为时间值；每次排序只为每个条目解析一次，未知格式继续按同级名称排序 |
| 10 | 长按回调作为 pointerInput key，重组会中断手势 | 快速路径与文件行都使用稳定身份作为 key，rememberUpdatedState 提供最新单击和长按回调 |
| 11 | Linux 或仓库的分享缓存不清理 | WorkspaceBrowserOperations 在外部打开或分享前清理超过七天未使用的分享缓存子目录，最近共享文件仍保留 |
| 12 | 画布搜索颜色固定，搜索文件末尾缺换行 | EditorTheme 提供普通与活动匹配颜色，画布直接读取；WorkspaceTextSearch 文件末尾补换行 |
| 13 | 文件复制与目录复制都传 recursive=true，目标父目录没有单独预检 | 剪贴板保存条目是否为目录；复制与跨环境剪切删除按该类型传递递归参数，粘贴先检查目标目录存在且为目录，再检查同名目标 |
| 14 | Ctrl+/ 只处理非空选区 | 有选区保留原规则；只有光标时对当前行注释，有行前缀的语言优先行注释，CSS 等仅块注释语言包裹当前行，空行也可切换；光标保持折叠，单次撤销恢复原文本与位置 |
| 15 | 重命名为原名进入目标冲突检查 | 对话框相同名称直接关闭；FileBrowserOperations 同一路径直接结束，不调用文件工具，也不报覆盖错误 |

## 工具复制与注释范围

StandardFileSystemTools.copyFileCrossEnvironment 只有在来源为目录时才检查 recursive；来源为单个文件时该值不会触发目录递归，因此原来对文件传 true 没有改变单文件复制含义。本次改为显式携带实际文件类型，减少调用歧义。目标目录预检失败会保留剪贴板与源文件，跨环境剪切仍在复制成功后删除源文件。

Ctrl+/ 的当前行支持已接入实际键盘处理入口和 EditorDocument，未要求用户先选择文本。多行选区仍按原来的块注释或行注释规则处理，撤销记录维持一次操作一条历史。只读文件与未注册格式继续保持已有行为。
