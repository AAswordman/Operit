# 主题透明度调试版回归

本次补录：用户确认目前 Bug 均已修复，本页功能验收结果按用户确认记为通过。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

安装本分支构建的 Debug APK，覆盖现有调试版，不卸载、不清数据。先记录设备、Android 版本、APK 提交及检查结果。

## 操作与预期

| 编号 | 操作 | 预期 |
|---|---|---|
| T01 | 覆盖安装后查看未修改的旧主题 | 气泡、输入框及原有透明/不透明效果不变 |
| T02 | 对话气泡：双方分别设置 0%、50%、100% | 背景对应不透明、半透明、全透明；互不影响 |
| T03 | 命令行样式：双方分别设置 0%、50%、100% | 用户背景和 AI 背景分别生效；旧 AI 默认外层仍透明 |
| T04 | 双方分别设置 1%、37%、99% | 数字准确显示，保存后值不跳变 |
| T05 | 调透明度后切换命令行/对话样式 | 每种样式保留自己的双方设置 |
| T06 | 命令行用户气泡开启跟随主题，再调透明度 | 背景颜色继续跟随主题，透明度独立生效 |
| T07 | 两种输入框分别设置 0%、50%、100% | 经典、Agent 输入背景均生效；100% 无残留背景装饰 |
| T08 | 输入框切换悬浮、非悬浮；输入、发送及展开菜单 | 透明度保留；布局、按钮、键盘和菜单可正常使用 |
| T09 | 浅色、深色主题及图片/视频背景下重复 T02、T03、T07 | 背景透明效果正确，文字与控件不随背景变淡 |
| T10 | 用户和 AI 图片气泡分别调 0%、50%、100% | 仅气泡背景图变淡，正文与附件不变；九宫格两种模式正常 |
| T11 | 支持玻璃的设备：输入框及气泡分别开启液态/水玻璃，调 0%、50%、100% | 保留选中样式；背景透明度生效；100% 不绘制玻璃背景 |
| T12 | 查看未设置新透明度的旧玻璃主题 | 保持原有效果，滑块显示对应的着色透明度 |
| T13 | 调气泡透明度后修改颜色；再在颜色选择器调 alpha | 颜色与透明度互相同步，文字颜色不因 alpha 突变 |
| T14 | 设置双方不同值，保存；重启应用 | 数值与实际背景都保留 |
| T15 | 修改后放弃保存；再测试主题重置 | 放弃恢复保存值；重置恢复默认主题背景 |
| T16 | 角色卡/角色组主题分别设置不同值，切换并复制主题 | 主题隔离和复制正常，未设置字段保留旧主题行为 |
| T17 | 渲染长消息、流式回复、代码块、工具结果、隐藏占位消息和附件 | 内容、选择、滚动与点击正常；背景衔接无新增异常 |
| T18 | 使用新 Debug 包删除 Ubuntu，再导入现有终端包 | 已验证的删除、重新导入能力无回归 |
| T19 | 首次进入插件市场，查看默认列表和精选按钮 | 精选默认未选中，列表不因精选条件隐藏非精选条目 |
| T20 | 手动开启精选，再关闭精选 | 开启时只显示精选条目；关闭后恢复未限定精选的列表 |
