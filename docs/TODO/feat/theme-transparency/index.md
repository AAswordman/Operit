# 主题背景透明度

将输入框原有的透明开关替换为 0–100% 滑块，并为命令行、对话气泡两种样式的用户和 AI 背景分别提供透明度设置。0% 为不透明，100% 为完全透明，步长为 1%。文字、头像、图标、附件内容不跟随背景变淡。

## 实现范围

- `data/preferences/transparency/ThemeTransparencyPreferences.kt` 定义五个独立主题字段及百分比换算。新字段加入主题浮点键集合，参与主题的保存、复制、读取和重置。
- `BackgroundTransparencySlider` 在输入设置和聊天样式设置中显示百分比。输入框覆盖经典、Agent 样式；命令行和对话气泡的双方背景分别保存。
- 普通气泡设置背景颜色的 alpha；图片气泡只对背景绘制图层进行透明合成，不影响正文；玻璃背景支持区域透明度覆盖，完全透明时不绘制玻璃背景。
- 命令行 AI 消息原本没有外层背景；未配置新字段时保持原状，设置透明度后绘制对应背景。
- 旧输入框透明开关、背景图片带来的默认透明值、已有气泡颜色 alpha 和玻璃着色透明值继续保留。没有为旧主题强制填入新默认值。
- 现有颜色选择器的 alpha 与新气泡透明度联动，自动文字颜色计算不跟随背景 alpha 变化。

## 插件市场默认筛选

插件市场不再默认开启“精选”：浏览状态和三个列表组件的默认值统一设为关闭，展示未限定精选的列表。保留精选按钮、手动切换回调和原有筛选逻辑，与透明度功能随同一份 Debug 包验收。
