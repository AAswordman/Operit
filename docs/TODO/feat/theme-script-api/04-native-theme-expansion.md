# 扩展原生主题制作范围并移除新格式的旧品牌标识

本轮在未发布的 `feat/oktheme-script-api` 与 PR #99 上继续迭代。此前只开放四个区域的装饰，无法完整配置输入按钮素材、通用组件形状或明暗色板。维护者要求参照二代主题模板的制作能力，在原生 Android 中扩大覆盖，同时保留角色卡/角色组、草稿和 `.oktheme`。

## 数据与包归属

沿用 `00-package-layout.md`，不增加 data 一级包。新增外观样式模型放入 `data/model/theme`，扩展资源束中的声明式外观，主题执行器向脚本提供这份只读外观；默认脚本直接返回它。可视化编辑和 JS 共同使用同一模型，避免可视化编辑覆写自定义源码。

新文件使用 `format: "oktheme"` 与独立数字 `schema`；参数码使用 `oktheme-params` 与 `oktheme://`。数字只用于机器校验，不作为产品版本名。已发布的 `operit-theme-v1`、旧参数格式和旧链接仅按明确格式读取；未发布的中间格式不保留。

## 本轮实施范围

1. 扩展共享外观：明暗色板、全局和部件字体排版、原生形状/描边/填色/文字颜色、尺寸与内距、多层素材、九宫格、按钮素材绑定及交互状态
2. 扩展真实原生入口：Classic/Agent 输入操作图标、消息和头像、顶栏/导航、通用按钮，以及设置卡片和常用弹窗内容；未接入的业务页面不宣称已支持自由布局
3. 增加可视化制作字段与素材选择，同时保留源码编辑；每次应用到草稿统一校验，保存和清理继续走角色主题会话
4. 更新 `.oktheme` 与分享码、新接口类型、示例、完整回归和 PR 描述；不运行本地构建或测试，推送后派发已有仓库工作流，不轮询 CI

## 完成判据

类型声明、原生消费、编辑入口和文档一致；不能只增加未消费的配置。独立按钮素材替换保留原点击行为。默认未配置时保留原有组件行为，显式错误显示诊断。文件及分享码新输出不带旧品牌，旧发布文件读取正常。
