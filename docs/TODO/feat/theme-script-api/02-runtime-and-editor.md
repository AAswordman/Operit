# 脚本执行、绘制与编辑

既有主题表现层没有外观脚本。本次在 `ui/theme/script` 使用独立 QuickJS 实例，模块读取冻结的主题上下文，返回有限的同步外观描述。工具引擎和原生调用桥不参与求值。

QuickJS 模块增加实例级内存、栈与单次执行时限；没有设置限制的既有执行器保持原有行为。脚本上下文不包含文件路径、聊天内容和角色资料。JSON 输出、素材和图层均在进入绘制前校验。

扩展为 19 个原生外观区域、13 个图标绑定、36 个明暗色板 token，增加全局/局部排版、形状、描边、阴影、头像尺寸、消息宽度和九宫格。消息覆盖 Cursor/Bubble 和现有宽窄布局；输入覆盖 Classic/Agent。按钮及常用 AlertDialog 通过原生适配器接入；顶栏、侧栏、设置卡片和消息菜单/面板/状态/工具调用条接入实际入口。原生材质先绘制，装饰背景、正文和装饰前景依次绘制，现有透明度参与合成。选中、禁用、错误状态只在传入状态的入口生效。

设置页制作窗口包含可视化部件、图标和明暗配色，保留源码编辑、JS 导入、素材导入替换和移除。内置森林/信纸模板，窗口内可预览基础外观和脚本共同产生的结果。默认脚本返回只读 `context.appearance`，可视化编辑不修改自定义源码。校验成功才创建草稿引用；正式保存、放弃和重置仍由原有主题页处理。主界面和草稿预览各自运行对应快照，错误记录诊断并显示提示。

SDK 提供 TypeScript 类型与 CommonJS 示例，内置 JS 示例可直接从编辑入口使用。接口范围、数值上限、绘制顺序和分享兼容写入 `docs/doc-src/feature-protocol/theme_script_api.md`。
