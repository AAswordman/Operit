# 主题 JSON 与 JavaScript 完整制作手册

## 原状与目标

现有协议概览和 TypeScript 声明偏向实现摘要，缺少完整字段的默认值、取值范围、配置位置、原生接入边界与可直接照做的示例。维护者要求先交付手机或工作区内可阅读的完整手册，并解释 JavaScript 能力上限。

本轮编写基于 `3005a7d7` 源码的接口参考稿，覆盖共享模型、JS 输入输出、资源工程和运行限制，不扩展原生协议或新增主题能力。手册与示例同步到手机下载目录，便于先行阅读和制作。

## 边界

本轮不运行应用、本地构建或测试，不查询或等待 CI。文档描述已实现的声明式外观接口；原生界面和性能的验证状态沿用已有回归记录。
