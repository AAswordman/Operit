# 原生消息预览的偏好字段修正

本轮继续在 PR #99 的原分支处理导入既有数据后进入主题工作室的崩溃。堆栈定位到 `StudioNativeMessage` 的用户气泡左留白读取，异常为 `IllegalArgumentException: Required value was null`。

## 已确认原因

正式偏好定义、默认值、分享模型和 dev 分支均使用 `bubble_content_padding_left/right`；原生预览误读了不存在的 `bubble_user_content_padding_left/right`。任何进入 Bubble 分支的数据都会触发读取，不以旧版导入为必要条件；没有证据将这次异常归因于脚本求值或数据版本差距。

`UserPreferencesManager.readThemePreferenceValues` 先以默认视觉值建立各类型映射，再合并持久化字段，继续沿用已发布的键名。主题包解析另有格式、字段及版本校验。本轮不扩大数据迁移范围，不新增错误键名、缺失值吞错或常量代填。
