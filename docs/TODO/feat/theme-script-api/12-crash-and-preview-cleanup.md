## 已确认的事实

设备 crash buffer 中出现多次 `SIGABRT`，调用从 `ThemeScriptResolver` 的原生求值进入释放路径，最后在 `malloc_usable_size` 的指针标签检查处中止。该日志不等于内存泄漏诊断。

`malloc_usable_size` 查询在主题改动之前已经存在；本 PR 为主题实例新增执行预算、内存分配额度和栈限制。最近一轮配色与预览修订没有再次修改这些原生代码，对比 `b4c7a046` 与 `6477b130`，JNI、运行包装和 CMake 未再变更，不能把旧释放函数直接认定为新改动。

预览当前引用 `ChatHeader`，正式主聊天页使用 `MainChatControls`。旧组件还经由嵌入式 `AIChatScreen` 默认分支被调用，清理应包含该入口迁移。

## 实现说明

当前原生库的 JSValue 地址取值使用 47 位掩码，Android 堆地址的顶字节标记会在该往返过程中丢失；随后进入既有释放路径，系统在 `malloc_usable_size` 检测到标记被截断并中止进程。本轮在应用清单显式设置 `android:allowNativeHeapPointerTagging="false"`，使进程分配的地址与既有库表示一致。该设置影响整个应用进程的原生堆顶字节标记检查；不改变引擎源码、主题隔离、内存预算、栈预算或超时。

正式主界面、嵌入式聊天和制作预览共用 `MainChatControlsContent`，布局为菜单、对话标题、悬浮窗和工作区。嵌入式宿主使用当前 `ChatSidebarContent` 管理对话与角色，应用级导航仍由外层宿主持有。

删除旧 `ChatHeader`、`ChatScreenHeader`、`ChatHistorySelector` 和 `ChatHistorySelectorPanel`，以及旧 `showChatHistorySelector` 服务/代理/ViewModel 状态和 `useMainSidebar` 分支。旧 `appBar.history` 图标槽和专用标签移除，使用实际接入的 `appBar.workspace`；十三个图标槽数量不变。该主题协议仍处于本开发 PR，旧开发工程的历史槽应改为当前工作区槽后再导入。
