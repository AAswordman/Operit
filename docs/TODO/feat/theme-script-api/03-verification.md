## 全量回归步骤

1. 导入已发布的旧 .oktheme 并保存、重启。预期：颜色、字体、媒体、布局和分侧样式与原主题一致。
2. 角色 A 制作主题、应用草稿并保存，再切换 A/B。预期：定制只作用于保存的角色，B 保留自己的主题。
3. 编辑与切换角色组及单角色主题。预期：各目标分别显示自己的外观和素材。
4. 双方分别选择 Cursor/Bubble，切换宽窄布局并调整消息宽度/外形/文字。预期：正文、长文、流式内容、选择和链接可用，局部样式作用于对应侧。
5. 切换 Classic/Agent 和浮动输入，聚焦、录音、发送、停止、排队。预期：定制图标和交互状态正确，原有操作可用。
6. 添加、替换、删除 PNG/JPEG/WebP/SVG 并引用。预期：正确显示；删除仍被引用的素材时明确报错。
7. 编辑亮暗两套色板，切换亮色、暗色及跟随系统。预期：36 个 token 按模式应用，脚本读取当前配色。
8. 将消息、输入和背景透明度分别设为 0/中间值/1，组合玻璃与图片气泡。预期：装饰按区域透明度合成，正文清晰，底色不重复绘制。
9. 应用后放弃、重置，移除外观后分别放弃和保存。预期：草稿与持久化边界正确，未保存的暂存资源释放。
10. 复制角色或应用到全部角色，逐个删除共享引用。预期：其他角色继续显示，最后一个引用移除后资源删除。
11. 导出带素材的新 .oktheme，取消预览，再导入确认和重新导出。预期：取消无缓存残留，应用后离线可用，外观、源码与素材完整。
12. 接收新旧参数码/链接及无脚本完整包。预期：参数码保留接收目标外观，完整包按完整替换清除旧外观；新输出只用 oktheme 名称。
13. 输入语法错误、Promise、未知部件、未声明素材和原生桥调用。预期：显示诊断，无效内容不能应用到草稿，已保存参数不被改写。
14. 模块顶层及 render 分别无限循环或超额分配后恢复正常源码。预期：执行被限制，之后仍可编辑、校验和应用。
15. 超过源码/结果/清单/素材/像素/SVG/图层/坐标/内距上限，导入缺失或越界资源。预期：明确拒绝并清理导入暂存。
16. 保留原头像、字体、玻璃、图片气泡、视频背景和布局，保存/放弃/重启/分享。预期：原有主题设置仍按原流程生效。
17. 选择森林/信纸模板，预览后关闭或应用，再正式保存。预期：模板只替换工作室工程；未应用不改变角色草稿，应用后仍需保存。
18. 在设计/源码/资源工作区来回编辑，脚本合并 context.appearance。预期：可视化不覆写自定义源码，预览与草稿使用同一基础外观。
19. 替换 13 个图标绑定，调整尺寸、透明度和前景着色。预期：仅原本存在的入口显示对应素材，点击/长按/无障碍保留。
20. 编辑顶栏、导航、卡片、常用按钮和弹窗外观。预期：实际接入入口显示形状、配色与图层，内容可读且业务操作可用。
21. 编辑消息菜单、复制面板、消息状态和工具调用条。预期：对应入口显示装饰；菜单选择、复制和工具展开仍可用。
22. 使用位图九宫格并调整原图切片，尝试 SVG 与中心为空的切片。预期：有效切片保留四角并拉伸中心，无效素材或取整后无中心明确拒绝。
23. 切换导航选中态、按钮按下/聚焦/禁用态，并通过明确提供错误状态的入口显示错误层。预期：颜色和图层读取同一原生状态，禁用按钮不能触发操作。
24. 编辑全局和部件排版、头像尺寸及纹理，切换预览明暗。预期：部件消费对应字段，预览与保存后同模式的结果一致。

25. 将消息与输入框的填色设为透明、区域不透明度设为 1，再分别切换区域不透明度至 0/中间值，并显示隐藏占位消息。预期：透明底色上的图片/九宫格正常显示，图层只跟随区域不透明度，隐藏占位消息不出现底色或装饰。

26. 从主题页进入工作室，切换设计/源码/资源，在小屏和键盘弹出时收起预览。预期：原生全屏入口可返回；源码和资源占满工作区，设计属性可滚动，没有自由拖拽分隔条。
27. 选择全局字体、配色、图标、普通容器、按钮及导航项。预期：前三区域只显示外观；容器有图层；只有实际交互部件显示状态。
28. 切换聊天/组件/导航，打开部件分组侧栏并搜索。预期：场景同步到可见部件，标签触控范围充足；聊天标题在上、消息靠下、输入区贴底。
29. 在各颜色入口调整 HSV、ARGB、RGBA、透明度和预设色，再从位图/SVG 点按取色。预期：可输入六位 RGB 和八位 ARGB，连续输入不被强制改写；取色保留像素 alpha，浅深两列互不改写。
30. 在浅深模式分别调整形状、颜色、排版和图标，应用并切换模式。预期：当前模式覆盖按声明生效，脚本收到展开后的外观；移除一侧图标不改变另一侧。
31. 创建嵌套中文目录，导入、移动、重命名图片和字体，删除空目录及仍被引用的文件。预期：素材 ID 不变，绑定和缩略图保持；非空目录、被静态引用的资源和非法路径明确拒绝。
32. 保存工程草稿后关闭、重进、撤销和重做导入/删除/目录操作；连续拖动滑杆或编辑数值。预期：按角色恢复制作进度，资源对象与工程共同恢复，连续调整合为一步。
33. 修改工程信息和许可，导出当前未应用工程，再导入工程及走完整主题导入。预期：源码与素材路径不打平，空目录和元数据保留；工作室只载入脚本工程，完整导入保留原角色应用流程。
34. 将普通图片切到九宫格、拖动四条切线或输入像素，更换图片并切回普通图片。预期：切片留下非空中心，拉伸预览和原生绘制一致，替换素材重新设置切线。
35. 对位图切换平滑/最近邻、平铺与对齐，并在支持系统调整模糊。预期：采样与图层属性被原生消费；Android 12 以下明确拒绝非零模糊的工程。
36. 在 theme.json/manifest.json 输入错误，再切换文件、工作区、保存或导出；修正后同步。预期：错误可见且未同步文本保留，不能把无效工程当作成功应用；源码查找和格式化可用。
37. 导出同时带角色媒体与制作资源的工程，并令二者文件名或父目录相冲突。预期：普通媒体分配未占用路径，工程原路径保留，包内引用可重新导入。

38. 应用分别选择浅色、深色和跟随系统后进入工作室，查看设计、源码、资源、部件选择及工程信息。预期：外壳随应用模式取色，标题、正文、图标、输入文字与字体缩略图可读；切换样例浅深模式只改变预览。
39. 在常规和窄屏、放大系统字体下选择形状、字体、图片铺放、状态与留白联动。预期：选项等分占满每行，最小触控高度 52 dp，字体较多时换行；选中状态、触控及读屏单选语义正确，不靠横向小标签操作。
40. 切换浅深聊天预览、双方 Cursor/Bubble、头像与状态部件，打开全屏预览和软键盘。预期：预览有独立匹配的前景色与留白，标题在上、消息靠下、输入区贴底；消息、顶栏和输入复用正式展示，样例元信息跟随主题选项，选中状态部件时单独展示状态；主题页和布局页保留原完整样例。

41. 查看工作室顶部工作区与预览工具栏，从场景下拉选择经典聊天、智能体聊天、常用组件、侧栏与顶栏，再选择不同场景的部件并切换浅深模式。预期：顶部三个工作区保留，场景与当前部件相互联动；浅深切换只改变预览，全屏与收起继续可用，源码和资源不出现预览工具栏。
42. 打开场景、工程操作、源码文件、添加资源和添加图层五处菜单，检查当前选中项、长菜单滚动、返回键、点外关闭以及窗口边缘和 RTL 布局。预期：菜单锚定触发按钮并使用统一的大选项行，选择只触发一次原操作；取消不改选择，源码未同步错误继续保留原稿。
43. 拖动属性数值、色相与透明度滑杆并用数值框编辑，检查最小、中间与最大值，再编辑只有固定切片值的小尺寸九宫格。预期：细轨圆形样式一致，数值、预览和撤销合并仍同步；零长度合法区间保持固定值，不产生无效轨道比例。

60. 在 JS 入口编辑关键字、函数、数字、单/双引号、模板字符串和单双行注释，尝试未闭合内容及长源码，再切换文件和明暗。预期：轻量语法颜色可区分，字符串中的注释符不误判，未闭合输入不崩溃，光标、选区、查找与保存不被高亮改写。

61. 分别使用默认数据和从稳定版恢复的数据，将双方消息设为 Bubble，并交替混用 Cursor；为双方左右留白设置不同数值，再进入工作室切换经典/智能体场景和明暗。预期：进入消息预览不因缺失偏好崩溃，四个留白与正式聊天一致；默认留白使用现有 12 dp，保存及重进后自定义值保留。

62. 关闭旧媒体背景，在工作室给背景添加图片或纯填色，应用到角色草稿并在主题页保存，进入正式聊天并切换经典/智能体、Cursor/Bubble 和明暗。预期：背景在内容区域可见，不只露出状态栏；消息及输入按自己的不透明度遮挡，工作室外壳和工作区页面保持原有底色。
63. 组合旧媒体背景与工作室背景，分别调整背景不透明度和图层不透明度为 0/中间值/1，再移除图层与填色、关闭脚本、切换角色并重启。预期：按媒体→脚本背景→业务内容的顺序合成，不串角色，不残留已移除的背景；没有自定义背景时普通内容恢复原底色。
