# 主题数据与分享

原有 `.oktheme` 只携带偏好和媒体资源，主题资源没有脚本引用。本次将 `custom_theme_script_uri` 纳入现有角色主题键清单，并纳入私有资源管理；复制、保存、重置、传播和角色删除使用现有主题操作链路。

协议使用 `data/model/theme` 的共享模型，资源束由 `data/resources/theme` 存储，分享继续在 `data/themesharing` 扩展。模型和资源层均不依赖 UI 或主题执行器。

完整包统一导出 `format: "oktheme"` 和数字 `schema: 1`；可选 `script` 包含基础外观、源码和素材声明。参数码使用 `oktheme-params` 和 `oktheme://`，不携带脚本与素材，接收时保留当前外观。已发布的旧包、参数码和旧链接按明确格式读取；完整包没有脚本时按完整替换语义清除目标旧脚本。未发布的中间格式已删除。

预览资源写入现有主题传输缓存，预览关闭时删除。确认应用后创建私有脚本资源束，将内部引用保存到选定角色；失败时清理新副本。导出重新枚举并分配素材路径，设备私有路径不进入归档。

资源验证限制条目、源码、64 KiB 独立脚本清单、192 KiB 完整主题清单、48 个素材、位图像素和 SVG 内容；共享资源保留到最后一个角色或角色组引用被删除。
