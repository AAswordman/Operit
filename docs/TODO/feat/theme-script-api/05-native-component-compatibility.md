## 形状约束

主题支持的圆角、切角和圆形均可保留角点形状类型。为 `CornerBasedShape` 提供明确重载，原生玻璃调用可以直接接收解析结果；不需要改变玻璃组件的参数类型或主题的外观含义。

## 参考效果范围

像素主题的背景、消息边框、输入框边框、按钮图像和文件字体分别由现有媒体背景、九宫格图层、图标绑定及字体设置承载。本阶段核对时尚无独立的最近邻采样选项；后续[主题工作室](06-theme-studio.md)已补入采样、资源字体和原生九宫格制作。API 接入不等同于成品视觉验证，仍需原始素材、字体和切片参数。界面结构继续由原生页面和当前设备布局决定。
