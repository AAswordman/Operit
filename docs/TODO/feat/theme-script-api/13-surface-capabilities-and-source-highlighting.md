# 部件属性消费、形状描边与源码高亮

本轮继续在 PR #99 的 `feat/oktheme-script-api` 分支处理工作室实测反馈。经典输入文本区域目前只消费文字样式，固定原生填色、圆角和 1 dp 外框没有读取工作室外观；共用装饰描边沿外轮廓居中绘制后被裁剪，粗边框与部件原有边框也可能叠加。属性面板目前只按部件类别区分，仍展示固定尺寸部件无法消费的高度、头像排版及圆形半径等选项。

## 实施范围

- [x] 核对十九个区域的填色、形状、描边与布局消费入口，建立工作室属性能力清单；隐藏实际未消费或当前形状不适用的选项
- [x] 经典输入框接入真实外框的主题填色、形状、描边、留白和文字颜色；智能体输入与现有绘制入口保持一致
- [x] 共用描边改为形状内侧绘制，继承实际原生形状，避免裁掉半宽或重复叠加；核对顶栏填色与预览选择边界
- [x] 核对当前侧栏、设置卡片、列表和状态样例，修正可以直接接入的遗漏，不为不支持的能力制作空控件
- [x] 源码编辑增加 JSON 字符串及 JavaScript 字符串、注释、关键字和数字高亮，保持原文、光标、选择、输入法组合和撤销语义
- [x] 同步作者说明及全量回归步骤和空白结果表；完成相称静态核对；提交、推送与仓库工作流派发以 PR 记录为准

## 验证边界

按仓库约定不执行本地编译、构建或测试。源码高亮的字符串转义、注释隔离及偏移边界适合加入 JVM 回归代码，由仓库 Android Tests 执行。真实填色、粗描边、圆角/切角/圆形、经典/智能体输入、明暗与源码编辑的设备结果分别记录，不能用静态核对代替。

本轮不改变主题脚本权限、预算或分享格式；现有主题协议仍在当前开发 PR 内迭代。

## 实际实现与静态结果

经典输入使用与原生按钮一致的交互源作用域，并把主题形状、填色、原生边框与装饰连接到真实文本外框；没有声明主题时仍保留原生输入框。智能体两条输入路径同步形状与占位文字。共用描边采用 Compose 内侧边框，明确传入原生形状；按钮、卡片与当前侧栏只保留一个边框消费入口。顶栏填色与预览选中边界使用相同形状和实际部件边界。

十九个区域均核对到绘制入口，工作室对十八个有边界的区域提供形状和描边；背景、头像文字、固定高度部件高度、非原生材质高度和圆形半径等选项按能力隐藏。普通图片与九宫格的铺放/对齐分开显示。隐藏控件保留现有字段和分享格式。

新增 `studio/source` 包保存轻量扫描和颜色变换。JSON 只着色字符串，JavaScript 着色字符串/模板、注释、关键字、数字、函数和常见上下文名称；颜色 span 使用原文偏移，不重写文本。新增六个 JVM 扫描边界用例，覆盖转义/URL、注释、数字与函数、未闭合行、块注释开闭和 Unicode/模板偏移；只编写，尚未运行。

静态核对覆盖 28 个 Kotlin 文件、两套各 222 项工作室字符串、42 个相对链接、19 个区域和完整 60 项步骤/结果行。本轮没有新增 Material 图标引用。未执行本地编译、构建、测试或 Android 实机操作；仓库验证与设备结果分别记录。
