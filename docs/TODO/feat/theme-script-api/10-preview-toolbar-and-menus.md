# 工作室预览工具栏与统一菜单

## 原状与目标

原工作室把设计、源码、资源与聊天、组件、导航都绘制为同级外观的 TabRow，场景和浅深模式又分成两排。本轮保留顶部三个工作区，将预览场景收成下拉入口，右侧保留浅深切换，其他布局与功能沿用现有实现，并使用项目自定义组件统一交互外观。

## 实施单元

- [x] 保留工作区与部件属性布局，把场景选择和浅深模式合并为预览工具栏，保留全屏、展开与收起
- [x] 在 ui/components/menu 中提供锚定菜单容器，复用已有 ActionSheetItem 作为菜单行，接入工作室各菜单
- [x] 工作室数值、色相与透明度滑杆复用 WorkbenchSlider，维持原范围、输入和编辑历史
- [x] 更新制作文档与 43 项完整回归表，完成本轮静态核对

## 实现结果

ThemeStudioPreviewToolbar.kt 负责设计工作区内的预览工具栏。场景改为聊天、常用组件、侧栏与顶栏，仍调用原有 selectScene 维持场景与部件联动；顶部工作区、属性页及保存流程沿用现有实现。

WorkbenchDropdownMenu.kt 提供独立于主题模型的锚定弹层。菜单按布局方向对齐、按窗口空间选择上方或下方并限制位置，长内容可滚动，支持返回键与点外关闭。场景、工程操作、源码文件、添加资源及添加图层五处入口复用此容器和至少 56 dp 高的 ActionSheetItem；场景与源码文件显示选中状态，原操作与源码同步保护继续由既有状态处理。

属性数值、色相与透明度直接使用 WorkbenchSlider。共享滑杆补齐合法固定区间的轨道计算，避免九宫格切片范围为零时产生 NaN；原数值输入、范围和手势结束回调保留。
