# 主题工作室与资源工程

## 原状与目标

当前脚本入口是主题页里的对话框，可视化、源码、资源都在同一弹窗内。原生引擎已有共享外观、19 个区域、13 个图标、36 个配色 token、图层状态和九宫格绘制，但 V3 设计稿中的独立页面、工程信息、完整属性制作、目录资源与部分运行时属性尚未接入。

本轮按维护者确认的 V3 做原生 Android 工作室。入口保留在主题界面，主题仍绑定角色草稿并通过 .oktheme 分享。资源目录在工作室、工程保存、发布导出与重新导入时保持一致。只对已实现的字段展示可用编辑入口。

## 约束

新工作室不使用 WebView 装入 HTML 作为实现。HTML 是设计参考，真实页面使用 Compose 并调用现有主题引擎。编辑错误需要可见，不能把失败的脚本或资源当作成功应用。工作室应用到当前角色草稿，角色最终保存仍沿用主题页的保存流程。

文件夹路径使用相对 assets/ 目录，拒绝绝对路径、点路径、重复分隔符和目录穿越。导出不打平相对目录，包内资源引用与清单必须一致。空目录作为工程元数据保存，不依赖 ZIP 目录条目。

本轮不执行本地构建或测试，新增回归由仓库工作流执行。无法完成的实机交互验证单独记录，不作为提交和工作流派发前置条件。

## 实现与验证边界

制作界面、协议和原生消费已接线；本轮静态核对覆盖 35 个 Kotlin 文件的词法结构、209 个工作室中英文字串与资源引用、协议 JSON、文档链接及 diff。新增 15 项 JVM 回归代码覆盖模式、状态、页签、目录归档与普通媒体路径分配，实际执行交给 Android Tests。

Android 界面、字体加载、取色、九宫格触控与模糊尚未实机验证；Android Tests 当前仅执行 JVM 回归，不编译或执行仪器测试。工作室导入只接收带脚本工程的 .oktheme；完整主题参数应用仍走既有导入页。应用到角色草稿和保存工程进度为独立操作。
