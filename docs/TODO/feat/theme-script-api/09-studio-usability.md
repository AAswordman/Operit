# 工作室配色、触控选项与聊天预览

## 原状与目标

实际截图显示，浅色应用打开工作室后被固定深色配色覆盖，但普通文字与图标仍继承外层浅色页面的黑色内容色。形状、字体等属性使用紧凑的横向滚动标签，聊天预览又把角色占位名称、思考入口和统计堆进很小的区域。

本轮在现有工作分支修正工作室外壳的主题来源和默认内容色，扩大属性选项，并整理原生聊天预览。继续使用现有模型、素材与渲染入口，提交后重新派发 Build 和 Android Tests。

## 实现与核对

工作室入口与全屏子页统一通过应用主题快照和系统模式调用已有配色解析器，并提供匹配的 LocalContentColor。选择项使用 primaryContainer/onPrimaryContainer、surfaceContainerHigh/onSurface 等配套语义色，资源字体缩略图和浅深颜色列边框也不再使用独立暗色外壳。

属性选项等分整行，最小触控高度 52 dp；字体较多时每行最多三项，并根据可用宽度减少列数，文字允许换行。属性标题改为 titleSmall，字体名称补齐中文和英文资源。单选项保留键盘与读屏选择语义。

聊天预览增加外框留白与可用高度，前景色按预览模式独立提供，顶栏与输入框有配套内容色。简洁对话继续使用原生消息样例渲染，只隐藏紧凑预览的角色占位、思考入口和统计；选择 status 时单独展示状态。主题页与布局页通过原入口继续显示完整元信息。
