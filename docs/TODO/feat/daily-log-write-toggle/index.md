# 每日重置的日志写入开关

日志查看与导出页增加“写入日志”开关，默认开启。关闭后在 AppLogger 统一拦截文件和系统日志，主日志与工具包日志均停止新增；当日重启保留关闭状态，下一个本地日期恢复开启。

使用独立的每日状态策略保存关闭日期，日志热路径不读取磁盘。关闭时使排队任务失效，并与正在写入的任务共用锁，避免关闭返回后继续追加或重新开启后补写旧任务。现有日志仍可查看、导出和手动清空。跨天及系统日期、时区变化刷新界面状态。

验证由 Android Build 与 Android Tests 工作流执行，本地仅检查差异与资源。每日策略的 JVM 用例覆盖同日关闭、重启恢复、跨天、重新开启及重新关闭。
