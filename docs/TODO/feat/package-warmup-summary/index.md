# 总结后的已激活包说明

## 原状

对话总结后的“对话回顾”会把工具调用参数压缩后重新展示。摘要也会附加已激活包列表，并附上对应工具说明。

## 意图

- 对话回顾保留工具名、参数预览和额外正文预览
- 将摘要中的包说明统一表述为“已激活包”
- 在已激活包块中说明列出的包可以直接使用
- 不在系统提示词中增加已激活包的长期规则

## 作用域

- `AIMessageManager` 的对话回顾与已激活包文本
- 中英文相关资源文本

## 预期结果

总结后的上下文继续携带压缩后的工具调用参数，便于回顾任务过程；模型看到已激活包块后，知道其中列出的包可以直接使用。
