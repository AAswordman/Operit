# 离线主题分享协议

## 分享码

处理顺序为紧凑 JSON、UTF-8、标准 zlib、无填充 Base64URL。新链接固定为 `oktheme://theme/import?schema=1&encoding=zlib-base64url&data=...`，导入界面也接受不带前缀的编码正文。该链接用于复制粘贴导入；本次未增加系统深链接注册或网络主题服务。

顶层字段为 `format`、`schema`、`name`、`author`、`config`、`layout`。新分享码的 `format` 为 `oktheme-params`，新主题文件为 `oktheme`，数字 `schema` 为 `1`；完整包可选 `script`。已发布 `operit-theme-params-v1`、`operit-theme-v1` 和旧 `operit://` 链接按其原字段明确读取，新输出不再使用这些名称。名称和作者各不超过 80 字符，名称不能为空。字符串、布尔、颜色整数和浮点数使用各自的 JSON 类型；可选颜色和界面不透明度以 `null` 表示删除局部值。

固定白名单覆盖 130 项非媒体主题字段，另带五项全局聊天布局。角色标题、用户名、发送方角色 ID、模型配置和聊天内容不进入协议。字段、类型、枚举、数值范围和必需项均由独立协议模块校验，不能把任意 DataStore 快照作为主题导入。

文件字体的选择属于媒体设置：发送方使用文件字体的槽位不携带该槽位的字体选择字段，接收方已经使用的文件字体也不会被分享码关闭或切换。其余普通字段按码中值更新。图片、视频、头像、字体文件、资源启用开关及媒体裁剪、拉伸、缩放、透明度、模糊等调整保持接收角色原值。普通气泡边距、圆角、界面透明度和玻璃效果属于可分享外观。

## 完整主题文件

`.oktheme` 是 ZIP。根目录必须有 `manifest.json`，资源放在 `assets/`，由应用导出为 `1.png`、`2.ttf` 等自动编号名称。同一来源资源在包内复用同一路径。配置字段与完整素材集合一起导出，包括停用但仍保存引用的资源；没有素材的纯参数完整包也有效。

完整包还可以携带脚本、声明式外观及绘图素材，详见 [原生主题外观接口](../../../doc-src/feature-protocol/theme_script_api.md)。完整配置共 166 项主题字段，省略角色标题，空资源写入 `null`，非空资源必须使用合法的包内相对路径。导出自动收集角色主题中的背景图片或视频、双方气泡图片、主字体及双方消息字体、双方头像。使用全局用户头像时，将其收为接收角色的局部头像，不导出或修改全局用户身份。

导入拒绝缺少配置、未知协议版本、非法字段、缺少或为空的引用素材、损坏 ZIP、重复条目、越界路径和未引用的额外素材。文件只在独立缓存目录解包，校验和预览均不写入角色主题。取消会释放预览素材。

分享码压缩数据上限为 32 KiB，解压 JSON 上限为 64 KiB。主题文件上限为 512 MiB，解包后总量上限为 512 MiB，单素材上限为 256 MiB，ZIP 条目上限为 64，完整清单上限为 192 KiB。读取时按实际字节数计量并校验 CRC，不仅依赖 ZIP 元数据。

## 角色选择与应用

导入预览必须手动选择目标角色卡，包含内置默认角色。全局聊天布局单独标示作用范围。默认外观直接应用；已有自定义外观需要确认覆盖，角色身份中的 AI 头像及角色标题不单独触发确认。角色是否为内置默认角色与是否使用默认外观分别判断。

导入预览复用应用的正式颜色、字体、图片气泡、玻璃和视频渲染，展示紧凑聊天示例；全局聊天布局仍随主题应用并单独标示作用范围。分享码预览合并所选接收角色的媒体；完整包预览使用缓存素材。确认应用后才复制素材到现有受管理私有文件目录，并在单笔 DataStore 写入中保存目标角色主题及五项全局聊天布局。保存前再次检查目标角色与已有主题，不切换当前角色、不导入发送方身份，保留接收角色的自定义聊天标题。

应用与角色删除、切换和主题编辑共用操作锁。保存失败清理本次新素材；保存成功交由现有资源引用清理机制回收失去引用的旧资源。
