## 页面与交互

- 入口保留记忆管理大标题、说明和最近更新，取消整页模拟设备外框。当前查看的空间展示一张大卡片，其余空间使用紧凑行；查看空间与全局默认、角色固定空间独立，切换查看不会改变角色使用配置
- 角色使用展示角色卡头像位置，预览内嵌标明为示例的人像；Android 对接已有角色头像偏好。默认空间按 ID 保留删除保护，允许修改名称
- 记忆库默认按已有文件夹总览，数量和跨文件夹联系从同一份示例数据计算。顶栏保留空间底部选择面板、文件夹、搜索、图谱／列表，并直接提供选择、关联、添加入口
- 点击节点打开居中详情，显示完整正文、标签、文件夹、UUID、来源、内容类型、可信度、重要性与创建／更新时间。编辑补齐对应可编辑属性，文档正文保留只读边界，保存继续保留 UUID 与创建时间
- 「只看关联」实际只显示当前记忆及直接相邻节点和它们之间的连接，可以恢复原查看范围。图谱保留平移、双指缩放、归中、定位、多选与框选
- 关系线支持查看、编辑类型／强度／说明和移除；常用类型使用固定中文选项，名称集中为中英文资源表，已有类型值与大小写保持原样。未知旧类型保留为可选的原有关系
- 表单下拉和操作菜单采用统一浮层，支持查找、键盘选择、取消和草稿保留。编辑滑块采用与已有 ThemeWorkbenchSlider 一致的细轨圆形视觉，不画刻度，保留范围、步进和数值反馈

## 示例与实施边界

默认示例包含 Default 与项目笔记两个空间，Default 有三个文件夹、十二条记忆和十八条关联。所有操作仅保留在当前打开的页面，刷新或重置恢复示例，不读取或修改真实记忆库。

导入只处理 1 MB 以内的 txt／md 文件；搜索是本页文字匹配，图布局是确定的示例布局，不代表 Android 检索策略、大图布局性能、PDF／Word 导入或实机触控已经完成。

本轮只交付 HTML 和设计说明，Android 页面与字符串资源尚未改动。后续实施需接入现有空间、角色头像、文件夹、记忆和关联数据，保留文档导入、向量索引及历史重建入口。记忆设置的自动提取、检索和历史重建继续保留现有结构、参数和逻辑，仅按本轮要求复用指定控件外观。
