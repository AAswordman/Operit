# 第二版反馈与定稿范围

用户已认可第一版整体方向。本轮先补齐 HTML 交互稿，再据完整稿件实施 Android 页面；不在本轮混入 Android 功能改造。

## 入口

- 去掉整页的模拟设备外框、卡片底板与大圆角，保留内部排版、记忆管理大标题和说明。
- 只为当前查看的空间显示一张大卡片；其他空间使用紧凑列表，查看选择与全局默认独立。
- 保留最近更新及其进入列表的查看方式，数据跟随当前查看空间。
- 角色使用显示角色卡头像。Android 对接现有 `getAiAvatarForCharacterCardFlow(card.id)`，HTML 使用标记为示例的本地内嵌头像。
- 默认空间允许改名，继续禁止删除。溢出按钮常态透明，按压反馈结束后恢复，避免触屏悬停残留背景。

## 记忆库与图谱

- 继续默认按文件夹总览，保留文件夹筛选和图谱／列表切换。
- 顶部空间下拉继续使用底部选择面板，只切换当前查看的记忆库。
- 选择、关联、添加入口明确可见；新建与导入使用统一的紧凑弹出菜单。
- 点击节点直接打开居中的完整详情。保留正文、文件夹、标签、UUID、来源、内容类型、可信度、重要性与创建／更新时间。
- 「只看关联」实际裁掉无关节点及连接；可以恢复当前范围的完整视图。
- 关系线支持查看、编辑类型、权重和描述、删除；不以简陋文本框直接代替完整交互。

## 编辑、选择器与滑块

- 补齐记忆编辑的标题、内容、文件夹、标签、来源、可信度和重要性；保留内容类型等已有元数据。
- 记忆模块预览中的表单下拉、空间管理菜单和工具菜单统一样式，避免弹出原生灰底选择列表。
- 关系类型使用固定常用选项，中文显示；原有类型字符串不改写，未知旧类型仍可保留。中英文关系名称集中为字符串表，并记录 Android 资源键映射。
- 滑块参照已经存在的 `ThemeWorkbenchSlider`：4 dp 细轨、20 dp 圆形滑块、无视觉刻度，保留原范围、步进与数值。
- 记忆设置的自动提取、检索、历史重建板块保持现有结构、参数与逻辑。Android 实施时仅将该模块内原生滑块替换为共享的已有样式，不扩展成全 App 的无关改造。
