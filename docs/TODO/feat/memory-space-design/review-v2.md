JavaScript 语法检查通过；jsdom 的 49 组 DOM 交互与模拟指针检查通过，没有未捕获脚本异常。中英文关系资源 11 组键一一对应，常用关系类型为 10 项，额外保留原有关系的展示名称。

## 与现有 Android 能力的对应

- 角色头像沿用 UserPreferencesManager.getAiAvatarForCharacterCardFlow(card.id) 的已有数据来源，HTML 的内嵌头像只表示角色卡头像位置
- 详情与编辑字段来自现有 MemoryDialogs、EditMemoryDialog，保留文档正文只读、UUID、来源、内容类型、可信度、重要性和时间信息
- MemoryLink.type 继续作为已有字符串处理，中文常用选项仅负责显示；relation-resources.json 提供中英文名称与后续 Android 字符串资源键，本轮尚未修改 Android values／values-en
- 滑块参照已有 ThemeWorkbenchSlider 的 4 dp 细轨和 20 dp 圆形滑块，Android 实施继续保留原生交互、范围、steps 和无障碍语义
- 记忆设置的自动提取、检索和历史重建不改变结构与业务逻辑，相关控件外观按已确认范围处理

## 预览限制

所有统计来自示例状态，重置恢复两个空间、十二条记忆和十八条关联。新增、删除、重命名、关系编辑、角色绑定和导入不连接真实存储。

导入仅支持 1 MB 以内的 txt／md，文档错误与取消检查使用明确提供的模拟文件输入。搜索是标题与可选正文的文字匹配，图谱使用固定示例布局。真实字体、窄屏排版、触屏按压恢复、浮层滚动与滑块视觉仍需手机评审；没有 Android 实施、构建、安装或设备性能完成结论。
