## 设计取舍

- 全局默认作为空间卡片的状态标记，打开内容与管理空间分开；角色使用直接展示跟随全局或固定空间。
- 总览按已有文件夹聚合，分组间关联数量从原始关联计算。不会凭视觉距离发明新的记忆关系。
- 记忆节点保留简短标题和标签；正文进入详情。中文关系名称只用于显示，关联详情保留原始类型和方向。
- 分组内以可读字号开始，采用拖动探索；选中后聚焦相邻关系，低倍率切换为标记，避免缩出一屏微小文字。
- 加入明确的缩放、归中、搜索定位与列表入口，框选和建立关联放到有文字说明的操作面板。

## 预览限制与后续映射

HTML 只维护当前页面的示例状态。导入仅处理 1 MB 以内的 txt 和 md 文件，不包含 PDF、Word 的原生解析；检索不连接嵌入服务，最近更新使用示例排序。没有 Android 数据迁移、真实空间写入或设备性能结论。

后续若实施 Android 页面，需要接入现有空间与角色偏好、记忆统计、文件夹和关联数据；保留检索设置、文档导入、向量索引及历史重建入口；针对大量节点处理可见区域和布局开销。当前 HTML 的聚焦行为和分组方式属于设计建议。
