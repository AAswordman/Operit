# Android 第二版实施

用户已确认第二版设计，要求在 `feat/memory-space-design` 直接实施。两边都有的功能采用设计版界面，设计新增交互接入真实数据；设计未涉及的功能保持原样。

## 实施顺序

1. 提取共享细轨滑块，建立记忆界面的弹窗、选择器和菜单控件
2. 入口接入真实空间统计、角色头像、当前查看空间与最近更新，保留创建、改名、删除和角色绑定
3. 图谱增加文件夹聚合、可读节点、缩放归中、关联筛选和列表；搜索继续使用现有检索配置与仓库实现
4. 详情、记忆编辑和关系编辑采用设计稿层次，保留全部字段及文档分块查看编辑入口
5. 补充相关回归用例和完整设备验收，静态核对后提交推送，派发 Debug 与 Tests 工作流

## 边界

- 不迁移记忆数据格式，不改变空间 ID、已有关系类型和角色绑定语义
- 不改变记忆设置的自动提取、检索和历史重建业务逻辑，仅复用滑块外观
- 文档导入保留现有 txt、Markdown、PDF、Word 支持，文件夹管理与文档分块编辑保留原入口
- 本地不执行 Gradle 编译或测试，云端工作流受理与最终通过分别记录，派发后不轮询

## 调试版构建修正

按仓库固定的 Material Icons 1.7.8 来源重新生成图标子集，补齐记忆工作台新增的六个 Filled 图标，并同步静态清单。动态 Filled 名称目录保持 2,132 项。已使用同一提交的 terminal 源码执行图标引用检查，结果通过；最终构建结果由联调分支的调试版工作流确认。
