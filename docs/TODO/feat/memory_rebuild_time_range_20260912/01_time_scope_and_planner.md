# 时间范围与窗口规划

旧实现：

- `ChatMemoryWindowPlanner.plan` 接收整段会话消息，按窗口大小切分
- `ChatMemoryRebuildManager.start` 只接收聊天 id 和窗口大小

意图修正：

- 用密封类型表达构建范围：全部消息，或设备时区下的闭区间日期
- DatePicker 给出的毫秒按 UTC 日历解析成日期，再换成本地当天 0 点到结束日次日 0 点的半开区间
- 规划器先按范围过滤消息，再沿用原有切窗规则
- 区间外的用户或助手消息不进入窗口，也不作为跨窗上下文补回

预期结果：

- 同一天选择合法，结束日当天的消息全部计入
- 西时区不会把 UTC 午夜解析成前一天
- 现有摘要排除、窗口边界和群聊切片行为不受时间范围影响
