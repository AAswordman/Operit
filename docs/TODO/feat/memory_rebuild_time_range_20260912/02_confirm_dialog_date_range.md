# 确认弹窗日期选择

旧实现：

- 确认构建记忆库的弹窗只提供窗口大小
- 开始构建后处理已选会话的全部原始消息

意图修正：

- 在确认弹窗中提供全部消息和指定时间段两个明确选项
- 指定时间段时先收起确认弹窗，再打开独立的日历弹窗，用月份网格点选起止日期
- 日历弹窗确定后回到确认弹窗，并展示已选日期；取消则回到确认弹窗且不改日期
- 尚未选出完整起止日期时禁用开始构建
- 所选时间段内没有可提取的用户消息时，失败文案说明是时间段为空，而不是笼统的无消息

预期结果：

- 用户可以只总结某个时间段的记忆
- 全部消息仍是进入弹窗时的当前选择，行为与改前一致
- 进度、取消和窗口失败继续保持原语义
