# 按时间段构建聊天记忆

## 原状

设置里的聊天记录批量操作只能先勾选整段会话，再选择窗口大小后重建记忆。长会话一旦选中，就会把该会话里全部原始用户和助手消息送进记忆模型，无法只总结其中某一段日子。

## 意图

在确认构建记忆库时，让用户明确选择两种范围：全部消息，或某个闭区间日期。指定时间段后，只把该区间内的消息交给现有窗口规划器，窗口大小、摘要排除、顺序重建和进度取消语义保持不变。

## 作用域

- 新增可单测的记忆时间范围类型，把日期选择器的 UTC 午夜毫秒转成设备时区的半开区间
- 窗口规划器按该范围过滤消息后再切窗
- 确认弹窗提供全部消息和指定时间段两种入口，指定时弹出日期范围选择器
- 为新增文案提供默认语言资源和已有记忆重建文案的语言

## 验收

- 用户可以选择全部消息，行为与改前一致
- 用户可以选择起止日期，只处理该闭区间内的消息
- 起止同一天合法，结束日当天的消息全部计入
- 指定时间段但尚未选出起止日期时，不能开始构建
- 所选时间段内没有可提取的用户消息时，任务失败并给出对应说明
- 取消、窗口失败继续、记忆空间绑定规则不因时间范围改变
