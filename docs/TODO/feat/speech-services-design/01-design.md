# 页面结构与能力对应

## 配置方式

顶部保留朗读 TTS、识别 STT、语音唤醒三个入口。TTS 和 STT 各自维护独立档案，顶部卡片显示当前名称、引擎及本地或在线属性；点击切换，更多菜单提供重命名、复制和删除，选择窗口提供新建。新建可从当前档案复制，删除保留至少一个档案。

常用参数以紧凑行和短输入框直接编辑，不将所有选项放进同一个巨大下拉表单。高级请求配置、语音包选项及清理规则默认折叠。手机上选择与编辑使用底部面板，较宽窗口使用居中面板；返回入口指向手机统一设计索引。

语速、音调与清理规则归当前 TTS 档案，切换引擎不重置语速音调。设计稿暂存同一档案中各引擎的示例输入，供比较页面；这些预览状态不表示已更改原生数据模型。

## 朗读

系统 TTS 显示语言与系统音色，支持音色搜索、手动填写 ID 和恢复系统默认。VITS/Piper 显示本地语音包、说话人和选项 JSON。在线引擎按各自需要显示地址、凭据、模型或 App ID、音色；密钥可以切换可见性。

九个引擎入口与当前 VoiceServiceFactory 对应：系统 TTS、HTTP、OpenAI Realtime、硅基流动、MiniMax、MiMo、豆包、OpenAI 兼容和 VITS/Piper。模型与音色列表均标明为示例，不能作为服务支持名单。

语速、音调保留 0.5–2.0 的原范围，步长 0.25。朗读清理规则支持添加、编辑和删除，显示有效规则数量。自定义 HTTP 保留方法、Content-Type、请求头、原始请求体模板和响应处理流水线；请求体不强制为 JSON，请求头校验为对象、流水线校验为数组。VITS 选项单独校验 JSON 对象。原生接入时继续使用实际类型的完整解析与错误反馈。

试听区允许编辑一段文字，展示播放、停止和服务错误状态。波形仅为交互示意，不代表已生成音频。

## 识别

识别引擎对应当前 SpeechServiceFactory 的三个枚举：Sherpa NCNN、OpenAI 兼容、Deepgram。原页面说明里提到的 Sherpa MNN 没有出现在当前枚举中，本稿不增加该引擎入口。

本地识别隐藏地址与密钥；在线识别显示地址、密钥和模型。测试区合并开始与停止操作，保留语言、状态、完整结果和复制入口；离开标签或切换档案、引擎时结束本次演示。权限未授予与服务不可用可从稿件底部切换查看，不检查真实权限。

## 唤醒

按后台监听、怎样唤醒、唤醒以后、关键词附件的顺序组织。系统助手设置保留独立入口。STT 文字匹配保留唤醒词和正则开关；个性化唤醒展示模板采集、清除和重新采集操作，当前三格仅演示过程。

SpeechServiceFactory.createWakeSpeechService 当前对在线识别档案仍选择本地 Sherpa NCNN，所以稿中将后台唤醒引擎明确显示为本地，不将在线 STT 档案误标为后台唤醒接口。

问候语跟随开关启用，新建对话关闭时分组输入不可编辑；无响应超时校验范围为 1–600 秒。屏幕、通知、位置、时间四项附件在同一组中展示，支持总开关、单项启用和逗号分隔的触发词。

## 原生落地边界

已有配置档案、全局唤醒偏好、服务调用契约和已发布数据格式需要继续保留。这些原生能力的实施情况见 [原生实现说明](../speech-services-workbench/01-implementation.md)。HTML 只使用内存状态，不改变应用设置；模型、音色、语音结果和模板数量都属于交互示例。

原生阶段继续使用提供方实际支持的语言与音色，不以稿中的示例名称作为能力判断。正则预览使用浏览器可表达的语法，最终执行仍遵循 Kotlin/现有清理器。
