# 完整核对记录

JavaScript 解析与二十八组 DOM 交互核对通过。环境为 Node.js + jsdom 26，dialog、滚动和剪贴板使用环境桩；这些结果验证页面状态与交互，不验证实际浏览器排版、Android 录音或任何真实语音服务。

## 复核命令

在独立临时目录安装预览检查依赖，不修改 Android 项目依赖：

```sh
npm install --prefix /tmp/operit-speech-preview --no-audit --no-fund jsdom@26
NODE_PATH=/tmp/operit-speech-preview/node_modules node docs/TODO/feat/speech-services-design/verify-design.cjs /tmp/operit-speech-preview/results.json
```
