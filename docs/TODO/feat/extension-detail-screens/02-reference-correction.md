# 完整参考图纠正

## 本轮交付目标

上一版只完成路由迁移，管理详情仍沿用弹窗的信息结构，长介绍未折叠；市场介绍完全隐藏，头部和操作区仍未按完整参考图组织。本轮直接修正两个详情入口，不再扩展 UI 自动化范围。

- 本地详情：头像或字形图标、名称、来源、类型和版本标签；紧凑的打开按钮与启用胶囊并列；横向展示类型、状态、版本、子包和界面数量
- 本地内容：简介默认短预览，展开全文和收起可用；界面、子包、依赖、包含内容、信息及移除管理分别组织，保留原有执行、启用、配置和确认删除逻辑
- 市场详情：名称与发布者、类型和版本标签、安装／历史版本／发布操作进入头部；横向展示下载、喜欢、版本、更新日期和类型
- 市场内容：简介和详细介绍分别默认预览，开发者卡片及表格式信息；保留既定独立简介／评论顶部标签，不复制参考图中的页底评论区
- 两页统一使用有内容预览的折叠组件；不增加设备空间、仅本机或可用位置功能；只显示当前宿主真实提供的数据

## 核对方式

按完整参考图分别审阅头部、操作、信息栏、初始折叠状态和各内容分区；检查明暗主题、长名称、长版本和字体放大时的换行或横向滚动。静态检查和远程 CI 结果分别记录；本地不执行编译、构建或测试，源码完成不等于新包界面已通过设备验收。

## 实现与验证记录

- 两个详情入口共用头部、横向统计、介绍预览、信息表和内容分区；本地继续保留打开界面、父子开关、脚本执行、检查更新及确认删除
