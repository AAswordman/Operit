# 补丁 18：终端显示与键盘输入

现有终端在首次就绪后注入 ASCII 标志和欢迎语，默认 Bash 提示符占用输入宽度，Canvas 用绿色字符块表示光标。输入连接没有完整接入输入法确认动作和实体键盘事件，连续输入还会分别启动异步写入任务。

本轮删除启动展示文字，以不可见的目录控制标记替代本地 shell 的可见提示符；保留登录、就绪、命令完成与退出码协议。光标改为跟随文字颜色的细竖线，使用单调时钟闪烁。软键盘和实体键盘共享按键编码，处理确认、方向、删除、修饰键及中文组合输入，直接输入按提交顺序写入对应会话。

## 工作范围

1. 在主应用固定的终端版本上建立本地工作目录，保留已有资源分发和会话维护代码
2. 由应用管理的交互 Bash 配置载入现有登录配置，再设置不占字符宽度的目录标记；后台命令执行保持原接口
3. 输出处理区分不可见提示符与正文，处理控制标记跨数据块传输、首屏清理和目录更新；实际工具完成仍以原唯一标记为准
4. 补齐输入法确认、组合输入、实体按键和常用终端控制序列，统一按原顺序写入 PTY
5. 更新光标默认色、细竖线绘制和闪烁生命周期，并核对独立终端输入框
6. 维护回归操作和独立结果表，执行相称的语法、资源与差异静态核对，保存跨仓库累计源码快照

## 本地集成

主应用仍使用 `terminal` 模块和既有 Compose 接口。终端工作目录位于主应用的 `terminal/`，从 gitlink 固定提交 `5eb6c2c335bd979c669dc5796ca546a4568ea6a9` 建立，本地分支为 `feat/patch18-terminal-input`。用户原克隆的 `master` 为 `e4442bc6a047b6165bf59103721ad143149c620d`，与固定版本有 11 个文件不同，本轮不将这些既有差异带入应用。

终端源码已独立提交为 [48ebcbab](https://github.com/3316891527/OperitTerminalCore/commit/48ebcbab46beb53b04aa7b36c4be870ad4c4b184)，本次统一 PR 将主应用 gitlink 更新到该提交。[统一集成与回归](../patch18-integration/index.md) 记录七项改动的提交验证阶段；此前仅本地的限制属于先前累积阶段。

## 验证记录

已完成源码实现和相称文档。累计 78 个 Kotlin、22 个 XML、字符串引用、两段 Shell 语法和两个仓库的差异空白检查通过。前六项 93 个文件逐字节不变，唯一共享路径是 TODO 索引追加本轮入口。编译、构建、测试运行、设备验收和真实 GitHub OAuth 均未执行。

本地交互 Bash 改用应用管理的 rcfile，并读取原登录配置。依赖 login_shell 标志或 .bash_logout 的定制行为仍需回归；现有会话重新创建后才使用新提示符。远端 SSH 提示符仍由服务端决定。


## 完整回归操作与预期

1. 在已安装和新安装的 PRoot、Chroot 环境新建会话：首次就绪为空白输入区，没有 ASCII 标志、欢迎语和本地主机提示符
2. 在窄屏、横屏和不同字号下连续输入长命令：从行首使用可用宽度，自动换行位置与 readline 一致
3. 聚焦终端后等待、连续输入再移走焦点：细竖线使用前景色，每 500 ms 切换显隐，输入后立即显示，失焦时不闪动
4. 运行会隐藏、恢复光标的终端程序：遵守 ANSI 光标可见性，不强制显示绿色字符块
5. 切换到含空格、中文、百分号与控制字符的目录：目录事件恢复真实路径，屏幕及工具输出没有目录协议标记
6. 通过工具分别执行成功命令、false 和非零退出脚本：唯一完成事件及退出码正确，不在中间提示符处提前完成
7. 通过工具执行无尾换行输出及以美元符、井号结尾的正文：正文完整保留，不误认成本地提示符
8. 连续提交三条命令和同名命令：原队列顺序、命令 ID、实时输出和完成结果保持对应
9. 分别使用输入法回车、发送、完成、前往和搜索动作：PTY 收到一次回车，交互程序正常确认
10. 使用实体键盘主回车和小键盘回车：均可提交命令和交互选项，抬起按键不会再次确认
11. 在 GitHub CLI OAuth 中切换选项并按回车、处理按回车继续步骤：各步骤能推进，不因输入路径缺失停住；结果只由实际操作填写
12. 使用 read -p 等无尾换行的交互提示输入文本并确认：文字先于回车到达，等待状态正常恢复
13. 在普通历史输入和应用光标键模式下使用方向键及长按：方向正确，长按不叠加两套重复事件
14. 使用 Tab、Shift+Tab 和 Escape 完成补全与选项操作：终端收到对应控制序列，Android 焦点不代替终端处理
15. 使用 Home、End、Insert、向前删除、Page Up/Down 及 F1 到 F12：常用终端程序收到相应按键
16. 分别使用实体及虚拟 Ctrl+C、Ctrl+D、Ctrl+Z、Ctrl+L：控制字符只发送一次，保留中断、EOF、挂起与清屏含义
17. 使用 Alt、带 Ctrl/Alt 的方向键、右 Alt 字符和重音组合：修饰序列不被二次转码，国际键盘字符不丢失
18. 使用中文候选词并分别触发 commitText、finishComposingText 和确认：只提交定稿文字，未定稿文字不重复写入
19. 使用按长度删除、向前删除和按 Unicode 码点删除：删除次数正确，组合缓存不拆坏代理对
20. 提交含 LF、CRLF 的多行文本：换行统一为终端回车，没有额外空行或重复提交
21. 快速输入后立即切换、关闭会话，以及在有候选词时切换会话：已排队输入留在原会话，旧连接不能把文字提交到新会话
22. 反复进入退出终端、切到后台再返回和释放视图：焦点与输入恢复，方向键不持续发送，也不保留独立光标闪烁任务
23. 连接 SSH 并输入密码、选择选项，再退出到本地 shell：远端提示符按服务端配置显示，返回本地后使用应用零宽提示符
24. 将目录标记、UTF-8 文本和 ANSI 序列在不同边界拆块，并在同块中进入退出全屏：没有乱码或可见控制标记，退出后的正文和完成标记不丢失
25. 使用带环境变量、别名和 PROMPT_COMMAND 的自定义登录配置：配置仍加载，既有钩子保留，应用提示符不占宽度；依赖 login_shell 或退出脚本的行为单独记录
26. 分别打开主应用嵌入终端、独立终端输入框、直接输入和只读输出：光标与修饰键一致，只读视图不接收输入；后台隐藏命令、资源外置和环境维护路径保持可用

以上 26 项全部未测。[结果表](results.md) 单独填写；累计交付报告同时保留前六项的 94 项回归。
