# 会话选择与导出

## 现状

设置中的导出按钮直接导出全部聊天记录。HTML 和 TXT 导出的消息总数及长文本进度也按全部会话计算。

## 改动

- 导出前显示聊天记录多选列表，支持单选、多选、全选和清空
- 选择完成后复用现有格式选择对话框
- 导出层只写入所选会话，并以所选会话计算文本导出统计
- 选中集合为空时不执行导出，也不会扩大为全量导出
- JSON 保持现有 `operit_chat_archive` v2 结构

## 预期

用户可从“设置 > 数据备份与恢复 > 聊天记录”选择一个或多个会话导出；全选仍可导出全部聊天记录。
