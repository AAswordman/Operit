# 工作台终端与资源入口界面整理

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

用户实测聊天性能修复后，终端页成为下一项体验问题：当前界面同时显示工作台页签、Canvas 内部终端页签和底部输入工具栏，层级关系不清晰；侧栏展开时主内容的 3D 旋转和阴影让右侧聊天页像被压出一层厚重阴影。HTML 打包器在资源缺失时允许继续进入，直到真正导出才失败；离线资源页功能完整但视觉和状态表达简陋。

本轮目标是让工作台终端采用单一顶部会话导航、清晰的终端内容区和稳定的底部快捷键区；在 HTML 打包器打开和选择平台时检查对应模板资源；重新组织资源页的卡片、状态、进度和操作；移除主内容的旋转与阴影，保留必要的抽屉边界和点击遮罩。

不改变终端会话、命令执行、资源下载协议、导出接口和聊天历史逻辑。下载页不新增大资源操作，只调整本地 UI 和已有资源调用。
