# 实现与依据

## 工作台终端

原来 `WorkspaceHubScreen` 只提供一个“终端”页签，`ComputerScreen` 在内部挂载完整 `TerminalScreen`，产生两排会话导航、命令输入行和附加工具栏。现在工作台通过 `WorkspaceSessionTabs` 直接显示实际终端会话，支持切换、新建和带确认的关闭；关闭最后一个会话返回主页。环境配置与终端设置进入顶部菜单，设置页返回控制台后重新读取字体和快捷键配置。

新增 `ui/features/terminal/`，使用已有 `CanvasTerminalScreen` 渲染当前会话，底部常驻两排已有快捷键配置。画布不再传入内部页签参数，输入直接发往现有 PTY。Ctrl、Alt 和方向键使用对应控制字符或 xterm 参数。键盘动画期间移动快捷键和画布视口，稳定后提交 PTY 高度，避免动画逐帧重排终端历史。

本次作用域是聊天工作台的嵌入终端。终端库、会话管理和独立终端页面接口继续沿用原实现。

## HTML 打包入口

`HtmlPackagerScreen` 进入后先检查 Android 与 Windows 两份模板。两者均缺失时显示资源准备界面，有一种可用即可进入表单。检查在已有资源访问层的 IO 上下文执行，工具处理器仅在导出完成后打开文件时获取，避免进入工具就初始化。

`ExportPlatformDialog` 共用 `PackagerPlatformDialog`：显示每个平台的模板状态，点击后再次校验对应模板；缺失则打开对应资源管理页，资源准备后返回会重新检查。该流程也覆盖工作区的导出入口，配置表单不会在模板缺失时继续打开。实际导出仍保留原有资源校验。

## 离线资源页

`OfflineResourcesActivity` 保留下载确认、导入、共享目录备份、取消和错误处理。界面拆到 `OfflineResourcesContent`：顶部显示用途概览和准备数量，四类资源卡片分别显示图标、用途、大小与状态；操作期间显示当前操作和进度，已准备资源的主要操作变为保存备份。增加重新检查入口，Ubuntu 已安装状态与安装归档是否保存分别呈现。

新增界面文案同步提供中文和英文。页面不会自动开始下载，后台缺资源检查不会自动打开页面。

## 手机侧栏

`PhoneLayout` 原来给主内容施加旋转、缩放、纵向位移、圆角裁切和 18 dp 投影。主内容现仅横向平移让出侧栏，抽屉自身的边界、玻璃外观和点击关闭区域继续由原有逻辑负责。
