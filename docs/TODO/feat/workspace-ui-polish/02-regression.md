# 完整回归清单

本次补录：用户确认目前 Bug 均已修复，本页功能验收结果按用户确认记为通过。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

在 Android 真机使用相同主题与工作区验证。前版聊天性能已由用户确认明显改善，本版保留启动、历史加载与快速滚动的回归项。界面与导出场景未在本地执行，不以源码核查或构建成功代替设备结果。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 01 | 冷启动恢复长聊天，加载更早消息并快速往返滚动 | 保持前版改善，无明显新增停顿 |
| 02 | 从工作台主页打开终端 | 顶部只有工作台会话导航；正文是画布，底部常驻两排快捷键 |
| 03 | 新建两个终端会话 | 新建有忙碌反馈，会话分别可切换，无重复创建 |
| 04 | 在多个会话中输入、执行、滚动，再切换返回 | 内容及滚动位置各自保留，输入进入当前会话 |
| 05 | 点击会话关闭按钮，再取消确认 | 原会话和运行程序保留 |
| 06 | 关闭当前会话，仍有其他会话 | 切到剩余会话，页签和画布对应 |
| 07 | 关闭最后一个会话，再从主页打开终端 | 回到主页；再次进入可新建会话 |
| 08 | 切到主页或工作区，再回终端 | 会话仍在，键盘不会遗留在不相关页面 |
| 09 | 多次弹出、收起输入法，切换会话 | 快捷键在输入法上方；画布与光标可见，无逐帧历史重排 |
| 10 | 使用 ESC、TAB、HOME、END、方向、翻页和 Ctrl+C / Alt+F | 控制字符及导航正常；修饰键高亮并在输入后释放 |
| 11 | 在终端设置更改字体和快捷键，再返回 | 配置在控制台生效，返回层级正确 |
| 12 | 从顶部菜单打开环境配置，返回或提交配置 | 回到控制台，配置操作沿用现有终端逻辑 |

| 14 | 只准备 Android 模板，分别选择两个平台 | Android 可配置；Windows 引导准备对应资源 |

| 16 | 两种模板均准备后选择项目、入口并导出 | 两个平台均可进入原有配置和导出流程 |
| 17 | 从聊天工作区的导出入口选择平台 | 同样先显示模板状态并检查对应资源 |
| 18 | 进入打包器后清理模板，再选择该平台 | 重新校验并引导准备，不进入缺资源的配置表单 |
| 19 | 从打包器进入资源页下载或导入，再返回 | 自动重新检查，返回后保留当前所选项目与入口 |
| 20 | 模板检查报错后点击重新检查 | 明确显示错误，可重新检查，不误报资源可用 |
| 21 | 首次进入资源管理，再点击重新检查 | 四类资源显示用途、大小、检查状态和准备数量 |
| 22 | 对缺失资源点击下载、取消确认或确认 | 确认前不下载；确认后显示当前操作及进度 |
| 23 | 下载中取消、断网，再重试 | 取消或失败有反馈，完整文件保留，未完成资源不误报就绪 |
| 24 | 导入正确 ZIP，分别尝试缺失、重复、越界及损坏 ZIP | 正确包可用；无效包拒绝，已有完整资源不被覆盖 |
| 25 | 保存共享目录备份，取消保存，再卸载重装后导入有效备份 | 成功备份可恢复；取消产生的不完整文档被清理 |
| 26 | 语音模型使用中尝试覆盖导入或清理 | 使用保护继续生效 |
| 27 | 已装 Ubuntu 但未保存安装归档时查看卡片 | 已安装与归档未保存分别呈现，原终端可离线使用 |
| 28 | 准备 Ubuntu 归档后安装，并导出归档备份 | 原有安装、命令退出码及备份流程正常 |
| 29 | 已有完整语音模型时离线识别，并使用在线语音和普通聊天 | 既有模型可用；在线语音及聊天不要求下载离线模型 |
| 30 | 打开资源来源链接，检查应用更新页面 | 来源指向个人资源发行版；应用更新仍忽略资源标签 |
| 31 | 展开侧栏，查看右侧主内容，再点击外部或按返回 | 主内容仅横向平移，文字无倾斜和自身投影；关闭正常 |
| 32 | 切换深浅主题、玻璃侧栏及导航动画设置 | 抽屉边界正常，无新的主页面厚重阴影 |
| 33 | 在窄屏和英文界面查看页签、快捷键及资源按钮 | 标签可读，长会话名省略，操作不越界 |
| 34 | 全新安装且离线资源缺失时启动 | 不自动打开资源页或开始下载 |
