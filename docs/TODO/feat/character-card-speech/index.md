# 角色卡发言设置与存储入口调整

在 `feat/data-and-backup` 分支继续迭代，随 PR #24 提交。本轮只将 Waifu 配置合并进角色卡编辑，并把设置首页的「数据与存储」入口移动到「数据和权限」分组。

现有角色卡编辑使用二级弹窗中的基础、内容、绑定三个标签；新增发言放在内容右侧，绑定仍为最后一项，沿用弹窗布局与各页滚动。保留 Waifu 开关、打字速度、标点、合并发送、附加提示词、表情和自拍配置，使用现有二级文字编辑与表情管理。

现有 Waifu 独立页只操作当前激活目标。编辑页改为按正在编辑的角色加载草稿，保存角色时提交，取消不写入发言配置；保存非当前角色不改当前聊天，保存当前角色同步现有运行配置。沿用已有 Waifu DataStore 键与角色前缀，不变更角色卡或导出格式。

表情库沿用独立资源管理的即时保存方式，显式绑定编辑目标，不切换当前角色；新建角色需先保存再管理表情。主设置页移除独立 Waifu 入口，原路由仍可恢复已有导航状态。

实施范围：

- 发言草稿、指定角色读写和角色编辑保存衔接
- 四标签与紧凑发言设置，按目标打开现有表情管理
- 设置分组移动、字符串与完整设备验收清单
