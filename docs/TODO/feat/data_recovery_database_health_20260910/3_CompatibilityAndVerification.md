# 兼容性与核对

## 已发布接口

数据救援界面已包含在 v1.12.1。现有原始快照导入导出、SQL 输入、预设查询和恢复后重启入口保持不变。

## 静态核对

- “配置和数据库检测”区域位于 SQL 执行器之后
- 检查报告默认折叠，仅直接展示通过数量和问题说明
- 检测操作不向实时数据库执行写入 SQL
- 配置检测只读取隔离副本，配置修复仅由用户确认后执行
- 修复操作需要用户二次确认
- 原件保全不要求数据库能够成功打开
- 中文、英文和日文文案同步维护
- 不修改应用启动和其他存储 owner

## 未执行项

按仓库执行准则，除非用户明确要求，不运行编译、构建或测试命令。
