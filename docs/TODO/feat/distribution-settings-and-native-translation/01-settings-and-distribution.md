# 设置、内置包与发行版界面

## 原状与目标

个人版中仍有三个重复或不再需要的内置插件、停用的心流提供商，以及仅在总结功能中可见的思考配置。模型选择、资源准备、存储扫描及项目归属入口需要更明确。

## 实现

- 内置包白名单删除 `12306.js`、`thinking_guidance`、`message_translation`，删除已跟踪的 12306 asset。示例源码继续保留供手动安装；同步脚本原有的未计划产物清理会移除旧打包文件。PackageManager 原有启动扫描会清理不存在的启用记录及解析缓存，同名手动安装文件仍按外部来源加载。
- 密钥池组件内部统一使用 `Toast.makeText`，覆盖保存、导入、导出、删除与可用性检测的结果提醒。运行时换钥继续使用现有静默处理；最终请求失败继续保留错误结果。
- 模型搜索框改用最小高度，允许字体撑开；模型条目背景透明，勾选框与排序继续表示当前状态。
- 删除心流枚举、预设及服务和模型列表分支。模型偏好版本升至 5：旧配置转换为通用 OpenAI 兼容类型，保留配置 ID、分组、模型及凭据，清空已停用官方地址并保留自定义地址。旧数组导出和带分组导出均能迁移后导入。
- 新增独立 `functional` 控件目录及 `enhance/thinking` 服务目录。支持思考的生成类功能展示独立开关与档位，读取并传入实际请求；强制思考模型禁止关闭。普通对话由输入栏逐次控制，向量功能继续使用其适用配置。
- 删除独立设置中的人设卡生成项及废弃导航参数，角色卡管理中的 AI 创作入口继续连接原生成页。
- 离线资源页采用概览、语音、运行环境及打包模板目录，卡片显示用途、大小、来源、可用状态与操作。原下载、导入、备份及取消逻辑保持接入。
- 数据与存储首次扫描占满可用列表区域，透明背景内居中显示加载；有旧快照时继续展示统计与刷新状态。
- 关于页项目菜单分别提供个人版和上游仓库，反馈连接个人仓库 Issues；保留原作者署名并显示个人版维护者。
- 生成时间紧接本条消息正文，在底部信息区靠左显示“生成于”，与详情和候选回复控件同组，避免右下角孤立时间被误读。

## 兼容性与验收

旧聊天和配置不重建、不清空。旧心流官方地址需重新填写可用服务；手动安装的同名插件不自动删除。界面在 Android 设备上的实际效果尚待本轮候选包验收，详见完整回归清单。
