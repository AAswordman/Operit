## 来源与数据库适配

功能以 [上游 PR #1036](https://github.com/AAswordman/Operit/pull/1036) 的实现为基础。该 PR 已关闭且未合并；其 v21 → v22 迁移不能直接套用本分支。本轮新增 v26 → v27 迁移并接入现有完整迁移链，原有聊天、消息片段、分组及统计表不变。

`message_translations` 以聊天 ID、消息时间戳和目标语言为联合主键，保存原文 SHA-256、译文和更新时间，并对聊天建立级联删除外键。读取必须同时匹配原文哈希，因此编辑正文或切换候选回复后不会误用不同内容的缓存。重新翻译只覆盖该消息该语言的记录。

## 交互与请求

用户和 AI 的可操作消息通过长按菜单打开翻译窗口，隐藏占位消息或清理后没有正文的消息不显示翻译操作。窗口提供目标语言、原文、译文、复制及重新翻译。首次打开和切换语言只查询本地缓存，点击翻译才发送请求；使用功能模型中的翻译配置和思考设置。

流式译文按时间间隔更新，提供商重试撤销事件会立即撤销失败片段；思考内容不作为译文显示。密钥池静默换钥的空提示不产生未知错误提醒。请求使用服务租约，配置更新不会提前释放正在使用的服务。取消、关闭窗口、切换聊天和离开页面会清理当前翻译状态，取消后的回调不得覆盖新窗口。

仅完整成功的非空译文写入缓存。未配置模型、空结果和请求失败在窗口及 Toast 中给出结果，失败片段不写入缓存。复制原文或译文使用 Android 剪贴板及 Toast。
