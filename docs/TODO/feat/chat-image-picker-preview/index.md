# 聊天附件图片预览与应用内选择器

对应独立发行版路线图第 21 条的两个板块。已添加的图片缩略图原先没有预览入口，聊天图片添加依赖系统文档选择器。

本次在聊天附件模块新增独立的图片组件目录，通过 Jetpack Compose 实现全屏预览和媒体库选择界面。

- 全屏预览支持双指缩放、双击放大或复位、放大后拖动，以及右上角关闭
- 经典和 Agent 输入布局共用同一套图片选择与预览组件
- 选择器直接读取 MediaStore，支持相册切换、多选、确认添加和预览选中图片
- 处理完整或部分照片权限、权限变化、空相册和读取失败；取消不添加附件
- 图片复制到既有附件临时目录后再使用，重复内容给出提示

第 6 条全局 Toast 和第 22.2 条删除动画保留待定。本功能已与其余聊天体验改动汇总到统一测试版本并通过验收。

细化实现和完整回归清单记录在 [01-实现与验证](./01-实现与验证.md)。
