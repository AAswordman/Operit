## C 请求错误与重试

- C05：单密钥持续返回 429、503、连接超时或首 token 超时；预期：完整使用重试预算，期间保持处理中，最终提示一次

- C07：已输出文字后连接失败并耗尽重试；预期：保留部分输出，退出加载，不发送成功完成通知
- C08：重新生成返回参数错误或无效密钥；预期：不发布完成变体，仅由重新生成调用边界提示一次
- C09：重新生成成功；预期：生成并切换变体，退出加载
- C10：请求或重试过程中点击停止；预期：按取消处理，不显示终止错误，不发送完成通知

- E02：关闭开关后发送消息、调用工具包并触发错误；预期：AppLogger 不再向主日志、工具包日志或系统日志新增记录
- E03：关闭后在同一天重启应用；预期：开关仍关闭，已有日志保留，启动过程不继续追加
- E04：保持应用运行跨过本地午夜；预期：开关自动开启，后续操作重新记录
- E05：关闭后在下一天冷启动；预期：恢复默认开启，按原启动规则开始记录
- E06：同一天手动重新开启；预期：后续新日志正常写入，再次关闭立即停止
- E07：大量日志产生时关闭，稍后重新开启；预期：关闭前排队但尚未写入的日志不补写
- E08：关闭时导出、查看并手动清空已有日志；预期：管理操作可用，清空后不因普通操作自动产生新记录
- E09：关闭后改变系统日期或时区，使本地日期变化；预期：按新的本地日期恢复开启，页面状态同步更新

## F 继续生成

- F01：分别打开 Agent 与 Classic 附件菜单；预期：“继续生成”按顺序位于“当前位置”之后，Agent 列表中位于其下方
- F02：已有有效历史时点击继续生成；预期：直接出现下一条 AI 回复，不新增或显示用户气泡
- F03：输入正文草稿后继续生成；预期：草稿不发送、不清空，模型只沿当前历史续写
- F04：添加图片或文件并设置回复目标后继续生成；预期：附件与回复目标保留，不作为本轮用户输入提交
- F05：空聊天或只有空白内容时打开菜单；预期：继续生成禁用
- F06：生成中、总结中或存在待发送队列时打开菜单；预期：继续生成禁用，原取消和排队操作仍可用
- F07：快速重复点击，或点击后在配置读取期间切换聊天；预期：重复请求被拦截，切换后不会向新聊天误发续写
- F08：续写期间停止或令请求返回无效密钥；预期：停止按取消处理，请求失败沿用一次性错误提示
- F09：续写后检查聊天标题、历史数量，再正常发送并触发自动续写；预期：手动续写不改标题，历史只增加 AI 回复，普通发送与自动续写正常
- F10：群聊在某个成员回复后继续生成；预期：沿用最后回复成员续写，不凭空广播一个用户“继续”消息

## G 语音通话与发送按钮

- G01：Agent 的两种输入布局清空正文和附件；预期：发送按钮为灰色禁用态，点击不启动语音通话
- G02：Classic 清空正文和附件；预期：发送按钮为灰色禁用态，点击无操作
- G03：只输入空格或换行；预期：仍保持禁用发送态
- G04：输入有效正文后发送；预期：按钮恢复可用，沿用原发送和 Token 上限提示
- G05：只添加附件而不输入文字；预期：允许正常发送附件
- G06：生成过程中清空草稿；预期：按钮仍提供取消，能停止生成
- G07：生成过程中输入草稿并点击按钮；预期：保留原加入待发送队列行为
- G08：Agent 附件菜单点击电话图标的“语音通话”；预期：关闭菜单，沿用麦克风授权与全屏通话入口
- G09：Classic 附件菜单分别授权及拒绝麦克风；预期：授权后进入原通话界面，拒绝时提示权限原因，按钮与菜单状态正常
