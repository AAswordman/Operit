# 工作区审查与修正

## 计划

1. 核对尺寸来源，不将持久化数据损坏的推测写成已确认根因；移除非法值替换默认值的新增逻辑，明确校验状态。
2. 修正崩溃计数和停用标记的落盘时机，以及停用或初始化失败后的服务生命周期处理。
3. 统一尺寸读写边界，避免小屏下上下限倒置；补齐手动重新启动时的时间戳清理。
4. 静态审查最终差异并提交。

## 审查结果

- 崩溃记录改为单次同步提交，消除异步写入与进程退出之间的竞态。
- 初始化失败后的启动回调停止服务；销毁流程不再访问未初始化的窗口对象，异常处理器在清理结束时解除。
- 尺寸读写共用合法区间；非有限值明确拒绝，文档保留 NaN 来源尚未确认的限制。
- 手动重新启动同时清除计数和时间戳。
- 服务未就绪时不暴露 Binder；委托记录绑定结果，并在空绑定或窗口显示失败时解绑、清除悬浮窗模式状态。
