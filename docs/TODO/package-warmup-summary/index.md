# 总结后的工具包预热语义

## 原状

对话总结后的“对话回顾”会把工具调用参数压缩后重新展示。工具包预热会执行 `use_package` 并附上返回的工具说明，但包系统提示只把聊天中显式出现的 `use_package` 调用识别为已激活，因此模型可能再次激活同一个包。

## 意图

- 对话回顾仅保留工具名，不展示工具调用参数
- 将总结中的工具包预热明确声明为一次有效激活
- 在预热返回的工具说明旁明确要求直接调用工具，不再调用 `use_package`

## 作用域

- `AIMessageManager` 的对话回顾与工具包预热文本
- `SystemPromptConfig` 的包激活判定说明
- 中英文相关资源文本

## 预期结果

总结后的上下文不再重复携带工具调用参数；模型看到预热块后，将其中列出的包视为已激活，并直接使用预热得到的工具定义。
