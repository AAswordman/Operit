# 生成期间的队列与引导

经典和 Agent 输入框允许用户在一轮生成期间补充消息。普通队列按顺序在当前轮结束后发送；用户也可以明确选择把一项交给正在生成的回复。附件和引用跟随各自的消息。

- 采样期间接受引导时，结束本次模型请求，保存已展示的内容，使用新输入继续请求。
- 正在执行工具时，先保存工具结果，再消费输入。取消或失败不吞掉尚未消费的队列项。
- 查看[队列协议](../../doc-src/feature-protocol/chat_queue_and_steering.md)了解适用范围和队列生命周期。
