# Operit Kong 1.12.2+6

本次更新集中改善聊天管理、附件操作和日常使用体验。

- 修复工作区选择、创建与终端的主题和状态栏适配，完整遮挡底层聊天标题。
- 新增对话归档、查看归档和恢复，保留消息、角色绑定、文件夹及备份中的归档状态。
- 修复删除当前对话受阻和锁定状态误报，区分锁定、不存在及实际删除失败。
- 修复请求失败后静默结束，错误按回合提示一次；无效密钥与参数错误停止无效重试，余额、限流和暂时故障保留对应重试策略。
- 图片附件支持全屏预览、双指缩放、双击放大与拖动；使用应用内 Compose 相册选择器，支持相册切换、多选、预览和重复图片拦截。
- 附件菜单增加“继续生成”，直接沿当前历史续写，不新增用户气泡，不发送或清空草稿、附件及回复目标。
- 语音通话移到附件菜单并使用电话图标；空闲且没有正文和附件时，输入框显示灰色禁用发送按钮。
- 日志查看器增加“写入日志”开关，当天关闭状态在重启后保留，跨天自动恢复开启；关闭后拦截 AppLogger 的日志记录。
- GitHub 账号管理集中到插件市场；角色卡右上角的小资料图标直达完整资料编辑页，保留保存提示与记忆空间管理。

沿用 Kong 包名和固定签名，内部版本号升至 62。发布提供完整 APK，并以 v1.12.2+5 为基线生成增量更新。
