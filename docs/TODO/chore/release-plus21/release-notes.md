# 1.12.2+21 更新说明

- A2UI 支持在当前任务中等待表单提交：表单显示后，提交结果直接返回当前任务并继续处理，无需再发送一条聊天消息。等待时间可配置，超时、主动取消和停止任务都有明确结果。
- 修复 A2UI 中 HTML 页面切换标签时的视图生命周期问题，调整 WebView 的复用和销毁时机。
- 修复长回复主题气泡的重复切角与描边接缝，主题九宫格图片的上下装饰各显示一次；调整上下留白，并修复自定义头像尺寸造成的首段与续段错位。继续保留长消息按需加载。
- 主题工作室按工程记住上次的深浅色、编辑组件、属性页和预览位置，重新打开后可接着原来的位置编辑。
- 改进终端命令取消与会话恢复，准确区分上下文保留和环境丢失，避免把已经恢复的取消或超时错误显示为环境丢失。
- 修复历史摘要中模型协议负载直接显示及再次进入请求上下文的问题，保留正常正文和代码示例。
- 点击聊天通知可打开对应会话；修复 Gemini 请求中的空内容片段问题。
- 补齐 MCP 服务启动过程及各类结果反馈；聊天建议菜单仅使用斜杠 `/` 触发，减少普通输入时的误触。

版本为 `1.12.2+21`，内部版本号为 `77`。沿用现有应用身份与固定签名，从 `1.12.2+20` 生成增量包，同时提供完整 APK。发行产物由工作流校验后发布到统一更新仓库，应用内检查此补丁版需开启 Beta 计划。
