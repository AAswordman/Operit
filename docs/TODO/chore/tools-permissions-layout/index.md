# 工具权限收口与目录整理

本次工作先将工具权限实现统一为标准、管理员和 Root 三档，再依据逐文件迁移清单整理工具目录。权限收口与目录迁移分别提交，便于核对行为变化与路径变化。

## 当前状况

用户可选模式已经是 `STANDARD`、`ADMIN`、`ROOT`，工具实现仍保留 Standard、Accessibility、Debugger、Admin、Root 多层继承。`core.tools.packTool` 的解析、加载、运行、安装、界面 DSL 和元数据文件混合放置，工具的其他目录也需要按职责整理。

## 执行顺序

1. [权限实现收口](01-permissions.md)：删除旧工具等级和无行为的中间层，管理员按实际授权使用无障碍、Shizuku，Root 复用管理员能力。
2. [目录迁移](02-layout.md)：读取权限收口后的工具源码，先记录逐文件当前路径、目标路径及目标包名，再按清单迁移并同步引用。

迁移清单只记录本次实际迁移的文件。目录整理以保持工具调用接口及现有行为为目标。

## 验证与交付

记录静态引用、路径、配置及差异检查，编译与 JVM 单测通过仓库工作流验证。推送工作分支后先派发仓库工作流，再创建以 `dev` 为目标的 PR。工作流受理与实际运行结果分别记录。

详见[验证记录](verification.md)。
