# 01 权限实现收口

## 原实现与目标

用户模式已经是 `STANDARD`、`ADMIN`、`ROOT`，但文件、系统、设备和 UI 工具仍经过无障碍、调试、管理员等历史继承层。目标是让工具实现直接对应实际职责，管理员统一使用已授权的无障碍和 Shizuku，Root 保留自身 UI 行为及现有能力选择。

## 修改范围

- 文件工具：将调试文件实现与管理员路由合并，直接继承标准文件工具，保留只读与写入操作原有路由。
- UI 工具：将无障碍操作与 Shell 操作收入管理员工具，显式区分内部操作方法；Root 继续继承管理员实现。
- 系统工具：管理员直接继承标准实现，承接原 Shell 操作。
- 设备信息及 Root 文件、系统工具：移除没有独立行为的工具壳，通过现有授权能力选择执行后端。
- Shell 与操作监听器：将 `Debugger` 实现准确命名为 `Shizuku`，同步工厂、日志和提示。
- 配置：历史值只由现有 DataStore 迁移入口转换为 `ADMIN`，运行时模式解析只识别三档名称。
- 回归覆盖：维护现有权限能力组合与偏好迁移测试，交由仓库工作流执行。

## 验收

- [x] 工具实现中不再存在无障碍等级、调试等级及对应继承层
- [x] 管理员包含原无障碍和 Shell 操作，Root 保留原操作行为
- [x] 运行时模式只有标准、管理员、Root，旧偏好可迁移
- [x] 工具名称、参数和结果格式保持现有契约
- [x] 静态引用与语法检查完成，操作体迁移逐项对比；仓库编译与运行验证结果在 PR 中记录
