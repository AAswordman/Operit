# 1.12.2+19 更新说明

- 新增角色自定义主题脚本接口与原生主题工作室，支持可视化编辑、真实聊天组件预览、主题工程与素材管理、形状描边、图标替换和源码高亮；修复气泡预览读取字段导致的崩溃，以及应用主题后背景只露出顶部的问题。
- 终端内置 `apply_patch`，已有 Ubuntu 环境也可在启动会话时安装；支持补丁检查、差异预览、禁止覆盖、文件输入和 JSON 输出。
- 工作区复制、移动改用流式文件传输，减少大文件操作的内存占用；复制、移动和删除过程提供进度显示。
- 统一标准、管理员与 Root 三档工具权限实现，按职责整理工具、聊天和工作区代码；外观设置相关标签统一为“界面”。
- 修正硅基流动 Qwen3-Omni 的音频请求格式，明确不支持的音频内容不再重复换钥请求；语音识别成功后，不再留下已放弃音频尝试的临时错误提示，已转写语音重试直接使用文字。
- 总结内部重试通过进度与 OKToast 实时提示，并正确区分并行会话、取消和切换会话的提示归属。
- 修复单密钥、空密钥池和空白密钥池的请求失败被误报为“密钥池耗尽”的问题，保留真实请求错误信息。
- 附件添加成功提示统一为简短文案，支持点击关闭，并同步多语言文字。

版本为 `1.12.2+19`，内部版本号为 `75`。继续使用现有应用身份与固定签名，从 `1.12.2+18` 升级；完整 APK、增量包及发行元数据由发行工作流生成并发布到统一更新仓库。应用内检查此补丁版需开启 Beta 计划。
