# 设置入口、终端核心与版本格式更新

本次补录：用户确认目前 Bug 均已修复，本页功能验收结果按用户确认记为通过。验证来源及现有 CI 记录见[验证结果补录](06-验证结果补录.md)。

模型配置页原有“上下文设置”和“总结设置”两组展开入口，设置首页另有独立的“上下文与总结”板块。本轮将入口集中到设置首页的 AI 模型配置板块，位于功能模型配置下方，继续进入已有的上下文与总结页面。

模型配置页移除重复入口及其本页专用组件。配置管理、上下文与总结页面、持久化字段和运行时上下文处理保持原有实现。

## 版本格式

上一固定签名版的 `1.12.2-personal.1` 不符合插件市场和 ToolPkg 的版本解析规则，分别导致市场页面抛出异常和沙盒包加载失败。新发行版改用现有规则支持的 `1.12.2+1`，versionCode 从 52 提高到 53，沿用已有固定签名、Kong 包名与 APK 专用构建。两处解析器的源码正则均已核对，不修改版本比较规则。

## +5 终端键盘修正

嵌入式终端停止向画布传入键盘动画平移量。原实现会先将全部终端内容向上平移，再在键盘稳定、PTY 行数提交后清零位移，导致画面被抬出视口又跳回。现在画布保持顶部锚点，快捷键栏继续跟随键盘，键盘稳定后按可用高度调整终端行数。宿主页继续由终端自行处理 IME，避免叠加外层填充。
