# 工具超时按失败返回

本次补录：用户确认目前 Bug 均已修复，本页功能验收结果按用户确认记为通过。验证来源及现有 CI 记录见[验证结果补录](06-验证结果补录.md)。

本轮补充到待发布的 `1.12.2+5`。此前普通终端、流式终端及隐藏终端虽然返回 `timedOut=true`，却将错误信息设为空，最终得到 `success=true`。三条路径现在均返回失败，并使用字符串资源提示“终端命令执行超时”。已收集的输出、会话标识、退出码和超时字段继续保留在底层结果中。

脚本调用经过现有公共桥接后，终端超时会拒绝 Promise，异常的 `data` 包含原始终端结果。`super_admin`、`github`、`code_runner` 等通过该桥接执行终端命令的包使用既有失败处理，不再因命令没有抛出普通异常而得到成功。依赖超时成功返回的脚本应在异常处理里读取 `data`；公开类型说明同步更新。

浏览器动作等待到期后，统一等待入口进入现有失败处理，提示“浏览器操作等待超时”，不再继续构造正常完成的响应。BLE 特征读取超时也改为失败，合法的零字节读取仍算正常完成。MCP 重启、聊天等待和普通 Shell 执行已有超时失败处理，本轮保持其行为。

终端与浏览器超时提示覆盖现有八种语言。工具结果的勾叉继续按 `success` 显示；本轮不新增耗时展示。
