## 仓库检查范围

- `assembleDebug`：构建包含全部迁移的 Android Debug 包
- Candidate checks：按实际源码与测试范围执行 Android JVM 完整回归，并编译受影响的 Android 测试；既有用例仅接续导入，保留全部断言
- `WorkflowModelCompatibilityTest`：读取迁移前五种节点、两种参数的完整类型名；新写入数据继续使用原类型名
- 既有模型、协议、数据库往返、聊天备份、记忆、密钥池、主题与工作流回归均继续纳入，不能只执行本次新增两项

## 静态核对

S01：逐一对照 42 项整文件迁移及混合文件拆分，除包名、导入和显式原 serial name 外，字段、默认值、字符串与实现一致。

S02：对照 Room 与 ObjectBox 数据库定义、全部 schema、实体字段和 UID；内容保持一致，属性转换器只更新引用。
