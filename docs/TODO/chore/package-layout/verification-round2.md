## 仓库工作流与执行限制

对最终提交派发以下既有工作流，派发受理不表示检查通过；不等待或轮询 CI。

- C01 Android Build：`:app:verifyCiPreviewRelease`，覆盖 Release 编译、打包及现有签名/安装身份检查，publish_release=false，complete_repository_migration=false。
- C02 Android Tests：`:app:testDebugUnitTest`，覆盖 Debug 主源码、既有 JVM 测试编译与执行，包含第一轮 API 和本轮功能、工具类涉及的既有测试。

第一轮测试变绿是维护者反馈，不能代替本轮最终提交验证。当前配置未开启 R8 压缩，不把构建描述为 R8 运行验证。Android 设备测试、系统文档访问、真实服务、语音、Widget 与设备 UI 未在本地执行，下面的设备回归为可选记录，不阻塞路径迁移交付。
