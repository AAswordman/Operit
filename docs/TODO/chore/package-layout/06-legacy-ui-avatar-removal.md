# 删除废弃原生工具界面与虚拟形象

基线为 `29972a8a1490b188dbca5ca505b08c1bd7ae3e0c`，继续使用 `refactor/package-layout` 与 PR #67，目标分支为 `dev`。

## 范围与边界

- 删除 AutoGLM、FFmpeg、Shell 和 SQL 的旧原生页面、专用 ViewModel、包装函数、Screen 和隐藏路由；保留插件及宿主底层执行器、手机自动化代理、数据库和终端。
- 删除动态虚拟形象的模型管理、导入预览、动画渲染、表情控制和语音悬浮界面中的形象展示，核对专用 XML 标签与提示词、原生模块、构建和资源引用。
- 保留 Waifu 模式的消息分段、流式输出、模拟打字、配置和插件 API；保留语音朗读、语音通话控制及普通悬浮聊天。
- 保留用户与 AI 的图片头像、角色卡头像和主题头像配置；头像图片与虚拟形象模型按实际数据来源区分。
- 保留旧工具箱 UI 注册接口的空操作兼容，以及默认 Compose DSL。

## 实际依赖与删除结果

虚拟形象配置由独立 AvatarRepository 管理，包含模型导入、动画映射和语音形象开关；聊天图片头像从主题和角色卡的图片 URI 读取，两者不共用模型配置。Waifu 模式提供消息分段和打字效果，它的处理器、偏好、SDK、QQ 插件调用和既有测试保持。

四组旧工具共 11 个页面/专用状态文件及对应五个 Screen 已删除，原生执行器、PhoneAgent、工具注册和应用数据库保持。虚拟形象的 35 个 core/avatar 文件、专用导入配置页、Repository、原生 View 与表情控制已删除，语音界面保留图片头像、波形、录音、通话和朗读。

清除形象专用的 <mood> 提示词注入、编辑建议和内置渲染处理。普通 XML 与插件 <emotion> 渲染继续使用既有处理，旧历史消息不重写。共享的 XML 清理函数原样移到 util/text/XmlTagCleaner，语音设置共用组件原样迁到现有 speech 包；不保留无调用的形象管理器。

移除 avator 下 DragonBones、FBX、MMD 三个专用模块，共 102 个受控文件，以及 Gradle 模块声明、Filament 依赖及 Candidate 范围中的对应项；保留其他原生模块和 FFmpegKit。旧配置和用户导入文件不会被后台清除。

九套语言各删除 307 个无调用字符串，共 2763 份定义，其余 74645 个资源条目与基线一致。当前 README、架构和构建说明同步删除已不存在的能力；历史迁移清单按原快照保留，本次差异由 removal-migration.json 记录。
