# 同步路径重构后的固定内置扩展资源

基线为 `f2d9a9caf1f17d5139cc1e2e33c0d92417369e48`。Android Tests 在 syncMainAssets 阶段发现 sandbox-automatic-ui-base 的固定源码指纹不匹配。共用 SDK 类型也参与每个扩展的指纹计算，本轮影响全部 40 个扩展，并非只有首个报错的脚本。

## 修复范围

1. 核对已有 51 个资源 ZIP 和 40 个真实已构建扩展与当前固定目录的大小及 SHA-256，并确认其源码指纹与重构前的 5efa22e 快照一致。
2. 使用本分支已经批准且逐文件核对的名称变换，同步已构建插件归档中的受影响脚本和清单；其余归档条目保持，更新全部扩展源码指纹并准备新固定版本。
3. 保持九种工程模板、语音引擎与 OCR 模型的内容及版本，逐项核对新目录、归档内容和校验清单。
4. 在维护者资源仓库发布完整新固定版本，更新应用 offline-packs.json，并再次执行 verify_hub_catalog.py。
5. 提交推送到原分支与 PR #67，重新派发 Android Build 和 Android Tests，不等待或轮询 CI。

本轮不修改资源校验规则，不运行本地 Gradle、TypeScript 编译或应用测试。已有真实扩展产物经过摘要匹配后，仅应用本分支已提交的受控名称变换；准备资源属于归档与校验操作。
