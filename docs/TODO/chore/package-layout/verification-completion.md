- S03 Android 包名：九份此前保留包声明的文件全部对齐物理路径；677 行最终 UI/工具/集成清单的目标均实际存在且包声明匹配。
- S04 Manifest：七个组件名称同步为新包名，其余属性、权限、authority 和结构保持；每个改名组件均可定位到对应源码。Widget XML 的 configure 指向新的配置 Activity。

- S06 旧名称：扫描 3,504 个有效文本文件，除清单内明确保留的旧 API 空操作、类型和导航忽略处理外，旧模块、FFmpeg 路由和迁出的组件完整名称没有残留。图标库关键词作为原样第三方检索数据保留。

- S09 格式与文档：工作树和暂存 diff 格式检查、更新文档的相对链接核对通过。SDK 与开发指南同步新接口和升级影响。
