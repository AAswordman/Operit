# 当前清理版本的验证与回归

本记录覆盖 PR #67 的 API 路径迁移、功能目录整理、工具箱注册兼容、Android 组件改包、固定资源同步及旧界面和虚拟形象删除。前三阶段静态结果按各自快照保留，本轮以 `29972a8a1490b188dbca5ca505b08c1bd7ae3e0c` 为比较基线。

## 已执行的静态核对

- S01 固定差异：逐项核对删除、移动和修改清单及 SHA-256，核对 1853 个范围外应用 Kotlin/Java 文件逐字节保持。
- S02 保留能力：939 个不同文件的摘要保持，覆盖 Waifu 消息处理、图片头像和角色卡偏好、执行器和数据库、SDK/插件与固定资源、语音以及 Android 组件入口。
- S03 共用实现：XML 清理函数正文保持，语音设置组件只改变包声明；Waifu 提示规则和手动朗读正文保持。
- S04 删除完整性：五个旧工具 Screen、形象配置 Screen、路由、形象控制与模型工厂、原生模块及构建引用无运行代码残留，剩余 Kotlin 词法结构、Python 语法和工作流 YAML 静态核对通过。
- S05 文案：九套语言各删除 307 个无调用字符串，共 2763 份定义；其余 74645 个资源条目与基线一致，XML 可解析。
- S06 固定资源：插件源码、SDK 与 offline-packs.json 保持；使用 `verify_hub_catalog.py` 确认当前 51 组资源、193 个模板源文件及固定指纹一致。
- S07 阶段证据：第一轮、第二轮和命名收尾记录分别在原快照复现，677 行路径表为命名收尾时的历史快照；本轮删除及语音组件移动由 removal-migration.json 记录。
- S08 提交检查：相对链接、实际暂存范围、工作树和暂存 `diff --check` 核对；提交、推送、PR 更新与两个工作流受理状态在交付收据中记录。

复现清理静态核对：

```sh
python tools/package_layout/verify_legacy_removal.py
python ci/distribution/resources/verify_hub_catalog.py
git diff --check
git diff --cached --check
```

静态结果只说明检查范围内的内容和引用一致，不能替代应用编译或设备功能检查。本地未运行 TypeScript、Gradle 编译、应用构建、JVM 或设备测试。只有最终提交的 Android Build 与 Android Tests 执行通过后，才能记为本轮仓库验证通过；派发 HTTP 204 不等于执行通过。

## 重点人工流程

工作流通过后优先执行下面七组代表流程。同一代表流程覆盖多个改动依赖，无须把所有模型、工具、页面和插件组合逐一尝试。其余项目保留在完整清单中，按使用场景和出现的问题选择，既有通过结果只有对应同一提交与环境时才能复用。

1. 现有数据启动与导航：安装升级后打开原有对话、设置和插件列表，再返回；预期数据保留、导航正常，没有旧工具箱或虚拟形象入口。覆盖 D01、D09、D10、D23。
2. 普通聊天与 Waifu：普通模式发送一条消息并取消一次，再开启 Waifu 接收含多句的回复；预期流式取消正常，分段与模拟打字延迟保持。覆盖 D01、D02、D24。
3. 语音和悬浮窗：使用现有语音档案完成一轮识别与朗读，点击头像结束语音态；预期图片头像、波形、录音、停止和返回正常，不初始化虚拟形象。覆盖 D04、D05、D06、D26。
4. 图片头像与角色卡：选择或查看一个现有角色卡头像及主题头像，重开聊天和语音界面；预期图片及保存值保持。覆盖 D09、D25。
5. 插件执行与界面：打开一个现有插件设置页并执行一个熟悉的工具；预期默认 Compose DSL 可交互、旧注册调用不阻断加载、工具仍执行。需要检查 FFmpeg/Shell 时使用信息查询或无副作用命令。覆盖 D08、D11、D19、D21、D22。
6. 附件和系统文件入口：通过系统文件选择器读入一份文件并发送或导出；预期授权、DocumentsProvider 和附件引用正常。覆盖 D03、D13、D15。
7. 桌面组件：重新添加一个常用的语音或 ToolPkg 组件并打开其路由；预期配置和渲染正常，旧组件身份变化的影响按此前约定处理。覆盖 D16、D20。
