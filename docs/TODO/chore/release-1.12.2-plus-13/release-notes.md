1.12.2+13

- 调整聊天发送协程和取消后的资源收尾，修复取消请求时可能触发的崩溃。
- 增量更新增加 HTTP 字节范围、响应长度和分段偏移校验，避免不匹配的下载数据进入安装包还原。
- 辅助音频理解将转写原话、声音观察和附加请求上下文分别处理，避免将背景描述混入原话；历史文字观察继续用于后续对话。
- 累计用量按用户消息、AI 消息、工具结果、系统提示词、常驻工具、模型上下文协议与包工具、技能目录、压缩摘要和其他九类展示与保存，兼容旧会话及 JSON、CSV 备份。
- 修复工具失败时重复展示同一错误的问题，终端非零退出时保留捕获到的命令输出、退出码和诊断信息。
- 缩小过期图片与音频标签，使标签对齐消息内容边缘，并恢复过期音频消息的头像显示。
- 模型上下文协议服务改为用户手动启动，移除应用开屏自动部署、启动及其进度提示；中文界面统一使用“模型上下文协议”和“技能”。
- 修复模型上下文协议配置缺少作者或作者为 null 时，刷新列表和复制元数据引发的异常，并保留备份导入中的整型时间戳。

提供固定签名的完整 Kong 安装包，以及从 1.12.2+12 升级的增量包。
