# 1.12.2+20 更新说明

- 附件、模型选择和聊天设置三个弹起菜单支持独立主题配置，可分别调整形状、描边、填色、图层、内容留白及上、下、左偏移；上下方向在编辑器中互斥，菜单位置限制在画布范围内。
- 主题工作室展示完整聊天场景，提供顶栏、消息和输入区的位置参照。小预览按宽度等比显示、支持上下滚动，选择菜单及已接入部件后自动定位到附近；全屏继续完整适配同一场景。
- 扩大主题工作室高清素材预算：单素材支持 8 MiB、单 SVG 支持 512 KiB，工程总预算提高至 64 MiB，位图总预算提高至 41,943,040 像素，导入、保存和解码使用同一组上限。
- 已安装且启用的 MCP 服务在进入主界面后自动静默加载，移除加载浮层、跳过提示和日志弹窗；服务结果与日志继续保留，便于从管理页或重启工具排查。
- 修复消息复制面板的顶部异常空白、底色错位和内容裁切，使正文与底部复制按钮随面板一起正确显示。

版本为 `1.12.2+20`，内部版本号为 `76`。继续使用现有应用身份与固定签名，从 `1.12.2+19` 升级；完整 APK、增量包及发行元数据由发行工作流生成并发布到统一更新仓库。应用内检查此补丁版需开启 Beta 计划。
