# 对话框模式表格横向滚动修复

## 原本状况

命令框模式与对话框模式共用 Markdown 表格组件。命令框模式已能在流式更新中保留表格的横向滚动状态，但对话框模式会按普通文本内容收缩消息气泡。表格进入该收缩布局时，移动端没有稳定的受限视口，用户无法通过左右拖动查看超出可见宽度的列。

## 修改意图

让对话框模式在消息包含 Markdown 表格时，将表格放入气泡的可用宽度内，供共享表格组件计算横向可滚动范围。

普通短文本继续按内容收缩，不改变聊天样式设置、消息数据或命令框模式行为。

## 期待结果

- 对话框模式中的宽表格在手机端可左右拖动
- 流式追加表格内容时，已拖动的位置保持可交互
- 普通对话框消息保持现有的紧凑宽度
- 命令框模式不受本次修改影响

## 作用域

- `BubbleAiMessageComposable` 的 Markdown 布局宽度决策
- 对话框模式下表格的 Compose 布局与手势回归覆盖
- 本修复的静态验证记录

## 验证记录

- 已检查表格节点出现时，两个对话框布局分支都会使外层气泡占用可用最大宽度
- 已执行 `git diff --check`
