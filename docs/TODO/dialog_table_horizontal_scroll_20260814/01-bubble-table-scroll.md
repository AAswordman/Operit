# 对话框表格视口

## 旧实现

对话框模式默认让 Markdown 内容按实际文本宽度排列。表格节点虽然使用共享的 `EnhancedTableBlock`，但外层气泡在进入表格前可能仍处于收缩布局，表格无法稳定取得气泡允许的最大宽度。

共享表格组件据此计算可滚动距离；没有受限视口时，宽表格不会形成可供横向拖动的溢出范围。

## 修正意图

表格节点出现时，以气泡可用宽度约束 Markdown 容器，使共享表格组件获得有限的可见宽度并保留自身的横向拖动状态。

## 预期结果

- 宽表格的可见区域与对话框气泡宽度一致
- 右侧被遮挡的列可由左右拖动显示
- 非表格消息不被无条件拉宽
