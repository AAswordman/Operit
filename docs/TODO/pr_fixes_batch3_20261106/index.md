## 既有 JVM 检查失败修正

上游 #1467 的 Android 构建成功；JVM 检查执行 1590 项，其中 2 项失败、9 项跳过。失败均位于早已存在的 `ToolPkgFloatingWindowControllerTest`，不是 #1466 或 #1467 新引入。

- `close` 原实现向桥接层返回 Kotlin `Unit`，而控制器文档和调用契约规定返回 `null`。关闭后显式返回 `null`，避免序列化为 `kotlin.Unit`。
- 隔离用例创建 A、B 两个同名窗口后，第一次关闭 A 自己的窗口却要求报错。改为先验证 A 成功关闭、B 仍存在，再验证 A 重复关闭不能触及 B。

沿用现有用例表达这两项契约，未运行本地 JVM 检查。
