# 工具结果按调用顺序输出

关联 Issue：#1159；作为 #1206 的源头修复替代方案，暂不合并该 PR。

现状：工具执行过程中逐段输出 XML，执行结束后另行聚合并排序供模型使用。保存路径使用实时流，导致结果顺序、数量和内容与循环内历史不同；拒绝结果还被按类别置于返回列表前端。

计划：

- 为每个原始调用分配本轮内的位置，拒绝、失败和成功均写入对应位置
- 保留并行执行，每个调用只输出一个聚合后的结果；按连续完成的调用位置发布
- XML 只生成一次，实时流和循环内历史复用相同文本
- 增加乱序完成、重复调用、拒绝、多段结果和历史往返的回归覆盖，更新协议说明

作用域：工具执行与结果格式化、EnhancedAIService 的结果接入、对应单测及文档。不变更 Provider ID 或已保存 XML 格式。

验证：遵循仓库约定，本次不主动运行构建或测试。现有 Android JVM CI 可覆盖新增单测。

实现及验证范围见 [01 实现记录](01-implementation.md)。
