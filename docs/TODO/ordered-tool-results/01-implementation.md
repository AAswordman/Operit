# 有序聚合结果

原实现的实时输出逐段进入保存流，而返回值另行聚合，且拒绝结果按类别前置。

现在 OrderedToolResults 为每个原始调用保留位置，使用互斥锁发布连续完成的结果。ToolExecutionManager 的每个完成路径均提交一个聚合结果，EnhancedAIService 复用已经发布的 XML 构建下一轮历史。

工具的并行执行保留。结果展示等待该调用完成，以及前序调用的结果发布。取消前只保留已发布的完整有序结果，不发布未完成的部分结果。

回归用例：

- 同名调用反序完成，按调用位置发布，并在末尾调用完成前发布已有连续结果
- 拒绝结果不插队，相同结果仍有独立位置
- 多段工具结果只产生一个聚合 XML，空结果和失败结果均有最终输出
- 取消传播、空批次
- 使用 Claude 生产历史序列化器，比较循环内历史与响应流拆成历史块后重建的请求前缀
