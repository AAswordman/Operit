# 工具结果按调用独立限制

## 原本状况

每个工具结果虽然会被限制长度，但整轮工具结果又被统一限制为 64,000 字符。并行调用多个工具时，前面的结果会占满整轮预算，后面的结果被直接丢弃，历史转换层只能把它们标记为缺失。

## 修改意图

只限制单个 `tool_result` 的序列化长度，整轮保留所有工具结果，确保每个工具调用都有对应的结果槽位。整体上下文长度继续由 token 统计和总结流程处理。

## 作用域

- 删除整轮工具结果的字符上限
- 将限制常量明确为单个工具结果上限
- 限制图片链接附加内容，避免单个结果再次突破上限
- 增加多工具结果保留的回归覆盖
