# 主题包与 UI IR

## 修改意图

新增独立主题包格式，不复用 ToolPkg 的脚本入口、生命周期和权限。主题源码使用类型化 TypeScript/JSX 风格 SDK，构建工具输出宿主可验证的 UI IR、参数模式、目录场景和资源清单。

UI IR 支持嵌套布局、条件、键控列表、响应式变体、受控插槽、声明式动画、展示局部状态、Canvas 绘制命令和宿主能力节点。业务状态与动作只能通过版本化表面快照和不透明动作句柄访问。

## 包结构

- 严格版本化的清单
- 主题与组件契约版本范围
- 显式基底主题及精确版本
- 编译后的 UI IR
- 用户参数模式与默认值
- 本地化元数据和组件目录场景
- 具备类型、尺寸和摘要的资源清单

## 生命周期

- 导入内容先进入应用私有暂存目录
- 完成归档、模式、契约、资源和完整覆盖校验后发布不可变版本
- 主题选择固定到已安装版本
- 被角色卡或群组引用的版本不能删除
- 更新内容完成校验后再切换已发布版本

## 首版边界

- 不执行主题作者源码
- 不允许网络、文件系统、Java、Android 或 ToolPkg 桥接
- 不允许 DEX、JAR、APK、原生库、WASM、HTML 或嵌套归档
- 为未来无权限隔离进程控制器保留协议版本，不开放执行入口
