# 组件契约核心与导航项试点

## 兼容边界

本单元以 `upstream/main@f323d6c50fa661837fad06d4618462861779b562` 为兼容基线。组件契约与主题包接口尚未对外发布，因此新增契约属于内部草案，不建立旧草案兼容层。

- 保留主侧边栏原生项与 ToolPkg 项的标题、图标、顺序、选中判断和路由动作
- 保留手机抽屉关闭后导航、平板侧边栏和现有导航注册接口
- 保留 `native_v1` 颜色、玻璃效果、尺寸、间距和文字层级
- 不修改主题偏好字段、角色卡与群组作用域、ToolPkg 导航格式或 App 路由目录

## 修改意图

建立首个可机器校验的语义组件契约和 `native_v1` 组件目录。契约只描述宿主与主题之间的稳定边界，不携带 ViewModel、导航器、Android `Context` 或任意业务回调。

主侧边栏导航项作为首个端到端试点：宿主提供标签、选中与启用状态以及前导图标插槽；主题实现渲染内部布局，并只能发出封闭的激活事件；宿主收到事件后执行既有导航动作。

## 契约草案

- 组件 ID：`operit.navigation.drawer_item`
- 版本：`1.0`
- 分类：导航
- 宿主表面：`MAIN`
- 状态字段：`label`、`selected`、`enabled`、`semantic_role`
- 事件：`activate`
- 必需插槽：`leading`
- 语义：路由项使用导航目标，ToolPkg 动作项使用操作按钮，并提供可访问标签、选中态、禁用态和至少 48dp 触控区域
- 目录场景：正常、选中、禁用、动作

## 最小范围

- 新增稳定 ID、主次版本、状态字段类型、事件、插槽、语义和目录状态模型
- 校验组件 ID、字段、事件和插槽唯一性，以及语义引用和交互触控规格
- 校验 `native_v1` 对全部必需契约的精确版本覆盖，不提供缺失实现的替代渲染
- 建立可按组件 ID 检查的目录元数据和正常、选中、禁用场景
- 将展开侧边栏中的原生导航项与 ToolPkg 导航项接入同一参考实现
- 使用封闭事件适配器连接现有 `onNavItemClick` 与 `onNavigationEntryClick`

## 不在本单元

- 折叠侧边栏、快捷操作、顶部栏、页面容器或对话框迁移
- Theme Studio 可视化组件目录
- 独立主题包、UI IR、作者 SDK、安装器或外部 API 冻结
- 业务路由、ToolPkg 执行模型和主题偏好持久化变更

## 验收标准

- 组件契约核心不依赖 Android 平台类型或业务层对象
- `native_v1` 目录初始化时拒绝重复 ID、未知契约、版本不匹配、缺失必需实现和场景覆盖不完整
- 导航项参考实现只接收类型化状态、受控前导插槽和封闭事件句柄
- 原生项与 ToolPkg 项继续执行原有导航动作，禁用场景不发出激活事件
- JVM 测试冻结契约、目录覆盖、校验错误和事件派发
- Android Compose 测试覆盖标签、选中、禁用和点击语义
- 静态检查通过；完成后由 Builder 执行 release 构建

## 实施记录

- `NativeThemeComponentContractV1` 登记稳定 ID、主次版本、状态字段、事件、插槽、宿主表面、语义角色和目录状态
- `NativeThemeComponentKeyV1` 将状态、事件和插槽类型绑定到唯一契约 Key；按 ID 检查目录元数据，实际渲染通过类型化 Key 取得实现
- `NativeThemeComponentCatalogV1` 对必需契约、精确版本、唯一 ID、已登记 Key、目录状态和真实场景语义角色执行初始化校验
- `operit.navigation.drawer_item@1.0` 提供正常、选中、禁用和动作场景，使用受控 `leading` 插槽及封闭 `activate` 事件
- 原生侧边栏项和 ToolPkg 路由项使用导航目标语义；ToolPkg 动作项使用操作按钮语义，既有宿主回调和抽屉关闭流程未改变
- 可见玻璃层与 48dp 交互层分离，保留 40dp 视觉高度且不裁剪液态玻璃阴影
- JVM 测试覆盖契约冻结、目录覆盖、版本、类型化 Key、场景、语义字段和事件派发；Android Compose 测试覆盖角色、选中、禁用、触控和前导插槽
