# 主题编辑器基础

## 旧实现

主题设置由基础、背景、聊天、输入和界面五个固定标签页组成。控件直接操作字符串字段，部分预览重新实现生产组件，预览与实际界面容易产生差异。

## 修改意图

把主题编辑器改为模式驱动的主题实例编辑器。编辑器读取 `ThemeDefinition` 的参数模式和组件目录，不硬编码具体主题 ID。首个注册定义为 `native_v1`，现有字段全部映射到新的编辑器模式。现有基础、背景、聊天、输入和界面五标签不再作为目标信息架构。

编辑器分为基础令牌、通用组件、Operit 领域组件、素材、动效和自适应环境。实际可编辑项目随生产组件迁移逐步开放，不展示尚未被运行时消费的配置。

## 预期结果

- 角色卡和群组选择、草稿、保存、重置与离开确认行为保持不变
- 编辑器预览使用真实主题解析器和真实生产渲染器
- 编辑器外壳始终使用已提交主题，草稿只作用于预览宿主
- 每个字段显示存储值、解析值、来源和校验结果
- 主题声明自己的可配置参数，宿主生成一致的编辑控件
- 素材使用会话暂存和受管理的不可变资源 ID

## 第一批试点

- 主题输入设置
- 语言设置中的通用列表和选择状态
- 基础颜色、字体与背景预览
- 权限浮层的独立主题宿主
