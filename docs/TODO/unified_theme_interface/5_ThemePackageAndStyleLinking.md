# 主题包与样式链接

## 修改意图

新增独立样式包格式，不复用 ToolPkg 的脚本入口、生命周期和权限。样式包只描述全局令牌、组件族样式和单组件状态样式，宿主继续持有组件结构、业务状态、动作、焦点和无障碍。

样式包通过严格 JSON 模式表达颜色、文字、形状、边框、透明度、模糊、材质、阴影、图标容器、菜单和受限动效。链接器在安装期间解析精确基底链、令牌引用、状态选择器、组件部件和 Compose 宿主能力，产出不可变的运行时样式表。

## 包结构

- 严格版本化的清单与 Style API 范围
- 显式基底主题、精确版本和摘要
- 组件契约范围、Compose 表面和必需能力
- 全局令牌、组件族和组件状态样式层
- 用户参数模式、默认值、本地化元数据和组件目录场景
- 具备类型、尺寸和摘要的资源清单

## 链接规则

- 基底链只允许单继承和精确版本，最大深度由模式限制
- 令牌引用必须形成有向无环图，覆盖时替换完整令牌值
- 样式按基底、子主题、实例顺序处理；每层按令牌、组件族、组件、通用、表面和状态顺序处理
- 状态选择器只允许有限状态轴的等值合取；可同时命中且无法确定优先级的属性冲突必须拒绝
- 主题实际使用的 Compose 能力必须与清单一致，宿主表面不具备必需能力时拒绝安装或激活
- 链接完成后每个必需组件、部件和属性必须完整，运行时不解析 JSON 或遍历字符串键

## 生命周期

- 导入内容先进入应用私有暂存目录
- 完成归档、模式、契约、资源、能力和完整覆盖校验后发布不可变版本
- 主题选择固定到已安装版本
- 被角色卡或群组引用的版本不能删除
- 更新内容完成校验后再切换已发布版本

## 首版边界

- 不执行主题作者源码
- 不允许任意布局、Canvas 命令、组件控制器、网络、文件系统、Java、Android 或 ToolPkg 桥接
- 不允许 DEX、JAR、APK、原生库、WASM、HTML 或嵌套归档
- 公开 Style API v1 仅支持 Compose 的 `MAIN`、`FLOATING`、`OVERLAY`、`OFFSCREEN` 和 `EDITOR_PREVIEW` 表面
