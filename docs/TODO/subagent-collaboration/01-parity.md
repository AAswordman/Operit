# 普通子代理体验与长会话

原移植缺少发送边界保护、只读记录查看入口及长会话处理。本轮保持现有上游模型配置接口，补齐普通子代理能力；不会加入 Orbit 自动唤醒或专属后台。

1. 在浮窗附件采集前固定目标，提交时检查目标，防止切换会话后写入只读记录。
2. 只读子聊天允许查看工具详情及 token、上下文和费用。
3. 长会话用消息锚点恢复位置，折叠过程按需读取，使用惰性列表显示。
4. 归档长期未使用且没有运行任务或待收消息的代理；保留聊天记录，释放名字，分段保存归档。
5. 根据目标模型的思考档位映射显式强度，保持未指定时继承配置。
