# 子代理 V2

普通聊天可以启动并行子会话、投递消息、请求继续、等待或中断。子会话复用父层的引导收件箱；用户可以查看其记录，从子会话返回主聊天。

- 数据库从 21 升级到 23，区分普通聊天、普通分支和子代理，并保存父子运行关系；保留现有 group 分组。
- 子会话不进入普通聊天列表；JSON v5 保留恢复协作记录所需的会话关系，继续支持 JSON v2 导入。
- 插件内部保留原有任务运行器。普通聊天可用的工具、权限和上下文边界见[协作协议](../../doc-src/feature-protocol/subagent_collaboration.md)。

本层仍为草稿。上游 #1478 为 Operit2 导入恢复了数据库 21；本方案的新数据库版本需要与该导入器协调后才能合并。未实现对已撤回文件夹预览版数据库的迁移，不能用于覆盖安装那些预览版。
