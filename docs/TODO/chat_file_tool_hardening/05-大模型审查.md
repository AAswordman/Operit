# 05 大模型审查

## 旧实现

无工具审查机制；功能模型体系已有 FunctionType（GREP 等）+ FunctionalConfigManager 映射 + 功能模型配置界面（卡片按枚举自动生成）+ callFunctionModel 调用范式；会话工具菜单只有 ALLOW/ASK/FORBID 分段控件，无审查开关。

## 意图修正

1. FunctionType.TOOL_REVIEW + FunctionTypeTest（11→12）+ strings（values 与 8 个 locale）+ FunctionalConfigScreen 显示名/描述两个 when 分支（卡片自动生成）；缺省映射回落主模型
2. ApiPreferences 加 tool_review_inside_workspace / tool_review_outside_workspace（默认 false）+ ApiConfigDelegate StateFlow/toggle
3. 开关 UI：AgentChatInputSection 工具组展开区加两行开关，仅 permissionLevel==ALLOW 显示；ClassicChatSettingsBar 镜像；AIChatScreen 接线
4. 审查执行（checkToolPermission，仅文件工具族 + ALLOW + 对应区开关开）：callFunctionModel(TOOL_REVIEW) withTimeout 15s；FunctionalPrompts.toolReviewPrompt（工具名/操作类别/路径/区内外/工作区根/内容参数摘要 500 字符）；lenient 解析 {compliant, reason}
   - 合规 → 直接执行（不弹窗）
   - 不合规 → 弹窗，"AI 审查意见"区块显示 reason，用户允许则执行、拒绝则 deny
   - 审查失败/超时 → 弹窗原询问窗口并提示审查错误信息，用户决定
   - 审查阶段 ToolProgressBus 显示"AI 审查中…"
5. ASK/FORBID 不跑审查；开关不显示

## 期待的新实现

允许模式下文件工具调用按区经大模型合规初筛；用户只看到被标记可疑的调用。
