# 网络失败消息收尾

## 旧实现

Provider 的异常分支先回滚当前请求保存点。保存点位于本轮请求起点，因此网络错误会让本轮文本变为空。最终错误被 EnhancedAIService 捕获后不再抛给下游，MessageProcessingDelegate 继续按正常完成逻辑落库空内容。

## 修正意图

将回滚放到确认会执行下一次请求之后。最终网络失败携带中断状态到消息处理层，由运行态消息对象完成并保存已接收的内容，禁止正常完成逻辑覆盖该内容。

## 期待的新实现

- 不会开始新请求的异常不发送回滚事件
- 重试耗尽后的流以可识别的失败状态结束
- 消息处理层通过已有中断消息收尾保存当前文本与回合统计
- 回归测试覆盖最终失败、已输出内容和消息最终落库
