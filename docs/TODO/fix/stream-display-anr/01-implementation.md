# 实现与行为边界

增量上下文只保存 Markdown 围栏、行内代码及 XML 名称、深度、引号、注释和 CDATA 状态，不保存或反复正则匹配已显示历史。协议头属性识别和代码示例闭合规则继续作用于当前候选文本。

显示过滤器保存可恢复的状态，协议头与待闭合代码候选缓冲区按前缀引用记录，避免每个保存点复制整段回复。正常保存点直接取当前状态；事件晚于文本到达时，从最近的已有状态派生对应坐标，回滚恢复保存点并处理保留尾部。

追加和回滚消费者在 Dispatchers.Default 下通过同一 Mutex 串行修改显示状态。主线程只接收 Compose 流替换，保存点、回滚及结束时的事件补齐均在后台完成。

TextStreamRevisionTracker 仍使用生产者的原始输出坐标。追加跳过已撤销区间；回滚在原缓冲区中删除对应可见范围，不为每个失败分片重建整段前缀。SmartString 仅增加内部范围截取与删除操作。

保持已闭合代码示例、跨分片协议隐藏、嵌套 XML、重试保存点和事件先后到达的行为。诊断页面与监控器未修改。
