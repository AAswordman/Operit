# 工具权限列表按应用语言展示说明

## 背景与范围

权限页面把执行确认使用的操作说明当成工具用途展示。部分原生蓝牙、浏览器和音乐工具的操作说明写成英文，并可能在缺少调用参数时形成残缺文本；其内容不随页面语言切换。原生工具的结构化目录已有中文和英文用途说明，脚本及插件元数据已有 LocalizedText。

本次只调整权限列表和添加工具面板的说明来源：原生工具使用已有结构化目录，包工具解析对应元数据，语言由应用设置及跟随系统的既有解析规则决定。包元数据读取放在后台，工具列表或语言变化时重新计算，避免使用单例初始化时的旧语言。MCP 服务说明按服务端原文展示，不新增自动翻译。缺少工具元数据的条目只保留名称，不复用另一份语言不确定的操作文案。

截图中的 bluetooth_* 仍有 Kotlin 原生执行器，不依赖 system_tools 脚本是否下载。本次不移除原生工具，也不改变工具执行、权限规则或参数。

## 实现步骤

1. 核对原生注册、操作说明和中英文结构化目录 [DONE]
2. 权限页采用独立的说明解析与后台加载，监听当前语言配置 [DONE]
3. 静态检查后提交工作分支，派发 Debug 和 Android Tests，创建目标 dev 的 PR

## 完整回归清单

- L01：应用跟随中文系统；蓝牙等已有中文目录的工具显示中文说明
- L02：应用跟随英文系统；同一原生工具显示英文说明
- L03：应用语言显式设为中文或英文；说明跟随应用设置，不被设备语言覆盖
- L04：应用使用其他语言；原生工具使用已有英文目录，插件有该语言元数据时按元数据解析
- L05：切换语言后返回权限页并打开添加面板；名称不变，说明和说明搜索使用新语言
- L06：查看同时提供中英文的脚本或 ToolPkg 子包；选择与当前语言对应的工具说明
- L07：快速切换列表或退出页面；异步说明加载取消，新增行和搜索不访问旧映射中的缺失键
- L08：查看 MCP 工具或没有可解析元数据的历史规则；MCP 保留服务端原文，缺元数据只展示名称
- L09：修改、撤销和批量应用权限；存储规则、工具参数及执行确认行为保持原有语义
