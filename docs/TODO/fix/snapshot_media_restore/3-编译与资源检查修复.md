# 编译与资源检查修复

## ZIP 文本读取

`RawSnapshotBackupManager.readBytesSafely` 在读取有大小上限的 ZIP 文本条目时使用 `ByteArrayOutputStream`。该用途独立于 Preferences protobuf 重写，保留相应导入及原有大小限制，保证 manifest 读取可编译。

## TensorFlow Lite namespace

应用代码及随仓库提供的工具没有直接调用 TensorFlow Lite，也没有 `.tflite` 模型资源。`app/build.gradle.kts` 中的 TensorFlow Lite 2.10.0 直接依赖额外引入了 `tensorflow-lite`、`tensorflow-lite-api` 两个声明相同 namespace 的 AAR。

移除未使用的直接依赖，并清理版本目录中的对应版本、别名。保留 MediaPipe 文本任务依赖；已核对 MediaPipe 0.10.11 的 `tasks-text`、`tasks-core` 发布 POM，二者不依赖这项 TensorFlow Lite AAR。

## 孤立日语字符串

`follow_chat_model_for_all_functions` 仅存在于日语资源，默认语言没有定义，应用代码也没有引用。删除该遗留条目，避免资源合并器因缺少默认值而移除资源并输出警告。
