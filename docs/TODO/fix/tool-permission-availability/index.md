# 工具权限列表实时反映可用工具

## 背景与范围

权限页此前只读取一次执行器名称，并把所有历史单项规则名称重新并入列表。停用、移除或未安装包的历史规则会继续显示；反过来，已安装启用但尚未在对话中激活的包，其工具可能不在执行器快照中。页面也不持续监听包和注册表变化。

权限目录改为合并已注册原生工具、已加载且开关有效的脚本执行包，以及已有活跃会话的 MCP 注册工具。ToolPkg 复用 PackageManager 对父插件和子包开关的判断，读取当前有效工具状态，排除容器和 advice 说明条目。读取目录不激活包、不连接 MCP 服务。

已保存规则不删除；主列表、添加面板、计数和选择只展示当前可用工具，重新安装启用后恢复原单项权限。图中的 bluetooth_* 有 Kotlin 原生执行器，按原生工具保留。说明语言由独立 PR #128 处理。

## 实现步骤

1. 原生注册表发布变更版本，复用包管理器已有状态通知，页面在后台观察并在退出时解除订阅 [DONE]
2. 包管理器在同一状态锁内读取已加载且父子开关有效的执行包快照 [DONE]
3. 页面、统计、添加面板、编辑及批量选择共用当前可用工具集合，历史规则不再反向注册工具 [DONE]
4. 补充 4 个目录回归用例及 V01–V18 全量回归清单 [DONE]
5. 静态检查后提交工作分支，派发 Debug 和 Android Tests，创建目标 dev 的 PR

## 完整回归清单

- V01：内置扩展未下载但存在历史授权；主列表、添加面板和计数均不显示对应包工具
- V02：已下载脚本或插件，但主开关关闭；对应工具不显示
- V03：已下载并启用沙盒包，尚未 use_package；可提前设置其真实工具权限，页面不激活该包
- V04：父插件开启、子包关闭；该子包工具不显示，其他启用子包正常显示
- V05：父插件和对应子包都开启；仅显示该子包当前真实执行工具
- V06：关闭父插件且保留子包偏好；所有子包工具消失，重新开启后按原偏好恢复
- V07：停用或重新启用单个子包；页面和已打开的添加面板同步更新，无需重启应用
- V08：卸载脚本或移除已下载内置扩展；已移除工具消失，原生工具保留
- V09：工具隐藏后重新安装启用；原有单项权限仍恢复，默认方式和其他规则不被改写
- V10：批量或添加面板已选工具随后停用；选择数量、提交集合及全选不再包含失效项
- V11：编辑中的工具失效；关闭对应编辑入口，不继续显示其规则弹窗
- V12：切换允许、询问、禁止及搜索；数量和列表仅统计当前可用工具的单项规则
- V13：已注册且已有活跃会话的 MCP 工具；正常展示，未连接或无执行器的服务不产生工具项
- V14：未下载 system_tools 时查看 bluetooth_*；原生 Kotlin 蓝牙工具仍存在，包前缀工具按安装开关过滤
- V15：调用不存在的工具；既有执行器查找返回 success=false 和 Tool not found，不因查找为空而抛出异常
- V16：打开权限页；不调用 usePackage，不建立或重连 MCP 会话，不下载资源
- V17：退出页面再回来；旧订阅解除，重新读取当前目录，默认工具注册完成后展示列表
- V18：包当前有效工具状态切换；只展示当前状态工具，advice 条目及旧执行器残留不重新出现
