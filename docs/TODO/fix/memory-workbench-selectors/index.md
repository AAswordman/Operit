# 记忆工作台选择器与默认空间删除状态

## 原有问题

默认记忆空间虽然禁止删除，但菜单文字和图标固定为红色，视觉上仍像可用操作。创建连接、新建或编辑记忆使用较窄的锚定菜单，长标题与路径反复换行，且关系类型因总数超过阈值而出现无必要的搜索框。

## 实现范围

- 删除操作保留默认空间 ID 保护，让菜单组件同时控制禁用颜色和点击状态，普通空间仍以红色显示删除
- 将表单选择器移到现有 workbench 包内的 MemoryPicker.kt，统一使用适应可用宽高的居中选择弹窗
- 使用完整宽度的懒加载列表显示长标题与文件夹副标题，当前项高亮并打勾，打开后定位到当前项
- 创建连接的起点、终点及记忆文件夹采用同一样式；仅这些内容超过八项时提供搜索，关系类型始终直接选择
- 关闭或取消选择不修改表单草稿；保留全部关系类型、旧类型值与空间切换方式

## 回归范围

- 默认空间（包括改名后）：删除文字和图标灰显且无法点击；普通空间仍可打开删除确认
- 创建连接：起点和终点打开独立选择弹窗，长标题可读，选中后更新相应字段，取消不修改草稿
- 创建或编辑连接：类型列表不显示搜索框，原有类型和全部常用类型均可选择
- 新建或编辑记忆：文件夹选择采用相同弹窗，未分类及现有路径均保留
- 多条记忆或文件夹：超过八项后可搜索，清空搜索恢复列表，无结果时给出提示
- 软键盘和小屏：列表在可用高度内滚动，关闭与取消操作可达，选项不依赖窄浮层定位
- 空间切换：仍只切换当前查看空间，不修改全局默认或角色绑定
