## 操作与预期

| 编号 | 操作 | 预期 |
|---|---|---|
| S01 | 中国大陆地区进入模型配置，选择会显示地区提醒的供应商 | 页面内地区横幅保留，不再在底部重复弹出相同文字 |
| S02 | 切换到不需要地区提醒的供应商，再切回 | 横幅按原规则更新；两次切换均无重复底部提醒 |
| S03 | 切换模型配置、返回并重新进入模型配置页 | 各配置和地区判断不变，不因进入页面重复弹出地区提醒 |
| S04 | 主动执行原有保存、登录或模型列表请求操作 | 原有成功与失败反馈仍按原规则显示，不被全局屏蔽 |
| S05 | 从关于入口打开用户协议并滚动到底部 | 标题、简明说明、完整协议、免责声明可完整阅读；无同意按钮或倒计时 |
| S06 | 浅色、深色主题分别打开协议，并在支持切换时更新主题 | 正文与背景具有正常对比度，文字颜色跟随主题 |
| S07 | 放大系统字体，窄屏与横屏查看协议并滚动 | 标题与正文可换行，内容不被固定标题挤出阅读区，无横向截断 |
| S08 | 对照现有协议查看完整正文 | 段落、换行和加粗正常显示，不展示 HTML 标签；条款、版本与内容未变 |
| S09 | 使用独立测试安装或测试数据验证首次启动，再正常重启 | 仍按原规则等待 5 秒后确认协议；已确认用户不被重新要求同意，后续引导不变 |
