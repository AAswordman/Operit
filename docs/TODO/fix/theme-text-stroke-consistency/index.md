# 文字描边输入与显示一致性

已发布主题仍使用浮点 dp 宽度与原有全局、区域声明。修复宽度编辑中途被判零，以及复制正文与原消息使用不同描边区域的问题；重新发行保留 1.12.2+22 和 versionCode 78。

## 输入草稿 [DONE]

原宽度框逐字符解析并写回主题，`0.` 会解析成零，零宽度随即隐藏编辑区。文字描边宽度改为独立字符串草稿，在输入法完成或失焦时提交完整合法值；空串、尾随小数点和非法值不改变生效宽度，确认零仍可关闭描边。滑条和细线预设继续即时生效。

工作室使用自身 Dialog 的焦点管理器，在保存草稿、应用角色、导出和关闭判断前完成编辑；切换区域、属性页、场景、浅深模式前也提交当前对象，防止草稿写入另一区域。撤销与重做先结束当前编辑，继续沿用原有历史记录。

## 文字路径 [DONE]

复制正文按原消息选择 userMessage 或 assistantMessage，显式传入描边设置，三种复制格式共用这一设置。面板标题和按钮保留面板自身作用域，复制字符串、选区和滚动状态保持原有实现。

原生 Canvas 与 StaticLayout 的文字轮廓改为单独图层合成时统一着色，富文本的字体和度量继续保留，轮廓绘制固定使用 STROKE，随后绘制原始填充和行内图片。插件 DSL BasicText 接入主题文字封装，并同步生成器，避免重新生成时丢失。

## 验证与交付

新增 4 项 JVM 数值编辑回归源码。完整旧场景及新增输入、复制和渲染场景见[文字描边完整清单](../../feat/theme-text-outline/index.md)。本地仅执行差异、仓库规范、本地化与文档链接静态检查；构建和 JVM 测试交由仓库工作流，Android 显示及交互结果待确认。

本轮修复分支加入现有发布后清理名单，清理仍以公开 Release 和附件核验成功为前提。版本、包名、签名与主题数据格式保持兼容。
