# 统一 Token 统计类型

## 旧实现

Token 统计由 `Int` 和 `Long` 混用。部分服务在返回给累计统计前会转为 `Long`，但响应解析、单轮状态、消息和会话持久化仍以 `Int` 承载，无法保证统计全链路的 64 位精度。

## 修正

1. 将输入、输出、缓存输入和当前窗口 Token 计数定义为 `Long`。
2. 使用 JSON 的 `optLong` 读取供应商 usage，并让 ToolPkg 数值读取返回 `Long`。
3. 同步消息、会话、归档、偏好与桥接的字段和回调签名。
4. 删除只为接收 `Int` 统计值保留的重载和截断转换。

## 验收

- 全局 Token 统计字段不再声明为 `Int`。
- usage 解析没有将 Token 统计读取为 `Int`。
- 上游 provider、持久化和 UI 使用同一 `Long` 类型。
