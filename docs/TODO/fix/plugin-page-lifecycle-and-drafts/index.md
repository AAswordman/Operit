# 插件页面生命周期与聊天草稿

本次补录：用户确认目前 Bug 均已修复，本页待填写的验收说明已按用户确认同步。验证来源及现有 CI 记录见[验证结果补录](../../chore/distribution_integration/06-验证结果补录.md)。

用户反馈插件首次打开或从 AI 对话切回时持续转圈，原版同一插件的页面可以保持；聊天输入框的未发送文字在切后台后丢失。另有插件加载超时变频繁的反馈，需要区分启动插件扫描与页面脚本执行。

1. 检查路由保活、页面脚本实例、首次加载标记和加载取消边界，修复已确定的不一致。
2. 为页面首轮执行提供明确的结束边界和可重试错误，核对插件启动超时的任务归属。
3. 检查草稿的所有者与清理路径，保证切页、切后台及 Android 状态重建后的未发送文字可恢复，已发送内容不会重新出现。
4. 静态核对改动并派发个人分支的 Android Build、Android Tests；设备行为按完整回归清单确认。

本轮保持现有插件公开接口和显式保活配置，正式发布编号沿用已约定的发布策略。
