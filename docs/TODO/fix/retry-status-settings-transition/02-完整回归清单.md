## 操作与预期

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| S01 | 普通对话正常流式输出 | 首个非空片段后显示接收状态，完成后正常结束 |
| S02 | 普通对话首块前触发可重试错误，再恢复响应 | 重试等待期间显示重试，恢复内容后切回接收 |
| S03 | 普通回复已输出一段时触发可重试错误，再恢复 | 新内容到达即切回接收，不等工具或整轮结束 |
| S04 | 同一请求连续发生两次可重试错误，每次均恢复输出 | 每次均能从重试切回接收，首块计时不反复重置 |
| S05 | 工具执行后的 AI 回复在首块前重试并恢复 | 恢复后显示工具后续回复的接收状态 |
| S06 | 工具执行后的 AI 回复中途重试并恢复 | 新内容到达即清除重试提示 |
| S07 | 重试等待时停止生成，再发送新消息 | 停止状态不被旧流覆盖，新回合状态正常 |
| S08 | 重试最终失败或关闭重试后发生错误 | 显示失败状态并解除加载，不被接收状态覆盖 |
| S09 | 子任务发生重试，主对话继续执行 | 子任务不把主对话标签改成自己的接收状态 |
| N01 | 开启导航动画，从设置首页进入显示与行为 | 无顶部栏先消失、首页列表上移后再切页的瞬间 |
| N02 | 从显示与行为使用页面返回按钮或系统返回 | 回到设置首页时无旧显示页下跳或重复标题栏 |
| N03 | 关闭导航动画后重复进入和返回 | 标题栏与内容留白正确，无闪动 |
| N04 | 设置首页滚动到中段后进入显示与行为再返回 | 首页滚动位置恢复，无因顶部栏变化产生的突跳 |
| N05 | 分别进入主题页、模型配置页并返回 | 原页面的标题栏、导航动画和留白保持正常 |
| N06 | 显示与行为调整数值后立即返回，再次进入 | 最后一次修改仍正确保存 |
| E01 | 当前请求输出一段后触发可恢复传输故障，再成功 | 仅本次失败尝试撤回，新回答完整重写；已完成的工具轮次保留 |
| E02 | 前一次尝试有输出并撤回，最后一次尝试不输出而失败 | 最终保留最后一次尝试的剩余内容，不恢复已撤回片段 |
| E03 | 最后一次尝试已输出部分内容后最终失败，重新打开对话 | 该次剩余部分可见且已保存，不标为正常完成 |
