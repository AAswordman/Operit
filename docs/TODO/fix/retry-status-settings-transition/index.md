# 重试状态与显示设置转场修复

普通回复在中途重试后已经继续输出，输入框上方却可能停留在“正在重试请求”；工具后续回复也存在同样的状态遗漏。进入自带标题栏的“显示与行为”页面时，设置首页仍在淡出，却已经失去宿主顶部留白，造成整个列表短暂上移。

本轮修复这两处显示问题，并沿现有请求、重试和消息保存路径说明错误发生时部分输出被撤回或停止的原因。用户已撤回对原生三位数错误码是否被包装的调查，本轮不继续该项。

## 范围与交付

- 在 `EnhancedAIService` 的普通回复与工具后续回复中，重新收到非空内容时把连接状态切换为对应的接收状态
- 将 `GlobalDisplaySettings` 标为不参与跨页淡入淡出，避免进出页面时退出中的内容使用新页面的宿主留白
- 记录 5000 系列传输错误对应的输出处理策略及其限制，保持现有错误码、重试、文本修订和存储行为

[实现及调查说明](01-实现与调查.md)记录源码依据，[完整回归清单](02-完整回归清单.md)供设备验收填写。

本轮不执行本地 Android 编译、构建或测试。交付前检查修改文件语法与差异，推送后派发 Debug 和 Android Tests，发布开关关闭；远端运行状态以 GitHub Actions 为准，不轮询结果。

既有页面与批量移动的完整验收仍见 [显示与行为](../../feat/display-behavior) 和 [主题布局与批量移动](../../feat/theme-layout-batch-move)，本轮清单只补充此次两项修复及调查相关行为。
