# 补齐自定义主题多语言并统一消息名称

主题工作室、主题脚本和部件编辑的新增文本此前主要只覆盖中英文，其他七种受支持语言会显示中文资源。此次补齐全部缺失主题文本，并统一用户消息、AI消息及对应头像和样式名称。

## 实现范围

- 主题区域、消息样式、不透明度和头像名称通过现有字符串资源统一为用户／AI用语，保留所有资源键和主题脚本中的 userMessage、assistantMessage 等标识。
- 为日语、韩语、西班牙语、马来语、印尼语、巴西葡萄牙语和罗马尼亚语分别补齐 348 条缺失文本，覆盖主题工作室、脚本操作、资源管理、配色角色、消息样式、图标和弹出菜单。
- 保留所有格式占位符、ARGB 格式说明、context.appearance 与 .oktheme 等技术标识，并按 Android 资源规则转义引号。
- 校正中文跟随主题文案；按全部九套语言资源核对 593 个主题相关资源键，缺失数为零。
