# 摘要为空时重新生成一次

模型请求结束后，摘要会经过协议和思考内容清理以及生成后钩子。此前最终正文为空时返回英文失败占位文案，上层将其当作非空摘要追加对话回顾并保存，下一轮上下文因此缺少有效摘要。

## 实现与边界

- 在完成内容清理和生成后钩子后检查正文；首次为空时通过现有请求错误通知通道显示本地化 OKToast，并使用同一批准备好的历史重新生成一次
- 连续两次为空时抛出本地化错误，现有保存入口不创建摘要卡片，原有摘要和消息不被本次失败替换
- 流结束后先进入正在收尾；只在获得有效非空正文后上报总结完成，重新生成时重置进度阶段与响应缓冲
- 请求异常和取消直接传播，原有请求层五次错误重试机会及其退避、通知和回滚逻辑保持；正文为空的重试次数单独固定为一次
- 两条新增提示覆盖九种语言；诊断日志只记录原始流、协议清理、思考清理和钩子后的长度

实现位于现有 core/chat/context 包，普通摘要配置和板块规则沿用现有处理。本次仅处理新生成的空正文，不迁移已保存的消息。

## 验证状态

新增七项纯 JVM 生成控制回归源码及一项进度回归源码，覆盖固定次数、异常透传、取消与收尾进度。现有请求重试、摘要进度和上下文组装用例继续由仓库工作流执行。

本地只执行静态检查，未运行 Kotlin 编译、单元测试或设备场景。Debug 和 Android Tests 的派发及运行结果在 PR 记录，设备 Toast 与卡片显示结果待确认。
