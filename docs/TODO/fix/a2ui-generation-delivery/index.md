# A2UI 编译说明与消息投递

旧行为在编译成功后仍要求模型准确输出三反引号短引用。普通 Markdown 合法的缩进、波浪号和更长围栏无法展开，历史摘要又容易被模型当作展示格式，导致成功生成却只显示文字。

本次共用 MarkdownFence 边界，保留原引用定位方式，并由宿主在本轮正常结束时追加尚未展示的真实文档。按实际正文去重与处理回滚，不将解析一次视为永久消耗。修订只自动投递尚未展示的最新版，已经展示的旧版继续保留。空正文可以追加；取消、其他轮次和无效源码不会制造卡片。

原生工具定义、a2ui_catalog、返回消息与可选引导说明同步。目录提供最小源码、真实图表结构、输入回写和 live 的区别；参数错误直接列出当前组件的签名、未知项与必填项。新 Express 校验已知初始图表系列的 label/values 或 points 字段，旧 JSON 继续按原协议读取。滑块取消 1000 跨度限制，保留端点和步数上限。

新增十七项 JVM 回归，包含多种围栏的全部分块边界、隐藏内容、回滚、自动投递、去重、修订、历史兼容、图表字段与滑块限制。完整实机清单保留原 48 项并扩到 64 项，旧确认记录保留，新增结果为空。未执行本地 Android 编译或测试，仓库工作流结果另记。
