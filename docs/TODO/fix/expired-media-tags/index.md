# 紧凑过期媒体标签

同一消息中的失效图片仍合为一个入口，标签只显示“图片”，右上角以数字角标显示失效数量，不再显示整句计数和固定的大宽度。完整计数保留给无障碍说明，点击标签任意位置或角标均提示“文件已过期”。

语音原文件缺失时，在两种聊天样式中显示气泡外的独立“音频”标签，不再由语音播放器在气泡内替换为文件卡片。父布局和播放器共用文件可用状态，失效时移除正常气泡并释放播放器，返回前台后仍重新检查文件。正常语音只显示原来的语音条，不增加普通附件入口。

录音附件、历史存档、仍存在图片的预览，以及文件存在但解码失败的处理保持兼容。新增两个资源键并提供九种语言，不删除旧的文件缺失提示。
