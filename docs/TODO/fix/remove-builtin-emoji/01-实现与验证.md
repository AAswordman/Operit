# 实现与验证

`CustomEmojiRepository` 删除 assets 复制和恢复默认逻辑，初始化只执行原有历史全局存储整理。`CustomEmojiPreferences` 移除默认分组清单及内置优先排序，各角色目标仅展示已持久化的分组。`CustomEmoji` 保留旧标记字段用于读取已有库，新导入图片统一按自定义表情保存。

`CustomEmojiManagementScreen` 移除恢复默认按钮、确认弹窗及状态，保留创建分组、删除分组、长按删图和预览。空库时添加按钮打开创建分组，删除最后一组后清空选择并禁用删除按钮；图片选择器返回后也会校验当前分组仍有效。空分组选择器不能展开，九种语言提供先创建分组的提示。

`CustomEmojiViewModel` 不再读取默认清单的首项；`OperitApplication`、`ConversationService`、`WaifuMessageProcessor` 均改为存储初始化。没有分组时，聊天继续使用既有的无可用自定义表情规则，图片查询返回空结果，不访问已删除的 assets。

已删除 53 份内置图片，原始大小合计 3,632,112 字节，约 3.46 MiB；该数字不等同于最终 APK 的压缩后减小值。移除八份语言资源中的 40 条表情恢复默认专用文案，并在九种语言中添加空分组提示。通用恢复默认文案仍供其他设置使用。

旧版已经复制到角色卡或角色组私有目录的图片与分组继续保留，同组用户导入的图片不会因此次更新被删除。已有分组仍可通过删除分组操作移除。
