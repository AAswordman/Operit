# 完整回归清单

范围覆盖新库、已有库、分组、图片、角色隔离和聊天引用。以下结果待本轮设备复核。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| E01 | 全新角色进入自定义表情页 | 分组和图片为空；没有恢复默认入口，页面正常显示 |
| E02 | 空库点击右下角添加按钮 | 打开创建分组弹窗，不向空名称目录导入图片 |
| E03 | 创建合法分组并确认 | 自动选中新分组，可以继续添加图片 |
| E04 | 创建非法名称或同名分组 | 显示现有校验提示，不创建重复或非法目录 |
| E05 | 向分组批量导入支持格式的图片 | 完整显示导入结果和缩略图，失败项按现有规则报告 |
| E06 | 点击预览并长按删除一张图片 | 预览正常；确认删除后移除对应图片与元数据 |
| E07 | 删除包含图片的自定义分组 | 保留确认操作，移除分组及其图片 |
| E08 | 删除最后一个分组后再次添加 | 选择清空，删除按钮禁用，添加按钮先创建分组 |
| E09 | 删除一组后创建另一组 | 不会重新弹出旧删除确认，选择新组并正常导入 |
| E10 | 图片选择器打开期间切换或删除当前分组 | 返回时不向已经失效的分组写入图片 |
| E11 | 升级后打开已有表情库 | 既有分组及用户图片可读取，不重新导入内置图片 |
| E12 | 切换角色卡和角色组后查看、复制表情库 | 保持目标隔离，空库不生成默认分组，已有库复制正常 |
| E13 | 没有表情分组时启用聊天表情规则并回复 | 按无可用自定义表情规则处理，缺失图片不导致崩溃 |
| E14 | 有自定义分组时让聊天引用该分组 | 从对应目标的自定义图片中取图，保留原有发送行为 |
| E15 | 切换九种界面语言查看空库 | 显示对应的先创建分组提示，没有表情恢复默认文案入口 |
