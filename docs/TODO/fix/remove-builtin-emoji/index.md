# 移除内置表情与恢复默认

应用不再附带 assets/emoji 中的图片，也不再生成默认分组。自定义表情页只管理当前角色卡或角色组已有的分组及图片，保留创建分组、删除分组和导入图片，移除恢复默认入口及其调用链。

新表情库从空状态开始。未创建分组时点击添加按钮先打开创建分组，删除最后一个分组后清空选择，避免继续向失效分组添加图片。旧版已保存到私有目录的表情和分组继续保留，因为旧元数据不能区分默认分组内的内置图片与用户后来导入的图片。
