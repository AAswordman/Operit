# 通用节点摘要与操作后快照交接

## 目标

结合 dsh-go 的通用无障碍思路与现有 PhoneAgent，不针对具体 App 编写流程，不再排查手机运行耗时。保持现有工具入口和用户配置的 UI_CONTROLLER 模型。

旧实现按前 120 个节点形成观察，布局和不可见节点占用模型上下文，驱动与执行器重复读取完整层级。单次探索点击需要提前描述下一页条件，也增加了猜测未见资源 ID 的机会。

## 已完成实现

- 解析节点可见性、父子关系、提示文字及滚动属性。明确不可见、祖先明确不可见及没有有效屏幕交集的节点不进入摘要或选择器匹配。未知可见性仍只按屏幕交集筛选，不能视作系统确认可见
- 折叠无语义布局，将非交互子文字合并到可点击父控件，同时保留父控件自身文字、独立子按钮、输入框与滚动列表。滚动列表不吞并整段列表内容
- 将模型节点载荷限制在 3000 字符内，每页最多 120 项，标签最多 60 字符。按焦点、任务关键词、控件角色和屏幕区域分配预算，再按位置排列；截断保留明确标记
- 增加基于本轮 screen/ref 的单控件 Tap 与 Type。仅允许使用实际发给模型的编号，派发前重新读取并解析唯一目标；显示去重不能消除执行时的原始候选歧义
- 统一使用控件与屏幕交集的点击坐标。编号和序列输入均要求普通、可编辑、已聚焦输入框，且当前只有一个可见输入获得焦点；Type 检查逐字回读
- 驱动不再额外读取整树，执行器负责派发前核对与动作后读取。结果快照在 1000 毫秒内交给下一轮观察，过期、暂停、坐标操作及观察方式切换均使旧引用失效
- Inspect 明确切换至截图观察，Observe 明确切换至节点观察。节点动作拒绝或变化尚未确认时仍返回节点状态；截图失败时不派发依赖截图的坐标动作
- 纯启动任务只接受已安装 App 名称或包名的精确匹配。启动后轮询前台 Activity，确认目标包名和已注册 Activity 即结束，不调用控制器、不读取 XML；附带搜索等后续要求的任务继续普通执行
- 启动后继续操作时等待约 3 秒。主屏彩虹边框从调用开始持续到最外层结束清理；截图只隐藏进度卡片，点击提示单独显示
- 同步中英模型协议和进度文案，展示已解析、有效候选及发给模型的数量；保留已核验参数化短序列的保存和复用

编号 Tap 的变化检测仅表示交互结构或状态发生变化，不证明到达用户要求的页面。动作受理、变化检测及模型 finish 均不会将编号动作自动保存为成功模板。本轮没有新增整任务记录的自然语言相似度检索。

前台查询的轮询预算约为 3 秒，只能在远程调用之间检查，不能中断阻塞的 Binder 调用。仅返回短类名或无法确认目标所属包名时，不将启动任务标记为成功。

## 提供者边界

当前仓库内置的是预编译 accessibility.apk 1.5，源码未在工作区找到，公开仓库搜索未找到对应实现。现有 AIDL 没有定向节点点击、采集预算或事件订阅接口。

本轮可见性筛选发生在收到 XML 后，不能声称减少了提供者内部遍历。点击仍使用提供者的坐标接口。原生控件 ACTION_CLICK、服务端限时采集与事件等待需要独立提供者配套实现，当前未接入。动作后保留明确的 300 毫秒等待，不将固定等待描述为事件稳定检测。

本轮参考行为设计，独立实现代码，不复制第三方仓库源码，也不添加未实现的远程方法。
