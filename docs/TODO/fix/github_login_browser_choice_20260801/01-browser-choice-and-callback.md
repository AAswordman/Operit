# 浏览器选择与回调

## 旧实现

旧版选择弹窗可进入内嵌 WebView，或用 `ACTION_VIEW` 打开外部浏览器。外部完成地址是 `operit://github-oauth-callback`，由 Activity 接收。

## 意图修正

Broker 登录不再允许旧自定义 Scheme，也不允许客户端持有 OAuth secret。外部浏览器改为使用 Worker 支持的本机回调地址：应用先监听 `127.0.0.1` 随机端口上的 `/oauth/github/complete`，再将该地址注册为事务完成地址。

## 预期结果

- 用户每次发起 GitHub 登录都先选择内嵌页面或外部浏览器
- 内嵌页面保持现有完成链接拦截逻辑
- 外部浏览器完成授权后，本机监听器接收完成链接并领取登录结果
- 监听器、活动事务和浏览器窗口在取消、超时或完成后释放
