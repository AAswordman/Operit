# 工具结果大字符串 OOM 定点修复

语音条反馈的部分堆栈显示 `ADBResultData` 在 JSON 编码和数组扩容时 OOM；工作流反馈显示 `trimIndent()` 创建字符串时 OOM。旧工具结果桥接会把结构化结果先转成 JSON 字符串、解析回 JSON 树，再编码整个结果，随后将完整结果插入回调脚本并处理缩进。两条路径均会放大大结果的瞬时内存。

本轮直接生成结构化 JSON，保留原有多态类型字段、Sandbox 结果形态及基础类型协议；工具结果与 IPC 通过固定 JavaScript 回调入口及 JSON 参数传递，不再把结果拼入待执行源码。完整结果继续传递，流式中间结果与错误处理保持现有接口。

## 范围及验证

- 修改工具结果编码与原生回调桥接，补充大字符串、转义、数据类型及回调语义回归
- 沿用远端 Debug 和 Android Tests 验证，本地仅做语法与差异核对
- `#1370` 是 ANR 监控器的堆栈拼接问题，和本轮工具结果桥接没有直接调用关系，本轮不修改 `AnrMonitor`
- 两张截图只展示失败分配位置；本轮消除对应代码路径的重复分配，原始设备 OOM 的消失仍需独立验证
