# 实现与验证

## 删除检查与结果

- 新增 `data/chat/deletion/ChatDeletionPolicy`，按目标会话的最新记录区分锁定、不存在和当前会话
- 删除准备阶段允许当前会话进入切换流程；真正删除时仍在会话互斥锁内重新读取数据库，拒绝删除锁定或仍被选中的会话
- `ChatHistoryDelegate` 的删除与清空共用同一流程，先取消对应会话的发送，再切换当前会话，最后删除
- 增加带原因的删除结果，保留原 Boolean 回调与 `canDeleteChatHistory` 的语义，已有调用方仍可使用
- `ChatViewModel` 只在目标实际锁定时显示锁定提示，不存在、切换未完成和一般失败分别处理
- 取消异常继续传播，数据库异常记录日志并反馈失败
- 提示补齐九种语言

[DONE]
