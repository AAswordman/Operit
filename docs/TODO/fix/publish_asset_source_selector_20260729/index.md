# Publish Asset Source Selector

## Context

The two source-mode labels could require more width than a narrow publish screen provides. The selected-state icon reduced the label width further and caused the selector to overflow horizontally.

## Scope

Keep the segmented mode control while constraining each segment to half of the available row width and giving both labels a stable two-line layout.

## Expected Result

Both publishing modes remain readable and selectable without horizontal overflow on narrow screens.
