# 回滚尾部渲染

## 旧实现

聊天界面收到 `ROLLBACK` 后会创建新的显示流，并把回滚后的完整内容再次写入该流。

Markdown 渲染器以流实例作为重置依据，因此会清空并重新解析整条 AI 消息。

## 修正意图

保留与回滚前缀一致的 Markdown 节点，只移除变化的尾部节点。

恢复解析器时以该前缀预热流式 Markdown 会话，replacement stream 只承载回滚后的新尾部。

## 预期结果

- 回滚只改变对应的消息尾部
- 未撤回的 Markdown 节点保持其渲染状态
- 重试后的内容继续追加，且不重播前缀
