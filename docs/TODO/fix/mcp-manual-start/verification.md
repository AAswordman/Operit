## 操作与预期

<details><summary>完整回归步骤</summary>

- S01：已安装且启用本地和远程服务时冷启动应用。预期：不自动部署、安装依赖或启动服务，不显示准备启动面板
- S02：首次安装并完成欢迎引导。预期：进入主界面，不启动模型上下文协议服务
- S03：旋转屏幕、恢复应用和重新进入包管理。预期：不触发开屏加载或重复启动批次
- S04：打开模型上下文协议页并刷新配置。预期：展示已安装服务及现有状态，读取操作不部署或启动服务
- M01：点击管理页启动按钮。预期：按用户启用配置启动服务，显示手动加载进度和工具就绪状态
- M02：手动启用或停用单个本地、远程服务。预期：保留既有控制行为及启用配置
- M03：手动加载时查看日志、折叠、展开和跳过面板。预期：保留原有交互；面板仅在手动加载过程中显示
- M04：明确调用重启并获取日志工具。预期：继续启动已配置服务并返回状态、分项日志和既有超时结果
- D01：读取没有 author 的旧配置并打开列表和详情。预期：使用原默认作者，仓库及界面 copy 不再因作者 NPE
- D02：读取 author 为 JSON null 的配置并搜索、编辑、刷新。预期：不因作者空值崩溃，列表和详情可用
- D03：读取 author 为空字符串的配置。预期：空字符串保留，仍能复制元数据及保存配置
- D04：读取含其他可选字段 null 的配置。预期：使用模型已声明的默认值，可空字段继续允许 null
- D05：保存、重读及备份导入已有本地命令、参数、环境变量和远程请求头。预期：原值、整型安装时间戳及启用状态保持一致，未知元数据字段不会影响读取
- D06：读取必要 id、name 或 description 为 null 的元数据。预期：配置解析拒绝非法必要字段，不捏造服务信息
- L01：中文界面查看包管理、市场、设置和手动加载提示。预期：统一使用模型上下文协议和技能，不把该服务称作普通插件
- L02：窄屏或较大字体下切换包管理四个页签。预期：完整名称可阅读和横向滚动，选中指示与页面对应
- L03：切换九种语言并手动启动服务。预期：资源可读取，数量占位符及服务名称显示正确
