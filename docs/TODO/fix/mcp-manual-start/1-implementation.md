## 手动启动

MainActivity 删除原有 startPluginLoading 方法、开屏自动调用和完成引导后的调用，不再延迟初始化或部署已安装服务。原本的启动专用三十秒计时及超时提示一并删除。普通启动仍执行原有聊天准备与配置读取。

## 名称

## 配置解析

日志中的异常明确指向 PluginMetadata.copy 的 author 参数。Gson 原先可以绕过 Kotlin 构造器，令声明非空且有默认值的字段在缺失或 JSON null 时仍变成空值，仓库刷新及配置页面复制元数据时因此崩溃。

配置 Gson 注册专用元数据反序列化器，通过既有 Kotlin 序列化模型应用声明的可选字段默认值。缺失或 null 作者使用原有 Unknown 默认值，空字符串作者保留；其他可选字段同样遵守原模型。必要的 id、name、description 仍校验，不创建虚构内容。配置读取与手动启动共用该解析入口。备份导入直接读取 JSON 子对象，避免中间通用 Map 将整型时间戳转成 Double。原配置字段与保存格式保留，不增加数据库迁移。
