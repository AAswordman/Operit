# 工具失败说明去重

## 原因与影响

维护者在缺少 GITHUB_TOKEN 的包激活测试中发现错误文字显示两遍。PackageActivationResult 同时提供 ToolResult.error 和结构化结果的 message，后者的 toString 返回同一段说明；ConversationMarkupManager 将两者无条件拼接，使同一段提示既在界面重复，也重复进入模型上下文。这是一次调用的结果格式化，不代表包激活或终端命令执行两次。缺少凭据的激活测试尚未执行到终端命令。

## 修改

在通用失败格式化处，只有规范化后的详情与错误说明不同才追加详情。失败状态、结构化错误码和原始结果数据不变；独立终端输出、包含错误摘要的更长详情和成功结果中的重复文本均保留，不进行模糊匹配或任意行去重。

新增五项 JVM 回归源码，覆盖全部八种包激活错误码、原有首尾空白规范化、独立终端详情、含摘要的更多输出、成功重复文本。仅静态语法及 diff 检查；未本地执行回归或 Android 编译，实际结果交给仓库工作流。

## 资源与交付

本修正只影响 Android 宿主 Kotlin，不修改 GitHub/worldbook 代码或固定资源清单，不发布新的资源 V2。resources-v2-d16730007f8d94095264 继续使用；旧 V2 也保留，旧 APK 的固定地址及重装仍依赖它，不能因发布了新资源就删除。

维护者已反馈此前统一 Debug 的其余可测项基本通过，部分不便测试项目获准合入但不记为通过。统一 PR #83 的 Fast checks、Android build、Android JVM tests、Candidate checks 已全部成功并合入 dev。本项单独修正后派发 Debug/JVM，不发布正式签名 APK。
