# 界面与媒体交互回归清单

本清单覆盖此次整批修复。代码核对、仓库自动验证和 Android 界面回归分别记录，未执行的项目不视为通过。

## 已完成的核对

- 中文协议正文未修改；八种外语正文由助手直接撰写
- 九份协议均为 22 章、121 条；编号顺序和项目反馈链接与中文原文一致，强调标记成对，无 Unicode 替换字符
- 复核八份译文中首次启动与单独同意、LGPLv3、个人信息、十四周岁以下未成年人、法定责任和争议解决条款
- 录音仍生成 WAV，转写与音频理解引用同一个原文件；只清理请求期间创建的媒体池副本
- 气泡和光标样式对语音条均使用专门解析，普通附件列表为空
- 媒体内容只随当前用户轮次发送，历史裁剪仅作用于请求副本；新上传图片、音视频及录音由原文件预览，缺失及图片解码失败都显示标签，未绑定原附件的旧池链接保持原格式

本地不执行 Gradle。构建与 JVM 测试使用既有 `Android Build` 和 `Android Tests` 工作流，派发受理与验证通过分别记录。新增单测已编写，尚未获得本次提交的运行结果；Android 实机回归项目均待执行。提交前的 XML、资源、文档链接和差异空白核对结果记录于本节，不能替代编译或设备验收。

本轮静态核对通过：27 份变更资源 XML 可解析；九种语言的 18 条新增提示定义齐全、无重复且占位符一致；删除 90 条失效轮次设置定义后无残留引用；图片过期数量保留九种语言定义用于合并标签；文档本地链接与差异空白检查通过。此前新增 17 项媒体回归用例，本轮补全其中的文件大小元数据并增加 7 项工具图片抽取用例；本次提交的用例执行结果待仓库工作流返回。

## Android 回归项目

准备深色与浅色主题、聊天壁纸、至少两个角色卡，以及 SDCard、Linux 和已授权的附加存储目录。文件操作使用可删除的样例文件和目录。涉及模型的项目使用具有对应能力且已启用直接处理的配置。

| 编号 | 做什么 | 预期行为 |
| --- | --- | --- |
| U01 | 开启聊天壁纸，在浅色和深色主题下切换使用标准顶栏的页面 | 顶栏及其状态栏区域使用主题底色，不透出壁纸；标题和按钮可读 |
| U02 | 在主题编辑页选择、切换角色卡，打开目标选择列表并查看页尾 | 当前角色名称、列表名称和页尾名称使用主题前景色 |
| U03 | 依次切换中文、英语、日语、韩语、西班牙语、马来语、印度尼西亚语、巴西葡萄牙语和罗马尼亚语，再打开协议 | 每次显示对应语言完整正文，22 章和 121 条可滚动阅读，链接可打开 |
| U04 | 在中文和至少一种外语界面展开语言列表，再选择跟随系统 | 列表名称使用当前界面语言；跟随系统项及当前选中项正确 |
| U05 | 在 360dp 与 590dp 宽度查看记忆库，切换空间、搜索和文件夹 | 上方控制区约占可用页面高度 20%；下方图谱或列表使用其余空间；功能可访问 |
| U06 | 放大字体、切横屏并弹出键盘，操作记忆库控制区 | 控制区仍受比例约束，可滚动访问全部操作，搜索文字不被固定高度裁切 |
| U07 | 打开已有崩溃报告并切换浅深主题 | 异常原因显示红字，文字背后没有红色块；时间和日志仍可读 |
| W01 | 在 SDCard、Linux 和附加存储目录打开文本、图片和媒体文件 | 成功读取后立即选中对应标签并显示内容，环境和路径正确 |
| W02 | 重复打开同一文件，切回文件列表，再次进入工作区 | 复用已有标签，不生成重复标签；已处理的入口请求不覆盖新选中的文件 |
| W03 | 编辑文本并使用撤销、重做、搜索和格式化，切换浅深主题 | 工具栏背景、启用与禁用图标可读，编辑操作作用于当前文件 |
| W04 | 点击刷新右侧多选按钮，勾选、取消、全选搜索结果、返回退出 | 数量与勾选一致；全选只选择当前过滤列表；退出后恢复普通打开行为 |
| W05 | 多选后刷新目录、进入文件再返回，切换目录或环境 | 同目录刷新只移除已不存在项；返回时恢复有效选择；换目录或环境清除原选择 |

| W08 | 在 SDCard、Linux 与附加存储之间剪切多项 | 每项先复制成功再删除其来源；目标内容完整，失败项不会被提前删除 |

| V04 | 不配置可用音频理解模型，使用现有 STT 配置发送 | STT 使用当前应用语言转写；请求包含文字和原音频路径，对话模型可按路径继续读取录音；文字可展开查看且不混入附件描述 |
| V05 | 发送语音并完成识别后继续多轮对话，查看后续请求及旧语音条 | 历史只携带已存文字，不重复音频输入、音频理解或 STT；原文件仍在时语音条持续可播放 |
| V06 | 录音后取消、重录、关闭面板或在请求中取消 | 未发送录音按会话生命周期清理；已发送录音保留；取消后不继续启动下一识别路径 |
| V07 | 删除一条语音对应的原文件，再点击播放；另制造非文件缺失的播放错误 | 原文件缺失时语音条替换为标签，点击提示“文件已不存在”；其他播放错误使用播放失败提示 |

| M02 | 打开上下文设置并使用旧配置继续对话 | 历史媒体轮次设置板块已删除，旧数值不影响当前轮次规则；其他总结配置可保存 |
| M03 | 发送音频和视频并超过请求媒体池容量，继续对话后打开旧附件 | 新消息使用 `cleanOnExit` 原文件播放，每个媒体只有一个预览入口；后续请求不自动重复携带旧媒体 |
| M04 | 分别清理图片、音频、视频与录音原文件，回到聊天并点击对应条目 | 同一消息的缺失图片合并成一个标签并显示实际过期张数，点击提示“文件已不存在”；其他缺失媒体使用原标签，尚存文件仍可预览，不留透明空图 |
| M05 | 发送一个无法解码的图片文件 | 显示无法预览标签，点击给出无法预览提示，不误报为文件已删除 |
| M06 | 缩略图已缓存时删除原图，直接点击图片组；全屏时删除文件再返回前台 | 点击前及返回前台重新核对文件，已删除图片改成标签；仍存在的图片可继续浏览 |
| M07 | 打开旧的纯媒体池消息，并在原文件存在或清理后重新启动应用 | 旧格式仍可读取可用池文件；已丢失文件提示不可用；`cleanOnExit` 按现有启动清理真实删除后，新绑定预览也显示缺失 |

| M09 | 让文件读取工具返回包含未注册图片标签的源码，再返回真实截图和混合内容，折叠工具结果 | 示例保留在工具结果中，不在外部生成 XML 卡片；真实可用图片仍可传给模型，不重复输出 |
| M10 | 用气泡和光标样式分别发送 1 张、10 张图片，清理全部或部分原文件，返回前台并点击标签 | 同一消息只出现一个过期图片标签，右上角数量准确；点击仍提示文件已不存在；保留的图片继续预览，不逐个列失效文件名 |
| S01 | 启用按消息条数总结，保存 1、20、21、50，再输入 0、51、小数与空值 | 1–50 的整数保存并回读一致；无效输入提示范围；默认值仍为 16 |
| S02 | 关闭总结或按消息条数总结，再保存其他设置；加载已有配置 | 停用字段不阻塞无关设置；已有值不在读取时被静默重写 |
| S03 | 在语音服务页拖动语速和音调滑块至两端并重新打开页面 | 使用统一细轨道样式且不画刻度；范围仍为 0.5–2.0，步进与保存行为保持 |
| S04 | 分别用气泡与光标样式发送请求，查看主题预览 | 请求浮点动画下移，与上一条消息分隔；预览同步位置变化 |
