# 总结请求的实时进度与错误提示

总结服务发送请求时没有传入非致命错误回调，内部重试因此没有界面提示。手动总结最终失败还使用模态错误弹窗，发送触发的异步总结失败只写日志。

- [x] 为总结请求逐层传递进度和重试错误回调
- [x] 每次重试更新标签并发送 OKToast，最终失败也使用 OKToast
- [x] 重试等待期间保留重试标签，收到内容后恢复实际阶段，回滚重算阶段进度
- [x] 覆盖手动、自动、插入总结与功能连接测试，补充回归代码和完整步骤

## 全量回归步骤

1. 手动总结首次请求返回可重试错误。预期：第一次失败就显示“正在重试请求”和上方 OKToast，保留原错误及重试信息。
2. 连续五次重试返回相同错误，最终一次仍失败。预期：每次重试均产生提示，最终错误另用 OKToast，不弹模态对话框。
3. 重试后收到新的总结内容。预期：标签恢复准备或实际生成阶段，随后按内容推进。
4. 总结已到后期阶段时回滚重试。预期：重算阶段与比例，等待期间不会被回滚覆盖为生成中。
5. 直接返回不可重试错误或服务未初始化。预期：直接显示失败 OKToast，不显示虚假的正在重试状态。
6. 手动总结正常成功。预期：完整生成并保存总结，沿用成功提示，最后解除总结状态。
7. 发送触发的异步总结失败。预期：每次重试和最终失败均有提示，收尾释放总结状态，正常聊天回复不被总结阶段覆盖。
8. 对单条消息执行插入总结。预期：同样显示重试与实时进度；插入、异常和取消均操作原会话。
9. 在等待重试时取消总结。预期：不发布取消后的错误或成功提示，输入状态和队列锁正常释放。
10. Token 超限触发总结续聊。预期：失败不启动续聊，成功仍沿用原续聊流程。
11. 在浅深模式、窄屏、悬浮窗查看提示。预期：使用已有 OKToast 外观，长错误可阅读，不出现复制／确定模态弹窗。
12. 在模型功能页测试总结连接。预期：每次重试都有 OKToast，测试用量记录开关不变，不把进度写到无关聊天。

## 实现与验证记录

ConversationService 使用每次调用独立的 SummaryProgressReporter 接收提供商重试事件，再通过 EnhancedAIService 与 AIMessageManager 将进度和错误传给入口。经典与 Agent 输入栏继续读取已有总结进度通道；会话状态同时更新文字供其他界面使用。每次重试的错误独立交付，进度文本去重不会吞掉相同错误；等待期间的回滚不覆盖重试状态，收到新内容后再恢复实际阶段。

手动、发送触发和插入总结共用上方 OKToast 反馈，最终失败不再进入总结模态弹窗；异步总结失败也有明确提示。并行总结记录最新会话标签，主回复完成后恢复该状态；插入与异常清理绑定原会话。功能页的总结连接测试也接收每次重试错误。

本轮核对 9 个 Kotlin 文件的包路径、重复导入和词法结构，中英资源引用、新增文档链接及 12 项完整步骤和空白结果行核对通过，git diff --cached --check 无空白错误。新增三项 JVM 回归覆盖逐次重复错误、回滚等待与进度恢复、取消后的迟到重试，交由 Android Tests 执行。未在本地编译、构建、运行测试或进行 Android 实机交互验证。
