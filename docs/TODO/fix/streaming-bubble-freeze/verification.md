# 完整验证与本轮流式补查

基线为 refactor/package-layout 的 a284c65e。用户此前反馈大部分常用功能正常，WASM、桌面组件和部分复杂路径仍未测，没有将概括反馈写成逐项通过。本轮重点检查 M、F、I 项，D、U 项作为既有完整回归范围保留，无需重新穷举全部组合。

本地不运行构建、JVM 或 Android 测试。源码解析和静态差异核对不能代替 Kotlin 类型检查；Android 仪器用例没有设备执行条件，仓库 JVM 工作流不会运行这些仪器用例。
