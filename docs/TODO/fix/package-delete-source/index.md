# 已安装扩展删除

删除路径来自当前 Android Context 的 externalFilesDir，不写死官方或 Kong 包名。旧实现找不到文件时仍返回成功，同一 ID 的多份安装文件也可能在刷新后重新出现。

## 改动

删除前刷新当前应用安装目录的扫描结果，按解析到的包 ID 收集真实源文件并删除全部对应副本。删除范围必须是当前应用 packages 目录的直接文件，文件确实消失后才返回成功。内置包、子包和仍有启用依赖的插件不能被这条入口删除。

确认弹窗阻止重复点击；失败保留弹窗并给出可读说明，成功后重新扫描列表。成功和失败文字覆盖当前九种语言。

## 全量检查项

- D01：Kong 安装目录删除文件，官方版本目录和其他插件保留
- D02：同 ID 多份安装文件全部删除，刷新后不再出现外部插件
- D03：源文件名与包 ID 不同、JS/TS/ToolPkg 均按扫描来源删除
- D04：无来源、文件不存在、目录越界或删除失败时不报成功
- D05：子包不伪装成独立安装文件删除，内置包和启用依赖受保护
- D06：删除期间阻止重复操作，失败可重试，成功刷新插件和脚本列表
- D07：九种语言正确显示删除提示
