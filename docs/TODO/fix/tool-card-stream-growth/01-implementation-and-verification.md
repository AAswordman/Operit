# 实现与验证

`NativeMarkdownStreamOperators` 从预热解析结果读取未结束的块和结束标记，并通过 `StreamGroup.continuesPrevious` 只允许接续对应块一次。`StreamMarkdownRenderer` 不再把重试后的所有同类型块合并；工具请求、结果和后续代码块按实际边界创建独立节点。

恢复未结束 XML 时，旁路订阅得到完整前缀与新尾部，正文只追加尾部。XML 子流结束或取消时先同步最后的稳定节点，再移除子流映射。已完成的卡片依靠节点全文显示和复制，不再保留额外整块回放。工具请求和结果解析按内容缓存，避免后续卡片更新反复扫描旧长文本。

消息正文、实际工具参数、执行结果、保存点事件和工具协议均未改变；单次调用确实产生的大参数仍完整保留。卡片计数是载荷的 UTF-8 字节数，没有将其当成内存测量，也未用截断内容掩盖累积。
