# 长时间工具调用的卡片累积

用户报告连续工具调用后，create_file 参数计数达到约二十万，页面逐渐卡住。计数来自参数载荷的 UTF-8 字节数。

源码中，重试恢复后的渲染器会将后续同类型块持续接到上一节点，没有遵守原生分段器的块边界；已完成 XML 节点还保留整块子流回放，旧卡片解析也随父级更新重新执行。

本修复由原生分段结果标记是否接续恢复前未完成的块，渲染器据此决定合并。XML 完成后先同步完整内容，再释放子流映射；卡片按内容缓存解析结果。保存的消息、工具参数、实际执行和结果协议不变。
