# 协议应答与交互输入

## 原状与目标

终端渲染提示后未处理设备状态报告查询。Survey 2.3.7 的确认读取先隐藏光标，再通过 CSI 6 n 查询尺寸和位置，等待应答后才进入普通答案读取。需要补齐标准终端协议，不识别命令名称，也不自动填写登录答案。Android 输入法显示由焦点与输入连接决定，单独验收。

## 实现

- CSI 5 n 返回 CSI 0 n
- CSI 6 n 返回以 1 为起点的行列坐标
- CSI ? 6 n 返回带私有前缀的光标位置报告
- 查询在解析时记录坐标，保留同块多查询的顺序；不完整控制序列跨输出块拼接
- 原点模式按滚动区域计算行号，待自动换行状态报告最后一列
- 应答携带输出源会话 ID，通过该会话的串行 PTY 输入队列发送
- 协议应答不清除等待用户输入标记，不结束命令，不推进命令队列，不应用快捷键修饰或追加回车

TerminalCore 提交为 `62dbf46a0c1af5255eb22f0c48ca215974ab1a10`，基于应用当前锁定的 `13adf4ae`。核心 PR 以已有 `fix/terminal-command-lifecycle` 为基分支，只展示本次协议变更；主仓库 PR 面向 dev 更新精确子模块提交。

## 回归与验证

新增十四项 JVM 回归源码，覆盖报告格式、无效请求、分段序列、顺序、原点模式、自动换行边界、Survey 尺寸探测、光标可见性、控制字符串以及多会话路由与等待状态。PR 的 JVM 检查显式执行 :terminal:testDebugUnitTest，确保终端模块的回归进入检查。
