# 请求终止错误传播与重试规则

对应路线图 25。响应流开始收集后，部分异常原先只记日志，既不设置终止错误，也不传给聊天请求边界，造成静默结束或失败被当作完成。

本次在共享请求重试入口和 Android 聊天请求边界统一处理：

- 参数和请求校验错误立即终止，不换钥重发相同参数
- 鉴权和模型访问失败立即排除当前密钥；有其他候选时换钥，没有候选时结束
- 余额不足、配额、限流、临时网络和服务端故障保留重试；单密钥为首次请求加最多五次重试，密钥池保留既有候选数预算
- 普通发送与重新生成只由各自请求边界提示一次终止错误；状态监听只同步状态
- 流式失败继续保留已输出内容，失败回合不触发完成通知；取消按既有流程处理

改动范围为 `EnhancedAIService`、`MessageProcessingDelegate` 及 `api/chat/keypool/`。不涉及账号、资料、归档、附件、Toast 样式或删除动画。目标分支为 `dev`。

实现与完整回归清单见 [01-实现与验证](./01-实现与验证.md)。
