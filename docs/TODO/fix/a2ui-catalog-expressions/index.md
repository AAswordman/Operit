# A2UI 动态表格与结构化事件上下文

## 背景与目标

原生界面演示连续两次未通过生成校验。动态表格单元格中的绑定及函数已经能求值，却被原始数组的标量检查拒绝。按钮事件的 `context` 支持对象结构的描述，也未在渲染器 Schema 中完整实现，直接传入用于重置或提交的对象会被拒绝。

用户确认由代码支持 Catalog 所表达的合理写法，减少模型反复重写界面的轮次。

## 范围与兼容性

扩展现有写法的接受范围，保留既有工具参数、卡片协议、数据路径、交互确认、取消及历史卡片行为。不替换已发布的用户接口。

只处理动态表格与事件上下文的校验、求值和派发，以及必要的示例、文档和回归覆盖。终端及 TerminalCore、其他上游同步、聊天消息结构、模型服务生命周期和品牌迁移不在范围内。
