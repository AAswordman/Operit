# 通知会话定位回归

以下为完整功能检查清单；本轮未执行 Android 实机验证，结果留空。

- N01：应用关闭时点击 AI 回复通知；启动后打开产生该回复的会话
- N02：应用已在另一会话时点击通知；切到通知来源会话，展示对应聊天内容
- N03：A、B 会话各保留一条通知，分别点击；每条通知打开自己的来源会话
- N04：通知产生后删除来源会话，再点击；保持现有聊天，不导航到已删除会话
- N05：调用 send_notification 并显式传入 chat_id；点击通知打开指定会话
- N06：调用 send_notification 不传 chat_id，或点击旧版通知；继续普通启动应用
- N07：连续点击同一会话和不同会话通知；每次请求均处理，待处理状态在结束后清除
- N08：正常使用设置快捷方式、文件分享和普通应用启动；原有导航仍可用
