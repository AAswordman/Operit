# 离线扩展导入与说明修复

已安装扩展的详情页仍显示导入 ZIP，资源导入选择器也列出这些扩展，实际操作会替换已有安装。扩展卡片统一显示包管理提示，用户无法在下载前了解用途。

本次在独立分支完成以下改动：

- 已保存的插件和沙盒脚本隐藏导入入口，并从资源导入选择器中排除。真正读取文件前和按包加锁的安装入口再次检查，已有数据必须先删除再导入。在线更新保留独立入口和原有使用中限制。
- 有更新时在详情页主操作区显示更新，已安装且没有更新时只显示备份与删除等适用操作。
- 构建时从脚本 METADATA 和插件 manifest 提取声明式资料，在 APK 中保留说明目录。资源列表和详情页按现有本地化规则显示扩展自己的描述，不再拿包管理通用提示充当描述。

不改工具参数、资源归档格式、下载摘要或固定发行地址。已有安装和启用状态保留，模型及运行环境的导入行为不变。

验证分别记录静态检查、远程构建及设备情况。本地不运行编译、构建或测试；设备需要检查未安装、已安装、启用中、可更新及删除后重新导入的状态。
