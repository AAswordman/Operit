# 消息复制预览的选区和滚动状态

上游 PR #1411 未修改消息复制窗口。本仓库将复制预览迁到独立 copy 包，使用状态版 BasicTextField 显式持有 TextFieldState 与 ScrollState；纯文本、Markdown、XML 分别使用 SaveableStateProvider，切换格式后返回可恢复该格式的选区与位置。正文改变时重新初始化编辑状态，文本保持只读，拖动选区仍由文本组件处理，不包裹另一个滚动容器。

保存状态只记录选区端点和滚动偏移；正文由调用方提供，避免把长消息重复写入系统状态包。原有格式转换和整段复制按钮保留。

这是状态生命周期修正，不足以单独证明所有焦点跳转问题已消失；消息复制场景需验证中段长按、拖动选区、格式往返、窗口变化以及不同消息隔离。源码审查及 git diff --check 通过，未本地构建或进行设备测试。未推送、创建 PR 或派发工作流。
