# 附件成功提示与点击关闭

文件选择、拍照、粘贴文本、包、屏幕、通知、位置、时间、记忆文件夹及外部分享原先使用不同成功提示，其中部分会拼接附件名称或数量。现在默认中文只显示“已成功添加附件”，并移除全部九套语言资源中的文件名占位符。附件本身的名称与添加逻辑保持原样。

`OKToast.success` 原来只能等待自动消失。现在成功提示与 `requestError` 共用 `Notice.cancel()` 关闭回调，复用现有正文点击、空白区域点击及无障碍关闭操作；可交互提示的系统建议显示时长也采用相同的控件标记。
