# 同步上游文档块编辑器高度限制

文档导入为超长单块时，编辑器原先随全文增高，可能超过 Compose 布局约束并退出。本次同步上游的 120–280dp 编辑视口和列表约束，让长块在编辑器内部滚动，继续支持编辑、搜索与保存。

## 实现范围

- 在当前 conversation/memory 包的 DocumentViewDialog.kt 中为块编辑器设置 120–280dp 高度、为列表分配剩余空间并调整条目间距，避免长块在无界测量中超出 Compose 高度限制；保留本仓库主题脚本组件。
- 将标题输入设为单行，搜索无匹配提示同样使用剩余有界空间，避免标题或提示挤占列表。
- 移植上游两项 Android Compose 回归并适配本仓库包路径，覆盖超长块、大字体、短块列表滚动、编辑和保存；新增注释使用中文。
