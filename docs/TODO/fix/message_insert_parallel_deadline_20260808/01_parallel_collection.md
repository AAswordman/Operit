# 并发采集与全局时限

## 旧实现

`buildExtraInfoAttachmentTags` 逐项等待每个启用的采集函数。天气、定位、OCR、通知和记忆检索的等待时间彼此累积。

## 修改意图

将每个启用项构造成独立任务，在同一个 8 秒绝对截止时间内执行。各任务独立处理完成、失败与超时，最终使用 `Promise.all` 保持配置顺序汇总结果。

## 预期结果

注入流程至多等待 8 秒。达到截止时间的任务只生成对应项目的 `timeout` 状态标记，不写入未完成的数据，也不生成错误附件；已经完成的任务仍会被注入。

超时值现由设置页以秒为单位配置，默认 8 秒，可设范围为 1 到 120 秒。
