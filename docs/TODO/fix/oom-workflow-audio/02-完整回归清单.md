## 操作与预期

- W01：依次运行短输出工作流；预期：节点结果及执行状态正确
- W02：同时触发两个定时工作流；预期：后者等待，前者结束后执行，无额外失败记录
- W03：启动两个不同的手动工作流；预期：按现有并发语义执行，分别记录各自结果
- W04：工作流节点输出超过 800 字符，下游引用结尾内容；预期：下游读到完整结果，日志和历史只显示预览
- W05：分别从手动页面及工具触发大输出工作流；预期：两条路径均不再格式化完整成功正文为日志
- W06：取消排队任务及正在运行的任务，再启动另一任务；预期：等待、运行状态清理，后续任务正常执行
- S01：正常触发总结，检查进度及最终文本；预期：阶段顺序和最终总结内容正确
- S02：阶段标记跨两个输出片段到达；预期：合并缓冲能识别标记，进度正常推进
- S03：长摘要或很细的响应分片；预期：进度不会为每个分片创建完整摘要快照
- S04：总结中途发生重试并继续输出；预期：仍按保存点修订摘要，最终文本无重复拼接
- S05：启用总结 Hook，处理长历史；预期：Hook 收到完整参数，函数正常完成，不为日志重复序列化参数
- S06：取消总结后再次总结；预期：取消与清理正常，后续请求可执行
- A01：插件资源回调用 filePath 返回 WAV，点击播放；预期：音频可正常读取和播放，响应不先创建整文件数组
- A02：多个语音条引用不同或同一个本地 WAV；预期：各资源正确读取，不为每次响应常驻一份完整文件数组
- A03：WAV 读取中关闭页面或取消加载；预期：文件流和相关视图正常释放
- A04：本地网页服务加载 WAV、图片、CSS 和 JS；预期：响应长度与内容正确，普通页面资源可用
- A05：插件 HTTP 改写读取 WAV，播放后中断请求；预期：边读边交付；响应流关闭时断开连接
- A06：HTTP 改写返回 404 或 500；预期：状态、错误体及响应头正确传递，连接不残留
- A07：原有文本、Base64、HTML 文件资源响应；预期：文本和 Base64 内容一致，HTML 桥接仍可用
- A08：快速进出带语音条的页面并重复播放；预期：无持续增加的播放器、文件描述符或插件引擎
- C01：反复展开收起语音条文字；预期：旧渲染回调被回收，当前控制台回调仍可用
- C02：旧界面显示期间后台产生新树；预期：两者需要的回调均可用，提交后只清理过期部分
- C03：点击后立即产生新树、排队事件稍后执行；预期：待执行回调不被抢先删除
- C04：按相反顺序确认两个渲染版本；预期：迟到确认不删除新树仍使用的缓存回调
- C05：切换同一插件的执行上下文；预期：旧上下文确认不影响新界面
- C06：WebView 注册独立接口后重绘；预期：接口方法仍可调用
- C07：子节点、插槽、修饰符、state 和 memo 缓存节点含回调；预期：仍需使用的回调均保留，重复 ID 不重复登记
- C08：普通插件页面、插件弹窗和 XML 标签分别反复交互；预期：三种宿主均回收旧树回调，原交互不失效
- R01：用原反馈工作流复现，记录 Java 堆、Native 堆与 OOM 调用链；预期：区分并发峰值、结果驻留或具体资源泄漏
- R02：用原语音条插件复现显示、播放、停止和总结；预期：按已确认的 WebView 直接文件播放路径记录 Java、Native 及渲染进程内存变化
