# 历史列表滚动验证

使用至少 100 条对话，包含多个角色分组、展开/收起文件夹、长标题、锁定/置顶对话、带父对话副标题的行。设备与版本由执行者填写；以下场景全部尚未执行。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| H01 | 对长列表慢速反复上滑、下滑 | 标题、图标和卡片一起移动，行之间不重叠 |
| H02 | 快速滑动后立即反向滑动，多次跨越分组边界 | 无半截旧文字、旧卡片残留或分组错位 |
| H03 | 拖动右侧滚动条跨越中部、顶部、底部，再用上下按钮 | 可见顺序与实际列表一致，无行叠加 |
| H04 | 在列表中间反复展开、收起角色分组及嵌套文件夹 | 隐藏内容不残留，后续行立即占据最终位置 |
| H05 | 切换普通/玻璃样式，分别执行 H01—H04 | 两种样式均无错位，玻璃效果保留 |
| H06 | 拖动对话/目录排序、移入文件夹，靠边触发自动滚动 | 浮层跟随手指，落点正确，结束后无悬留卡片 |
| H07 | 侧滑编辑、删除普通对话，并尝试删除锁定对话 | 编辑/删除正常，锁定保护保留，删除后无旧行残留 |
| H08 | 切换搜索、排序、归档及多选，再返回长列表 | 条目完整、顺序正确，无重叠或误选 |
| H09 | 滚动期间接收对话标题/生成状态更新 | 当前状态对应正确对话，不串行或错位 |
| H10 | 离开侧栏后返回，并重启应用 | 文件夹归属、排序、展开偏好和选择行为正常 |
