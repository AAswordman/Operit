# 终端与离线资源紧急修复

版本为 1.12.2+3、versionCode 59，先提交个人修复分支并派发调试构建，不发布正式 Release。

原有终端配置先执行 dpkg 配置，缺失依赖时会提前结束；离线资源没有删除入口，安装状态只在进入页面时读取一次。

- 终端模块调整 APT 修复顺序，增加维护期间关闭会话和重置初始化的接口
- 离线资源页支持删除语音模型、Ubuntu 和导出模板；Ubuntu 同时删除已安装环境与安装归档
- 删除须确认，完成后重新读取资源和安装状态，支持再次导入符合现有格式及校验规则的 ZIP
- 终端删除记录先原子落盘，主应用重启后继续清理，未完成时显示未安装并阻止启动与导入
- 同时清理安装临时目录与锁目录，重复恢复在维护锁内复查记录，避免清理已重新导入的资源
- 删除语音资源沿用运行时占用保护；Ubuntu 清理不跟随符号链接，保留共享存储与已导出备份

验证项目与结果表见 [回归清单](01-regression.md)。不执行本地 Android 构建或测试，构建验证交给仓库 Android Build。
