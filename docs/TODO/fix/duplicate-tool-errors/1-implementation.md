# 实施与回归

## 行为与实现

ToolExecutionManager.aggregateToolResults 将最终失败保留在 error 字段，不再额外合成同一条 Step error 正文；最终步骤提供的独立诊断正文仍保留。前序步骤的错误继续保存在聚合正文中，最终状态仍以末次结果为准。

统一格式化器继续生成详情展示、复制和模型历史共用的工具结果内容。此修复不修改 JSON 参数、不改变目标工具是否执行，也不重写历史已经保存的消息。

OrderedToolResultsTest 更新既有部分输出后失败用例，新增七项回归，覆盖单次失败、独立诊断、不同步骤错误、后续成功和缺少 error 字段。原有顺序、权限拒绝、分段成功、空批次、取消及正文标签用例均保留。

终端非零退出的原生 TerminalCommandResultData 和 super_admin 包返回的结构化失败数据都经过同一聚合入口。本次保留 command、output、exitCode 与 sessionId 及错误信息，非零退出仍标记失败。新增两项用例分别覆盖原生结果和包失败协议解码后的聚合结果。

## 操作与预期

<details><summary>完整回归与可填写结果</summary>

- 01：同名工具倒序完成。预期：仍按调用顺序发布
- 02：权限拒绝与相同调用并存。预期：各调用保留独立位置
- 03：成功工具分多段返回。预期：合并为一个结果，展示与模型历史一致
- 04：空结果或已有部分输出后失败。预期：仍发布失败结果，保留部分输出，最终错误出现一次
- 05：分段输出后取消。预期：保留取消语义，不伪造已完成结果
- 06：空工具批次。预期：不生成工具结果标签
- 07：工具正文包含 content 标签或源码。预期：正文保持原样，展示与模型历史一致
- 08：单次失败且只有 error 字段。预期：详情和模型输入只含一次错误
- 09：失败同时提供独立诊断正文。预期：错误、已有输出及诊断正文均保留
- 10：前序步骤和最终步骤分别失败。预期：两处不同错误各自保留，最终错误不再复制
- 11：前序步骤失败后最终成功。预期：保留前序错误，成功状态及后续输出正确
- 12：最终失败没有 error 字段。预期：保留既有失败标记
- 13：原生终端捕获输出后以非零码退出。预期：失败状态、完整捕获输出、命令、退出码、会话信息保留，错误只展示一次，模型历史与展示一致
- 14：super_admin 包返回终端结构化失败。预期：协议解码与聚合后 output、command、exitCode、sessionId 不丢失
