# 模型上下文协议静默加载

## 问题与目标

原先只有包管理启动按钮和重启工具会运行服务，并通过全屏加载浮层显示进度。改为主界面创建时在后台检查已安装且启用的服务，有服务就加载，没有可启动服务就直接结束。自动加载、手动启动与工具重启均不显示加载浮层、跳过提示或失败引导。

## 实现范围

- 主界面启动加载任务并在销毁时取消，生命周期注册仍用于工具读取加载状态与日志
- 加载状态独立保存实际运行标记、服务结果与日志；并发请求共用正在执行的批次
- 无服务或全部禁用时结束，不创建启动器或初始化本地桥接；失败仅记录状态与日志
- 删除加载浮层、日志弹窗和专用进度动画，包管理页改为读取实际运行状态

## 验证记录

执行差异空白检查及引用核对。未运行本地编译、构建或测试，签名预览构建交由工作分支 Build 工作流；不等待或轮询执行结果。真实本地与远程 MCP 连接未在本次设备上验收。

<details><summary>回归范围</summary>

- 无已安装服务：主界面正常进入，无加载浮层、跳过提示与本地桥接初始化
- 有已启用服务：后台加载并注册工具，禁用服务不启动
- 服务连接失败：保留失败状态与日志，不显示弹窗或引导
- 包管理手动启动：按真实加载状态禁用重复操作，结束后刷新工具列表
- 重启工具：返回服务结果与日志，不显示加载界面
- 自动加载期间再次请求启动：合并到当前批次，不重置正在更新的日志
- 主界面销毁或重建：取消旧任务，新界面重新检查配置

以上为待执行的设备回归范围，不代表实测通过。
