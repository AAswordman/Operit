# A2UI HTML 标签切换生命周期

## 背景与目标

用户在合法的 `Tabs` 与 `Html` 布局之间切换时遇到 Compose 界面更新异常。现有 HTML 承载器通过 `AndroidView.onReset` 参与组合复用，并在重置、释放和不可见更新中同步销毁 WebView。平台视图销毁会产生同步回调，不应与尚未应用完成的组合交错。

本次修正 HTML 承载器的复用和销毁时机，不改变 Express 语法或已保存的卡片协议。原工作区的未提交改动不属于本分支。

## 实现范围

- HTML 承载器不参与 `AndroidView` 复用，标签页切换时各自持有独立实例
- 释放时立即解绑高度回调和令牌，并从承载器移除旧 WebView
- 通过主线程消息队列在当前 Compose 更新完成后停止、暂停并销毁旧 WebView
- 保留离屏释放、生命周期暂停、点击加载和只读离线 HTML 的现有行为

## 回归检查

- A01：加载包含两个 HTML 子页的卡片，反复切换标签；页面内容正确，无 Compose 异常
- A02：快速连续切换两个标签并滚动聊天；不会出现旧页覆盖、新页空白或承载节点复用异常
- A03：HTML 卡片滚出可见区再滚回；旧 WebView 被释放，重新加载后高度正常
- A04：切换后台再恢复；不可见页面停止运行，恢复后可继续浏览
- A05：切换字体缩放和屏幕方向；HTML 按当前尺寸重建，迟到高度回调不更新已释放页面
- A06：仅包含原生控件的 Tabs、Carousel 和 Conditional；原交互正常
- A07：HTML 请求网络、文件或执行作者脚本；仍被离线承载规则阻止
