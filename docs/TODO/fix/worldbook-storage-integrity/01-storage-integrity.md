# 存储与运行时

空文件、损坏 JSON 和错误顶层结构会记录错误并中断操作，不再作为空库保存。变量库验证全局、角色及会话状态。

每次保存先写同目录临时文件、回读校验、fsync，然后通过 android.system.Os.rename 替换目标。通用 move 工具可能复制覆盖，不能提供这里所需的提交语义。失败不会直接截断原文件，也不进行复制覆盖。

UI 通过既有 ToolPkg IPC 将操作发送到主运行时；条目、分组和变量同步共用主运行时队列，覆盖完整读改写。初始化共享 Promise，失败显式报错。旧目录迁移先校验并保存新文件，保留旧目录及其中其他文件。

分组删除保留被其他分组引用的条目。涉及条目和分组的操作先读完受影响文件，再更新引用。不同文件仍分别提交，不能承诺断电时的多文件事务。

宿主将插件配置目录展示为受保护的“插件数据”，禁止勾选和批量删除。删除入口再次校验分类与规范路径，防止数据目录通过其他分类进入清理流程。
