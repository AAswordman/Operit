# 实现与验证记录

## 作用域

- 在现有 keypool 包内调整冷却时长、配置恢复和错误分类
- 保存密钥或端点等连接配置、重新测试成功后，解除相关旧冷却
- 设置列表和信息弹窗每秒展示临时冷却，结束后移除倒计时；手动清除同时解除临时冷却
- 池耗尽保留明确错误，停止重复选钥与虚构失败统计；全池冷却时显示最早等待秒数
- 普通路由 404 与 405 提示检查服务商和完整路径，明确模型错误继续按模型处理

## 回归范围

- 鉴权或余额失败后，一分钟到期可重新选择；模型失败三分钟到期可重新选择
- 同一密钥 ID 修正内容后立即解除相关冷却，其他密钥及空间配置不受影响
- 修改连接配置、重新测试成功或主动清除状态后，旧冷却不再阻止调用
- 普通名称编辑和轮询索引更新保留冷却；成功请求只清除全局与当前模型的冷却
- 空池及被包装的空池异常停止重试，保留诊断，不新增 HTTP 失败记录
- 端点 404/405 不换钥，明确模型 404 仍可换钥
- 大小密钥池显示临时冷却汇总，列表及信息弹窗按全局或具体模型显示剩余秒数，倒计时结束后消失
- 批量测试仍只处理未测试密钥，测试可用性标记继续持久保存
- 自定义 /v2 路径保持原样，裸域名和 /v1 保留原有自动补全
