# 密钥池冷却与恢复

鉴权失败和余额不足原先分别冷却十二小时、四小时，模型访问失败冷却三十分钟。用户修正密钥、充值或修正模型后，旧冷却会继续阻止选择，界面也没有剩余时间。池耗尽与地址类错误仍可能进入通用换钥处理。

本次将鉴权和余额冷却设为一分钟，模型冷却设为三分钟；补齐配置修正、测试成功和手动清除后的恢复；展示真实内存冷却；对空池快速失败，并提示检查自定义端点完整路径。

沿用现有批量测试标记、测试范围、请求预算和端点自动补全规则。内存冷却不写入持久配置，不修改用户数据格式。
