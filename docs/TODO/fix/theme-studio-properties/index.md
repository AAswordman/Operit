# 修正主题属性入口与描边可见效果

主题工作室的消息颜色入口重复，描边只改颜色时可能仍为零宽度，背景透明度还会把描边一起隐藏。此次按真实渲染关系整理颜色、描边和线条图层入口，并说明会影响可见效果的继承、透明度和原生布局条件。

## 实现范围

- ThemeStudioProperties 将消息填色、正文色明确命名为消息背景色和消息文字色；区域字体区保留字体与排版参数，移除与区域正文色互相覆盖的第二个颜色入口，全局文字色入口保留。
- ThemeStudioState 按当前渲染优先级显示既有主题的区域颜色；主动编辑区域正文色时清理该区域重复的排版色，避免清空后旧值重新出现，保留字体和其他模式配置。
- 描边颜色与宽度在默认外观和交互状态下共同编辑；从零宽度选择描边颜色时开启 1dp 描边，已有正宽度和显式透明色保持不变，宽度仍可设为零关闭。
- ThemeScriptDecoration 让自定义描边由自身颜色透明度和组件不透明度控制，修复背景透明度为零时描边也被隐藏的问题；背景填充与图片图层继续使用原有背景透明度。
- 线条图层使用单一颜色入口，编辑后移除相互遮蔽的第二个颜色字段；宽度显示与实际绘制的 1 像素下限一致，必需颜色不提供无来源的继承操作，其他图形的描边颜色同样能开启零宽度描边。
- 颜色对话框标题包含当前部件、颜色用途和浅深色模式；图层类型名使用已有本地化资源，补充消息背景透明度、头像遮挡、额外留白、最小高度和全局文字色优先级提示。
- 保留原有能力目录，核对 22 个区域、交互状态、全局配色与排版、动作图标和各绘制图层的消费入口；本组新增 11 条文案同步全部九种语言，提供完整回归表。
- 新增纯 JVM 主题声明回归源码，覆盖重复颜色清理、默认与交互态描边启用、继承宽度、显式透明色以及导出后的模式和其他字段保留。
