# 语音理解限定为忠实转写

音频理解功能模型的结果会作为用户语音文本持久化并交给后续对话。旧提示允许补充语气和背景声音，并与录音链接放在同一个用户回合，容易把理解性补充混入转写。

现在将转写要求作为独立系统指令，用户回合仅携带当前录音。九种语言提示统一要求保留原语言、人称和疑问句，不翻译、改写、续写或回答，不生成身份和背景描述；不清晰部分明确标记，无人声时不猜测。

原有直接音频、音频理解功能模型和 STT 的处理顺序，以及明确解析后才缓存的语义保持兼容。不会据此改写历史已保存的识别结果。

## 验证与限制

已核对九语种资源键唯一性、XML 格式和请求角色。该变更为提示词与请求角色调整，不新增模拟准确率测试；提交后派发 Debug 构建。本地未运行构建或测试。

粉丝原话由用户确认为“你是我的小猫吗”，当前只有截图，没有原音频、功能模型配置和请求数据。尚未复现其识别结果，也不能据此承诺准确率已恢复。需要同一录音与配置对照才能判断该案例是否改善。
