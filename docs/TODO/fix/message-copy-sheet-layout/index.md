# 消息复制面板的底色与裁剪范围

## 问题与改动

复制消息面板原先在 `ModalBottomSheet` 的调用方修饰符中添加裁剪、底色和主题装饰。修饰符位于原生面板内部位移之外，底色绘制在未位移的位置，裁剪范围也不能覆盖位移后的全部内容。反馈截图中表现为顶部大面积深色空白、正文被截断且复制按钮不可见。

`ChatArea.kt` 将主题底色与轮廓交给原生面板的 `containerColor` 和 `shape`，主题正文色通过 `contentColor` 传递。主题装饰移到面板内部的内容列，跟随容器位移。保留原生拖动手柄、关闭方式、原有内容高度约束、三种复制格式及各自的选区与滚动状态。

## 验证记录

差异空白检查通过，并静态核对复制面板调用方不再施加外层底色与裁剪。未运行本地编译、构建或测试；工作分支派发签名预览 Build，不等待或轮询结果。截图所示设备效果本次未实机复核。
