# 工作区复制内存与文件操作进度

工作区将内置 Ubuntu 文件复制到手机目录时，跨环境实现会完整读取文件、经过字符串转换，反向复制还会累积完整字节数组。目录递归会忽略子项失败，粘贴界面只显示旋转圆环。

本批优化本机 Android 与内置 Ubuntu 的文件复制，并为单项和批量删除补齐共用进度窗口，保持公开工具参数、权限路由、覆盖规则及删除确认。传输逻辑放入 `core/files/transfer/`，不修改终端子模块、应用身份或数据库。

- [x] 使用固定缓冲区复制二进制，逐层遍历目录，不保留完整目录清单
- [x] 使用终端现有挂载映射处理 Ubuntu、手机共享目录及 `~`
- [x] 为单次粘贴隔离进度，显示当前文件、来源、目标、已复制量、剩余量、速度及百分比
- [x] 统计期间显示明确状态，已知总量后显示确定进度；完成前不显示 100%
- [x] 子项失败立即返回失败，剪切来源只在对应项完整成功后删除
- [x] 补充二进制大文件、隐藏文件、空目录、同路径、符号链接及失败/取消的 10 条 JVM 回归用例
- [x] 完成差异空白、XML 和调用关系的静态核对
- [x] 为单项和批量删除复用进度窗口，显示真实的所选项目完成数，保留既有删除后端和确认提示
- [x] 删除失败、取消时清理窗口状态，停止后续项目；跨环境剪切清理不另弹删除窗口
- [x] 补充删除进度、部分失败及取消的 7 条回归用例，更新完整验证范围
- [ ] 远端构建与测试结果确认

远程 SSH、SAF 和独立 Shell 复制继续使用各自原有工具实现；只有后端提供真实字节进度时才显示字节百分比，否则显示当前项目和处理中状态。不会以经过时间推算百分比。

删除仅按所选项目计数，单个目录内部的进度未知。取消将在当前删除调用返回后停止后续项目；已删除内容不恢复，错误继续显示在文件浏览器。跨环境剪切清理不另弹删除窗口。

完整范围和可填写结果见[验证记录](01-validation.md)。本地未编译、构建或执行测试；CI 与 PR 交付到独立工作分支，目标为 `dev`。
