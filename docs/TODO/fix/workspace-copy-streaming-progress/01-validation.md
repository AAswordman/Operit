# 工作区复制与删除验证

## 已完成的静态核对

- `git diff --check` 通过
- 9 组新增语言资源 XML 均能解析，每组包含 19 个界面条目
- 核对复制入口继续经过既有文件工具及权限路由，本机传输复用终端挂载映射
- 核对传输缓冲区为任务级复用的 256 KiB，目录遍历不缓存完整文件清单
- 核对界面通过单次调用令牌接收复制进度，结束、失败时均移除观察者并清空面板状态
- 核对单项和批量删除复用进度窗口，既有 `delete_file` 参数、权限路由和确认入口未变；剪切收尾不弹出删除窗口

未执行本地编译、构建或测试。共新增 17 条 JVM 回归用例，包含 10 条流式复制用例及 7 条删除状态用例。这些用例由仓库 Android Tests 运行，远端结果以对应工作流为准；Android 实机内存峰值和 UI 尚未测量。

| A10 | 复制空目录并检查递归开关 | 关闭递归时拒绝；开启时以零字节完整完成 |
| D1 | 删除单个目录并观察工具返回前后的状态 | 执行期间不显示未知百分比，成功后才计入完成并清理窗口 |
| D2 | 删除不同来源环境的多个所选项目 | 逐项报告当前路径，完成数和比例只随成功返回推进 |
| D3 | 批量删除第二项失败 | 失败项不计完成，不开始后续项，已完成通知和错误均保留 |
| D4 | 当前删除调用期间取消 | 当前调用返回后停止后续项，不撤销已完成项，清理窗口 |
| D5 | 操作开始前已取消 | 不调用删除工具，不打开窗口 |
| D6 | 提交空删除列表 | 不调用工具或成功通知，不打开窗口 |
| D7 | 删除失败后重新开始操作 | 新任务从零开始，路径和总数不残留上次状态 |
| M1 | 将 `/root/Operit` 从本机 Linux 复制到手机目录，再反向复制大文件 | 原始字节保持一致，不出现整文件字符串或字节数组累积 |
| M2 | 在 Linux 使用 `~/`、`/sdcard` 和宿主挂载路径复制 | 映射与终端一致，同一实际位置仍被拒绝 |
| M3 | 单选、全选、多选和跨目录粘贴 | 全批次预检重名；多项显示序号及当前项目进度 |
| M4 | 跨环境剪切，并制造目标写入失败 | 对应项完整复制成功后才删除来源；未完成的剪切项留在剪贴板 |
| M5 | 在标准、管理员和 Root 模式执行既有文件操作 | 权限后端沿用既有路由；Shell 路径没有字节数据时显示处理中 |
| M6 | 使用远程 SSH 和 SAF 粘贴 | 使用既有提供方；未知总量不显示虚构字节数或百分比 |
| M7 | 在深浅主题、大字体及横屏查看复制面板 | 标题居中、路径可辨认、百分比位于 6dp 进度条右上方；超高内容可滚动 |
| M8 | 成功、失败、点击取消和离开文件浏览器 | 面板与观察者正确结束，错误仍显示在文件浏览器中 |
| M9 | 在文件菜单确认单个文件或目录删除 | 确认后显示居中删除标题、名称和来源路径；不显示复制目标、字节数或速度 |
| M10 | 多选并确认批量删除 | 全批次显示同一窗口，所选项目完成数和百分比正确；单个目录内进度保持未知 |
| M11 | 批量删除时制造权限错误，或点击取消 | 失败/取消后不开始后续项，列表刷新，未完成项不误清选择；已删除内容不恢复 |
| M12 | 在标准、管理员、Root、Linux 和 SAF 环境删除 | 沿用原删除工具、环境及递归参数；同一删除窗口不改变后端权限 |
| M13 | 跨环境剪切进入清理来源阶段 | 保持移动窗口，不叠加删除窗口；完成、失败与取消后状态正确清理 |

复制链接到不支持符号链接的目标存储会明确失败并保留来源。失败时已经写入的部分目标保留，不自动删除其他文件。扫描与复制期间持续修改来源不会构成目录快照。

删除百分比仅按所选顶层项目计数，不代表目录内文件数或字节数。已有同步删除工具不能在调用中途保证停止，取消在当前调用返回后阻止后续项；不撤销已完成删除。
