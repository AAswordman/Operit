# +17 完整回归记录

## 用例

| 编号 | 做什么 | 预期行为 |
|---|---|---|
| P01 | 仅元数据版本变化 | 识别旧目录，载荷不移动、不重复下载 |
| P02 | 文件内容发生变化 | 旧安装继续可用，标记可用更新 |
| P03 | 连续升级且最新清单再次变化 | 私有安装登记继续识别先前安装 |
| P04 | 新旧版本均完整 | 优先选择清单当前版本 |
| P05 | 旧载荷被改坏 | 拒绝为完整安装，不删除原文件 |
| P06 | 出现未登记的目录 | 不授予内置身份 |
| P07 | 安装标记身份或版本不符 | 不识别为完整安装 |
| P08 | 扩展包名身份变化 | 不沿用另一身份的旧安装 |
| P09 | 旧安装缺少文件 | 保留数据但不算完整 |
| P10 | 导出再解包旧安装 | 仍可按固定旧清单验证 |
| P11 | 明确删除资源组 | 各版本和登记记录全部删除，不复现 |
| P12 | 旧版本正被运行占用 | 整个资源组不可删除 |
| P13 | 强制重新校验 | 相同时间戳也不能掩盖被篡改字节 |
| P14 | 登记记录与当前固定清单冲突 | 不能覆盖当前版本校验摘要 |
| P15 | 登记版本含越界路径 | 拒绝读取组外路径 |
| P16 | 只留下未完成记录临时文件 | 不当作已完成安装 |
| A01 | 请求不存在的内置或外部包 | success=false，PACKAGE_NOT_FOUND 和包名准确 |
| A02 | 激活失败的其他原因 | 各自错误类型及可读原因保持 |
| A03 | 成功描述包含错误字样 | 仍按成功结果处理 |
| A04 | 错误数据序列化 | 错误类型与包名可往返读取 |
| E01 | 真实 +15 安装升级到 +17，离线启动 | 已有有效扩展被识别，不要求全部重下 |
| E02 | 真实 +16 安装升级到 +17 | 当前安装保留，旧目录仍在时可重新识别 |
| E03 | 显式更新有变更的扩展 | 保留原安装至校验成功，新载荷进入自己的版本目录 |
| E04 | 取消或下载更新失败 | 旧安装及启用偏好保留 |
| E05 | 原有普通导入插件与 Skill | 安装目录、配置和使用行为保留 |
| E06 | MCP 本地和远程配置 | 配置及安装目录仍保留，实际情况待设备核实 |
