# 自定义主题字段导入导出

## 范围

分享码维持现有参数 JSON、zlib 和 Base64URL 编码，只增加自定义外观字段，不携带媒体文件、资源标识、本机路径或脚本源码。完整主题包维持 ZIP 格式的 `.oktheme`，继续保存工程和全部配套资源。格式、链接版本及现有容量预算不变，PhoneAgent 分支保持搁置。

导出说明改为“包含完整的主题资源”，同步已有翻译。

## 实现

分享码增加可选 `appearance` 字段，使用现有外观数据模型序列化配色、部件、图层、模式、状态、文字描边和弹窗偏移等参数。只读取工程配置清单，不把完整主题包转换成文字。序列化省略模型默认值，旧分享码没有该字段时保持原有行为。

导入时保留接收方的媒体资源和绑定。图标按部件 ID 对应；有 ID 的图片图层按 ID 对应，无 ID 的图片图层按同部件内的序号对应；缺少绑定的资源项不创建空引用，其他外观参数继续生效。接收方已有的文件字体保持引用，更新字号、描边等参数。未被引用的现有图像层及图标继续保留。

预览和实际应用共用外观参数合并逻辑。接收方已有工程保留其脚本、资源和工程信息；没有工程时使用编辑器现有的默认工程入口。预览生成的缓存随预览关闭释放，实际应用的新增文件纳入原有失败清理事务。

完整主题包的工程字段已由现有序列化模型覆盖。本次将传输层的八层嵌套限制改为复用主题契约的十六层预算，并为传输根对象增加一层，允许合法的模式、图层、文字描边等组合；异常深度仍会拒绝。
