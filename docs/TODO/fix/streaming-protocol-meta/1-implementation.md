# 实施记录

## 显示投影

新增 core/chat/protocol/ProtocolMetaDisplayFilter，按增量字符识别三个既有协议提供方：gemini:thought_signature、openai:responses_reasoning、openai:responses_output_item。开始标签和结束标签可跨输入片段，属性识别支持单双引号、大小写和引号内大于号；未知提供方、HTML meta、相似标签名和其他属性保持原文。

已识别的协议正文不交给 Markdown/XML 解析，不依赖外层节点是否闭合。无协议内容的正文批次直接传递；长协议负载不进入可见前缀，也不反复全文扫描。

代码示例中的候选协议先暂存，代码闭合后按原文显示。代码未闭合时，结束投影继续隐藏协议负载，静态 Text 片段使用同一规则，避免切换渲染阶段后恢复负载。普通正文和不包含这些协议标记的代码继续增量显示。

## 入口与回滚

rememberRevisableTextStream 是气泡、游标和聊天分块共用入口，原文继续交给 TextStreamRevisionTracker，只有过滤后的显示增量进入下游 Markdown。普通流和带保存点事件的流使用同一显示投影；回滚仍按原文保存点截断，再重建显示前缀及未结束标签状态。

服务原始流、消息保存、sections、JSON/CSV 和提供方后续请求逻辑均未修改。结束时保留显示回放的原有生命周期行为。MessageSectionMarkdown 仅投影 Text 显示内容，不改写原 MessageSection；Protocol 片段继续跳过绘制。

## 回归与验证

新增十六项显示过滤用例，覆盖原 XML 分类器被未闭合外层节点占用的固定输入、三个协议提供方、全部单切分位置、逐字符输出、256 KiB 负载、未闭合标签、代码示例、属性边界、直接相邻标签和保存点回滚。另补三项静态正文集成用例，验证显示投影、代码示例、结束切换及原文保留。
