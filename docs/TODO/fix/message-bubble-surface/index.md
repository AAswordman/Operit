# 分块消息的连续主题气泡外壳

长消息达到 24 个可见节点或 32,000 字符后，时间线会按正文和工具分组拆成惰性列表条目，避免离屏内容全部进入布局。原生圆角和图片气泡已经区分首尾，但主题自定义形状、边框、上下内边距和主题九宫格图层仍在每片上完整绘制，导致连续切角、横向接缝和重复的图片首尾。

## 实现范围

- 在显示入口传递消息实际可见块的首尾标记，主题层按 surface ID 使用，不把消息节点或解析器引入主题绘制
- 保留圆角、切角及圆形的角点类型，只保留整条外壳首部的上角和尾部的下角，中段不再切角
- 描边只沿连续外边缘绘制，上下内边距只出现在消息两端；分块后不为每片重复设置最小高度或独立投影
- 主题九宫格图层只在消息首尾绘制上下装饰，中段使用相同的源图片中心区间；模糊显示列表把首尾变化纳入缓存输入
- 续段使用主题指定的头像宽度占位，避免更换头像尺寸后同一条气泡左右错位
- 内容拆块阈值、节点缓存、Markdown/工具/A2UI 渲染器和卡片交互保持原实现

## 边界与取舍

本次统一容器几何和九宫格首尾。普通 `image` 图层仍按既有图层规则绘制，本次没有把任意图片改为按整篇消息总高度拉伸；要做全文比例拉伸，需要另外处理尚未布局的离屏内容高度。本次不为背景图片提前布局整篇正文，也不生成整条消息的大位图。

单段消息以及用户气泡、按钮、工具卡等其他 surface 沿用原有样式。主题文件字段和导入导出格式不变。长消息由分块容器组成时，不再在每个块上重复应用最小高度和独立投影。

## 实现步骤

1. 增加主题外壳首尾描述与角点、描边、九宫格轴向布局规则 [DONE]
2. 显示入口传递首尾，接入主题装饰与模糊缓存，并修正续段头像占位 [DONE]
3. 补充 6 个 JVM 几何回归用例及完整设备回归清单 [DONE]
4. 完成静态检查，推送工作分支并派发仓库工作流

## 回归清单

- B01：短消息分别设置圆角、切角、圆形；仍按单个完整气泡显示
- B02：包含至少 24 个可见节点的正文和工具混排，设置切角和描边；仅最外四角切角，中间没有重复横边
- B03：超过 32,000 字符的长正文；仍按可见块加载，背景两侧连续
- B04：给助手气泡设置较大上下内边距和最小高度；中段没有每片重复的留白或最小高度
- B05：主题九宫格使用明显的上下花纹，分别查看首、中、尾；首尾各出现一次，中心源区间一致
- B06：现有图片气泡分别使用九宫格和重复中心模式；裁切、缩放和透明度仍可用，首尾规则不变
- B07：头像宽度分别设置为 16、32、64dp；同一消息首段和续段左右位置一致
- B08：收起、展开工具组或思考块；首尾跟随实际可见内容，纯隐藏内容不生成空气泡
- B09：流式回复越过拆块阈值并持续追加，最后停止；内容继续更新，末端只出现在最后可见块
- B10：长消息中操作 A2UI 输入、标签、提交，点击链接和工具卡；交互与状态保持原行为
- B11：气泡透明度为 0、0.5、1，切换前后台和明暗主题；背景透明度正确，正文清晰
- B12：检查 Cursor 风格、用户气泡、按钮和独立工具卡；其他 surface 不受助手消息首尾标记影响
- B13：工作室及全屏预览选择用户或助手气泡；单条预览显示完整外壳
- B14：首尾块很短、描边较粗、图层启用模糊时反复折叠与滚动；边框不重复横切，模糊首尾随内容更新
- B15：普通 image 图层和主题资源导入导出；保留现有绘图规则与文件格式
- B16：快速来回滚动长消息并多次展开工具；检查卡顿、闪烁和内存变化，记录设备及观察结果
