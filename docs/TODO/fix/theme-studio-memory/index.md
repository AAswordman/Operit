# 主题工作室记住编辑位置

工作室每次创建状态时都回到浅色和助手气泡，退出后无法接着编辑上次的组件。本次把编辑位置保存为本机工程偏好，在工程加载完成、显示预览之前恢复。

## 改动范围

- 记住预览深浅色、组件、属性页和状态，以及设计/源码/资源工作区、预览场景、输入栏样式和预览折叠状态
- 沿用工程标识的哈希隔离不同角色或工程，位置不进入主题资源束、导出文件或角色主题草稿
- 选择变化后异步落盘，关闭时补存最后位置；保存、应用或放弃主题内容不重置编辑位置
- 首次打开没有位置记录的工程时，使用现有初始值；不改变当前应用主题或自动应用编辑内容

## 实现步骤

1. 新增工作室位置模型和本机偏好存储，使用一次事务保存整组位置 [DONE]
2. 工程加载时恢复位置，页面观察选择变化并在关闭前保存 [DONE]
3. 完成差异与仓库静态检查，推送工作分支并派发仓库工作流

## 回归清单

- M01：深色模式选择用户气泡，退出再打开；仍显示深色和用户气泡
- M02：选择按钮的图层页，退出再打开；组件、属性页和对应预览场景一致
- M03：选择可编辑状态及预览场景、输入栏样式，折叠预览后重开；恢复各项选择
- M04：切换设计、源码或资源工作区后重开；恢复上次工作区
- M05：后台结束应用进程后重开同一工程；位置仍保留
- M06：分别编辑两个角色工程再切回；各自恢复自己的位置
- M07：同一帧切换选择后立即关闭；下次恢复最后选择
- M08：保存草稿、应用到角色、放弃未保存内容后分别重开；位置保留，原有内容保存行为不变
- M09：首次打开新工程；仍使用既有浅色和助手气泡初值
- M10：工程加载失败后重试；成功后恢复位置，失败期间不写入初始位置
