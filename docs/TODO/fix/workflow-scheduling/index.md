# 工作流定时执行修复

本计划处理 Android 应用内自动化工作流的定时触发，协作分支为 `feat/data-and-backup`，随 PR #24 提交。

原调度会在应用冷启动与普通工作流编辑时替换 WorkManager 请求，固定间隔向下截断分钟且首次立即运行，Cron 只支持少量模板并从保存时刻累加。部分日历规则只执行一次，重复和截止配置也未完整生效，导致时间偏移或漏执行。

修复将纯时间计算放入独立 `core/workflow/scheduling/`。保留现有任务命名、触发器配置和串行执行队列；启动恢复保留有效任务，普通编辑不重置计划，日历规则逐次续排，并在执行前检查当前配置。详细行为见 [调度规则与迁移](01-scheduling.md)。

31 项 JVM 用例覆盖 Cron、时间与计划身份边界，已加入仓库供远端工作流执行。本地仅进行语法与资源核对，未运行 Android 编译或测试。完整设备检查统一保留在 [数据与备份验收清单](../../feat/data-and-backup/verification.md)。

实现 [DONE]；远端结果和设备验收待确认。
