# 实施与回归

## 实现

BubbleUserMessageComposable 的图片组沿用正文右边界：普通气泡显示头像时预留同一份头像尺寸和间距，关闭头像时使用正文原有留白，宽屏布局使用宽屏正文边界。

过期音频从独立的全宽媒体行移入原有消息内容位置，只替换气泡内容为紧凑音频标签。普通和宽屏布局继续执行原有头像及姓名代码，因此文件失效不会再把发送者身份一起隐藏；过期分支不创建气泡背景。

SentImageGroup 内部使用右对齐，避免混合可用和过期图片时，较窄的过期标签落在组的左侧。原有数字角标、过期提示和预览流程保留。

- 05：开启宽屏气泡，查看正常消息及过期媒体。预期：图片和音频标签采用宽屏正文边界，过期音频保留原有标题及头像

- 08：查看正常录音并播放、展开转写。预期：继续显示语音条及原头像，播放与原话展示正常
- 09：查看正常图片、普通文字、其他附件及隐藏占位消息。预期：保留原有显示和交互，图片组与正文对齐
- 10：切换游标样式查看正常与过期图片和录音。预期：保留该样式原有正文位置，混合图片组的过期入口在右侧对齐
- 11：分别使用图片气泡、玻璃效果和普通背景查看过期音频。预期：只显示紧凑音频标签和原有消息身份信息，不显示空背景气泡
