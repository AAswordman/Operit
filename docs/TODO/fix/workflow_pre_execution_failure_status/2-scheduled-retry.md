# 调度重试与运行环境准备

## 旧实现

`WorkflowWorker` 将仓库返回的所有失败和协程取消都转为 `Result.failure()`。工作请求没有为重试配置明确的退避时间。

执行器在构造时获取工具处理器，工具包初始化失败可能发生在运行日志创建之前，或在节点中被压缩为“工具不存在”。

## 修正意图

在创建运行日志后准备默认工具和工作流引用的工具包运行环境。初始化异常作为可重试失败返回给定时入口。

## 预期实现

- 运行记录持久化 `failureStage` 与 `failureReason`
- `WorkflowWorker` 仅对可重试启动失败返回 `Result.retry()`
- 取消继续由 WorkManager 的取消语义处理
- 工作请求使用指数退避延迟
