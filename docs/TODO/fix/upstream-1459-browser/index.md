# 同步点击目标与导航结果校验

浏览器点击此前可能只完成触摸派发就返回成功，即使目标被遮挡、页面尚未导航或加载失败。现在点击前确认稳定可见目标，点击后结合 DOM 事件和实际文档导航判断结果，失败时返回可定位的原因。

## 实现范围

- StandardBrowserSessionTools 点击前统一准备 ref/selector 目标，核对滚动、视口、遮挡和框架坐标；无效几何信息明确失败，避免坐标裁剪后误点。
- 原生触摸在主线程读取尺寸并分时派发按下和抬起，校验会话、视图附着和 WebView 接受状态；JS 激活同时确认目标未变化。
- 新增 BrowserNavigationDiagnostics，记录点击捕获、默认行为取消、框架加载与导航阶段，工具结果按真实 DOM 和文档状态判断成功。
- BrowserToolSupport 与 BrowserWebViewSupport 区分待导航 URL 和已提交文档，识别主框架网络或 HTTP 失败；保留现有导航策略、弹窗限制和下载处理。
- 同步原生坐标回归源码并适配当前包路径，提供完整点击与导航回归表。
