# 对话历史文件夹

当前上游用聊天记录上的文本分组，文件夹没有独立身份、父目录和排序。
本轮将已有文件夹实现移植到上游 dev `927d6ce41`，准备独立贡献分支。

## 实施范围

1. 将旧分组按角色卡和角色组作用域迁移为稳定文件夹 ID，数据库从 21 升级到 22
2. 支持嵌套、独立排序、跨文件夹拖动、折叠、层级搜索和路径展示
3. 保留普通对话分支；同步 Android、外部聊天入口与 Web 的文件夹归属
4. JSON v4 保存文件夹层级；兼容旧归档，CSV 保留文件夹路径

不包含消息引导队列、回复折叠、子代理 V2、标签制或平板侧滑改造。

功能说明见[嵌套聊天文件夹](../../doc-src/feature-protocol/nested_chat_folders.md)。

## 验证

Android 主代码及测试代码编译通过，40 项聚焦测试通过，无失败或跳过。
测试涵盖旧分组迁移、保存期间的目录归属、排序、导入版本、空目录导出、深层异常归档及拖动合并。
Web 类型检查、生产构建和 4 项历史同步测试通过。
逻辑、性能、界面体验三项独立静态审计均为 PASS/CLEAN。

Debug APK 构建通过，已覆盖安装 Operit Debug 1.12.2（versionCode 51）。
安装前后签名一致，首次安装时间未变，未卸载或清除数据。手机界面体验仍待用户检查。
本地 Windows 构建使用短路径、CMake 3.31.6 及同版本 Saba 解压缓存；这些环境配置不进入贡献代码。
未运行 Lint，尚未推送或创建 PR。专题 #710 还包含其他交互议题，本分支只处理文件夹相关范围。

## 手机验收

由用户在 Operit Debug 中检查：

1. 原有聊天及分组仍在，角色绑定正确。
2. 创建三级目录，拖动目录排序、把聊天拖入另一目录；重新打开应用后位置保留。
3. 折叠目录后搜索其中的聊天，能看到命中路径；清空搜索后恢复折叠。
4. 同名目录的移动目标能区分，“最近”和“收藏”切换正常。
5. 使用测试聊天验证 JSON 导出与导入，包含空目录和嵌套目录。

### 短列表拖动裁切修复

手机截图显示：只有少量聊天时，列表按内容高度收缩，向下拖动的卡片在原列表底边被裁切。
列表容器改为占满标题栏下方的剩余空间，拖动区域随之延伸至面板底部。
复测时覆盖仅一条聊天的向下拖动，以及长列表靠近底部时的自动滚动。
