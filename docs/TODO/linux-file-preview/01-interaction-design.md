# 工作区文件界面与交互设计

状态：实现中的交互规范；视觉稿用于评审，当前运行时代码已接入主要页面。

## 01 文件浏览

旧实现：工作区目录选择页调用浏览器时没有传入文件打开回调；浏览器长按菜单只在管理模式启用。工具箱文件管理器另行实现较完整的文件操作。

本次意图：用户在选择工作区之前就能检查目录和文件，绑定后继续使用同一套浏览、管理与预览能力；工具箱重复入口移除，已有有效操作迁入共用组件。

界面布局：

- 使用单栏文件列表，上方依次为标题栏、来源切换、路径面包屑、目录工具行。
- 标题栏：返回、页面标题、搜索和更多操作；工作区选择模式标题可为“选择工作区”，绑定后使用“工作区文件”。
- 来源切换：设备、Linux、附加存储仓库，复用现有可访问的位置。保留各来源的路径信息。
- 目录工具行：上一级、新建、排序；更多操作内提供显示隐藏文件及刷新。
- 文件行：类型图标、文件名、修改时间和大小。文件夹排序在前。
- 工作区选择模式底部显示“使用此文件夹”；已绑定工作区的日常浏览模式隐藏选择确认栏。
- 配色跟随应用主题；文件页面的 Surface 同时提供 surface/onSurface，标签栏提供 surfaceVariant/onSurfaceVariant，工具栏图标不继承外层聊天颜色。视觉稿中的粉紫色仅用于展示主题效果。

交互：点击文件夹进入目录；点击文件按类型进入默认应用内查看器。浏览和预览不改变当前绑定的工作区，只有点击“使用此文件夹”才提交绑定。返回查看页前所在的列表时保留路径和滚动位置。

## 02 长按操作菜单

参考用户提供的文件管理器排版，采用两列图标和文字的圆角悬浮菜单。菜单顶部显示目标名称，背景轻微变暗；点击菜单外部或返回关闭菜单。

| 左列 | 右列 |
| --- | --- |
| 复制 | 剪切 |
| 粘贴 | 重命名 |
| 打开方式 | 分享 |
| 删除 | 留白 |

此处只有以上七种操作；编辑操作属于打开后的文本查看页。文件夹菜单只显示适用于文件夹的操作，不出现文件“打开方式”。

| 操作 | 行为 |
| --- | --- |
| 复制 | 记录来源环境和路径，进入目标目录后执行粘贴。 |
| 剪切 | 记录来源环境和路径，粘贴成功后完成迁移；点击剪切时保留原文件。 |
| 粘贴 | 文件菜单中的粘贴目标为当前显示目录；文件夹菜单中的目标为该文件夹。剪贴板为空时禁用，目的地无写权限时说明原因。 |
| 重命名 | 显示原名称，提交后刷新列表；重名时明确提示并保留输入。 |
| 打开方式 | 为本次打开选择适用的应用内查看方式或用户主动选择外部应用；不改写文件内容，不自动修改默认关联。 |
| 分享 | 分享实际文件；Linux 或附加仓库来源通过应用缓存与可分享 URI 接入 Android 分享界面。 |
| 删除 | 显示文件或目录名称及确认界面，用户确认后执行删除并刷新。 |

每项触控区域至少 48dp；删除使用错误色，其余使用主题文字和图标色。禁用项仍保留位置，避免菜单布局跳动。菜单关闭后，复制或剪切状态保留在共用浏览器中。

## 03 默认查看与文本编辑

| 文件类型 | 默认查看 | 编辑行为 |
| --- | --- | --- |
| 文本、源码、日志、配置、CSV 等 | 原始文本与适用的语法高亮 | 直接使用已有 `CodeEditor`，支持修改和保存 |
| Markdown、HTML | 默认显示源码，提供预览切换 | 源码页面继续使用已有编辑器 |
| 图片 | 图片缩放和移动 | 使用图片预览，不显示文本编辑操作 |
| 音频、视频 | 本地播放与进度控制 | 使用媒体播放器 |
| PDF | 按页查看 | 使用 PDF 预览 |
| Word、Excel | 本地转换后的预览 | 使用文档预览 |

文本编辑页：

- 顶部显示返回、文件名、撤销、重做、搜索和保存操作。
- 内容区直接使用已有 `CodeEditor`，保留行号、语法高亮、长按选择、全选、复制和撤销重做。
- 搜索打开输入框，匹配内容在编辑器中高亮，并可在匹配项之间移动；编辑时保留有效匹配序号，不自动改变视口，主动按上/下一处或搜索提交时才定位。
- 有未保存修改时离开需要明确处理；保存按文件携带的 Android、Linux 或仓库环境写回。
- 文本类型判断共用 `FileUtils` 的扩展名和常见无扩展名文件名判断。
- Markdown、HTML 的源码编辑和预览处理文件原始内容，不走聊天 XML 消息渲染链路。

文件读取、文档转换与媒体播放使用本地能力，不调用大模型。读取 Linux 与附加仓库文件时保留来源环境；媒体读取避免整份大文件经过 Base64 中转。预览失败应给出当前文件的具体原因。

## 04 聊天文件链接

聊天内文件链接在链接预览弹窗点击“访问”后进入共用工作区查看入口；目录链接进入文件浏览，文本链接支持 `#L12`、`:12` 和 `?line=12` 行号定位。链接保留环境与路径，不把 Linux 路径交给 Android 外部应用作为默认处理方式。普通网页链接沿用网页打开行为。

从聊天进入的独立查看页面可直接返回聊天；它不要求用户先绑定工作区。ZIP 等未内建预览的格式显示路径、大小、打开方式和分享，也可进入其父目录。外部打开和分享使用实际文件的可授权 URI，Linux 或附加仓库文件先写入应用缓存。文件页面关闭后返回聊天，不改变当前聊天的工作区绑定。
