# 聊天文件链接的第二轮审阅修正

对应 [PR #1344 第二条复审](https://github.com/AAswordman/Operit/pull/1344#pullrequestreview-5425369094)，基线为 a6ae432c。本轮继续使用原功能分支和 dev 目标分支。

## 修改意图与范围

- 聊天链接的文本分支读取前检查文件工具返回的大小，超过 10 MiB 时显示文件信息、原因、系统打开和分享入口，避免一次点击将大日志全量读入编辑器。目录浏览的文本打开与作为文本打开使用同一上限。
- 明确行号优先级为 fragment、query、路径后缀，并解释有有效行号时剥离后缀的行为。
- 将 /mnt 纳入 Android 默认路径；显式 Linux、Android、仓库协议和 environment 参数保持最高优先级，不增加双环境试探。
- CodeEditor 明确接收文件 key，初始行号的消费状态同时关联文件 key 和行号；同文件编辑不会重复定位。
- 英文打开方式文案沿用第一轮已完成的修正；新增超限提示同时提供中文和英文。已有链接单测的 CI 结果以具体报告记录，本轮新增用例由更新后的工作流验证。
