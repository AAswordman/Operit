# 长聊天卡片的单层滚动渲染

当前 dev 使用普通滚动列布局聊天消息，长回复的工具调用和思考分组集中在完整消息中布局。维护者使用发行版里已有的长聊天记录，将所有可展开的思考和工具调用展开后，末尾几个工具调用已无法点击。

本改动把主聊天切换为标准 Compose LazyColumn，并将长回复的分组标题和内容节点作为外层列表条目渲染，让末尾工具卡片保持可达且不增加整条回复的内部滚动框。

作用域包括聊天列表、Markdown 内容准备、内容块渲染、卡片展开状态、连续消息外观、滚动跟随和历史定位。PR 分支为 `fix/single-scroll-chat-cards`，目标分支为 `dev`。

PR #1278 保持独立。组合分支 `test/single-scroll-chat-cards-with-1278` 的 `0266d82e` 用于实机验收，并已处理重叠渲染文件及结构化静态消息入口的适配；组合代码不并入本 PR。

本次补充修复空白气泡和首尾断层：按实际可见内容判定拆块、生成分块行和确定首尾，XML 绘制沿用同一可见性规则。补充修复只更新本 PR 工作分支，组合测试分支保持原提交；本次未进行新的实机回归。
