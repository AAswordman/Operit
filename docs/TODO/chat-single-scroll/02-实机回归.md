## 完整回归参考

1. 短回复：打开普通文字、Markdown 和图片回复。预期内容完整，气泡、头像、名称和统计栏无重复
2. 单个大工具组：展开包含大量调用的分组，依次点开前、中、末尾执行结果。预期最后的结果仍能点击查看和复制
3. 多个思考工具组：依次展开同一回复的所有分组，再操作最后几组。预期无数量限制，较早分组不会被强制收起
4. 整条长回复滑动：从正文、卡片标题和气泡空白处上下拖动。预期聊天连续移动，没有整条回复内部的独立滚动框
5. 离屏返回：展开分组、工具参数和思考卡片，滚到其他消息后再返回。预期手动展开选择保留
6. 分组独立性：收起中间一个分组，再展开并检查前后分组。预期只改变被操作的分组，内部卡片状态不串组
7. 超长纯文本：查看包含中文与 emoji 的长正文，从头滚到末尾。预期内容完整，字符正常，末尾仍可操作
8. 混合 Markdown：查看标题、粗体、链接、代码、表格和公式混合回复。预期内容次序及链接操作正确
9. Cursor 风格：复测长聊天和卡片点击。预期只有首块显示 Response，内容缩进连续，统计栏只显示一次
10. 普通气泡：复测宽布局、普通布局、头像开关和圆角开关。预期各块宽度与缩进一致，只有消息首尾出现外侧圆角
11. 自定义背景：分别使用平铺、九宫格图片和玻璃气泡，滑动并展开长回复。预期顶底装饰不逐块重复，背景没有影响阅读的接缝或闪烁
12. 流式输出：发送包含多次工具调用的请求，保持位于底部。预期输出持续，能跟随最新内容，跨越内容拆分条件时无内部滚动框
13. 流式阅读历史：输出期间向上阅读，再按回到底部。预期阅读时暂停跟随，回到底部后恢复
14. 输出结束：输出期间手动展开和收起卡片，等待结束后再检查。预期手动状态正确；自动展开按既有设置结束，不串到其他卡片
15. 显示设置：切换思考显示、状态标签和工具折叠模式。预期遵守设置，重新显示的内容身份与操作对应正确
16. 历史加载：加载较早历史再返回新消息。预期当前阅读位置不无故跳动，较早和最新消息都可达
17. 消息定位：从搜索、收藏或定位面板选择长回复。预期跳到对应消息，导航显示的消息与实际一致
18. 消息操作：在长回复不同块长按，执行复制、收藏、多选、编辑或删除。预期作用于完整消息，索引正确，多选只计一条消息
19. 回复版本：切换同一回复的不同版本。预期内容和统计属于所选版本，展开状态不串到其他版本
20. 完整预览与导出：预览或导出长回复图片。预期包含完整消息，不仅包含当前可见块；预览不误用聊天中的单个块
21. 组合版协议内容：在 #1278 组合版查看 token 思考标签及包含 XML、代码或结束标签文本的工具结果。预期思考边界和结果正文正确，展开与复制可用
22. 组合版旧数据：覆盖安装或恢复旧版备份，打开旧聊天并继续发送消息。预期迁移后旧消息正常，新旧卡片均可操作
