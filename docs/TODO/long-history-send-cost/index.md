# 长会话发送前性能优化

长会话在没有总结时会保留全部运行态历史。发送前的总结检查仍会预读历史，运行态加载还会读取未选中的候选正文，请求日志会复制并格式化完整请求。

本次减少这些额外工作，保持发送历史范围、消息顺序、当前候选、角色转换、工具协议和插件钩子规则相同。数据库记录、界面分页及总结设置保持原有语义。

- 关闭总结时跳过总结判断专用的历史预读
- 在同一事务中读取基础消息、候选数量和当前选中候选正文
- 为远程模型请求生成有界日志，减少请求 JSON 的重复转换

[验证清单](./verification.md)记录回归范围和待验证项。#1157 的执行线程优化独立保留，本次从 dev 提交补充改动。

代码实现完成 [DONE]。新增回归用例交由仓库工作流执行，运行结果记录在上游 PR 中。
