# 记忆检索相关性与诊断（#1320）

## 已处理

- 工具查询、仓库查询以及中英文系统工具 Schema 统一使用默认相关性阈值 0.025，模型提示和工作流表单的默认值保持一致；调用方仍可显式指定 `threshold=0`
- 向量检索启用时按余弦相似度筛选，默认最低 0.5；在记忆搜索设置中可调。向量权重为零或云向量配置未就绪时，阈值滑块及其文字置灰，已保存的值不重置
- 每个关键词最多融合 50 个语义候选；无文件夹范围时最多从索引取 50 个近邻。文件夹及未分类范围复用已按文件夹、时间过滤的记忆向量，每次查询只解码一次，对每个关键词直接计算范围内同维度向量的余弦相似度，再按门槛及前 50 条筛选，避免重复读取全局索引及范围外记忆
- 图传播只影响当前文件夹和时间范围内的记忆；最终结果再次校验范围
- `Tools.Memory.query` 的结构化结果增加总分与关键词、标签、逆包含、语义、图传播分项；`*` 列表和按标题读取没有相关性分数
- 声明 `getByTitle` 的结构化结果/文档分块字符串返回类型；说明 `*` 对普通记忆只返回预览；候选不足日志同时记录当前条数与最低条数


## 验证

自动用例覆盖语义相似度门槛、候选上限、全局索引候选请求边界、图传播后最终范围过滤、评分结果序列化和无评分结果。
仓库工作流运行 Android Build 与 Android Tests；结果以对应提交的实际运行记录为准。
