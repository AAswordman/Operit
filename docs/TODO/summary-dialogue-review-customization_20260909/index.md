# 对话回顾自定义与折叠编辑器

## 原状

总结生成后，`AIMessageManager` 会在摘要末尾程序化拼接对话回顾。用户无法关闭该模块或调整标题。总结结构中的四个板块也始终展开，编辑一个板块时需要经过其余完整编辑器。

## 目标

对话回顾可按模型配置启用或关闭，并支持自定义标题。回顾的用户、助手、工具调用和结果条目继续由程序生成。总结结构的四个板块和对话回顾编辑器默认折叠。

## 范围

- 模型配置与总结配置传递
- 对话回顾的拼接
- 上下文总结设置页
- 本地化资源与单元测试
