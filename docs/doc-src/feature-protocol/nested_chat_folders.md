# 嵌套文件夹与会话分类

Android 历史列表支持嵌套文件夹，以及拖动文件夹和聊天来调整位置。文件夹身份使用稳定 ID，
同名文件夹不会因为名称相同而合并。角色绑定与文件夹位置分别保存，移动分类不改变聊天绑定的角色。

“全部”视图可以管理文件夹。“最近”按实际最后消息时间排列，不接受手工排序；
收藏视图调整可见聊天顺序时，未收藏的聊天保留原有位置。搜索期间不提供拖动排序，
临时展开命中路径，清空搜索后恢复先前的折叠状态。移动选择器保留完整名称，并区分同路径的同名目录。

拖动提交会携带开始拖动时的同级列表快照。若另一操作已经改变列表，过期快照会被拒绝，
避免覆盖较新的移动结果。文件夹不能移入自身或自己的后代。

数据库升级会把旧分组按角色卡、角色组和组名转换为文件夹，保留聊天内容及原有绑定。
JSON v4 全量导出保留空文件夹；局部导出只包含选中的聊天及其文件夹祖先，不额外带出父聊天。
支持最多三层目录，导入前拒绝循环或过深结构。CSV 导出包含文件夹 ID 和路径。
Web 聊天的分类接口同时携带文件夹 ID，重命名和删除不再仅按名称匹配；展示和搜索使用完整文件夹路径。
