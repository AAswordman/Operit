# Waifu 展示、语音和通知的清理边界

Waifu 气泡需要保留 Markdown 结构和已注册 XML 插件。`WaifuMessageProcessor.cleanContentForWaifuDisplay` 用于展示分句，保留标题、链接、图片、强调、引用、列表和行内公式标记。

`cleanContentForWaifu` 继续供 `ChatViewModel.speakMessage`、`SpeechInteractionManager.cleanTextForTts` 和 `AIForegroundService` 调用。此入口剥离 Markdown 标记，链接只保留标签文字，清理代码块、XML 块和多余空白。插件是否注册不改变语音和通知的纯文本结果。

两种入口都会过滤思考、工具调用、工具结果、状态、搜索和协议元数据。已注册的表情 XML 只在展示路径保留；语音和通知不接收插件 XML 及其正文。

## 分句与流式边界

列表序号后的点在切句前暂时保护，覆盖行首、空白后和句末标点后的序号。还原时只补回点，数字保持原样。临时前缀避开原文已经使用的前缀，用户输入的 `{WAIFULISTDOT:99}` 和 `{WAIFUENTITY:99}` 不会变成内部索引。

引用和无序列表按行恢复原生分块器剥离的标记。恢复器缓存跨 chunk 的 `>`、空格和换行前缀，已经存在的标记保持一次；分句后的每个结构片段仍保留对应标记。

插件 XML 的清理与闭合检查按同名标签深度配对。属性值、注释和 CDATA 中的结束标签文字不参与配对，外层未闭合时不把内部正文当作回答输出。这些检查覆盖文本清理边界；原生 Markdown/XML 分块的复杂嵌套场景仍需要 Android 环境验证。

行内美元公式要求非空白开头和结尾，关闭标记后紧跟数字时按金额文本处理。未闭合的单个美元符号后直接跟数字时按金额处理，例如 `$5`；完整的 `$5 + 2$` 仍通过行内公式保护。数字开头但尚未闭合的公式与金额存在文本歧义，可使用 `\(…\)` 明确公式边界。

块公式从原生分块器返回时可能缺少 `$$`；展示路径会恢复分隔符，让后续气泡识别并渲染公式。`\[…\]` 和已有的 `$$…$$` 保持原样。

## 回归项目

- 普通回复：按完整句子输出，末尾内容在完成时输出
- 有序列表：将 `1.` 拆成多个 chunk，完整列表项保留 `1.`，后续回复继续输出
- 行中序号：输入 `结束。1. 事项。`，序号不作为单独气泡输出
- 序号和小数：输入 `12. 数值 1.5。`，序号与小数均保持原样
- 引用和无序列表：逐字符输入多行内容，每行保留结构标记，已有标记不重复
- Markdown：标题、强调、删除线、行内代码、链接、图片在展示中保留，语音与通知接收纯文本
- 未完成的链接和行内公式：闭合后输出，后续正文不丢失
- 金额：输入 `$5` 与 `$5 and $10`，不作为未闭合公式等待
- 代码块、表格和块公式：完整分块输出，公式分隔符只恢复一次
- URL、域名与邮箱：句末切分不截断地址
- 插件 XML：注册后显示完整块，未注册块、思考、工具和状态继续过滤
- XML 清理边界：同名嵌套、属性、注释、CDATA 中的结束标签文字不提前关闭外层
- 字面量临时标记：输入合法、越界及超长数字形式，原文保持，分句结束
- 自动朗读、手动朗读、悬浮语音和回复通知：Markdown 与插件 XML 不进入纯文本输出
- 测试隔离：每次测试结束注销本次注册的插件 ID，不影响其他测试
