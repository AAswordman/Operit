# 主题工作室手机验收指南

这份指南覆盖[既有完整 63 项回归](../../TODO/feat/theme-script-api/03-verification.md)及聊天弹起菜单的主题配置，共 17 个操作场景，保留此前已有能力和历史用例。先做 T01–T08，再按使用范围做 T09–T17；不要求在一次操作中穷举所有组合。

本页只描述做什么与预期行为。所有结果在末尾单独填写，空白表示未执行；已有具体通过记录可保留其构建号，本轮相关改动另记复测结果。总体“体验正常”的反馈不代替单项结果，也不把仓库构建成功当作视觉验证通过。

## 准备与覆盖组合

准备两个测试角色 A/B、一份已有主题和一张本地图片；字体、静态 SVG、视频与嵌入式聊天按现有条件补测。记录应用构建、Android 版本、屏幕方向与系统字体大小。操作使用测试角色，项目保存与角色主题保存分开记录。

用以下四组代表组合检查消息与输入，不必把每个场景重复四遍：

- M1：浅色、智能体输入、双方 Bubble
- M2：深色、经典输入、用户 Cursor / 助手 Bubble
- M3：浅色、经典输入、用户 Bubble / 助手 Cursor
- M4：深色、智能体输入、双方 Cursor

没有对应设备或素材时填写“未测 + 缺少条件”，保留其他结果；无法执行的扩展路径不自动成为合入 dev 的前置要求。

## 第一轮：核心使用路径

### T01 既有数据与旧主题

操作：在已恢复稳定版数据的测试角色中导入已有主题，保存并重启。切换双方 Bubble 与混合消息样式后进入工作室；另验证已有参数码或链接的接收。

预期：不因缺失气泡留白字段崩溃，原颜色、字体、媒体和布局保留；参数码不清除接收角色已有脚本，完整无脚本主题按完整替换语义移除旧脚本。对应全量：1、12、61。

### T02 工程、角色草稿与正式保存

操作：在 A 修改一项显眼颜色，只保存工程草稿后关闭重进；再应用到角色草稿，分别尝试主题页放弃和保存。切到 B、角色组和 A；对工程编辑执行撤销/重做。

预期：工程草稿可继续编辑，未应用不影响正式聊天；放弃还原原主题，保存后重启保留；角色与角色组互不串改。对应全量：2、3、9、32、33。

### T03 素材分享、复制与重导

操作：A 使用一张图片、头像或字体后导出完整主题，在 B 导入并保存；复制测试角色，再删除一个测试副本的主题引用。对带中文子目录的工程重导一次。

预期：源码、素材及目录保留，普通角色媒体与工程同名资源不互相覆盖；另一个引用继续可用，取消导入不应用主题，离线仍能读取已导入素材。对应全量：10、11、16、37。

### T04 正式消息与预览

操作：使用 M1–M4，分别显示短文、长文和已有含链接/代码的消息，切换宽窄气泡、头像及消息背景透明度，滚动并选择文字。

预期：双方风格、留白、字体、消息页脚与正式主题一致，长文和链接可操作；透明填色不隐藏图层，部件不透明度单独生效，不出现重复底色。对应全量：4、8、25、40。

### T05 两种输入与原生动作

操作：经典/智能体、浮动/贴边分别打开，输入长短文字、提及和全屏输入；使用已有条件验证附件、录音、发送、停止与排队。进入工作室触摸相同样例。

预期：正式输入和原动作保持可用，图标只在对应入口出现；工作室点击只选择部件，不发送消息、不拉起输入法、不修改会话。对应全量：5、48。

### T06 连续编辑与当前界面

操作：连续调整内容色、排版色、直角/圆角/切角，撤销、重做、退出和重进。对照正式顶栏的菜单、标题、悬浮窗与工作区入口；有嵌入式聊天时检查侧栏动作。

预期：没有闪退、冻结或旧历史面板；正式页面、嵌入入口和工作室使用当前控件布局。对应全量：52、53、54。

### T07 形状、描边与属性能力

操作：在消息、头像、顶栏、输入、导航、卡片、列表、状态和工具行设置对比填色及 0/1/8/16 dp 描边；形状在继承、直角、圆角、切角和圆形之间往返，查看选中、按下和禁用状态。检查实际打开的菜单、面板与弹窗。

预期：保留的属性产生对应效果，填色贴合形状，边线不损失半宽或重复；无效属性隐藏，圆形没有半径，状态与原生交互一致，文字/图标和业务动作可用。对应全量：20、21、23、24、47、55、56、57、58。

### T08 工作室背景与正式页面

操作：关闭旧媒体背景，只在工作室“背景”中添加图片或填色，应用并在主题页保存，进入正式聊天；切换明暗、M1/M2 和工作区。再组合旧媒体背景、修改图层透明度、移除背景、切角色并重启。

预期：图片或填色在消息间与页面空白可见，不只露出状态栏；顺序为旧媒体→工作室背景→业务内容。气泡、输入及顶栏各自的实色填充仍能遮挡背景，工作区保持独立底色；移除后没有残留或串角色。图层不透明度还会乘以原背景不透明度，1.00 不代表最终合成必定不透明。对应全量：62、63。

## 第二轮：编辑与扩展路径

### T09 明暗、字体与文字色

操作：应用分别设为浅色、深色和跟随系统，再切工作室样例明暗。通过普通字体窗口及工作室全局/局部排版改字号、字体和文字色，应用、保存、放弃并重导。

预期：外壳随应用、样例随预览选择；浅深互不覆盖，区域和状态文字色按优先级生效，两个全局编辑入口共享同一数据。对应全量：7、30、38、44。

### T10 图片、字体、目录与缩略图

操作：导入图片、静态 SVG 和字体，创建中文子目录，移动、重命名、替换资源；尝试删除仍被引用资源与非空目录，查看头像及图标缩略图。

预期：素材 ID 稳定、绑定不丢失，缩略图来自实际素材；被引用资源和非空目录明确拒绝删除。对应全量：6、31、49。

### T11 工作室导航与操作

操作：切换设计/源码/资源、预览场景、部件搜索、全屏与收起；打开各菜单并取消，调整滑杆/数值，载入模板再撤销，查看较大系统字体下的选项。

预期：场景和部件联动，菜单锚定并可滚动/关闭，选项触控充足；连续调整合为一步，模板与草稿边界正确，自定义 JS 不被可视化编辑覆写。对应全量：17、18、26、27、28、39、41、42、43。

### T12 颜色与取色

操作：输入六位 RGB、八位 ARGB 和 RGBA，调整色相与透明度，选透明/继承，再在位图或 SVG 上取色。

预期：输入不被过早改写，浅深分别保存；透明度和像素 alpha 保留，棋盘格不超出圆角色块，图层单色行垂直对齐。对应全量：29、45。

### T13 图片铺放、九宫格与模糊

操作：切换裁切/完整/拉伸/平铺、对齐与最近邻；将普通图片和九宫格宽高设为 100%，移动两轴，调整切片并更换图片。在支持系统分别设置 0、中间值和 8 dp 模糊。

预期：满幅图层仍可移动，越界部分裁剪；九宫格保留四角和有效中心，SVG 不作为九宫格。合法模糊持续调整不崩溃，8.01/32 dp 及不支持系统上的非零模糊明确拒绝。对应全量：22、34、35、46、51。

### T14 图标与新建源码

操作：在可用入口替换十三个图标槽，分别保留原色、使用内容着色和固定着色；切换浅深，检查按键动作。新建工程查看 main.js，再导入自定义格式 JS。

预期：尺寸和颜色正确，图标不增加不存在的业务按钮；`appBar.workspace` 对应当前工作区。新源码多行四空格，导入源码保留原格式。对应全量：19、50。

### T15 源码编辑与高亮

操作：在 theme.json、manifest.json 和 JS 中编辑转义、URL、中文、emoji、模板与注释，测试查找、选区、输入法组合、格式化、同步和撤销；留下一处未闭合字符串后切换文件。

预期：JSON 只着色字符串，JS 轻量颜色可区分；光标和选择位置不偏移，错误有诊断且未同步内容保留，修正前不能应用或导出。对应全量：36、59、60。

### T16 无效工程与执行边界

操作：在测试工程副本中分别制造语法错误、Promise 返回、未知字段/素材、越界数值及超额循环/分配；修正后重新同步。尝试缺失素材与不合法归档路径的工程。

预期：明确诊断并拒绝应用无效工程，不改写已保存主题；超预算被终止，之后可继续编辑正常内容，取消或失败不遗留导入暂存。对应全量：13、14、15。

### T17 聊天弹起菜单的形状与位置

操作：在“弹窗与面板”依次选择附件、模型选择、聊天设置弹起菜单，分别设置圆角/直角/切角/圆形、可见描边色与 0/1/16 dp 宽度、四边留白；切换浅深并设置上/下/左 0/24/256 dp，应用保存后重开三个真实菜单。展开模型、记忆、工具和插件，检查滚动、选项、外部点按关闭、返回键、小窗口与 RTL；导出重导并重启应用。

预期：三个区域互不覆盖，描边与形状一致；只有上/下/左位置控件，向上与向下取差，完整容器与点击区域一起移动，到达窗口边缘后停止。展开内容重新定位且可滚动，未设偏移时保留原位置；保存、导出重导和重启保留对应模式的外观。旧主题不受影响，负值、256.01 dp、非有限数值、`right` 和其他区域的非零偏移被拒绝。

## 与合入 dev 的关系

本轮先修复已确认的背景遮挡问题，新提交仓库检查通过后可作为合入 dev 的候选。T01–T08 用于集中复核核心体验，T09–T17 与完整清单用于持续回归；不把未来特效开发、无法执行的设备能力或所有组合穷举当作当前落地的前置条件。

实际合并由维护者决定，本页不表示任何条目已经在设备通过。制作字段与应用/保存流程见[制作手册](theme_authoring_guide.md)。
