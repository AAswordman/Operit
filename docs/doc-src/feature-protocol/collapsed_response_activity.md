# 折叠回复过程

在全局显示设置的“消息显示设置”中开启“折叠回复过程”，可在助手回复结束后，
收起最终答复之前的思考、工具调用和过程说明。点击带箭头的“用时…”行可查看完整过程（无耗时数据时显示“回复过程”），
再次点击可收起。最后答复包含的标题、多个段落和代码块会一起保留。

开关默认开启（保留用户已保存的选择，重置设置后恢复开启），适用于 Android 的气泡和 Cursor 消息显示。生成期间保持展开；
只有思考或工具记录、没有后续答复的消息不折叠。此设置不折叠之前的用户消息，
不改写历史内容，也不改变发送给模型的上下文。

同一回复中由引导或子代理事件分隔的助手过程可以一起折叠。上下文总结后的续答
与总结前的过程合并显示，总结消息和用户补充仍然可见。展开状态按会话保留，
从子代理会话返回时不需要重新展开。定位到折叠内容时先展开，再计算滚动位置。
